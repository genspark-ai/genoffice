# 키보드 단축키

편집기마다 고유한 키 바인딩이 있고, 그중 어디에서나 동작하는 것은 일부뿐입니다. 이 문서는 전체 목록을 애플리케이션별로 묶고, macOS와 Windows / Linux 조합을 나란히 놓았습니다.

## 먼저 읽으세요

**여기 있는 것 중 전역인 것은 거의 없습니다.** 아래 세 개의 진입 키만 전역이고, 그 뒤의 것은 모두 지금 앞에 있는 애플리케이션의 것이며 탭을 바꾸면 달라집니다.

| 동작                                    | macOS | Windows / Linux |
| --------------------------------------- | ----- | --------------- |
| 사용자 가이드 열기 — 앱 어디에서나 동작 | F1    | F1              |
| 리본 접기／펼치기 — 모든 편집기 공통    | ⌥⌘R   | Ctrl+F1         |
| 키보드 단축키 시트 열기 — Word 전용     | ⌘/    | Ctrl+/          |

- **F1이 여는 것은 이 매뉴얼**이며 단축키 시트가 아닙니다. 애플리케이션 메뉴에 속하므로 Word, Sheets, Slides, PDF, Home 탭 어디에서나 동작합니다.
- **리본 전환은 `Ctrl+F1`, macOS에서는 `⌥⌘R`입니다.** `F1`만 누르면 아무 일도 일어나지 않습니다. F1은 매뉴얼이고 리본 키는 일부러 그걸 공유하지 않습니다. macOS에서도 `Ctrl+F1`을 사용할 수 있지만, Office for Mac이 실제로 쓰는 키는 `⌥⌘R`입니다.
- **키보드 단축키 시트는 Word에만 있습니다**(`⌘/`). 아래 Word 표의 내용을 그대로 담고 있으며, 다른 편집기에는 없습니다.

![Word만의 키보드 단축키 시트: 왼쪽이 동작, 오른쪽이 조합 키이며 파일, 편집, 텍스트 서식, 단락 서식, 삽입, 검토와 도구, 보기 그룹으로 나뉘어 있습니다](img/word-shortcuts.png)

- **`⌘O`, `⌘S`, `⌘P`는 편집기마다 따로 구현되어** 동작도 완전히 같지 않습니다. Word의 `⌘P`는 먼저 인쇄 미리보기를 조판해 종이 한 장이 화면 한 쪽과 정확히 맞도록 합니다. PDF의 `⌘P`는 PDF 인쇄 대화 상자를 열고, Sheets와 Slides는 또 각자의 방식을 씁니다.
- **나머지는 애플리케이션별로 다릅니다.** Word 탭이 활성 상태일 때 `⌘B`는 Word의 굵게입니다. Slides가 활성 상태일 때 `⌘B`는 Slides의 굵게이고, 그 키가 속한 메뉴도 익숙한 메뉴가 아닙니다. 선택 항목이 있어야 하거나 특정 창에서만 동작하는 조합은 동작 열에 적어 두었습니다.

## 표기 규칙

- macOS 열은 익숙한 기호를 씁니다: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- Windows / Linux 열은 이름을 그대로 적습니다: `Ctrl`, `Alt`, `Shift`.
- GenOffice가 두 플랫폼에서 실제로 서로 다른 키를 써야 하는 곳은 표에 그대로 드러납니다. 흔한 경우는 찾기 및 바꾸기의 `⌃H`(macOS에서는 `⌘H`가 가리기용), 이동의 `⌥⌘G`, 그리고 Slides의 닫기 키입니다.
- 선택 항목이 있어야만 동작하는 조합은 별도 열을 늘리지 않고 동작 열에 적으므로, 표는 세 열로 유지됩니다.

## Word

Word에는 완전한 메뉴 막대가 있으므로 아래 파일 및 서식 조합은 Word 탭에 포커스가 있는 동안, 어떤 문서가 열려 있든 동작합니다. 편집 조합은 문서가 열려 있고 편집 가능하며 캐럿이 본문에 있어야 합니다. 찾기 상자, AI 프롬프트, 그 밖의 입력란에 입력하는 동안에는 동작하지 않습니다.

### 파일

| 동작                | macOS | Windows / Linux |
| ------------------- | ----- | --------------- |
| 새로 만들기         | ⌘N    | Ctrl+N          |
| 새 창               | ⇧⌘N   | Ctrl+Shift+N    |
| 열기…               | ⌘O    | Ctrl+O          |
| 저장                | ⌘S    | Ctrl+S          |
| 다른 이름으로 저장… | ⇧⌘S   | Ctrl+Shift+S    |
| 인쇄                | ⌘P    | Ctrl+P          |
| 닫기(탭)            | ⌘W    | Ctrl+W          |

⌘P는 브라우저의 인쇄가 아닙니다. Word는 먼저 인쇄 미리보기를 조판해 종이 한 장이 화면 한 쪽과 정확히 맞게 한 뒤, 자체 인쇄 대화 상자를 엽니다.

| 잘라내기               | ⌘X    | Ctrl+X          |
| 복사                   | ⌘C    | Ctrl+C          |
| 붙여넣기               | ⌘V    | Ctrl+V          |

바꾸기가 두 플랫폼 모두에서 Ctrl+H인 이유는 macOS에서 ⌘H가 창을 가려서 Word에 닿지 않기 때문입니다. 이동은 Word 자체의 구분을 따릅니다: Mac에서는 ⌥⌘G로, ⇧⌘G는 글자 수에 남겨 둡니다.

### 보기

| 동작                   | macOS | Windows / Linux |
| ---------------------- | ----- | --------------- |
| 확대                   | ⌘=    | Ctrl+=          |
| 축소                   | ⌘-    | Ctrl+-          |
| 100%로 확대            | ⌘0    | Ctrl+0          |
| 서식 기호 표시／숨기기 | ⌘8    | Ctrl+Shift+8    |

서식 기호 조합도 Word 자체의 구분을 따릅니다: ⌘8과 대조되는 Ctrl+Shift+8입니다. Word의 확대/축소는 위의 세 메뉴 조합으로만 됩니다 — 여기서 ⌘+는 아무 일도 하지 않습니다.

F1이 여는 것은 이 목록이 아니라 **사용자 가이드**입니다. 단축키 시트는 ⌘/ 또는 Ctrl+/이고 Word 메뉴 항목이므로, Word 탭이 활성 상태일 때만 나타납니다.

## Sheets

GenOffice Sheets는 Excel과 호환되는 스프레드시트입니다. 아래 단축키 대부분은 이미 아는 Excel 단축키입니다.

> **편집이 우선입니다.** 셀을 편집하는 중이거나 **수식 입력줄**에 입력하는 동안 Sheets의 거의 모든 단축키는 무시됩니다. 그래야 입력, 캐럿 이동, Delete 키가 본래 텍스트 편집의 의미를 유지하기 때문입니다. 어떤 키가 아무 일도 하지 않는 것 같다면 편집 중인지 확인해 보세요: 먼저 Esc나 Enter를 누른 뒤 다시 시도합니다. 선택 영역에 작용하는 명령도 대화 상자가 열려 있는 동안에는 아무 일도 하지 않습니다. 이 규칙의 예외인 조합은 표에 적어 두었습니다.

Sheets에만 해당하는 규칙이 두 가지 있습니다. `⌘`와 `⌃`는 같은 수정자 자리입니다 — 둘 다 모든 플랫폼에서 사용할 수 있으므로 `⌘1`과 `Ctrl+1`은 같은 조합입니다. **Windows / Linux 칸이 비어 있으면 그 조합은 macOS에만 있다는 뜻입니다.**

## Slides

GenOffice Slides는 PowerPoint 방식의 프레젠테이션 편집기입니다. 대부분의 키는 어디서 써도 같은 일을 하지만, 일부는 포커스에 따라 뜻이 달라집니다 — 텍스트 상자 안이거나 **축소판 창**, **개요 창**, **슬라이드 정렬 창**에 키보드 포커스가 있을 때입니다. 이런 경우는 동작 열에 표시되어 있습니다.

| 저장                 | ⌘S    | Ctrl+S          |

탭을 닫는 것이 두 플랫폼이 완전히 갈라지는 유일한 지점입니다: macOS에서는 ⌘W, Windows와 Linux에서는 탭이 아니라 앱 전체를 종료하는 Ctrl+Q입니다.

| 선택한 주석 삭제 | Delete 또는 Backspace | Delete 또는 Backspace |

주석, 도장, 편집 또는 이미지가 선택되어 있을 때만 활성화됩니다.

### 취소와 대화 상자

| 동작                     | macOS  | Windows / Linux |
| ------------------------ | ------ | --------------- |
| 가장 위의 상태 취소      | Escape | Escape          |
| 열려 있는 대화 상자 확인 | Enter  | Enter           |

Escape는 한 겹씩 되돌립니다 — 먼저 열려 있는 대화 상자, 다음 AI 팝오버, 텍스트 초안, 검색 패널, 마지막으로 선택 자체입니다. 캐럿이 검색 상자에 있으면 Enter와 ⇧Enter가 다음과 이전 일치 항목으로 이동하고 Escape가 패널을 닫습니다; 새 텍스트 메모에 캐럿이 있으면 ⌘⏎가 이를 확정합니다.

## Markdown

GenOffice Markdown는 옆에 실시간 미리보기를 두고 Markdown을 편집합니다.

### 파일과 보기

| 동작                | macOS      | Windows / Linux    |
| ------------------- | ---------- | ------------------ |
| 저장                | ⌘S         | Ctrl+S             |
| 다른 이름으로 저장  | ⇧⌘S        | Ctrl+Shift+S       |
| 인쇄                | ⌘P         | Ctrl+P             |
| 찾기                | ⌘F         | Ctrl+F             |
| 소스／미리보기 전환 | ⌘E         | Ctrl+E             |
| 확대                | ⌘= 또는 ⌘+ | Ctrl+= 또는 Ctrl++ |
| 축소                | ⌘-         | Ctrl+-             |
| 실제 크기(100%)     | ⌘0         | Ctrl+0             |

축소에는 ⌘_와 Ctrl_도 됩니다. 트랙패드를 두 손가락으로 모으거나, 문서 위에서 ⌘ 또는 Ctrl을 누른 채 스크롤해도 확대/축소됩니다.

### 블록

| 동작                                        | macOS | Windows / Linux      |
| ------------------------------------------- | ----- | -------------------- |
| 선택한 블록 복제                            | ⌘D    | Ctrl+D               |
| 선택한 블록 삭제                            | ⇧⌘⌫   | Ctrl+Shift+Backspace |
| 선택한 블록 위로 이동                       | ⇧⌘↑   | Ctrl+Shift+ArrowUp   |
| 선택한 블록 아래로 이동                     | ⇧⌘↓   | Ctrl+Shift+ArrowDown |
| 선택 영역에 링크 삽입                       | ⌘K    | Ctrl+K               |
| 링크 제거(링크가 선택된 상태에서 다시 누름) | ⌘K    | Ctrl+K               |

### 수식 블록 안

이 항목들은 떠 있는 LaTeX 편집기가 열려 있을 때만 적용됩니다.

| 동작                      | macOS | Windows / Linux |
| ------------------------- | ----- | --------------- |
| 수식 적용                 | ⌘⏎    | Ctrl+⏎          |
| 적용하지 않고 편집기 닫기 | Esc   | Esc             |

빈 수식을 적용하면 대신 그 블록이 삭제됩니다. 문서가 조금이라도 바뀌면 편집기가 닫히고, 바깥을 클릭해도 닫힙니다.

## HTML

GenOffice HTML은 실시간 미리보기 옆에 코드 편집기를 보여 줍니다. 페이지 요소에 작용하는 키는 미리보기 자체에 키보드 포커스가 있을 때만 적용됩니다.

### 파일과 소스 보기

| 동작                            | macOS      | Windows / Linux    |
| ------------------------------- | ---------- | ------------------ |
| 저장                            | ⌘S         | Ctrl+S             |
| 다른 이름으로 저장              | ⇧⌘S        | Ctrl+Shift+S       |
| 보기 전환(편집／분할／미리보기) | ⌘\         | Ctrl+\             |
| 찾기                            | ⌘F         | Ctrl+F             |
| 확대                            | ⌘= 또는 ⌘+ | Ctrl+= 또는 Ctrl++ |
| 축소                            | ⌘-         | Ctrl+-             |
| 실제 크기(100%)                 | ⌘0         | Ctrl+0             |

축소에는 ⌘_와 Ctrl_도 됩니다.

### 서식과 기록

| 동작                 | macOS | Windows / Linux |
| -------------------- | ----- | --------------- |
| 굵게                 | ⌘B    | Ctrl+B          |
| 기울임꼴             | ⌘I    | Ctrl+I          |
| 실행 취소            | ⌘Z    | Ctrl+Z          |
| 다시 실행            | ⇧⌘Z   | Ctrl+Shift+Z    |
| 다시 실행(대체 조합) | ⌘Y    | Ctrl+Y          |

코드 편집기 안이나 양식 입력란에서는 그 입력란 자체의 편집 키가 대신 담당합니다.

### 미리보기 프레임 안에서 요소를 선택한 상태

| 동작                        | macOS      | Windows / Linux    |
| --------------------------- | ---------- | ------------------ |
| 이 요소에 대해 AI에게 묻기  | ⌘K         | Ctrl+K             |
| 요소 삭제                   | ⌫ / Delete | Backspace / Delete |
| 이전 형제 요소              | ↑          | ArrowUp            |
| 다음 형제 요소              | ↓          | ArrowDown          |
| 부모 요소 선택              | ←          | ArrowLeft          |
| 첫 번째 자식 요소 선택      | →          | ArrowRight         |
| 문서에서 요소를 위로 이동   | ⌥↑         | Alt+ArrowUp        |
| 문서에서 요소를 아래로 이동 | ⌥↓         | Alt+ArrowDown      |
| 선택 해제                   | Esc        | Esc                |

이 항목들은 모두 요소를 미리 선택해 두어야 합니다. 선택된 것이 없으면 그 키는 아무 일도 하지 않습니다.

### 미리보기 프레임 안에서 텍스트를 직접 편집

| 동작                   | macOS | Windows / Linux |
| ---------------------- | ----- | --------------- |
| 편집 확정              | Esc   | Esc             |
| 편집 확정(대체 조합)   | ⌘⏎    | Ctrl+⏎          |
| 선택 범위를 굵게       | ⌘B    | Ctrl+B          |
| 선택 범위를 기울임꼴로 | ⌘I    | Ctrl+I          |

확정하면 입력한 내용은 그대로 남고 요소는 선택된 상태로 돌아갑니다.
