# 홈 화면: 파일이 있는 곳

홈은 GenOffice의 시작 페이지입니다. 왼쪽에는 탐색 사이드바, 오른쪽에는 파일 목록과 빠른 생성 카드가 있습니다.

![홈 화면](img/home-screen.png)

## 사이드바 탐색

- **최근 사용**: 최근에 연 파일입니다. 각 줄에는 시간이 찍힙니다 — 오늘, 어제, 또는 날짜.
- **즐겨찾기**: 즐겨찾기한 파일입니다. 파일 줄에 포인터를 올려 별표를 누르면 등록하거나 해제할 수 있습니다.
- **사용자 가이드**: 이 설명서를 엽니다.
- **Genspark Projects**: Genspark 계정으로 로그인하면 웹의 Genspark AI로 만든 프로젝트가 표시됩니다. 누르면 브라우저에서 편집을 계속할 수 있습니다. 검색, 시간순 정렬, 새로 고침, 더 불러오기를 지원합니다.
- **폴더**: **폴더 추가…** 로 사이드바에 넣거나 파일 관리자에서 끌어다 놓은 디렉터리입니다. 각각이 루트가 되어 열거나, 그 안에 하위 폴더를 만들거나, 이름을 바꾸거나, 제거할 수 있습니다. 오프라인이 된 루트는 사용할 수 없음으로 표시되며 목록에서 제거할 수 있습니다. **새 폴더** 로 하나를 더 만들 수 있습니다.

여기에는 휴지통 항목이 없습니다. 삭제한 파일은 시스템 휴지통으로 가며, 되돌리는 일은 OS가 처리합니다.

## 파일 목록

각 줄에는 아이콘, 파일 이름, 수정 시각 등이 표시됩니다. 줄의 **⋯ 메뉴**에는 다음 항목이 있습니다.

- **열기**, 그리고 파일 관리자에서 그 파일을 찾아주는 **폴더에서 보기**.
- **경로 복사**.
- **폴더로 이동…**: 폴더 선택기를 열고 파일을 실제로 옮깁니다. 목적지에 같은 이름의 파일이 이미 있으면 건너뛰거나, 덮어쓰거나, 이름을 바꿀 수 있습니다.
- **이름 바꾸기**: 그 자리에서 이름을 바꿉니다(확장자는 자동으로 유지됩니다).
- **즐겨찾기에 추가 / 즐겨찾기에서 제거** — 즐겨찾기는 재시작 후에도 유지되며, 이름을 바꿔도 파일을 따라갑니다.
- **복사본 만들기**: 같은 폴더에 사본을 만듭니다.
- **삭제**: 파일을 시스템 휴지통으로 옮깁니다. 완전 삭제가 아닙니다.
- **목록에서 제거**: 최상위 **최근 사용** 화면에서 파일은 건드리지 않고 항목만 지웁니다.

### 여러 파일 한 번에

행의 체크박스를 켜거나 ⌘/ctrl 클릭으로 선택을 모읍니다. 머리글의 체크박스는 지금 목록에 있는 것을 전부 선택하고, 목록 위의 표시줄이 몇 개가 선택되었는지(**{n}개 선택됨**) 알려 주며, 선택 전체에 **폴더로 이동…** 과 **파일 삭제** 를 제공합니다. 여러 파일을 선택한 상태로 사이드바의 폴더에 끌어다 놓을 수도 있습니다.

## 검색

위쪽 검색창은 두 가지를 함께 검색합니다.

- **파일 이름**: 이름으로 빠르게 거릅니다.
- **파일 내용**: GenOffice는 백그라운드에서 파일에 색인을 만듭니다(docx/xlsx/pptx/pdf/md/html 안의 문자, 스캔한 PDF는 OCR로 보완). 그래서 본문 문자열로 검색해도 파일이 나옵니다. 검색 범위와 각 스위치는 검색 설정에서 바꿉니다.

## 빠른 시작 카드

목록 위의 카드로 한 번에 새 문서를 만들 수 있습니다. 카드를 누르면 그 종류의 파일이 만들어지고 해당 편집기가 열리니 바로 쓰기 시작할 수 있습니다. AI가 초안을 쓰게 할 수도 있습니다(각 편집기 리본에 **AI 버튼**, 선택 후 컨텍스트 메뉴에 **AI 수정 요청**이 있습니다).

새 파일은 사이드바에서 현재 선택된 폴더에 만들어집니다. 선택된 폴더가 없으면 기본 폴더에 들어갑니다.

각 카드의 역할:

- **AI Docs**(.docx): Docs 편집기의 빈 문서입니다. 파일은 **처음 저장할 때** 디스크에 기록됩니다. 새 문서는 AI 패널이 펼쳐진 상태로 열리며, 필요 없으면 설정 → "새 문서에서 AI 패널 열기"에서 끌 수 있습니다.
- **AI Sheets**(.xlsx): Sheets 편집기의 빈 스프레드시트입니다. 저장하기 전에는 디스크에 파일이 없고, 이름은 첫 저장을 위해 예약됩니다. 처음 AI로 내용을 만든 뒤에는 내용에 따라 파일 이름을 자동으로 바꿀 수도 있습니다.
- **AI Slides**(.pptx): Slides 편집기의 빈 프레젠테이션입니다.
- **AI Markdown**(.md): Markdown 편집기의 빈 Markdown 문서입니다.
- **AI HTML**(.html): HTML 편집기의 빈 웹 페이지입니다.
- **AI PDF**(.pdf): 다른 카드와 다릅니다. **즉시** 대상 폴더에 진짜 한 페이지짜리 빈 PDF를 만들고 일반 파일로 엽니다(PDF 편집기는 실제 파일을 다룹니다). 주석 달기, 가리개 처리, 텍스트 추가에 적합합니다. 처음 저장할 때 내용에 따라 파일 이름을 자동으로 바꿀 수도 있습니다.
- **로컬 파일 열기**: 시스템 파일 선택 창을 엽니다. Word(.docx/.doc), Excel(.xlsx/.xlsm/.xls/.csv/.tsv), PowerPoint(.pptx/.ppt), PDF, Markdown(.md/.markdown), 웹 페이지(.html/.htm)을 지원합니다. 여러 개를 한 번에 고를 수 있고, 각 파일은 별도의 탭으로 열립니다.

> 팁: 메뉴의 파일 ▸ 새로 만들기에서도 같은 종류의 문서를 만들 수 있습니다(⌘N/Ctrl+N의 기본값은 텍스트 문서). 파일을 창으로 끌어다 놓으면 그대로 열립니다.

## 클라우드 프로젝트(Genspark Projects)

- 처음 쓰려면 Genspark 계정으로 로그인해야 합니다(기기 코드 방식: GenOffice가 코드를 보여 주고 브라우저에서 로그인을 마칩니다).
- 프로젝트 목록은 웹과 동기화됩니다. "브라우저에서 열기"로 이동해 편집을 계속할 수 있습니다.
- 로그인하지 않아도 로컬 기능에는 아무 영향이 없습니다.
