# Font: typeface sistem dan keluarga yang dapat diunduh

## Daftar font

Kontrol font berada di tab Beranda tiap editor (di bawah ini: grup font di Slides):

![Grup font di friso Slides](img/fonts.png)

Pemilih font tiap editor menggabungkan: font yang terpasang di komputer + kandidat umum platform (keluarga Windows dan macOS yang lazim, baik Latin maupun CJK, termasuk nama terlokalisasi yang dilaporkan sistem untuk font CJK). Ketika sistem dapat membuat daftar font lokal, daftarnya dikelompokkan menurut apa yang benar-benar ada; kalau tidak, daftar itu turun ke daftar kandidat lengkap.

## Font yang dapat diunduh (Slides)

- Pemilih font Slides membuka **katalog font**: pilihan OFL yang dikurasi, mencakup banyak sistem tulisan; setiap keluarga menyertakan bobot reguler dan tebal.
- Memilih salah satu akan mengunduh dan memasangnya dari CDN (dengan Checksum yang dikunci) ke menyimpan font aplikasi — tersedia untuk setiap dokumen setelahnya, tanpa pemasangan di level sistem.
- Pemasangan berada di direktori privat aplikasi dan hilang bersama aplikasinya.

## Tipografi CJK

- Font CJK di Docs mendapat kompresi tanda baca dan aturan pemenggalan baris kinsoku yang selaras dengan Word (lihat bab Docs).
- Keluarga CJK dalam katalog mencakup Tionghoa Sederhana/Tradisional, Jepang, dan Korea, dalam versi serif maupun sanserif.

## Mengelola font lokal

- Entri install-local-font-files memuat berkas .ttf/.otf dari disk ke penyimpanan font aplikasi.
- Penyimpanan diarsipkan menurut keluarga; beberapa bobot dari satu keluarga dapat hidup berdampingan.
