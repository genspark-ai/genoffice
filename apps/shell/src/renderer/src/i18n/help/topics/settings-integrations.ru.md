# Настройки, язык, тема и интеграции MCP

## Как открыть настройки

Строка аккаунта в левом нижнем углу «Главной» открывает панель настроек (когда вы не вошли, там написано «Войти»). В ней шесть разделов: «Аккаунт», «Модель ИИ», «Медиа и поиск ИИ», «Общие», «Интеграции» и «О программе».

![Настройки ▸ Общие, где находятся язык, тема, автосохранение и переключатель статистики использования](img/settings-general.png)

Настройка моделей вынесена в отдельную статью; в разделе **Медиа и поиск ИИ** вы включаете для каждого провайдера генерацию изображений, анализ изображений, анализ видео, веб-поиск и поиск локальных файлов.

## Язык

- В настройках предлагается **21 язык интерфейса**: английский, упрощённый китайский, японский, корейский, французский, немецкий, испанский, тайский, индонезийский, русский, арабский, португальский, итальянский, польский, чешский, нидерландский, малайский, иврит, хинди, традиционный китайский, вьетнамский.
- Переключение применяется сразу и сохраняется; системное меню перестраивается под новый язык.

## Тема

Светлая / Тёмная / Как в системе. Режим «Как в системе» следует оформлению ОС, и редакторы перекрашиваются синхронно без мигания.

## Привязка приложений по умолчанию

В настройках можно зарегистрировать GenOffice как приложение для открытия .docx / .xlsx / .pptx / .pdf и подобных файлов (регистрация приложения по умолчанию на уровне системы; при запросе требуется подтверждение).

## Уведомления о стороннем ПО и обновления

- Справка ▸ Уведомления о стороннем ПО: полный перечень лицензий открытого ПО, поставляемых с приложением.
- Справка ▸ Проверить обновления…: запускает проверку вручную; при выходе более новой версии предлагается её установить.

## Вход в Genspark

- Вход (из настроек или из списка облачных проектов) использует схему **с кодом устройства**: GenOffice показывает код и открывает страницу входа в браузере; после завершения процесс продолжается сам.
- Вход нужен только для списка облачных проектов и моделей Genspark. Без входа все локальные возможности и собственные модели продолжают работать.
- Выход выполняется одним щелчком в настройках.

## Интеграция MCP (для опытных пользователей / ИИ-клиентов)

**Интеграции** — это панель, которая подключает GenOffice к агенту для программирования, и у неё есть отдельная статья: Подключение агента для программирования. Коротко — выберите путь (командная строка или MCP), следуйте соответствующему разделу, а потом начните новый чат и задайте вопрос.

![Настройки ▸ Интеграции: три шага, затем строки навыков и параметры MCP](img/settings-integrations.png)

В разделе **Локальный HTTP-сервер** приложение может взять запуск сервера на себя — переключатель включения и порт —, а **Дополнительно** добавляет адрес проверки состояния и файл журнала, вместо того чтобы оставлять это помощнику. Он слушает только на localhost.

## Шпаргалка по командной строке

| Команда            | Что делает                     |
| ------------------ | ------------------------------ |
| `genoffice <file>` | открыть файл                   |
| `genoffice mcp`    | запустить локальный MCP-сервер |
| `genoffice --help` | все команды и параметры        |
