# עורך ה-HTML

עורך ה-HTML פותח .html / .htm בשני מצבים: **תצוגה מקדימה** (הדף המרונדר) ו**מקור**.

- **תצוגה מקדימה**: רינדור אמיתי; גיליונות סגנון ותמונות יחסיים נטענים לצד הקובץ.
- **בוחן התצוגה המקדימה**: לחצו כדי לבחור רכיב, לחיצה כפולה כדי לערוך את טקסטו במקום, מחיקה מסרגל הכלים, ושאל את ה-AI על הבחירה.
- **מצב מקור**: עריכת ה-HTML; ctrl+F לחיפוש, החלפת הכול שומרת את הסימון המשוכתב.
- **שמירה**: נאמנה לבתים (BOM/CRLF/שורת שיור בסוף נשמרים); שמירה ללא שינוי אינה כותבת מחדש.
- **זום**: ctrl+גלגל / צביטה מגדילים את התצוגה המקדימה; ctrl+Z בתוך התצוגה מבטל את העריכה האחרונה.

## סרגל הכלים

לחצו על כל רכיב בתצוגה המקדימה וסרגל כלים יצוף מעליו:

![סרגל הכלים הצף מעל רכיב שנבחר](img/html-toolbar.png)

- **קובץ והיסטוריה**: שמירה, שמירה בשם, ביטול, ביצוע מחדש, חיפוש; מתג **שמירה אוטומטית** כותב שינויים מדי פרק זמן.
- מתג **תצוגה מקדימה / מקור**; **מסך מלא** מציג את הדף במסך מלא.
- **עיצוב**: מודגש, נטוי, הגדלת והקטנת גודל גופן; **לוח הסגנון** לרכיב שנבחר (צבעים ועוד).
- **הוספה**: כותרת, פסקה, טבלה, תמונה (לפי קישור), עוד.
- **פעולות תמונה** (כאשר תמונה נבחרה): חיתוך, **הסרת רקע**, החלפה, נעילת יחס גובה-רוחב.
- **פעולות רכיב** (כאשר רכיב נבחר בבוחן התצוגה המקדימה): מחיקה, שכפול, העברה למעלה/למטה.
- **כפתור AI**: פותח את חלונית ה-AI; אפשר לשאול ישירות על הרכיב שנבחר.
