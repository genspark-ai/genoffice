# AI 模型与设置

## 服务提供商与模型配置

所有 AI 模型、协议端点与 API 密钥都统一在「设置」窗口中进行管理（点击主屏左下角的账户栏即可打开）：

![设置窗口](img/settings-general.png)

- **Genspark 官方托管服务**：如果你希望开箱即用，只需通过设备码流程登录你的 Genspark 账号（在浏览器里确认一次验证码即可），就能直接调用官方托管的大模型与多模态服务，完全不需要自己去申请和填写任何 API Key。
- **接入自定义端点（自带密钥 BYOK）**：如果你有自己购买的各家大模型密钥或企业内部网关，可以在 **设置 ▸ AI 模型**（以及 **生图、媒体与搜索**）里按协议类型分别填写基础地址（Base URL）和 API Key——内置原生支持 OpenAI 兼容协议、Anthropic（Claude）、Google Gemini、DeepSeek、阿里通义千问 DashScope（Qwen）、MiniMax 以及 Atlas Cloud 等主流协议。你填写的所有密钥都只加密或受限保存在你本机的应用配置文件中（仅当前系统用户可读），在实际发起请求时也只会放进发往你所填端点的 HTTP 请求头里，绝不会经过任何第三方中转。
- **按能力自由混搭不同模型**：GenOffice 不会强迫你用同一个模型包办所有事——你可以为**正文对话与文档生成**、**AI 图像生成**以及**图像/视频视觉理解（看图提问）**分别指定最擅长该领域的服务商和具体模型。
- **MiniMax H3-Image 与 H3-Image Highspeed 图像生成**：在图像生成服务商中选择 MiniMax 时，除了经典的 `image-01` 模型外，现在还原生支持最新的 **MiniMax H3-Image**（默认选中，画质更细腻）与追求更快出图速度的 **MiniMax H3-Image Highspeed**（国内平台 `api.minimax.cn` 与海外平台均可调用）；这两款 H3 图像模型默认按清晰的 **2K 分辨率**请求生成图片，并且在基于已有图片做局部重绘或风格改图时，单次最多支持同时传入 **16 张参考图**。
- **保存前一键连接测试**：填好端点地址和密钥后，点击旁边的**连接测试**按钮，系统就会在落盘保存之前实际向该端点发起一次轻量探测，帮你当场验证网络是否连通、密钥是否有效以及所选模型是否真实可用。
- **完美兼容带路径与查询参数的网关地址**：如果你填写的自定义 Base URL 是企业反向代理或带有子路径与查询串（Query String）的聚合网关地址，GenOffice 在拼接具体 API 路由时会自动识别并保留你原有的路径结构与参数，不会把网关参数截断弄丢。

## 本机命令行（CLI）编程助手集成

- **指定本机 Codex 类 CLI 程序路径**：除了直接走 HTTP API 调用云端模型外，设置面板还支持直接填入你电脑上已安装的本地 CLI 推理程序路径（完整支持带有中文等非 ASCII 字符的用户主目录，也支持直接以 `~/` 开头缩写，系统会自动为你展开为完整绝对路径）；填好后点击**检测模型**，应用就会自动调用该 CLI 探测并列出它当前可用的全部模型清单。
- **宽松自然的路径校验**：路径输入框在做合法性校验时只检查该磁盘文件是否真实存在且可访问，不会对目录名施加死板的纯英文字符集限制。

## 配置修改何时生效

- **保存即刻生效且不打断当前回答**：你在设置面板里切换的新模型、新端点或新密钥在点击保存的瞬间就会在全局生效；如果此时某个编辑器的 AI 面板里正好有一轮回答还在流式输出中，正在进行的这一轮会平稳用完旧配置直到回答结束，从你发出的下一条消息开始立即无缝切换到新模型。
