# הגדרות, שפה, ערכת נושא ושילובי MCP

## פתיחת ההגדרות

שורת החשבון בפינה השמאלית-תחתונה של הבית פותחת את חלונית ההגדרות (כשאינכם מחוברים היא כותבת "התחברות"). בה שישה מקטעים: חשבון, מודל AI, מדיה וחיפוש AI, כללי, שילובים ואודות.

![הגדרות ▸ כללי, שם נמצאים השפה, ערכת הנושא, השמירה האוטומטית ומתג סטטיסטיקת השימוש](img/settings-general.png)

להגדרת המודלים יש פרק משלה; במקטע **מדיה וחיפוש AI** מפעילים, לכל ספק בנפרד, את יצירת התמונות, ניתוח התמונות, ניתוח הוידאו, החיפוש באינטרנט והחיפוש קבצים מקומיים.

## שפה

- בהגדרות יש **21 שפות ממשק**: אנגלית, סינית פשוטה, יפנית, קוריאנית, צרפתית, גרמנית, ספרדית, תאית, אינדונזית, רוסית, ערבית, פורטוגזית, איטלקית, פולנית, צ'כית, הולנדית, מלאית, עברית, הינדית, סינית מסורתית, וייטנמית.
- המעבר חל מיד ונשמר; שורת התפריטים המקורית נבנית מחדש לפי השפה.

## ערכת נושא

בהיר / כהה / עקוב אחר המערכת. במצב "עקוב אחר המערכת" העורכים מחליפים ערכת צבעים בהתאם למראה המערכת, בלי הבהובים.

## רישום כאפליקציית ברירת מחדל

אפשר לרשום את GenOffice כמטפלת בקובצי .docx / .xlsx / .pptx / .pdf וכדומה (רישום אפליקציית ברירת מחדל ברמת המערכת; יש לאשר כאשר מוצגת בקשה).

## הודעות צד שלישי ועדכונים

- עזרה ▸ הודעות על תוכנות צד שלישי: רשימת הרישיונות המלאה של הקוד הפתוח שנשלחה עם האפליקציה.
- עזרה ▸ בדוק עדכונים: מפעיל בדיקה ידנית; אם קיימת גרסה חדשה מוצעת התקנה.

## התחברות ל-Genspark

- נתיב ההתחברות (בהגדרות או ברשימת הפרויקטים בענן) משתמש בתהליך **קוד מכשיר**: GenOffice מציג קוד ופותח את דף ההתחברות בדפדפן; לאחר השלמתה התהליך ממשיך אוטומטית.
- ההתחברות משמשת רק ל: רשימת הפרויקטים בענן ולמודלים המתארחים של Genspark. בלעדיה כל תכונה מקומית ומודלים מותאמים ממשיכים לעבוד.
- ההתנקות היא בלחיצה אחת בהגדרות.

## אינטגרציית MCP (למשתמשים מתקדמים / ללקוחות AI)

‏**שילובים** הוא המקטע שמחבר את GenOffice לסוכן תכנון, ולו יש פרק משלו: חיבור סוכן תכנון. הגרסה הקצרה — בחרו דרך (שורת הפקודה, או MCP), עקבו אחרי אותו מקטע, ואז פתחו שיחה חדשה ושאלו.

![הגדרות ▸ שילובים: שלושת השלבים, ואז שורות המיומנויות ואפשרויות ה-MCP](img/settings-integrations.png)

תחת **שרת HTTP מקומי**, האפליקציה יכולה גם להריץ את השרת בעצמה — מתג הפעלה ופורט — ו**מתקדם** מוסיף את כתובת בדיקת התקינות ואת קובץ היומן, במקום להשאיר אותו לעוזר. היא מאזינה רק ב-localhost.

## תזכורת לשורת הפקודה

| פקודה              | מה היא עושה                |
| ------------------ | -------------------------- |
| `genoffice <file>` | פותחת קובץ                 |
| `genoffice mcp`    | מפעילה את שרת ה-MCP המקומי |
| `genoffice --help` | כל הפקודות והדגלים         |
