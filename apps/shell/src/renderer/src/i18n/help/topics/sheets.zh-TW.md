# Sheets：試算表

Sheets 是類 Excel 的表格編輯器；運算由一個獨立的 Rust 引擎程序負責（那裡就算當掉，也不會拖垮整個應用程式）。開啟與儲存的都是真正的 .xlsx；.csv 與 .tsv 會以表格方式開啟。

## 介面

- **功能區**：八個分頁，下面逐一說明。
- **公式列**：顯示並編輯作用中儲存格的公式；支援常用函數。
- **工作表索引標籤**（底部）：新增／重新命名／刪除／移動工作表。
- **儲存格編輯**：按兩下或直接輸入；Enter 確認並下移、Tab 右移、Escape 取消（沿用 Excel 習慣）。
- **快捷鍵**：與 Excel 系列一致（ctrl+C/V/X、ctrl+Z/Y、ctrl+F⋯）。

## 功能區分頁

- **常用**：字型、填滿、框線、數值格式（貨幣／百分比／千分位、小數位增減）、對齊、合併、插入列欄與調整大小、格式化的條件、格式化為表格、儲存格樣式、剪貼簿與格式刷、排序與篩選。
- **插入**：圖片、圖形、文字方塊、連結、註解、核取方塊、頁首及頁尾、符號、方程式；**九種圖表類型**（直條圖、橫條圖、折線圖、區域圖、圓形圖、散佈圖、雷達圖、環圈圖，以及直條＋折線組合圖），另有**建議圖表**——它會依所選範圍為這些類型排序並預覽；從目前所在儲存格建立**樞紐分析圖**；**走勢圖**（折線、直條、勝／負）；用於篩選樞紐分析表的**交叉分析篩選器**與**時間表**。
  - 圖表、樞紐分析圖和走勢圖都是儲存後活頁簿裡的真正物件。
  - **交叉分析篩選器**和**時間表**屬於工作階段層級的控制項：它們所做的篩選會被儲存，Excel 顯示的也是同一張篩選後的樞紐分析表，但交叉分析篩選器按鈕本身並不在檔案中。
- **版面配置**：佈景主題色彩與字型、列印格線／列印標題開關、分頁預覽。
- **公式**：自動加總與插入函數、定義名稱（也可由選取範圍建立）、追蹤前導參照／從屬參照、監看視窗、重新計算工作表／活頁簿。
- **資料**：排序與篩選（含進階篩選、清除篩選）、資料剖析、合併活頁簿、全部重新整理。
- **校閱**：瀏覽註解（顯示、上一則／下一則）、翻譯，以及**保護**群組——**保護工作表**、**保護活頁簿**與**允許編輯範圍**。
  - 保護會寫入 .xlsx，而本應用程式施加的保護不含密碼，因此同一個按鈕會變成**取消保護…**並將其撤銷。其他程式施加、*確實*帶有密碼的保護，無法從這裡移除。
  - 兩個保護按鈕會立即生效——沒有可取消的對話方塊，只會在狀態列提示：儲存時會寫入。
  - **允許編輯範圍**會標示在工作表其餘部分鎖住時仍可編輯的儲存格。
- **檢視**：格線、**公式列**、標題和突出顯示作用中列與欄的開關；縮放；**標準模式**與**分頁預覽**。格線與標題會隨工作表一起儲存；突出顯示則是你自己的偏好設定。
- **圖表設計**：選取圖表時才會出現——圖表類型、樣式與色彩、編輯資料範圍。

「資料」分頁逐個按鈕（對照下圖，由左至右）：

![資料分頁](img/sheets-data.png)

- **樞紐分析表**：由目前範圍建立樞紐分析表，拖曳欄位即可彙整。
- **重新整理**：重新計算目前樞紐分析表的資料。
- **從文字/CSV**：把 .csv/.txt 依分隔符號匯入成新的工作表。
- **合併活頁簿**：把其他 .xlsx 中的工作表併入目前這一份。
- **全部重新整理**：重新計算所有樞紐分析表與外部資料集。
- **排序**（下拉）：遞增／遞減／自訂排序（多欄條件）。
- **篩選**：在標題列加上 ▼ 下拉，勾選要保留的值。
- 旁邊縱排的小按鈕：**清除**（讓所有列回來）、**重新套用**（再跑一次目前的篩選）、**進階**（以條件範圍做篩選）。
- **資料剖析**（下拉）：依分隔符號或固定寬度，把一欄拆成多欄。
- **快速填入**：給一個範例，其餘列依範例自動填入（ctrl+E）。
- **移除重複**：依選取的欄位去掉重複的列。
- **資料驗證**（下拉）：為選取範圍設定輸入規則（下拉清單、數值範圍⋯）。
- **合併彙算**：依類別把多個範圍彙整到一處。
- **模擬分析**（下拉）：目標搜尋——求解一個輸入儲存格的值，讓公式儲存格的結果達到目標值。
- **群組／取消群組**（下拉）：將列或欄組成群組，並可摺疊與展開。
- **小計**：依分類欄位插入小計列。

「公式」分頁逐個按鈕：

![公式分頁](img/sheets-formulas.png)

- **插入函數**（fx）：搜尋函數，並附上參數精靈。
- **自動加總**（下拉）：一鍵 SUM，另有平均值／計數／最大／最小。
- **最近使用過的函數／財務／邏輯／文字／日期和時間／查閱與參照／數學與三角函數／其他函數**：依類別瀏覽並插入函數。
- **名稱管理員**：檢視、建立與刪除具名範圍。
- **定義名稱**（下拉）：為選取範圍命名；**用於公式**可把既有名稱插入公式；**從選取範圍建立**則以首列／首欄的文字批次建立名稱。
- **追蹤前導參照／追蹤從屬參照**：以藍色箭頭標出公式的資料來源與流向何處；**移除箭號**可清除。
- **顯示公式**：儲存格顯示公式本身而非結果。
- **錯誤檢查**：找出並說明公式錯誤。
- **監看視窗**：把在意的儲存格釘選起來，隨時查看其目前值。
- **計算選項**（下拉）：自動或手動重新計算；手動模式下用旁邊的**立即計算／計算工作表**手動觸發。

## 數值與格式

- 數值格式：通用格式、數值、貨幣、百分比、日期／時間、分數、科學記數等。
- 對齊、換行、合併儲存格、框線與填滿。
- 以拖曳調整列高與欄寬；在分隔線上按兩下可自動符合。

## 資料

**排序與篩選**（以依某欄遞減為例）：

1. 按一下**該欄中的任一儲存格**（不必選整欄）。
2. 常用分頁 ▸ **排序與篩選** ▸ **遞減**；整列會一起重排（該範圍視為一個整體排序）。
3. 想用自己的規則（多欄、依色彩）：走同一條路徑，選 **自訂排序**。
4. 篩選：選取標題列後按 **排序與篩選 ▸ 篩選**，每個標題都會出現 ▼ 下拉，勾選要保留的值；清除篩選即可讓全部回來。

- 排序與篩選。
- 凍結窗格。
- .csv / .tsv：直接以表格開啟（以定位符分隔的 tsv 會解析成一張表）；儲存時會寫回原本的格式。

## 右鍵選單

- **在格線中**：編輯器（Univer）自帶的選單——剪下／複製／貼上、插入與刪除列欄、隱藏、合併儲存格、凍結窗格等日常項目。
- **在底部狀態列上**：選擇狀態列要顯示哪些統計值（平均值／計數／加總⋯）；選擇會被記住。
- **在底部的工作表索引標籤上**：新增／重新命名／刪除／上色／隱藏工作表（Univer 的索引標籤選單）。
- 上方分頁列的右鍵選單請見[分頁與視窗管理](help://tabs-and-windows)。

## AI

- 側邊的 AI 面板：選取範圍後用自然語言下指令（重排格式、產生資料、撰寫公式）。
- 用 📎 按鈕在提示詞中附加檔案，或把檔案拖到面板上；檔案會隨問題一起送出，圖片則以縮圖回傳。
- 回答可以參照某個儲存格——點一下參照，格線就會跳到那裡。
- AI 的修改可以從面板回復。

## 儲存與匯出

- 儲存 .xlsx（公式與格式都會保留）；另有另存新檔；匯出 PDF 依列印分頁。
- 自動儲存遵循全域規則（第一次手動儲存後才啟用）。

## 穩定性

- Rust 運算引擎與介面是程序隔離的：即使極端資料把它逼到退出，你也只會看到一則訊息與一次工作階段復原嘗試——不會是整個應用程式當掉。
