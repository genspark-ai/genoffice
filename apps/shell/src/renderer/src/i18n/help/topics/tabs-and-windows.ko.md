# 탭과 창 관리

GenOffice에서 여는 모든 파일은 Word 문서, Excel 통합 문서, PowerPoint 프레젠테이션, PDF를 가리지 않고 기본적으로 하나의 메인 창을 공유하며, 창 상단의 탭 바를 통해 웹 브라우저처럼 빠르고 직관적으로 전환할 수 있습니다.

![탭 바: 홈과 문서 두 개](img/tabs.png)

## 기본 조작

- **탭 전환**: 상단 탭 바에서 원하는 탭을 클릭해 해당 문서를 앞으로 가져오거나, 탭 바 위에 마우스 포인터를 올린 채 마우스 휠을 굴려 열려 있는 문서 탭들을 순서대로 빠르게 순환할 수 있습니다.
- **탭 닫기**: 탭 오른쪽의 `×` 버튼을 누르거나 단축키 `⌘W`(macOS) / `Ctrl+W`(Windows·Linux)를 누릅니다. 아직 저장하지 않은 변경 사항이 남아 있으면 실수로 작업 내용을 잃지 않도록 저장, 변경 내용 버리기, 취소 여부를 먼저 물어봅니다.
- **새 탭 만들기**: 탭 바 오른쪽 끝에 있는 `+` 버튼을 누르면 현재 창 안에 새로운 빈 문서 탭이 열리고 곧바로 편집기 화면으로 들어가 작업을 시작할 수 있습니다.
- **누르는 즉시 전환 반영**: 탭 전환은 마우스 버튼을 눌렀다 떼는 클릭 동작이 끝날 때까지 기다리지 않고 버튼을 누르는 그 순간 즉시 이루어지므로, 여러 문서를 번갈아 보며 대조할 때 매우 빠르고 쾌적하게 반응합니다.
- **열려 있는 파일 이름 바꾸기**: 이미 디스크에 저장된 문서의 이름을 바꾸고 싶을 때는 해당 탭을 **더블클릭**하거나, 탭을 **마우스 오른쪽 버튼으로 클릭한 뒤 컨텍스트 메뉴에서 '이름 바꾸기'**를 선택하면 탭 제목이 그 자리에서 바로 입력란으로 바뀝니다. 일반적인 한 번 클릭은 탭을 활성화할 뿐이므로 실수로 이름 바꾸기 모드로 들어가지 않습니다.

## 이름 바꾸기: 탭 더블클릭 또는 오른쪽 클릭

디스크에 저장된 파일 탭을 **더블클릭**(또는 탭 오른쪽 클릭 메뉴에서 **이름 바꾸기** 선택)하면 탭 제목이 현재 파일 이름이 채워진 인라인 입력 상자로 즉시 전환됩니다. 새 파일 이름을 입력하고 `Enter` 키를 누르거나 입력란 바깥을 클릭해 포커스가 벗어나면 변경 사항이 확정되며, 도중에 취소하고 싶다면 언제든 `Esc` 키를 눌러 원래 이름을 그대로 유지할 수 있습니다. 한국어나 일본어, 중국어 등 입력기(IME) 조합 중에 글자나 후보를 확정하려고 누르는 `Enter` 키는 스마트하게 구분하므로, 글자 입력 도중에 파일 이름이 반쯤 잘린 채 제출되는 일이 없습니다. 이름 변경은 홈 화면의 파일 목록과 똑같은 안전 검사(확장자를 생략했을 때 기존 확장자 자동 유지, 운영체제에서 금지한 특수문자 차단, 같은 폴더 내 동일한 파일 이름 충돌 방지)를 거친 뒤 디스크의 실제 파일 이름을 즉시 바꾸고 '최근 항목'과 '즐겨찾기' 목록까지 함께 갱신합니다.

## 드래그로 탭 순서 바꾸기

여러 파일을 동시에 열어 두었을 때 원하는 문서 탭을 마우스로 잡고 좌우로 끌어당기면 탭 배열 순서를 자유롭게 바꿀 수 있습니다. 드래그하는 동안 이웃한 탭들이 실시간으로 옆으로 비켜나며 들어갈 자리를 보여 주고, 마우스 버튼을 놓는 순간 새로운 순서가 확정됩니다. 또한 4픽셀의 흔들림 방지 영역(데드존)이 적용되어 있어 평소 탭을 클릭할 때 손이 살짝 움직여도 탭이 의도치 않게 흔들리지 않습니다.

## 탭 컨텍스트 메뉴(오른쪽 클릭)

문서 탭 위에서 마우스 오른쪽 버튼을 클릭하면 탭 자체의 창 배치 관리와 실제 디스크 파일 작업을 아우르는 전체 컨텍스트 메뉴가 열립니다(저장된 파일의 경우 메뉴 맨 윗줄에 디스크 경로 요약이 회색으로 표시되어, 이름이 비슷한 여러 파일을 열어 두었을 때도 어느 폴더의 파일인지 한눈에 확인할 수 있습니다). 메뉴 상단에서는 편집기 리본으로 들어갈 필요 없이 곧바로 **저장**, **다른 이름으로 저장…**, **인쇄…**를 실행하거나 **이름 바꾸기**, **복제**, **경로 복사**, **파일 이름 복사**, **Finder / 파일 탐색기에서 표시**, **기본 앱으로 열기**를 사용할 수 있습니다. 메뉴 하단에서는 **옆에 분할하여 열기**, **새 창에서 열기**, 백그라운드에서도 렌더러를 유지하는 **탭 고정**, **왼쪽으로 이동 / 오른쪽으로 이동**, 그리고 **닫기**, **다른 탭 닫기**, **오른쪽 탭 닫기**, **모두 닫기**, **닫은 탭 다시 열기**까지 모두 현재 설정된 앱 인터페이스 언어로 제공됩니다.

## 독립된 창으로 분리하기(Tear-off)

두 문서를 모니터 좌우에 나란히 띄워 놓고 비교하고 싶다면 **탭을 잡고 상단 탭 바 영역 밖으로 끌어내거나** 탭 오른쪽 클릭 메뉴에서 **새 창에서 열기**를 선택하세요. 해당 탭이 작업 중이던 실시간 문서 내용과 실행 취소 기록을 고스란히 간직한 채 독립된 새 창으로 분리됩니다. 분리된 창은 메인 창과 완전히 동등한 기능을 갖추고 있어 편집, 저장, AI 어시스턴트 사용을 그대로 이어갈 수 있으며, 비교 작업이 끝난 뒤 탭을 다시 메인 창의 탭 바 위로 끌어오면 원래 자리로 매끄럽게 다시 합쳐집니다.

## '모든 탭' 전체 목록 메뉴

열려 있는 탭이 많아져 창 상단 가로 폭을 넘어가면 탭 바 오른쪽 끝에 작은 탭 목록 아이콘이 나타납니다. 이 아이콘을 누르면 열려 있는 모든 탭을 빠짐없이 보여 주는 운영체제 네이티브 메뉴(아래쪽 편집기 캔버스에 가려지지 않음)가 열리며, 마우스 클릭이나 위아래 방향키로 원하는 문서로 단번에 이동할 수 있습니다.

## 모든 편집기 상단의 빠른 도구 모음 줄

각 편집기 탭의 상단에는 자주 쓰는 핵심 명령을 모아 둔 도구 모음 줄이 자리하고 있습니다(정확한 배치와 모양은 편집기 특성에 맞춰 조금씩 최적화되어 있습니다):

- **저장(`⌘S` / `Ctrl+S`) 및 다른 이름으로 저장**: 언제든 현재 변경 사항을 디스크에 저장하거나, '다른 이름으로 저장'을 눌러 원본 파일은 그대로 둔 채 새로운 경로와 이름으로 사본을 분기할 수 있습니다.
- **다단계 실행 취소 및 다시 실행**: 여러 단계의 실행 취소(Undo)와 다시 실행(Redo)을 지원하며, 각 문서 탭마다 작업 기록이 독립적으로 유지되어 다른 탭의 편집 내역과 섞이지 않습니다.
- **찾기(`⌘F` / `Ctrl+F`)**: 현재 편집기 전용 본문 검색 및 찾아바꾸기 패널을 즉시 엽니다.
- **자동 저장 스위치**: 켜 두면 타이핑을 잠시 멈출 때마다 변경 사항이 주기적으로 디스크에 안전하게 기록되며, 꺼 두면 수동으로 저장할 때만 디스크에 기록됩니다(저장되지 않은 변경이 있을 때는 탭 제목에 표시가 나타나 알려 줍니다).

## 홈 탭

탭 바 맨 왼쪽에 항상 고정되어 있는 '홈' 탭은 모든 파일과 폴더로 통하는 출발점이므로 닫을 수 없습니다. 어느 편집기에서 작업하고 있든 맨 왼쪽의 홈 탭을 클릭하거나 상단 메뉴에서 **파일 ▸ 홈으로 돌아가기**를 선택하면 언제든 최근 문서 목록과 지식베이스로 돌아갈 수 있습니다.
