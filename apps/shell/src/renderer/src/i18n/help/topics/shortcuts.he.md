# קיצורי מקלדת

לכל עורך יש מקשים משלו, ורק מעט מהם עובדים בכל מקום. זו הרשימה המלאה, מקובצת לפי אפליקציה, עם קיצורי macOS ושל Windows / Linux זה מול זה.

## קראו לפני שמתחילים

**כמעט שום דבר כאן הוא גלובלי.** שלושת מקשי הגישה שלהלן הם כן; כל מה שאחריהם שייך לאפליקציה שלפניכם, ומשתנה כשמחליפים כרטיסיות.

| פעולה                                         | macOS | Windows / Linux |
| --------------------------------------------- | ----- | --------------- |
| פתיחת המדריך למשתמש — פועל בכל מקום באפליקציה | F1    | F1              |
| כיווץ / הרחבה של סרגל הכלים — בכל עורך        | ⌥⌘R   | Ctrl+F1         |
| פתיחת גיליון קיצורי המקלדת — רק ב-Wאוd        | ⌘/    | Ctrl+/          |

- **F1 פותח את המדריך הזה**, ולא את גיליון הקיצורים. הוא שייך לתפריט האפליקציה, ולכן הוא עובד באותו אופן מ-Wאוd, מ-Sheets, מ-Slides, מ-PDF או מכרטיסיית הבית.
- **מקש הסרגל הוא `Ctrl+F1`, או `⌥⌘R` ב-macOS.** לחיצה על `F1` בלבד לא עושה דבר — F1 הוא המדריך, ומקש הסרגל אינו משתף איתו במכוון. `Ctrl+F1` מתקבל גם ב-macOS, אך `⌥⌘R` הוא המקש ש-Office fאו Mac משתמש בו.
- **גיליון קיצורי המקלדת הוא של Wאוd בלבד** (`⌘/`). הוא מפרט בדיוק את טבלת Wאוd שלהלן. אין לאף עורך אחר גיליון כזה.

![גיליון קיצורי המקלדת של Word עצמו: הפעולה בשמאל, צירוף המקשים בימין, מקובל לפי קבוצות קובץ, עריכה, עיצוב טקסט, עיצוב פסקה, הוספה, סקירה וכלים, תצוגה](img/word-shortcuts.png)

- **`⌘O`, `⌘S` ו-`⌘P` מיושמים בנפרד מאחורי כל עורך**, והם לא מתנהגים בדיוק כמו זה על זה. ה-`⌘P` של Wאוd מרכיב תחילה תצוגה מקדימה להדפסה, כך שגיליון מודפס אחד שווה בדיוק לעמוד אחד על המסך; של PDF פותח את תיבת הדפסת ה-PDF; ל-Slides ול-Sheets יש שוב משלהם.
- **כל השאר הוא לפי אפליקציה.** כשכרטיסיית Wאוd פעילה, `⌘B` הוא המודגש של Wאוd. כש-Slides פעיל, `⌘B` הוא המודגש של Slides, והתפריט שאליו הוא שייך אינו זה שאתם רגילים אליו. היכן שקיצור פועל רק עם בחירה, או בחלונית מסוימת, עמודת הפעולה אומרת זאת.

## מוסכמות

- עמודת macOS משתמשת בסימנים המוכרים: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- עמודת Windows / Linux כותבת את שמותיהם במלואם: `Ctrl`, `Alt`, `Shift`.
- כאשר ל-GenOffice באמת צריך מקשים שונים בשתי הפלטפורמות, הטבלה מציגה זאת. המקרים הנפוצים הם `⌃H` עבור חיפוש והחלפה (ב-macOS `⌘H` שייך להסתרה), `⌥⌘G` עבור מעבר אל, ומקש הסגירה של Slides.
- קיצור שפועל רק עם בחירה נכתב בעמודת הפעולה במקום לקבל עמודה משלו, כדי שהטבלה תישאר ברוחב של שלוש עמודות.

## Wאוd

ל-Wאוd יש שורת תפריטים מלאה, ולכן קיצורי הקובץ והעיצוב שלהלן פועלים בכל רגע שבו לכרטיסיית Wאוd יש מיקוד, בכל מסמך פתוח. קיצורי העריכה דורשים מסמך שנטען וניתן לעריכה, עם הסמן בתוך הטקסט; הם אינם פועלים בזמן שאתם מקלידים בתיבת החיפוש, בתיבת הנחיה של AI או בכל שדה אחר.

## Sheets

GenOffice Sheets הוא רשת תואמת ל-Excel. רוב הקיצורים שלהלן הם הקיצורים של Excel שכבר הכרתם.

> **העריכה מנצחת.** כמעט כל קיצור ב-Sheets מתעלם בזמן שאתם עורכים תא או מקלידים ב**שורת הנוסחאות**, כדי שהקלדה, הזזת הסמן ומקש Backspace ישמרו את משמעות העריכה הרגילה של טקסט. אם מקש נראה כמו שאינו עושה דבר, בדקו אתם באמצע עריכה: לחצו תחילה על Esc או Enter, ואז נסו שוב. פקודות שפועלות על הבחירה אינן עושות דבר בזמן שתיבת דיאלוג פתוחה. היכן שקיצור הוא חריג מהכלל הזה, הטבלה אומרת זאת.

שתי המוסכמות הבאות מיוחדות ל-Sheets. `⌘` ו-`⌃` הם אותה משבצת מקשי שינוי — שניהם מתקבלים בכל פלטפורמה, כך ש-`⌘1` ו-`Ctrl+1` הם אותו קיצור. **תא ריק בעמודת Windows / Linux אומר שהקיצור קיים ב-macOS בלבד.**

## Slides

GenOffice Slides הוא עורך מצגות בסגנון PowerPoint. רוב המקשים עושים את אותו דבר בכל מקום שבו אתם נמצאים, אך כמה משנים משמעות לפי המיקוד — בתוך תיבת טקסט, או כש**מסילת התמונות הממוזערות**, **מבנה המבנה** או **ממיין השקופיות** מקבלים מיקוד מקלדת. המקרים האלה מסומנים בעמודת הפעולה.

### קובץ ויישום

| פעולה                    | macOS | Windows / Linux |
| ------------------------ | ----- | --------------- |
| שמירה                    | ⌘S    | Ctrl+S          |
| שמירה בשם                | ⇧⌘S   | Ctrl+Shift+S    |
| פתיחה                    | ⌘O    | Ctrl+O          |
| סגירת הכרטיסייה הנוכחית  | ⌘W    | Ctrl+Q          |
| הדפסה                    | ⌘P    | Ctrl+P          |
| ביטול                    | ⌘Z    | Ctrl+Z          |
| ביצוע חוזר               | ⇧⌘Z   | Ctrl+Shift+Z    |
| ביצוע חוזר (קיצור חלופי) | ⌘Y    | Ctrl+Y          |

סגירת כרטיסייה היא המקום היחיד שבו שתי הפלטפורמות נפצעות לגמרי: ⌘W ב-macOS, וב-Windows וב-Linux זו Ctrl+Q, שיוצאת מכל האפליקציה ולא רק מהכרטיסייה.

שקופית חדשה היא פיצול הפלטפורמות האחרון. לכל פלטפורמה יש מקש משלה והמקש של השנייה אינו עושה דבר: ⇧⌘N ב-macOS, Ctrl+M ב-Windows וב-Linux. ה-`⌘M` אינו יכול לבצע את העבודה ב-macOS משום שזהו מקש המזעור של המערכת.

בחירת הכול מתנהגת לפי המיקוד: כשמסילת התמונות הממוזערות, מבנה המבנה או ממיין השקופיות מקבלים מיקוד, היא בוחרת כל שקופית, ובכל מקום אחר היא בוחרת כל רכיב בשקופית הנוכחית. Tab מעבר בין הצורות שעל השקופית, ורק כאשר הקנבס עצמו מקבל מיקוד.

## Markdown

GenOffice Markdown עורך Markdown עם תצוגה מקדימה חיה לצדו.

### קובץ ותצוגה

| פעולה                              | macOS    | Windows / Linux  |
| ---------------------------------- | -------- | ---------------- |
| שמירה                              | ⌘S       | Ctrl+S           |
| שמירה בשם                          | ⇧⌘S      | Ctrl+Shift+S     |
| הדפסה                              | ⌘P       | Ctrl+P           |
| חיפוש                              | ⌘F       | Ctrl+F           |
| הפעלה/כיבוי של מקור / תצוגה מקדימה | ⌘E       | Ctrl+E           |
| הגדלה                              | ⌘= או ⌘+ | Ctrl+= או Ctrl++ |
| הקטנה                              | ⌘-       | Ctrl+-           |
| גודל אמיתי (100%)                  | ⌘0       | Ctrl+0           |

הקטנה מקבלת גם ⌘_ ו-Ctrl+_. צביטה על משטח המעקב, או החזקת ⌘ או Ctrl עם גלילה מעל המסמך, גם מגדילות.

### בלוקים

| פעולה                                | macOS | Windows / Linux      |
| ------------------------------------ | ----- | -------------------- |
| שכפול הבלוקים הנבחרים                | ⌘D    | Ctrl+D               |
| מחיקת הבלוקים הנבחרים                | ⇧⌘⌫   | Ctrl+Shift+Backspace |
| העברת הבלוק הנבחר למעלה              | ⇧⌘↑   | Ctrl+Shift+ArrowUp   |
| העברת הבלוק הנבחר למטה               | ⇧⌘↓   | Ctrl+Shift+ArrowDown |
| הוספת קישור לבחירה                   | ⌘K    | Ctrl+K               |
| הסרת הקישור (לחצו שוב כשהקישור פעיל) | ⌘K    | Ctrl+K               |

### בתוך בלוק מתמטיקה

אלה חלים רק כאשר עורך ה-LaTeX הצף פתוח.

| פעולה                | macOS | Windows / Linux |
| -------------------- | ----- | --------------- |
| החלת הנוסחה          | ⌘⏎    | Ctrl+⏎          |
| סגירת העורך ללא החלה | Esc   | Esc             |

החלת נוסחה ריקה מוחקת את הבלוק. העורך נסגר גם בכל שינוי במסמך, ולחיצה מחוצה לו סוגרת אותו.

## HTML

GenOffice HTML מציג עורך קוד לצד תצוגה מקדימה חיה. המקשים שפועלים על רכיב בדף חלים רק כאשר לתצוגה המקדימה עצמה יש מיקוד מקלדת.

### קובץ ותצוגת המקור

| פעולה                                    | macOS    | Windows / Linux  |
| ---------------------------------------- | -------- | ---------------- |
| שמירה                                    | ⌘S       | Ctrl+S           |
| שמירה בשם                                | ⇧⌘S      | Ctrl+Shift+S     |
| מעבר בין תצוגות (עריכה / מפוצל / מקדימה) | ⌘\       | Ctrl+\           |
| חיפוש                                    | ⌘F       | Ctrl+F           |
| הגדלה                                    | ⌘= או ⌘+ | Ctrl+= או Ctrl++ |
| הקטנה                                    | ⌘-       | Ctrl+-           |
| גודל אמיתי (100%)                        | ⌘0       | Ctrl+0           |

הקטנה מקבלת גם ⌘_ ו-Ctrl+_.

### עיצוב והיסטוריה

| פעולה                    | macOS | Windows / Linux |
| ------------------------ | ----- | --------------- |
| מודגש                    | ⌘B    | Ctrl+B          |
| נטוי                     | ⌘I    | Ctrl+I          |
| ביטול                    | ⌘Z    | Ctrl+Z          |
| ביצוע חוזר               | ⇧⌘Z   | Ctrl+Shift+Z    |
| ביצוע חוזר (קיצור חלופי) | ⌘Y    | Ctrl+Y          |

בתוך עורך הקוד או בשדה טופס, מקשי העריכה של השדה עצמו מקבלים את השליטה.

### במסגרת התצוגה המקדימה, עם רכיב נבחר

| פעולה                   | macOS      | Windows / Linux    |
| ----------------------- | ---------- | ------------------ |
| שאלת AI על הרכיב        | ⌘K         | Ctrl+K             |
| מחיקת הרכיב             | ⌫ / Delete | Backspace / Delete |
| אח הקודם                | ↑          | ArrowUp            |
| האח הבא                 | ↓          | ArrowDown          |
| בחירת ההורה             | ←          | ArrowLeft          |
| בחירת הילד הראשון       | →          | ArrowRight         |
| העברת הרכיב למעלה במסמך | ⌥↑         | Alt+ArrowUp        |
| העברת הרכיב למטה במסמך  | ⌥↓         | Alt+ArrowDown      |
| ביטול הבחירה            | Esc        | Esc                |

כל אחד מאלה דורש שכבר נבחר רכיב; כשאין דבר נבחר, המקש אינו עושה דבר.

### במסגרת התצוגה המקדימה, עריכת טקסט במקום

| פעולה                      | macOS | Windows / Linux |
| -------------------------- | ----- | --------------- |
| אישור העריכה               | Esc   | Esc             |
| אישור העריכה (קיצור חלופי) | ⌘⏎    | Ctrl+⏎          |
| הדגשת הטווח שנבחר          | ⌘B    | Ctrl+B          |
| הטיות הטווח שנבחר          | ⌘I    | Ctrl+I          |

האישור שומר על מה שהקלדתם ומחזיר את הרכיב למצב הנבחר.
