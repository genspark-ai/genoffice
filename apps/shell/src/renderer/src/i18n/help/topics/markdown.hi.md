# Markdown एडिटर

Markdown एडिटर .md / .markdown को "स्रोत + रेंडर किया गया पूर्वावलोकन" अनुभव के साथ खोलता है।

- **खोलें**: होम से या File ▸ खोलें से; कमांड लाइन भी काम करती है।
- **संपादन**: सादा-पाठ संपादन; GFM एक्सटेंशन (तालिकाएँ, कार्य सूचियाँ, स्ट्राइकथ्रू, स्वतः लिंक) पूर्वावलोकन में रेंडर होते हैं।
- **पूर्वावलोकन**: लाइव; चित्र जैसे सापेक्ष संपत्तियाँ दस्तावेज़ के बगल में हल होती हैं।
- **सहेजना**: बाइट-ईमानदार — BOM, CRLF और अंतिम नई पंक्ति की मौजूदगी सुरक्षित रहती है; बिना बदलाव के सहेजना फ़ाइल दोबारा नहीं लिखता।
- **खोजें और बदलें**: ctrl+F स्रोत में खोजता है; सभी बदलें वापस लिखता है।
- **AI**: प्रीसेट बटन सहायक को दस्तावेज़ फिर से लिखने, विस्तारित करने या अनुवाद करने देते हैं।

## टूलबार

एडिटर के ऊपर बटनों की एक पंक्ति (टिप देखने के लिए होवर करें):

![Markdown टूलबार](img/md-toolbar.png)

- **फ़ाइल और इतिहास**: सहेजें, इस रूप में सहेजें, पूर्ववत, फिर से करें, खोजें; दाईं ओर **स्वतः सहेजना** टॉगल समय-समय पर बदलाव डिस्क पर लिखता है।
- **AI बटन**: AI पैनल खोलता है; बगल में पुनर्लेखन / विस्तार / अनुवाद के प्रीसेट हैं।
- **अनुच्छेद शैली** (ड्रॉपडाउन): सादा पाठ और शीर्षक स्तरों के बीच बदलें।
- **इनलाइन स्वरूपण**: **बोल्ड**, _इटैलिक_, ~~स्ट्राइकथ्रू~~, `इनलाइन कोड`, लिंक।
- **सूचियाँ**: बुलेट, क्रमांकित, कार्य सूची।
- **सम्मिलित करें**: तालिका, छवि, क्षैतिज रेखा।
- **गुण**: फ़ाइल के शीर्ष में YAML front matter ब्लॉक सम्मिलित करें या उस पर कूदें।
- **रूपरेखा**: शीर्षक पदानुक्रम के अनुसार कूदें।
- **वर्तनी जाँच**: इस दस्तावेज़ के लिए वर्तनी जाँच चालू/बंद करें।

तीन त्वरित उदाहरण:

- **शीर्षक**: कर्सर उस पंक्ति में रखें ▸ अनुच्छेद-शैली ड्रॉपडाउन ▸ "शीर्षक 1" चुनें।
- **तालिका**: **तालिका सम्मिलित करें** पर क्लिक करें ▸ पंक्ति/स्तंभ संख्या खींचें ▸ सेल में टाइप करें; पूर्वावलोकन उसे तुरंत रेंडर कर देता है।
- **कार्य सूची**: कुछ पंक्तियाँ चुनें ▸ **कार्य सूची** दबाएँ ▸ हर पंक्ति `- [ ]` बन जाती है, जो पूर्वावलोकन में चेकबॉक्स के रूप में दिखती है।
