# Markdown 편집기

Markdown 편집기는 .md / .markdown을 원본과 렌더링된 미리보기를 나란히 보며 엽니다.

- **열기**: 홈 또는 파일 ▸ 열기. 명령줄에서도 열 수 있습니다.
- **편집**: 일반 텍스트로 편집합니다. GFM 확장(표, 작업 목록, 취소선, 자동 링크)은 미리보기에 렌더링됩니다.
- **미리보기**: 실시간입니다. 이미지 같은 상대 경로 자산은 문서 옆에서 찾아집니다.
- **저장**: 바이트 단위로 충실합니다. BOM, CRLF, 끝의 줄바꿈 유무가 그대로 보존되며, 수정하지 않았다면 파일을 다시 쓰지 않습니다.
- **찾아바꾸기**: ctrl+F로 원본을 찾고, 모두 바꾸기로 되돌려 씁니다.
- **AI**: 프리셋 버튼으로 어시스턴트에게 문서 다시 쓰기, 늘이기, 번역을 시킬 수 있습니다.

## 도구 모음

편집기 위에 한 줄로 버튼이 있습니다(마우스를 올리면 설명이 보입니다).

![Markdown 도구 모음](img/md-toolbar.png)

- **파일과 기록**: 저장, 다른 이름으로 저장, 실행 취소, 다시 실행, 찾기. 오른쪽의 **자동 저장** 전환이 변경을 주기적으로 디스크에 기록합니다.
- **AI 버튼**: AI 패널을 엽니다. 옆에는 다시 쓰기/늘이기/번역 프리셋이 있습니다.
- **단락 스타일**(드롭다운): 본문과 각 제목 수준 사이를 바꿉니다.
- **행내 서식**: **굵게**, _기울임꼴_, ~~취소선~~, `인라인 코드`, 링크.
- **목록**: 글머리 기호 목록, 번호 매기기 목록, 작업 목록.
- **삽입**: 표, 이미지, 구분선.
- **속성**: 파일 맨 앞의 YAML front matter 블록을 삽입하거나 그리로 이동합니다.
- **개요**: 제목 계층으로 이동합니다.
- **맞춤법 검사**: 이 문서의 맞춤법 검사를 켜고 끕니다.

바로 해 볼 세 가지:

- **제목**: 그 줄에 커서를 놓고 ▸ 단락 스타일 드롭다운 ▸ "제목 1".
- **표**: **표 삽입**을 누르고 ▸ 행과 열 수를 끌어 고르고 ▸ 셀에 입력합니다. 미리보기에 바로 렌더링됩니다.
- **작업 목록**: 몇 줄을 선택하고 ▸ **작업 목록**을 누르면 ▸ 각 줄이 `- [ ]`이 되고, 미리보기에는 체크박스가 붙은 목록으로 렌더링됩니다.

## 내보내기

파일 메뉴에 있으며 모두 로컬 작업이고, 저장 위치도 모두 묻습니다.

- **Word로 내보내기…**와 **PDF로 내보내기…**는 실제 .docx 또는 .pdf를 씁니다.
- **이미지로 내보내기…**는 직접 고른 폴더에 한 페이지당 PNG 하나씩 씁니다.
- **Docs 문서로 변환하여 열기**는 .docx로 변환한 뒤 이 앱 안의 내장 Docs 탭에서 엽니다. 클라우드의 어떤 것으로 넘기는 것이 아니며, 변환된 사본은 약 일주일 뒤 정리되는 캐시 폴더에 들어 있습니다.

## 소스 보기

도구 모음에 **소스** 전환이 있습니다(앱과 같은 언어로 표시됩니다). 켜면 편집기가 그대로의 Markdown으로 바뀝니다. 저장이 쓰는 것과 정확히 같은 텍스트이며, 다듬지도 않고, 뒤에서 정규화되지도 않습니다.

- **편집은 바이트 단위로 충실합니다.** 소스 보기에서 저장한 결과는 편집기에서 저장한 결과와 같은 바이트입니다. BOM, CRLF, 끝 줄바꿈 유무가 모두 그대로 남습니다.
- **같은 문서입니다.** 앞뒤로 자유롭게 오가세요. 소스는 편집기 자체의 텍스트이지, 합쳐야 하는 복사본이 아닙니다.
- **소스 보기가 열려 있는 동안에는 서식 도구 모음을 쓸 수 없습니다.** 대부분 그 버튼들이 렌더링된 쪽에서만 의미를 갖는 편집기 구조를 삽입하기 때문입니다. 보기를 닫으면 다시 나타납니다.
- **JSON 같은 소스 모드 파일**은 여기로 바로 열립니다. 그릴 것이 없으므로, 소스가 곧 문서입니다.
