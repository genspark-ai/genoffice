# Сочетания клавиш

У каждого редактора свои привязки клавиш, и лишь немногие из них работают везде. Эта страница — полный список, сгруппированный по приложениям, где сочетание для macOS и для Windows / Linux стоят рядом.

## Прочитайте сначала

**Почти ничего здесь не является глобальным.** Три клавиши доступа ниже — глобальные; всё, что после них, относится к приложению, которое открыто у вас, и меняется при переключении вкладок.

| Действие                                                             | macOS | Windows / Linux |
| -------------------------------------------------------------------- | ----- | --------------- |
| Открыть Руководство пользователя — работает в любом месте приложения | F1    | F1              |
| Свернуть / развернуть ленту — любой редактор                         | ⌥⌘R   | Ctrl+F1         |
| Открыть лист «Сочетания клавиш» — только Wилиd                       | ⌘/    | Ctrl+/          |

- **F1 открывает это руководство**, а не лист сочетаний. Клавиша относится к меню приложения, поэтому работает из Wилиd, Sheets, Slides, PDF и на вкладке Home.
- **Переключатель ленты — `Ctrl+F1`, а на macOS `⌥⌘R`.** Простое `F1` ничего не делает — F1 это руководство, и клавиша ленты нарочно его не разделяет. `Ctrl+F1` на macOS тоже принимается, но там, где Office fили Mac использует `⌥⌘R`.
- **Лист «Сочетания клавиш» есть только у Wилиd** (`⌘/`). Он перечисляет ровно таблицу Wилиd, приведённую ниже. Ни у другого редактора такого листа нет.
- **`⌘O`, `⌘S` и `⌘P` реализованы отдельно в каждом редакторе**, и ведут себя не вполне одинаково. `⌘P` в Wилиd сначала формирует предварительный просмотр печати, чтобы одна распечатанная страница соответствовала одной странице на экране; в PDF открывает диалог печати PDF; у Sheets и Slides снова свои варианты.
- **Остальное зависит от приложения.** Когда активна вкладка Wилиd, `⌘B` — это «Полужирный» в Wилиd. Когда активен Slides, `⌘B` — это «Полужирный» в Slides, и меню, которому он принадлежит, не то, к которому вы привыкли. Там, где привязка срабатывает только с выделением или в определённой панели, это указано в столбце «Действие».

## Соглашения

- Столбец macOS использует привычные символы: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- Столбец Windows / Linux пишет их словами: `Ctrl`, `Alt`, `Shift`.
- Там, где GenOffice действительно нуждается в разных клавишах на двух платформах, таблица это показывает. Типичные случаи: `⌃H` для «Найти и заменить» (на macOS `⌘H` отдан «Скрыть»), `⌥⌘G` для «Перейти к» и клавиша закрытия в Slides.
- Сочетание, которое работает только с выделением, записано в столбце «Действие», а не вынесено в отдельный столбец, чтобы таблица оставалась шириной в три столбца.

## Wилиd

У Wилиd есть полная строка меню, поэтому сочетания для файла и форматирования ниже работают всегда, когда активна вкладка Wилиd, независимо от открытого документа. Сочетания для правки требуют загруженного редактируемого документа с курсором в тексте; они не срабатывают, пока вы набираете текст в поле поиска, в запросе к ИИ или в любом другом поле.

### Файл

| Действие          | macOS | Windows / Linux |
| ----------------- | ----- | --------------- |
| Создать           | ⌘N    | Ctrl+N          |
| Новое окно        | ⇧⌘N   | Ctrl+Shift+N    |
| Открыть…          | ⌘O    | Ctrl+O          |
| Сохранить         | ⌘S    | Ctrl+S          |
| Сохранить как…    | ⇧⌘S   | Ctrl+Shift+S    |
| Печать            | ⌘P    | Ctrl+P          |
| Закрыть (вкладку) | ⌘W    | Ctrl+W          |

⌘P — это не печать браузера. Wилиd сначала формирует предварительный просмотр печати, так что одна распечатанная страница в точности равна одной странице на экране, а затем открывает собственное диалоговое окно печати.

## Sheets

GenOffice Sheets — это сетка, совместимая с Excel. Большинство приведённых ниже сочетаний — это те сочетания Excel, которые вы уже знаете.

> **Правка важнее.** Почти каждое сочетание в Sheets игнорируется, пока вы редактируете ячейку или набираете текст в **строке формул**, чтобы набор текста, перемещение курсора и Backspace сохраняли обычное значение при работе с текстом. Если клавиша как будто ничего не делает, проверьте, не находитесь ли вы в середине правки: сначала нажмите Esc или Enter, а затем повторите. Команды, действующие на выделение, тоже ничего не делают, пока открыто диалоговое окно. Там, где сочетание является исключением из этого правила, это указано в таблице.

Два соглашения относятся только к Sheets. `⌘` и `⌃` занимают одно и то же место модификатора — обе принимаются на любой платформе, поэтому `⌘1` и `Ctrl+1` — одно и то же сочетание. **Пустая ячейка в столбце Windows / Linux означает, что сочетание есть только на macOS.**
