# AI 模型與設定

## 服務供應商與模型設定

所有 AI 模型、協定端點與 API 金鑰都統一在「設定」視窗中進行管理（點擊首頁左下角的帳戶列即可開啟）：

![設定視窗](img/settings-general.png)

- **Genspark 官方託管服務**：如果你希望開箱即用，只需透過裝置碼流程登入你的 Genspark 帳號（在瀏覽器裡確認一次驗證碼即可），就能直接呼叫官方託管的大模型與多模態服務，完全不需要自己去申請和填寫任何 API Key。
- **接入自訂端點（自帶金鑰 BYOK）**：如果你有自己購買的各家大模型金鑰或企業內部閘道器，可以在 **設定 ▸ AI 模型**（以及 **生圖、媒體與搜尋**）裡依協定類型分別填寫基礎位址（Base URL）和 API Key——內建原生支援 OpenAI 相容協定、Anthropic（Claude）、Google Gemini、DeepSeek、阿里通義千問 DashScope（Qwen）、MiniMax 以及 Atlas Cloud 等主流協定。你填寫的所有金鑰都只受限儲存在你本機的應用程式設定檔中（僅目前系統使用者可讀），在實際發起請求時也只會放進發往你所填端點的 HTTP 請求標頭裡，絕不會經過任何第三方中轉。
- **依能力自由混搭不同模型**：GenOffice 不會強迫你用同一個模型包辦所有事——你可以為**內文對話與文件生成**、**AI 圖像生成**以及**圖像／影片視覺理解（看圖提問）**分別指定最擅長該領域的服務商和具體模型。
- **MiniMax H3-Image 與 H3-Image Highspeed 圖像生成**：在圖像生成服務商中選擇 MiniMax 時，除了經典的 `image-01` 模型外，現在還原生支援最新的 **MiniMax H3-Image**（預設選取，畫質更細膩）與追求更快出圖速度的 **MiniMax H3-Image Highspeed**（國內平台 `api.minimax.cn` 與海外平台皆可呼叫）；這兩款 H3 圖像模型預設依清晰的 **2K 解析度**請求生成圖片，並且在基於已有圖片做局部重繪或風格改圖時，單次最多支援同時傳入 **16 張參考圖**。
- **儲存前一鍵連線測試**：填好端點位址和金鑰後，點擊旁邊的**連線測試**按鈕，系統就會在寫入磁碟儲存之前實際向該端點發起一次輕量探測，幫你當場驗證網路是否連通、金鑰是否有效以及所選模型是否真實可用。
- **完美相容帶路徑與查詢參數的閘道器位址**：如果你填寫的自訂 Base URL 是企業反向代理或帶有子路徑與查詢字串（Query String）的聚合閘道器位址，GenOffice 在拼接具體 API 路由時會自動辨識並保留你原有的路徑結構與參數，不會把閘道器參數截斷弄丟。

## 本機命令列（CLI）程式設計助手整合

- **指定本機 Codex 類 CLI 程式路徑**：除了直接走 HTTP API 呼叫雲端模型外，設定面板還支援直接填入你電腦上已安裝的本機 CLI 推論程式路徑（完整支援帶有中文等非 ASCII 字元的使用者主目錄，也支援直接以 `~/` 開頭縮寫，系統會自動為你展開為完整絕對路徑）；填好後點擊**偵測模型**，應用程式就會自動呼叫該 CLI 探測並列出它目前可用的全部模型清單。
- **寬鬆自然的路徑校驗**：路徑輸入框在做合法性校驗時只檢查該磁碟檔案是否真實存在且可存取，不會對目錄名施加死板的純英文字元集限制。

## 設定修改何時生效

- **儲存即刻生效且不打斷目前回答**：你在設定面板裡切換的新模型、新端點或新金鑰在點擊儲存的瞬間就會在全域生效；如果此時某個編輯器的 AI 面板裡正好有一輪回答還在串流輸出中，正在進行的這一輪會平穩用完舊設定直到回答結束，從你發出的下一條訊息開始立即無縫切換到新模型。
