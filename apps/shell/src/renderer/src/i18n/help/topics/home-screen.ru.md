# Главный экран: где хранятся ваши файлы

«Главная» — стартовая страница GenOffice: слева панель навигации, справа списки файлов и карточки быстрого создания.

![Главный экран](img/home-screen.png)

## Навигация на боковой панели

- **Недавние**: файлы, которые вы открывали недавно, сгруппированные по времени (на этой неделе / ранее в этом месяце / ещё раньше).
- **Избранное**: файлы, которым вы поставили звёздочку. Наведите курсор на строку файла и нажмите на звёздочку, чтобы добавить или убрать.
- **Genspark Projects**: после входа в аккаунт Genspark показывает проекты, созданные вами с Genspark AI в вебе; нажмите на проект, чтобы продолжить редактирование в браузере. Доступны поиск, сортировка по времени, обновление и догрузка.
- **Папки**: закрепляйте часто используемые каталоги на боковой панели (Добавить папку…) и переходите к ним как по закладкам. Недоступные корни показываются как недоступные, их можно убрать из списка.
- **Корзина**: указывает на системную корзину — удалённые файлы попадают туда, и их можно восстановить средствами ОС.

## Список файлов

В каждой строке показаны значок, имя файла, время изменения и прочее. **Меню ⋯** строки предлагает:

- **Переименовать**: прямо на месте, расширение сохраняется автоматически.
- **В избранное / Убрать из избранного**
- **Создать копию**: создаёт копию в той же папке.
- **Удалить**: перемещает файл в системную корзину — это не безвозвратное удаление.
- **Показать в папке**: находит файл в вашем файловом менеджере.

## Поиск

Поле поиска вверху находит сразу два вида совпадений:

- **Имена файлов**: быстрая фильтрация по имени.
- **Содержимое файлов**: GenOffice индексирует ваши файлы в фоне (текст внутри docx/xlsx/pptx/pdf/md/html, с запасным вариантом через OCR для сканированных PDF), поэтому поиск по тексту документа тоже находит файлы. Область поиска и переключатели заданы в настройках поиска.

## Карточки быстрого старта

Карточки над списками создают новый документ за один шаг. Нажатие на карточку создаёт файл такого типа и открывает его редактор — можно сразу писать, а можно поручить AI сделать черновик (в каждом редакторе есть **кнопка AI** на ленте и **Спросить ИИ** в контекстном меню выделения).

Новый файл попадает в папку, выбранную сейчас на боковой панели; если ничего не выбрано, он попадает в папку по умолчанию.

Что делает каждая карточка:

- **AI Docs** (.docx): пустой текстовый документ в редакторе Docs. Файл записывается на диск только при **первом сохранении**; новые документы открываются с развёрнутой панелью ИИ (это отключается в Настройки → «Открывать панель ИИ в новых документах»).
- **AI Sheets** (.xlsx): пустая таблица в редакторе Sheets. До первого сохранения файла на диске нет — имя зарезервировано для первого сохранения; после первой генерации ИИ файл также может быть переименован автоматически по содержимому.
- **AI Slides** (.pptx): пустая презентация в редакторе Slides.
- **AI Markdown** (.md): пустой документ Markdown в редакторе Markdown.
- **AI HTML** (.html): пустая веб-страница в редакторе HTML.
- **AI PDF** (.pdf): отличается от остальных — она **сразу** создаёт настоящий пустой одностраничный PDF в целевой папке и открывает его как обычный файл (редактор PDF работает с настоящими файлами). Подходит для аннотирования, сокрытия данных и добавления текста; при первом сохранении файл можно переименовать автоматически по содержимому.
- **Открыть локальный файл**: системный выбор файлов для Word (.docx/.doc), Excel (.xlsx/.xlsm/.xls/.csv/.tsv), PowerPoint (.pptx/.ppt), PDF, Markdown (.md/.markdown) и веб-страниц (.html/.htm). Можно выбрать несколько файлов сразу; каждому файлу достаётся своя вкладка.

> Совет: меню Файл ▸ Создать на панели меню создаёт те же типы документов (⌘N/Ctrl+N по умолчанию создаёт текстовый документ); перетаскивание файла в окно открывает его.

## Облачные проекты (Genspark Projects)

- При первом использовании нужен вход в аккаунт Genspark (схема с кодом устройства: GenOffice показывает код, а вы завершаете вход в браузере).
- Список проектов синхронизируется с вебом; команда «Открыть в браузере» переходит туда, чтобы продолжить работу.
- Отказ от входа не влияет ни на одну из локальных возможностей.
