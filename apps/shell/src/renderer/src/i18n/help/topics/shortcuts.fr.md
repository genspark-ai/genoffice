# Raccourcis clavier

Chaque éditeur a ses propres combinaisons de touches, et seules quelques-unes fonctionnent partout. Cette page en donne la liste complète, regroupée par application, avec la combinaison macOS et celle de Windows / Linux côte à côte.

## À lire avant tout

**Presque rien ici n’est global.** Les trois touches d’accès ci-dessous le sont ; tout ce qui suit appartient à l’application qui se trouve au premier plan, et change lorsque vous changez d’onglet.

| Action                                                                   | macOS | Windows / Linux |
| ------------------------------------------------------------------------ | ----- | --------------- |
| Ouvrir le guide de l’utilisateur — fonctionne partout dans l’application | F1    | F1              |
| Réduire / agrandir le ruban — tous les éditeurs                          | ⌥⌘R   | Ctrl+F1         |
| Ouvrir la feuille des raccourcis clavier — Word uniquement               | ⌘/    | Ctrl+/          |

- **F1 ouvre ce manuel**, pas la feuille des raccourcis. Cette touche appartient au menu de l’application : elle fonctionne donc aussi bien depuis Word, Sheets, Slides, PDF ou l’onglet Home.
- **Le bouton du ruban est `Ctrl+F1`, ou `⌥⌘R` sur macOS.** Appuyer sur `F1` seul ne fait rien — F1 est le manuel, et la touche du ruban ne partage volontairement pas ce code. `Ctrl+F1` est acceptée sur macOS également, mais `⌥⌘R` est la touche qu’utilise Office pour Mac.
- **La feuille des raccourcis clavier appartient au seul Word** (`⌘/`). Elle reprend exactement la table Word ci-dessous. Aucun autre éditeur n’en possède.

![La feuille des raccourcis clavier propre à Word : l’action à gauche, le raccourci à droite, regroupés par Fichier, Édition, Mise en forme du texte, Mise en forme du paragraphe, Insertion, Révision et outils, Affichage](img/word-shortcuts.png)

- **`⌘O`, `⌘S` et `⌘P` sont implémentés séparément derrière chaque éditeur**, et ils ne se comportent pas tout à fait de la même façon. Le `⌘P` de Word met d’abord en page un aperçu d’impression, afin qu’une feuille imprimée corresponde exactement à une page à l’écran ; celui de PDF ouvre la boîte de dialogue d’impression PDF ; Sheets et Slides ont de nouveau les leurs.
- **Le reste est propre à chaque application.** Lorsque l’onglet Word est actif, `⌘B` correspond au Gras de Word. Lorsque Slides est actif, `⌘B` correspond au Gras de Slides, et le menu auquel il appartient n’est pas celui auquel vous êtes habitué. Lorsqu’une combinaison ne se déclenche qu’avec une sélection, ou dans un volet particulier, la colonne Action l’indique.

## Conventions

- La colonne macOS utilise les symboles habituels : `⌘` Commande, `⌥` Option, `⇧` Maj, `⌃` Contrôle.
- La colonne Windows / Linux les écrit en toutes lettres : `Ctrl`, `Alt`, `Shift`.
- Lorsque GenOffice a réellement besoin de touches différentes sur les deux plateformes, la table le montre. Les cas courants sont `⌃H` pour Rechercher et remplacer (sur macOS, `⌘H` est réservé à Masquer), `⌥⌘G` pour Aller à, et la touche de fermeture de Slides.
- Une combinaison qui ne fonctionne qu’avec une sélection est écrite dans la colonne Action plutôt que de recevoir une colonne à elle, afin que chaque table reste large de trois colonnes.

## Word

Word possède une barre de menus complète : les combinaisons de fichier et de mise en forme ci-dessous fonctionnent dès qu’un onglet Word a le focus, quel que soit le document ouvert. Les combinaisons d’édition exigent un document chargé et modifiable, avec le curseur placé dans le texte ; elles ne se déclenchent pas pendant que vous tapez dans la zone de recherche, dans l’invite IA ou dans tout autre champ.

| ----------------- | ----- | --------------- |
| Nouveau           | ⌘N    | Ctrl+N          |

| Ouvrir…           | ⌘O    | Ctrl+O          |

`⌘P` n’est pas l’impression du navigateur. Word met d’abord en page un aperçu d’impression, si bien qu’une feuille imprimée correspond exactement à une page à l’écran, puis ouvre sa propre boîte de dialogue d’impression.

## Sheets

GenOffice Sheets est une grille compatible avec Excel. La plupart des raccourcis ci-dessous sont ceux d’Excel que vous connaissez déjà.

> **L’édition l’emporte.** Presque tous les raccourcis de Sheets sont ignorés pendant que vous modifiez une cellule ou que vous tapez dans la **barre de formule**, afin que la saisie, le déplacement du curseur et la touche Retour arrière conservent leur sens habituel en édition de texte. Si une touche semble ne rien faire, vérifiez si vous êtes en cours d’édition : appuyez d’abord sur Esc ou Enter, puis réessayez. Les commandes qui agissent sur la sélection ne font rien non plus tant qu’une boîte de dialogue est ouverte. Lorsqu’une combinaison fait exception à cette règle, la table le précise.

Deux conventions sont propres à Sheets. `⌘` et `⌃` occupent le même emplacement de modificateur — les deux sont acceptées sur toutes les plateformes, si bien que `⌘1` et `Ctrl+1` sont la même combinaison. **Une cellule Windows / Linux vide signifie que la combinaison n’existe que sur macOS.**

## Slides

GenOffice Slides est un éditeur de présentations de style PowerPoint. La plupart des touches font la même chose où que vous soyez, mais quelques-unes changent de sens selon l’élément qui a le focus — dans une zone de texte, ou quand le **volet des miniatures**, le **volet du plan** ou le **mode trieur de diapositives** a le focus clavier. Ces cas sont signalés dans la colonne Action.

### Fichier et application

| Action                             | macOS | Windows / Linux |
| ---------------------------------- | ----- | --------------- |
| Enregistrer                        | ⌘S    | Ctrl+S          |
| Enregistrer sous                   | ⇧⌘S   | Ctrl+Shift+S    |
| Ouvrir                             | ⌘O    | Ctrl+O          |
| Fermer l’onglet actuel             | ⌘W    | Ctrl+Q          |
| Imprimer                           | ⌘P    | Ctrl+P          |
| Annuler                            | ⌘Z    | Ctrl+Z          |
| Rétablir                           | ⇧⌘Z   | Ctrl+Shift+Z    |
| Rétablir (combinaison alternative) | ⌘Y    | Ctrl+Y          |

Fermer un onglet est le seul endroit où les deux plateformes se séparent complètement : `⌘W` sur macOS, et sous Windows et Linux Ctrl+Q, qui quitte toute l’application plutôt que l’onglet.

### Édition

| Action                                                         | macOS  | Windows / Linux |
| -------------------------------------------------------------- | ------ | --------------- |
| Nouvelle diapositive                                           | ⇧⌘N    | Ctrl+M          |
| Rechercher (pas pendant l’édition de texte dans une forme)     | ⌘F     | Ctrl+F          |

| Faire défiler la sélection de forme vers l’avant / l’arrière   | ⇥ / ⇧⇥ | Tab / Shift+Tab |

La nouvelle diapositive est l’autre divergence entre plateformes. Chaque plateforme a sa propre touche et l’autre ne fait rien : `⇧⌘N` sur macOS, Ctrl+M sous Windows et Linux. `⌘M` ne peut pas faire le travail sur macOS, car c’est la touche système Réduire.

Tout sélectionner suit le focus : quand le volet des miniatures, le volet du plan ou le trieur de diapositives a le focus, la commande sélectionne toutes les diapositives ; partout ailleurs, elle sélectionne tous les éléments de la diapositive en cours. Tab parcourt les formes de la diapositive, et uniquement lorsque le canevas de la diapositive lui-même a le focus.

## PDF

PDF n’a pas de menu propre : toutes les combinaisons ci-dessous suivent l’onglet actif et ne fonctionnent que lorsqu’un onglet PDF est au premier plan.

### Fichier et édition

| Action                           | macOS | Windows / Linux |
| -------------------------------- | ----- | --------------- |
| Enregistrer                      | ⌘S    | Ctrl+S          |
| Annuler                          | ⌘Z    | Ctrl+Z          |
| Rétablir                         | ⇧⌘Z   | Ctrl+Shift+Z    |
| Rechercher (ouvrir la recherche) | ⌘F    | Ctrl+F          |
| Imprimer                         | ⌘P    | Ctrl+P          |

Annuler et Rétablir font avancer l’historique du document ; lorsque le curseur se trouve dans un champ de texte, ils laissent `⌘Z` à ce champ. `⌘P` ouvre la même boîte de dialogue d’impression intégrée que le bouton Imprimer de la barre d’outils.

### Affichage

| Action               | macOS       | Windows / Linux |
| -------------------- | ----------- | --------------- |
| Zoom avant           | ⌘=          | Ctrl+=          |
| Zoom arrière         | ⌘-          | Ctrl+-          |
| Ajuster à la largeur | ⌘0          | Ctrl+0          |
| Zoom (continu)       | ⌘ + molette | Ctrl + molette  |

Le zoom avant répond aussi à `⌘+` et Ctrl++.

### Navigation entre les pages

| Action                                | macOS             | Windows / Linux   |
| ------------------------------------- | ----------------- | ----------------- |
| Page suivante                         | →                 | →                 |
| Page précédente                       | ←                 | ←                 |
| Faire défiler d’un écran vers le bas  | PageDown ou Space | PageDown ou Space |
| Faire défiler d’un écran vers le haut | PageUp            | PageUp            |
| Faire défiler vers le bas             | ↓                 | ↓                 |
| Faire défiler vers le haut            | ↑                 | ↑                 |
| Aller à la première page              | Home              | Home              |
| Aller à la dernière page              | End               | End               |

Ces touches ne prennent aucun modificateur, si bien que les deux plateformes se lisent de la même façon. ↓ et ↑ sont la seule ligne qui change selon le focus : dans le document, elles décalent la page, mais avec le focus dans la barre latérale des miniatures, elles avancent d’une page entière. Elles ne font rien pendant que vous tapez dans un champ.

### Échap et boîtes de dialogue

| Action                                 | macOS  | Windows / Linux |
| -------------------------------------- | ------ | --------------- |
| Annuler l’état le plus au premier plan | Escape | Escape          |
| Confirmer la boîte de dialogue ouverte | Enter  | Enter           |

Échap remonte une couche à la fois — d’abord une boîte de dialogue ouverte, puis le menu contextuel IA, un brouillon de texte, le panneau de recherche et enfin la sélection elle-même. Avec le curseur dans la zone de recherche, Enter et `⇧Enter` passent à la correspondance suivante et à la précédente, et Échap ferme le panneau ; avec le curseur dans une nouvelle note de texte, `⌘⏎` la valide.
