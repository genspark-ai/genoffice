# Docs: 문서 처리

Docs는 Word와 비슷한 문서 편집기입니다. 진짜 .docx를 읽고 쓰며, 쪽나누기를 WYSIWYG로 처리합니다.

## 리본

탭은 **홈 / 삽입 / 그리기 / 레이아웃 / 디자인 / 참조 / 검토 / 보기**이며, 선택한 개체에 따라 컨텍스트 탭(표 서식 및 레이아웃, 그림, 머리글/바닥글)이 추가됩니다.

- **홈**: 클립보드, 글꼴(동아시아 문자 크기와 강조 기호 포함)에 **모든 서식 지우기**와 **편집 기호 표시/숨기기** 전환, 단락(정렬/들여쓰기/줄 간격/목록)에 **새 글머리 기호 정의 / 새 번호 서식 정의 / 다단계 목록**(직접 만든 목록 스타일을 문서에 저장), 스타일(제목 1-6/기본/인용, 수정 가능)과 전체 목록을 보여 주는 **스타일 창**.
- **삽입**: 쪽 나누기/구역 나누기, 표(행 × 열 표, 정확한 크기는 **표 삽입…**), 그림, 도형, 텍스트 상자, 준비된 갤러리의 **표지**와 **새 페이지**, **차트**, **단락의 첫 문자 장식**, **WordArt**, 필드(날짜, 시간, 페이지 번호, 전체 페이지 수, 파일 이름), 하이퍼링크, **책갈피**와 상호 참조, 메모, 머리글/바닥글과 페이지 번호, 기호와 수식.
  - **차트**는 그림이 아니라 자체 데이터를 가진 실제 차트 개체를 삽입합니다 — 막대, 선, 원. Word의 _데이터 편집_으로 그 뒤의 숫자가 열립니다.
- **그리기**: 페이지 위에 잉크로 그리는 작업은 **그리기 도구** 그룹에서 합니다 — **선택**으로 텍스트 편집으로 돌아가고, 이어서 **펜**, **형광펜**, **지우개**(한 번 클릭하거나 한 번 쓸어내면 획 전체가 지워집니다). 그 옆의 **펜 스타일** / **형광펜 스타일**은 색 견본과 굵기 한 줄을 담은 하나의 조절 요소이며, 레이블은 지금 켜진 도구를 따라갑니다. 잉크는 텍스트 위에 떠 있는 주석으로 문서에 저장되므로 저장 후 다시 열어도 남아 있고, 다음 그룹의 **모두 지우기**가 전부 지웁니다.
- **레이아웃**: 여백, 용지 방향과 크기, 단, 단락 들여쓰기와 간격.
- **디자인**: 테마, 색 세트, 워터마크, 페이지 테두리.
- **참조**: 목차(업데이트 가능), 각주/미주, 캡션, 상호 참조.

  ![참조 탭](img/docs-references.png)

- **검토**: **편집기**는 문서 전체의 맞춤법, 문법, 문장부호를 검사합니다. **번역**, 맞춤법 검사, 메모(**AI 메모 처리**는 열려 있는 메모를 처리합니다), 변경 내용 추적(모든 표시/간단한 표시 보기, 적용/취소), **AI 변경 내용 요약**, 단어 개수, 다른 파일과 **비교**, **문서 보호**.
- **보기**: 파일을 보는 방법은 다섯 가지 — **인쇄 모양**, **웹 모양**, **개요**, **읽기 모드**, **페이지 미리 보기**; 축소/확대/백분율/페이지 너비/한 페이지, **AI 패널**, **다크 모드**, 눈금자, 눈금선, 탐색 창, **새 탭**, **분할**, **탭 전환**, 그리고 검색 가능한 **키보드 바로 가기** 대화상자.
  - **다크 모드**는 페이지와 그 주변 캔버스를 어둡게 하지만 리본은 결코 어둡게 하지 않습니다. 이것이 바로 Word가 어두운 편집 화면과 어두운 창을 나누는 방식입니다. 이 선택은 기억되며, 어느 경우든 앱 테마보다 우선합니다.
  - **분할**은 첫 번째 창을 그대로 되짚는, 독립적으로 스크롤되는 두 번째 창을 아래에 엽니다. 가장자리의 ×로 닫습니다.

## 탐색 창

**보기 ▸ 탐색 창**을 열면 문서의 제목 개요, 문서 전체를 대상으로 하는 검색 상자, 페이지마다 한 개씩의 축소 그림을 담은 옆 창이 열립니다. 열려 있는지는 실행할 때마다 기억되므로, 개요로 찾아 읽는 문서는 찾아 읽기 쉬운 상태로 이어집니다.

**개요**는 제목 트리입니다. 개요의 제목을 오른쪽 클릭하면 접는 것뿐만 아니라 구조도 바꿀 수 있습니다.

- 제목의**축소/확장**은 그 제목의 전체 하위 트리를 접습니다. 장은 사라지지만 본문 텍스트는 문서에 그대로 남습니다.
- **모두 축소/모두 확장**은 트리 전체를 한 번에 접거나 펼칩니다. 긴 보고서에서는 이것이 읽기 편한 개요와 글자 더미를 가르는 차이입니다.
- **제목 수준 표시**는 관심 있는 깊이만 트리에 남기므로, *제목 1 표시*로 두면 실제로 훑어볼 수 있는 목차만 남습니다.
- **수준 올리기/수준 내리기**는 제목의 수준을 바꾸고, 그 아래 모든 제목이 물려받는 수준도 함께 바꿉니다. 장이 절이 되는 것과 같은 방식입니다.
- **앞에 새 제목/뒤에 새 제목**은 창을 벗어나지 않고 커서 위치에 제목을 하나 삽입합니다.
- **삭제**는 제목과 *그 아래의 모든 것*을 함께 지웁니다. 이 항목만 주의하면 됩니다. 줄 삭제가 아니라 하위 트리 삭제입니다.
- **제목 및 내용 선택**은 제목부터 그 하위 트리의 끝까지 선택하므로, 절 전체를 한 번에 편집할 수 있습니다.

## 오른쪽 클릭 메뉴

본문 어디에서든 오른쪽 클릭하면 메뉴가 누른 대상에 따라 달라집니다. 주요 그룹은 다음과 같습니다.

- **클립보드**: 자르기/복사/붙여넣기/**서식 없이 붙여넣기**.
- **글꼴, 단락**: 리본으로 가지 않아도 글꼴과 크기, 굵게/기울임꼴/밑줄, 정렬/들여쓰기/줄 간격을 바꿉니다.
- **유의어**: 선택한 단어의 유의어를 목록으로 보여 줍니다. 하나를 누르면 교체됩니다.
- **번역**(AI): 선택한 문자열을 대상 언어(영어, 중국어 간체, 일본어, 한국어, 프랑스어, 독일어, 스페인어 등)로 AI 패널을 통해 번역합니다.
- **새 메모**: 선택 범위에 메모를 붙입니다.
- **맞춤법**(철자가 틀린 단어에서): 대안으로 바꾸기, 모두 무시, 사전에 추가, 교정 언어 설정.
- **하이퍼링크**: 열기 / 편집 / 링크 복사 / 하이퍼링크 제거.
- **그림**: 이미지 보기, 이미지로 저장, **텍스트 줄 바꿈**(글자와 같은 줄/좌우로 감싸기/위아래로 감싸기/글자 뒤/글자 앞), 겹침 순서 바꾸기.
- **필드**(목차, 페이지 번호 등): 필드 업데이트/필드 코드 표시 전환/필드 편집.
- **번호 매기기**(목록 안에서): 번호 다시 매기기/번호 계속 매기기/목록 수준 변경/번호 매기기 값 설정.
- **표**(커서가 표 안일 때): 행/열 삽입, 셀 병합/분할, 표 분할, 셀 크기에 맞춤, 셀 맞춤, 행/열 너비 균등 조정, 표 속성, 삭제 메뉴, 선택.

## 편집

- 찾아바꾸기(ctrl+F / ctrl+H): 대/소문자 구분, 단어 단위, 정규식.
- 서식 복사, 여러 단계 실행 취소/다시 실행, 붙여넣기 옵션.
- 표: 셀 병합/분할, 행/열 조작, 테두리와 음영, 정렬, 수식.
- 그림: 텍스트 줄 바꿈, 자르기, 압축, 그리기 캔버스.

## 동아시아 조판

- 문장부호 압축과 금칙 처리는 Word와 맞추어져 있습니다. 전각/반각 변환도 됩니다.
- 글꼴 후보는 Windows와 macOS의 일반적인 동아시아 계열 이름을 다룹니다.

## AI

- 리본의 AI 버튼과 옆 패널: 다시 쓰기, 늘이기, 번역, 요약, 표 삽입 프리셋에 더해 자유로운 지시도 줄 수 있습니다.
- AI는 매 회 변경하기 전에 스냅숏을 남깁니다. 버전 목록에서 되돌릴 수 있고, 되돌린 것 자체도 다시 되돌릴 수 있습니다.

## 저장과 내보내기

- .docx로 저장합니다. 바뀐 단락만 다시 쓰므로 건드리지 않은 부분은 바이트 단위로 그대로입니다.
- PDF(현재 쪽나누기 그대로)와 한 페이지씩 이미지로 내보냅니다.

## 인쇄

ctrl+P로 시스템 대화상자를 열어 WYSIWYG 페이지로 인쇄합니다.
