# Docs: 문서 처리

Docs는 Microsoft Word와 깊이 호환되는 본격적인 워드프로세서입니다. 표준 `.docx` 파일을 직접 읽고 쓰며, 화면에서 보이는 줄 바꿈과 다중 페이지 표 분할, 머리글과 바닥글이 인쇄물 및 내보낸 PDF에서도 똑같이 재현되는 정밀한 WYSIWYG 쪽나누기 엔진을 제공합니다.

## 리본

탭은 **홈 / 삽입 / 그리기 / 레이아웃 / 디자인 / 참조 / 검토 / 보기**이며, 선택한 개체에 따라 컨텍스트 탭(표 서식 및 레이아웃, 그림, 머리글/바닥글)이 자동으로 추가됩니다. Docs의 명령 띠에는 별도의 밀도 모드가 있습니다: **컴팩트**(⌥⌘K / Ctrl+Alt+K)는 아이콘만 남기고 텍스트 라벨을 숨겨 세로 편집 공간을 넓혀 주며, 선택한 상태는 다음 실행 때도 그대로 기억됩니다.

- **홈**: 클립보드와 서식 복사, 글꼴(동아시아 전통 글자 크기와 강조점, 위/아래 첨자 포함)에 **모든 서식 지우기**와 **편집 기호 표시/숨기기** 전환, 단락(정렬/들여쓰기/줄 간격/목록)에 **새 글머리 기호 정의 / 새 번호 서식 정의 / 다단계 목록**(직접 만든 목록 번호 스타일을 문서에 저장), 스타일(제목 1-6/기본/인용, 모두 수정 가능)과 전체 목록을 보여 주는 **스타일 창**. 스타일에서는 동아시아(한글·한자) 글꼴과 라틴(영문·숫자) 글꼴을 따로 지정할 수 있으며(예: 한글 글꼴에 Times New Roman 조합), 이 글꼴 쌍은 `.docx` 저장과 Word 왕복 편집에서도 온전히 유지됩니다.
- **삽입**: 쪽 나누기/구역 나누기, 표(행 × 열 격자 선택, 또는 정확한 크기와 자동 맞춤을 지정하는 **표 삽입…**), 그림, 도형, 텍스트 상자, 내장 갤러리의 **표지**와 **새 페이지**, **차트**, **단락의 첫 문자 장식(Drop Cap)**, **WordArt**, 동적 필드(날짜, 시간, 페이지 번호, 전체 페이지 수, 파일 이름), 하이퍼링크, **책갈피**와 상호 참조, 메모, 구역별 머리글/바닥글과 페이지 번호, 특수 기호와 수식.
  - **차트**는 단순한 정적 그림이 아니라 자체 데이터 표를 품은 실제 차트 개체(막대형, 꺾은선형, 원형 등)를 삽입하므로, GenOffice에서든 Word의 _데이터 편집_에서든 언제나 그 뒤의 원본 숫자를 열어 수정하고 차트를 다시 그릴 수 있습니다.
- **그리기**: 페이지 위에 자유롭게 펜으로 필기하고 표시하는 작업은 **그리기 도구** 그룹에서 합니다 — **선택**을 누르면 일반 텍스트 편집으로 돌아가고, 이어서 **펜**, **형광펜**, **지우개**(한 번 클릭하거나 가볍게 쓸어내면 획 전체가 깔끔하게 지워집니다)를 사용할 수 있습니다. 그 옆의 **펜 스타일** / **형광펜 스타일**은 색상 팔레트와 선 굵기 목록을 하나로 묶은 컨트롤이며, 레이블은 현재 켜진 도구를 자동으로 따라갑니다. 그린 잉크는 텍스트 위에 떠 있는 표준 주석 레이어로 문서에 저장되므로 저장 후 다시 열어도 그대로 남아 있고, 옆 그룹의 **모두 지우기**를 누르면 페이지의 모든 필기를 한 번에 지울 수 있습니다.
- **레이아웃**: 페이지 여백, 용지 방향(세로/가로)과 표준 용지 크기, 다단 편집, 단락 들여쓰기와 단락 앞뒤 간격을 세밀하게 조정합니다.
- **디자인**: 문서 전체의 테마, 색상 세트, 대각선 텍스트나 그림 워터마크, 페이지 테두리를 설정합니다.
- **참조**: 클릭해 이동하고 페이지 번호를 언제든 새로 고칠 수 있는 자동 목차, 각주/미주, 그림·표 캡션, 제목이나 책갈피를 가리키는 동적 상호 참조를 삽입합니다.

  ![참조 탭](img/docs-references.png)

- **검토**: **편집기**는 문서 전체의 맞춤법, 문법, 문장부호를 한 번에 교정합니다. 다국어 AI **번역**, 맞춤법 검사, 메모(**AI 메모 처리**를 누르면 아직 해결되지 않은 검토 메모를 AI가 읽고 본문 수정을 대신 적용합니다), 변경 내용 추적(모든 표시/간단한 표시 보기 전환, 개별 또는 일괄 적용/취소), 변경된 핵심을 요약해 주는 **AI 변경 내용 요약**, 실시간 단어·글자 수 통계, 다른 버전의 파일과 차이를 대조하는 **비교**, 그리고 무단 수정을 막는 **문서 보호**를 제공합니다.
- **보기**: 문서를 살펴보는 다섯 가지 보기 모드 — **인쇄 모양**, **웹 모양**, **개요**, **읽기 모드**, **페이지 미리 보기**; 축소/확대/100%/페이지 너비/한 페이지 맞춤, 오른쪽 **AI 패널**, **다크 모드**, 눈금자, 눈금선, 왼쪽 탐색 창, **새 탭**, 상하 창 **분할**, **탭 전환**, 그리고 모든 단축키를 실시간 검색할 수 있는 **키보드 바로 가기**(`⌘/` 또는 `Ctrl+/`) 대화상자.
  - **다크 모드**는 편집 중인 종이 표면과 주변 캔버스만 눈이 편안한 어두운 색으로 바꾸고 상단 리본은 원래 모습을 유지합니다 — Word가 어두운 편집 화면과 창 테마를 구분하는 방식과 같으며, 실제 인쇄나 PDF 내보내기 시에는 원래 작성된 글자색과 흰 종이 배경이 그대로 출력됩니다. 이 설정은 따로 기억되며 앱 전체 테마보다 우선합니다.
  - **분할**은 현재 편집 창 바로 아래에 독립적으로 스크롤되는 두 번째 창을 열어 같은 문서의 앞부분과 뒷부분을 동시에 띄워 놓고 대조하며 편집할 수 있게 해 주며, 경계선 가장자리의 `×` 버튼으로 언제든 닫을 수 있습니다.
- **스타일이 없는 문서의 스마트 개요 추론**: 계약서나 외부에서 가져온 문서처럼 정식 '제목 1 / 제목 2' 스타일을 적용하지 않고 짧은 굵은 글씨 줄, 전체 대문자 줄, 혹은 로마 숫자·아라비아 숫자 번호가 붙은 짧은 단락(예: `I. BACKGROUND` 또는 `1. 사업 개요`)으로만 절을 구분한 문서에서도, Docs가 원본 파일을 단 1바이트도 바꾸지 않은 채 문맥 구조를 파악하여 개요 보기와 스토리 보기에 '추론된 제목' 표시와 함께 목차를 자동으로 구성해 줍니다. 추론된 항목에 정식 제목 스타일을 적용하면 즉시 실제 문서 제목으로 승격됩니다.

## 탐색 창

**보기 ▸ 탐색 창**을 열면 문서의 제목 개요, 문서 전체를 대상으로 하는 검색 상자, 페이지마다 한 개씩의 축소 그림을 담은 옆 창이 열립니다. 열려 있는지는 실행할 때마다 기억되므로, 개요로 찾아 읽는 문서는 찾아 읽기 쉬운 상태로 이어집니다.

**개요**는 제목 트리입니다. 개요의 제목을 오른쪽 클릭하면 접는 것뿐만 아니라 구조도 바꿀 수 있습니다.

- 제목의**축소/확장**은 그 제목의 전체 하위 트리를 접습니다. 장은 사라지지만 본문 텍스트는 문서에 그대로 남습니다.
- **모두 축소/모두 확장**은 트리 전체를 한 번에 접거나 펼칩니다. 긴 보고서에서는 이것이 읽기 편한 개요와 글자 더미를 가르는 차이입니다.
- **제목 수준 표시**는 관심 있는 깊이만 트리에 남기므로, *제목 1 표시*로 두면 실제로 훑어볼 수 있는 목차만 남습니다.
- **수준 올리기/수준 내리기**는 제목의 수준을 바꾸고, 그 아래 모든 제목이 물려받는 수준도 함께 바꿉니다. 장이 절이 되는 것과 같은 방식입니다.
- **앞에 새 제목/뒤에 새 제목**은 창을 벗어나지 않고 커서 위치에 제목을 하나 삽입합니다.
- **삭제**는 제목과 *그 아래의 모든 것*을 함께 지웁니다. 이 항목만 주의하면 됩니다. 줄 삭제가 아니라 하위 트리 삭제입니다.
- **제목 및 내용 선택**은 제목부터 그 하위 트리의 끝까지 선택하므로, 절 전체를 한 번에 편집할 수 있습니다.

## 오른쪽 클릭 메뉴

본문 어디에서든 오른쪽 클릭하면 메뉴가 누른 대상에 따라 달라집니다. 주요 그룹은 다음과 같습니다.

- **클립보드**: 자르기/복사/붙여넣기/**서식 없이 붙여넣기**.
- **글꼴, 단락**: 리본으로 가지 않아도 글꼴과 크기, 굵게/기울임꼴/밑줄, 정렬/들여쓰기/줄 간격을 바꿉니다.
- **유의어**: 선택한 단어의 유의어를 목록으로 보여 줍니다. 하나를 누르면 교체됩니다.
- **번역**(AI): 선택한 문자열을 대상 언어(영어, 중국어 간체, 일본어, 한국어, 프랑스어, 독일어, 스페인어 등)로 AI 패널을 통해 번역합니다.
- **새 메모**: 선택 범위에 메모를 붙입니다.
- **맞춤법**(철자가 틀린 단어에서): 대안으로 바꾸기, 모두 무시, 사전에 추가, 교정 언어 설정.
- **하이퍼링크**: 열기 / 편집 / 링크 복사 / 하이퍼링크 제거.
- **그림**: 이미지 보기, 이미지로 저장, **텍스트 줄 바꿈**(글자와 같은 줄/좌우로 감싸기/위아래로 감싸기/글자 뒤/글자 앞), 겹침 순서 바꾸기.
- **필드**(목차, 페이지 번호 등): 필드 업데이트/필드 코드 표시 전환/필드 편집.
- **번호 매기기**(목록 안에서): 번호 다시 매기기/번호 계속 매기기/목록 수준 변경/번호 매기기 값 설정.
- **표**(커서가 표 안일 때): 행/열 삽입, 셀 병합/분할, 표 분할, 셀 크기에 맞춤, 셀 맞춤, 행/열 너비 균등 조정, 표 속성, 삭제 메뉴, 선택.

## 편집

- 찾아바꾸기(ctrl+F / ctrl+H): 대/소문자 구분, 단어 단위, 정규식.
- 서식 복사, 여러 단계 실행 취소/다시 실행, 붙여넣기 옵션.
- 표: 셀 병합/분할, 행/열 조작, 테두리와 음영, 정렬, 수식. 행은 필요하면 페이지를 넘어 나뉘고, 셀 안에서 Ctrl+Enter를 누르면 그 지점에서 페이지가 넘어갑니다 — 인쇄와 PDF도 같습니다.
- 그림: 텍스트 줄 바꿈, 자르기, 압축, 그리기 캔버스.

## 동아시아 조판

- 문장부호 압축과 금칙 처리는 Word와 맞추어져 있습니다. 전각/반각 변환도 됩니다.
- 글꼴 후보는 Windows와 macOS의 일반적인 동아시아 계열 이름을 다룹니다.

## AI

- 리본의 AI 버튼과 옆 패널: 다시 쓰기, 늘이기, 번역, 요약, 표 삽입 프리셋에 더해 자유로운 지시도 줄 수 있습니다.
- AI는 매 회 변경하기 전에 스냅숏을 남깁니다. 버전 목록에서 되돌릴 수 있고, 되돌린 것 자체도 다시 되돌릴 수 있습니다.

## 저장과 내보내기

- **변경된 단락만 다시 쓰는 바이트 보존형 `.docx` 저장**: 저장할 때 실제로 수정한 단락의 XML만 다시 기록하므로, 건드리지 않은 나머지 단락과 복잡한 필드, 원본 서식 구조는 바이트 단위로 원본과 완전히 동일하게 보존됩니다.
- **PDF 및 페이지별 이미지 내보내기**: 현재 화면의 쪽나누기 결과 그대로 표준 PDF 파일로 내보내거나 각 페이지를 고해상도 PNG 이미지로 내보낼 수 있습니다.

## 인쇄

`⌘P` / `Ctrl+P`를 눌러 내장 WYSIWYG 페이지 인쇄 미리보기를 열고 용지 크기와 인쇄 범위를 확인한 뒤 시스템 인쇄 대화상자로 출력합니다.

- **커서가 있는 페이지에서 바로 열리는 인쇄 미리보기**: 수십 페이지짜리 긴 문서의 중간을 편집하다가 `⌘P` / `Ctrl+P`(또는 '파일 ▸ 인쇄')를 눌러 인쇄 미리보기를 열면, 매번 1페이지부터 다시 스크롤해 내려갈 필요 없이 현재 텍스트 커서가 놓여 있는 바로 그 페이지가 즉시 펼쳐집니다.
