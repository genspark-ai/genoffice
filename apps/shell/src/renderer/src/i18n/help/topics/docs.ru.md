# Docs: работа с текстом

Docs — текстовый редактор, похожий на Word: читает и пишет настоящие .docx с настоящей пагинацией «как на экране».

## Лента

Вкладки: **Главная / Вставка / Макет / Конструктор / Ссылки / Рецензирование / Вид**, а также контекстные вкладки для выбранного объекта (конструктор таблиц, рисунки).

- **Главная**: буфер обмена; шрифт (включая кегли для CJK и знаки выделения); абзац (выравнивание/отступы/интервалы/списки); стили (Заголовок 1-6/Обычный/Цитата, изменяемые).
- **Вставка**: разрывы страницы и раздела, таблицы (включая быстрые таблицы), рисунки, фигуры, гиперссылки, колонтитулы, номера страниц, дата, надписи.
- **Макет**: поля, ориентация и размер бумаги, колонки, отступы и интервалы абзаца.
- **Конструктор**: темы, наборы цветов, подложка (водяной знак), границы страниц.
- **Ссылки**: оглавление (обновляется), сноски и концевые сноски, названия, перекрёстные ссылки.

  ![Вкладка «Ссылки»](img/docs-references.png)

- **Рецензирование**: проверка орфографии, примечания, исправления (представления «Все» и «Простое»), статистика.
- **Вид**: линейка, сетка, область навигации, масштаб и **окно сочетаний клавиш** с поиском.

## Меню по правому щелчку

Щёлкните правой кнопкой в любом месте текста — меню подстраивается под то, что вы выбрали. Основные группы:

- **Буфер обмена**: вырезать / копировать / вставить / **вставить как обычный текст**.
- **Шрифт, абзац**: сменить гарнитуру и кегль, полужирный/курсив/подчёркивание, выравнивание/отступы/интервалы, не заходя на ленту.
- **Синонимы**: показывают синонимы выбранного слова; щёлкните по одному, чтобы заменить.
- **Перевод** (ИИ): переводит выделенное на целевой язык (английский, упрощённый китайский, японский, корейский, французский, немецкий, испанский, ...) через панель ИИ.
- **Создать примечание**: прикрепляет примечание к выделенному.
- **Правописание** (на ошибочном слове): предлагаемые замены, пропустить все, добавить в словарь, задать язык проверки.
- **Гиперссылка**: открыть / изменить / скопировать ссылку / удалить гиперссылку.
- **Рисунок**: открыть изображение, сохранить изображение как…, **обтекание текстом** (в тексте / квадрат слева и справа / сверху и снизу / за текстом / перед текстом), порядок размещения.
- **Поля** (оглавление, номера страниц): обновить поле / показать или скрыть коды полей / изменить поле.
- **Нумерация списка** (внутри списка): начать нумерацию заново / продолжить нумерацию / изменить уровень списка / задать значение нумерации.
- **Таблица** (курсор внутри таблицы): вставить строки/столбцы, объединить / разделить ячейки, разделить таблицу, подобрать размер, выравнивание ячеек, распределить строки/столбцы, свойства таблицы, меню удаления, выделение.

## Редактирование

- Поиск и замена (ctrl+F / ctrl+H): с учётом регистра, по целому слову, регулярные выражения.
- Формат по образцу, глубокая отмена и повтор, параметры вставки.
- Таблицы: объединение и разделение ячеек, операции со строками и столбцами, границы и заливка, сортировка, формулы.
- Рисунки: обтекание текстом, обрезка, сжатие; холст для рисования.

## Типографика CJK

- Сжатие знаков препинания и правила переноса кинсоку совпадают с Word; есть перевод из полноширинных символов в полуширинные и обратно.
- Список предлагаемых шрифтов охватывает распространённые названия семейств CJK в Windows и macOS.

## ИИ

- Кнопка ИИ на ленте и боковая панель: переписать, развернуть, перевести, кратко изложить, вставить таблицу, а также произвольные инструкции.
- Каждый заход ИИ сначала делает снимок; откат доступен из списка версий, причём сам откат тоже можно отменить.

## Сохранение и экспорт

- При сохранении .docx перезаписываются только изменившиеся абзацы — нетронутое содержимое остаётся побайтово тем же.
- Экспорт в PDF (с текущей пагинацией) и в картинки постранично.

## Печать

ctrl+P через системный диалог, страницы выглядят так же, как будут напечатаны.
