# 설정, 언어, 테마와 MCP 연동

## 설정 열기

홈의 왼쪽 아래 계정 줄에서 설정 패널을 엽니다(로그아웃한 상태에서는 "로그인"으로 표시됩니다). 이 패널에는 여섯 개 절이 있습니다: 계정, AI 모델, AI 미디어 및 검색, 일반, 연동, 정보.

![설정 ▸ 일반 — 언어, 테마, 자동 저장, 사용량 통계 스위치가 있는 곳](img/settings-general.png)

모델 구성에는 별도 장이 있습니다. **AI 미디어 및 검색**에서 제공업체별로 이미지 생성, 이미지 분석, 동영상 분석, 웹 검색, 로컬 파일 검색을 켭니다.

## 언어

- 설정에서는 **21개의 UI 언어**를 제공합니다: 영어, 중국어 간체, 일본어, 한국어, 프랑스어, 독일어, 스페인어, 태국어, 인도네시아어, 러시아어, 아랍어, 포르투갈어, 이탈리아어, 폴란드어, 체코어, 네덜란드어, 말레이어, 히브리어, 힌디어, 중국어 번체, 베트남어.
- 전환은 즉시 적용되어 유지되며, 네이티브 메뉴 바도 그 언어로 다시 만들어집니다.

## 테마

라이트/다크/시스템 따르기 세 가지입니다. 시스템 따르기를 고르면 OS 화면 설정에 따라 바뀌고, 편집기 영역도 함께 바뀝니다(깜빡임 없음).

## 기본 앱 연결

설정에서 .docx / .xlsx / .pptx / .pdf 등의 파일을 GenOffice로 열도록 등록할 수 있습니다(플랫폼 수준의 기본 앱 등록. 물으면 확인합니다).

## 서드파티 고지 및 업데이트

- 도움말 ▸ 타사 소프트웨어 고지: 앱에 함께 들어 있는 전체 OSS 라이선스 목록.
- 도움말 ▸ 업데이트 확인: 수동으로 한 번 검사합니다. 새 버전이 있으면 설치를 권합니다.

## Genspark 로그인

- 로그인 진입점(설정 또는 클라우드 프로젝트 목록)은 **기기 코드** 방식을 씁니다. GenOffice가 코드를 보여 주고 브라우저 로그인을 엽니다. 끝나면 자동으로 이어집니다.
- 로그인은 클라우드 프로젝트 목록과 Genspark 제공형 모델에만 쓰입니다. 로그인하지 않아도 모든 로컬 기능과 사용자 지정 모델은 계속 동작합니다.
- 로그아웃은 설정에서 한 번 클릭하면 됩니다.

## MCP 연동(고급 사용자/AI 클라이언트용)

GenOffice를 코딩 에이전트에 연결하는 곳이 **연동** 패널입니다. 이 주제만 다룬 별도 문서 「코딩 에이전트 연결」이 있습니다. 요약하면 — 방법(명령줄 또는 MCP)을 고르고 그 절을 따라간 뒤, 새 대화를 열어 물어보세요.

![설정 ▸ 연동: 세 단계, 그다음 스킬 행과 MCP 옵션](img/settings-integrations.png)

**로컬 HTTP 서버**에서는 어시스턴트에게 맡기는 대신 앱이 서버를 직접 실행하게 할 수도 있습니다(켜기 스위치, 포트). 그리고 **고급**이 상태 확인 URL과 로그 파일을 더합니다. localhost에서만 수신합니다.

## 명령줄 요약

| 명령               | 하는 일            |
| ------------------ | ------------------ |
| `genoffice <file>` | 파일 열기          |
| `genoffice mcp`    | 로컬 MCP 서버 시작 |
| `genoffice --help` | 모든 명령과 옵션   |
