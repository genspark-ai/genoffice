# HTML 편집기

HTML 편집기는 .html / .htm을 두 가지 모드로 엽니다. **미리보기**(렌더링된 페이지)와 **소스**입니다.

- **미리보기**: 실제로 렌더링됩니다. 상대 경로의 스타일시트와 이미지는 파일 옆에서 불러옵니다.
- **미리보기 검사기**: 눌러 요소를 선택하고, 더블클릭해 그 자리에서 글자를 편집하고, 도구 모음에서 삭제하고, 선택한 내용에 대해 AI 수정 요청을 할 수 있습니다.
- **소스 모드**: HTML을 편집합니다. ctrl+F로 찾고, 모두 바꾸면 고쳐 쓴 마크업을 저장합니다.
- **저장**: 바이트 단위로 충실합니다(BOM/CRLF/끝 줄바꿈 보존). 수정하지 않았다면 다시 쓰지 않습니다.
- **확대/축소**: ctrl+휠/핀치로 미리보기 비율을 바꿉니다. 미리보기 안에서 ctrl+Z는 마지막 편집을 되돌립니다.

## 도구 모음

미리보기에서 요소를 누르면 그 위에 도구 모음이 떠오릅니다.

![선택한 요소 위에 뜬 도구 모음](img/html-toolbar.png)

- **파일과 기록**: 저장, 다른 이름으로 저장, 실행 취소, 다시 실행, 찾기. **자동 저장** 전환이 변경을 주기적으로 기록합니다.
- **미리보기 / 소스** 전환. **전체 화면**으로 페이지를 전 화면에 표시합니다.
- **서식**: 굵게, 기울임꼴, 글꼴 크기 늘이기/줄이기. 선택한 요소의 **스타일 패널**(색 등).
- **삽입**: 제목, 단락, 표, 이미지(링크로 지정), 기타.
- **이미지 작업**(이미지를 선택했을 때): 자르기, **배경 제거**, 바꾸기, 가로세로 비율 고정.
- **요소 작업**(미리보기 검사기에서 요소를 선택했을 때): 삭제, 복제, 위로/아래로 이동.
- **AI 버튼**: AI 패널을 엽니다. 선택한 요소에 대해 바로 물어볼 수 있습니다.

## 내보내기

파일 메뉴에 있으며 모두 로컬 작업이고, 저장 위치도 모두 묻습니다.

- **Word로 내보내기…**와 **PDF로 내보내기…**는 실제 .docx 또는 .pdf를 씁니다.
- **단일 파일 HTML로 내보내기…** 이미지를 내장한 단일 .html 파일을 씁니다. 지금 열려 있는 파일을 덮어쓰지 않으며, 내장하지 못한 이미지 개수를 알려 줍니다.

## 스켈레톤 삽입

빈 페이지에서는 **삽입 ▸ 스켈레톤 삽입**으로 최소한의 표준 모드 문서를 씁니다:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

각 부분에 이유가 있기 때문에, 입력하는 것이 아니라 명령입니다:

- **doctype**가 없으면 미리보기가 quirks 모드로 돌아가서, 박스 크기 계산과 표 레이아웃이 생각과 다른 규칙을 따릅니다.
- **`lang`**가 없으면 스크린 리더가 페이지를 읽을 언어가 없어서, 브라우저가 엉뚱한 언어의 글꼴과 맞춤법 검사기를 고릅니다.
- **charset**가 없으면 라틴 문자가 아닌 텍스트가 깨진 글자로 해석될 수 있습니다.

뷰포트 meta는 일부러 넣지 않았습니다. 데스크톱 창에서 그려지므로, 영향을 줄 모바일 뷰포트가 없습니다.

`lang`은 앱의 UI 언어를 따릅니다. 그래서 삽입되는 스켈레톤은 지금 쓰는 도구가 이미 맞춰 둔 것과 같습니다. 그다음에는 편하게 고치세요.

이 항목은 편집 모드에서, 문서가 비어 있을 때만 보입니다. 내용이 있으면 스켈레톤을 넣을 _자리가_ 없기 때문입니다.
