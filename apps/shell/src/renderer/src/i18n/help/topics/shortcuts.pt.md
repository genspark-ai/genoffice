# Atalhos de teclado

Cada editor tem as suas próprias combinações de teclas, e apenas algumas funcionam em todo o lado. Esta página é a lista completa, agrupada por aplicativo, com a combinação de macOS e a de Windows / Linux lado a lado.

## Leia primeiro

**Quase nada disto é global.** As três teclas de acesso abaixo são-no; tudo o que se segue pertence ao aplicativo que tiver à frente, e muda quando muda de guia.

| Ação                                                      | macOS | Windows / Linux |
| --------------------------------------------------------- | ----- | --------------- |
| Abrir o guia do usuário — funciona em todo o aplicativo   | F1    | F1              |
| Recolher / expandir a faixa de opções — todos os editores | ⌥⌘R   | Ctrl+F1         |
| Faixa compacta — só Docs                                  | ⌥⌘K   | Ctrl+Alt+K      |
| Abrir a folha de atalhos de teclado — apenas Word         | ⌘/    | Ctrl+/          |

- **F1 abre este manual**, não a folha de atalhos. A tecla pertence ao menu do aplicativo, por isso funciona igualmente a partir de Word, Sheets, Slides, PDF ou da guia Início.
- **O interruptor da faixa de opções é `Ctrl+F1`, ou `⌥⌘R` no macOS.** Pressionar `F1` sozinho não faz nada — F1 é o manual, e a tecla da faixa de opções deliberadamente não compartilha essa combinação. `Ctrl+F1` também é aceito no macOS, mas `⌥⌘R` é a tecla que o Office para Mac usa.
- **A folha de atalhos de teclado é só do Word** (`⌘/`). Lista exatamente a tabela do Word abaixo. Nenhum outro editor tem uma.

![A folha de atalhos de teclado do próprio Word: a ação à esquerda, o atalho à direita, agrupados por Arquivo, Edição, Formatação de texto, Formatação de parágrafo, Inserir, Revisão e ferramentas, Vista](img/word-shortcuts.png)

- **`⌘O`, `⌘S` e `⌘P` estão implementados à parte por trás de cada editor**, e não se comportam exatamente da mesma forma. O `⌘P` do Word dispõe primeiro uma pré-visualização de impressão, de modo que uma folha impressa corresponda exatamente a uma página na tela; o do PDF abre a caixa de diálogo de impressão de PDF; o Sheets e o Slides têm novamente as suas.
- **O resto é por aplicativo.** Quando a guia do Word está ativa, `⌘B` é o Negrito do Word. Quando está o do Slides, `⌘B` é o Negrito do Slides, e o menu a que pertence não é aquele a que está habituado. Sempre que uma combinação só dispara com algo selecionado, ou em um painel concreto, a coluna Ação indica-o.

## Convenções

- A coluna de macOS usa os símbolos habituais: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- A coluna de Windows / Linux escreve-os por extenso: `Ctrl`, `Alt`, `Shift`.
- Onde o GenOffice precisa mesmo de teclas diferentes nas duas plataformas, a tabela mostra-o. Os casos comuns são `⌃H` para Localizar e substituir (no macOS, `⌘H` é para Ocultar), `⌥⌘G` para Ir para, e a tecla de fechar do Slides.
- Uma combinação que só funciona com uma seleção escreve-se na coluna Ação em vez de ter coluna própria, para que a tabela se mantenha com três colunas.

## Word

O Word tem uma barra de menus completa, por isso as combinações de arquivo e de formatação abaixo funcionam assim que uma guia do Word tenha o foco, seja qual for o documento aberto. As combinações de edição exigem um documento carregado e editável, com o cursor no texto; não disparam enquanto escreve na caixa de pesquisa, no pedido de IA ou em qualquer outro campo.

## Sheets

O GenOffice Sheets é uma grade compatível com o Excel. A maioria dos atalhos abaixo são os do Excel que já conhece.

> **A edição ganha.** Quase todos os atalhos do Sheets são ignorados enquanto edita uma célula ou escreve na **barra de fórmulas**, para que escrever, mover o cursor e a tecla Retrocesso mantenham o seu significado habitual de edição de texto. Se uma tecla parecer não fazer nada, verifique se está a meio de uma edição: pressione primeiro Esc ou Enter e tente de novo. Os comandos que atuam sobre a seleção também não fazem nada enquanto houver uma caixa de diálogo aberta. Onde uma combinação seja a exceção a esta regra, a tabela indica-o.

Duas convenções são próprias do Sheets. `⌘` e `⌃` ocupam a mesma posição de modificador — ambas são aceites em todas as plataformas, por isso `⌘1` e `Ctrl+1` são a mesma combinação. **Uma célula de Windows / Linux vazia significa que a combinação só existe no macOS.**

## Slides

O GenOffice Slides é um editor de apresentações ao estilo do PowerPoint. A maioria das teclas faz o mesmo onde quer que esteja, mas algumas mudam de significado conforme o foco — dentro de uma caixa de texto, ou enquanto o **painel de miniaturas**, o **painel de esquema** ou o **organizador de slides** tiver o foco de teclado. Esses casos estão marcados na coluna Ação.

### Arquivo e aplicativo

| Ação                             | macOS | Windows / Linux |
| -------------------------------- | ----- | --------------- |
| Salvar                           | ⌘S    | Ctrl+S          |
| Salvar como                      | ⇧⌘S   | Ctrl+Shift+S    |
| Abrir                            | ⌘O    | Ctrl+O          |
| Fechar a guia atual              | ⌘W    | Ctrl+Q          |
| Imprimir                         | ⌘P    | Ctrl+P          |

| Refazer                          | ⇧⌘Z   | Ctrl+Shift+Z    |
| Refazer (combinação alternativa) | ⌘Y    | Ctrl+Y          |

Fechar uma guia é o único local onde as duas plataformas se separam por completo: `⌘W` no macOS e, no Windows e Linux, Ctrl+Q, que sai de todo o aplicativo em vez de apenas da guia.

| Ação                                                    | macOS  | Windows / Linux |

O novo slide é a outra divisão entre plataformas. Cada plataforma tem a sua própria tecla e a outra não faz nada: `⇧⌘N` no macOS, Ctrl+M no Windows e Linux. `⌘M` não pode fazer o trabalho no macOS porque é a tecla do sistema para minimizar.

Selecionar tudo segue o foco: com o painel de miniaturas, o painel de esquema ou o organizador de slides com o foco, seleciona todos os slides, e em qualquer outro local seleciona todos os elementos do slide atual. Tab percorre as formas do slide, e só quando o próprio painel do slide tem o foco.

## PDF

O PDF não tem menu próprio, por isso todas as combinações abaixo seguem a guia ativa e só funcionam enquanto uma guia de PDF estiver à frente.

### Arquivo e edição

| Ação                         | macOS | Windows / Linux |
| ---------------------------- | ----- | --------------- |
| Salvar                       | ⌘S    | Ctrl+S          |
| Anular                       | ⌘Z    | Ctrl+Z          |
| Refazer                      | ⇧⌘Z   | Ctrl+Shift+Z    |
| Localizar (abrir a pesquisa) | ⌘F    | Ctrl+F          |
| Imprimir                     | ⌘P    | Ctrl+P          |

Anular e Refazer avançam no histórico do documento; quando o cursor está em um campo de texto, deixam `⌘Z` para esse campo. `⌘P` abre a mesma caixa de diálogo de impressão do aplicativo que o botão Imprimir na barra de ferramentas.

### Vista

| Zoom (contínuo)   | ⌘ + roda do mouse | Ctrl + roda do mouse |

Ampliar também responde a `⌘+` e Ctrl++.

### Navegação de páginas

| Ação                         | macOS             | Windows / Linux   |
| ---------------------------- | ----------------- | ----------------- |
| Página seguinte              | →                 | →                 |
| Página anterior              | ←                 | ←                 |

| Deslocar uma tela para cima  | PageUp            | PageUp            |

Não levam modificador, por isso as duas plataformas se leem da mesma forma. ↓ e ↑ são a única linha que muda com o foco: no documento deslocam a página, mas com o foco na barra lateral de miniaturas avançam uma página inteira. Não fazem nada enquanto escreve em um campo.

### Escape e caixas de diálogo

| Ação                                | macOS  | Windows / Linux |
| ----------------------------------- | ------ | --------------- |
| Cancelar o estado mais à frente     | Escape | Escape          |

O Escape desfaz uma camada de cada vez — primeiro uma caixa de diálogo aberta, depois o menu de contexto de IA, um rascunho de texto, o painel de pesquisa e por fim a própria seleção.
