# Markdown 编辑器

Markdown 编辑器打开 .md / .markdown，双栏体验：源码 + 渲染预览。

- **打开**：主页或 文件 ▸ 打开；也支持从命令行。
- **编辑**：纯文本编辑，GFM 扩展（表格、任务列表、删除线、自动链接）在预览中渲染。
- **预览**：实时渲染；相对路径的图片等资源随文档解析显示。
- **保存**：字节级忠实——BOM、CRLF、结尾是否有换行都原样保留；未改动时保存不重写文件。
- **查找替换**：ctrl+F 在源码中查找，全部替换后写回。
- **AI**：AI 预设按钮可让助手改写、续写、翻译当前文档。

## 工具条

编辑区上方一排按钮（悬停可见说明）：

![Markdown 工具条](img/md-toolbar.png)

- **文件与历史**：保存、另存为、撤销、重做、查找；右侧的**自动保存**开关定时把改动写盘。
- **AI 按钮**：展开 AI 面板；旁边是改写、续写、翻译等预设按钮。
- **段落样式**（下拉）：正文与各级标题之间切换。
- **行内格式**：**加粗**、_斜体_、~~删除线~~、`行内代码`、链接。
- **列表**：无序列表、有序列表、任务列表。
- **插入**：表格、图片、分隔线。
- **属性**：在文首插入或跳转到 YAML front matter（文档属性块）。
- **大纲**：按标题层级快速跳转。
- **拼写检查**：开关当前文档的拼写检查。

上手三例：

- **标题**：光标放到该行 ▸ 段落样式下拉 ▸ 选「标题 1」。
- **表格**：点 **插入表格** ▸ 拖选行列数 ▸ 编辑单元格；预览侧立即渲染。
- **任务列表**：选中若干行 ▸ 点 **任务列表** ▸ 每行变成 `- [ ]`，预览里是可勾选样式的列表。

## 源码视图

工具排上有一个 **源码** 开关（随应用一起本地化）。打开后，编辑器会被原始的 Markdown 取代：就是保存时写入的那份文本，不美化，也不会在你背后做规范化。

- **编辑是字节级忠实的。** 在源码视图里保存，产出的字节与在编辑器里保存完全相同——BOM、CRLF 以及结尾是否有换行都原样保留。
- **还是同一份文档。** 随便来回切换；源码就是编辑器自己的文本，不是需要另行合并的副本。
- **格式工具条在这期间不可用**，因为那些按钮大多插入的是编辑器构造，只在渲染侧才有意义。关掉视图后它会回来。
- **JSON 等源码模式的文件**直接在这里打开：没有东西要渲染，源码*就是*文档本身。
