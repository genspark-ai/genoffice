# Markdown 编辑器

GenOffice 的 Markdown 编辑器专门用于打开和编辑 `.md` / `.markdown` 文档——同时也负责直接以纯净源码视图打开 `.txt` 纯文本与 `.json` 数据文件——采用现代轻量的所见即所得与源码切换体验，让你既能享受直观的排版渲染，又能随时掌控底层的每一行纯文本字符。

- **多种打开途径**：既可以从主屏文件列表或顶部菜单 **文件 ▸ 打开** 点选文件进入，也支持直接在终端命令行里通过 `genoffice <文件名.md>` 快速唤起。
- **完整支持 GFM 扩展语法**：在基础 Markdown 语法之上，完整支持 GitHub Flavored Markdown（GFM）扩展，包括多列表格、可点击勾选的待办任务列表（`- [ ]` / `- [x]`）、删除线、代码块语法高亮、数学公式块（LaTeX）以及网址自动识别链接。
- **所见即所得实时渲染**：输入语法符号的同时画布即刻渲染出排版效果；文档中引用的相对路径本地图片等资源会自动相对于当前 `.md` 文件所在的磁盘目录解析并直接显示出来。
- **字节级忠实保存**：保存文件时严格尊重你原有文件的底层编码细节——无论是文件开头的 UTF-8 BOM 签名、Windows 风格的 `CRLF` 还是 Unix 风格的 `LF` 换行符，乃至文件末尾是否留有空换行，都会原封不动地保留；如果你打开文件后没有做任何实质修改就按保存，编辑器甚至不会去重写磁盘文件以保护原始时间戳。
- **源码级查找与批量替换**：按下 `⌘F` / `Ctrl+F` 即可打开查找与替换面板，支持在整篇文档中快速定位关键词并一键「全部替换」后落盘。
- **AI 辅助写作与隐私隐藏**：顶部工具栏内置了一排 AI 快捷预设按钮，点一下就能让 AI 助手帮你润色改写、顺着下文续写或翻译当前文档；如果文档里包含不想发给云端大模型的密码、密钥或私密段落，同样支持选中后**对 AI 隐藏**（详见「AI 助手面板」一章）。

## 顶部快捷工具条

在编辑区正上方常驻着一排高频排版与文件操作按钮（把鼠标指针悬停在任意图标上都会显示对应的功能提示与快捷键）：

![Markdown 工具条](img/md-toolbar.png)

- **文件与操作历史**：最左侧依次排列着保存（`⌘S` / `Ctrl+S`）、另存为、多级撤销、重做以及全文查找按钮；工具条右侧则配有**自动保存**独立开关，开启后会在你打字停顿期间自动把最新内容安全写回磁盘。
- **AI 助手与快捷预设**：点击醒目的 **AI 按钮**即可展开或收起右侧 AI 对话面板，紧挨在它旁边的则是**改写、续写、翻译**等一键式预设操作按钮。
- **段落样式下拉框**：无需手动敲 `#` 号，直接从下拉列表里就能把当前光标所在行在「正文」与「一级标题至六级标题」之间快速切换。
- **行内文字格式**：选中文字后一键套用或取消**加粗**、_斜体_、~~删除线~~、`行内代码`高亮，或者为选区绑定跳转超链接（快捷键 `⌘K` / `Ctrl+K`）。
- **三种列表切换**：一键将当前段落或选中的多行转换为无序圆点列表、自动递增的有序数字列表，或是带复选框的交互式待办任务列表。
- **常用块级插入**：支持通过网格选择器一键插入多行多列的标准 Markdown 表格、从本地挑选插入图片，或者插入一条横向水平分隔线（`---`）。
- **文档属性（YAML Front Matter）**：点击**属性**按钮即可在文档最顶部自动插入（或直接跳转到已有的）YAML Front Matter 元数据块，方便使用 Hugo、Hexo、Jekyll 或 Obsidian 的用户管理文章标题、日期与标签属性。
- **章节大纲跳转**：点击展开侧边大纲面板，系统会自动提取全文各级标题生成目录树，点击任意标题即可在长篇技术文档中瞬间定位。
- **文档拼写检查**：随时开启或关闭针对当前这篇 Markdown 文档的拼写错误波浪线提示。
- **自定义图床自动上传设置**：写技术博客或团队文档最头疼本地图片发给别人看不了——在**图床设置**里配置好你自己的云存储后，每当你往编辑器里粘贴截图或拖入本地图片时，GenOffice 都会自动先把图片上传到你指定的图床（原生支持 Cloudflare R2、阿里云 OSS、腾讯云 COS、MinIO 等所有 **S3 兼容对象存储**，以及 **SM.MS** 和 **GitHub 仓库图床**）并自动插入线上图片链接，同时还会在本地 `assets` 文件夹保留一份原图副本作为离线兜底。

三个最常用的上手小例子：

- **快速设标题**：把光标放到某一行文字里 ▸ 点开工具条上的**段落样式**下拉框 ▸ 选择「标题 1」，该行就会立即变成一级大标题。
- **可视化插表格**：点击工具条上的**插入表格**图标 ▸ 用鼠标在弹出的小网格上滑过需要的行数与列数并单击 ▸ 直接在渲染好的表格单元格里填字即可，无需自己手敲繁琐的竖线 `|` 和对齐横线。
- **制作待办清单**：用鼠标框选写好的几行计划 ▸ 点击工具条上的**任务列表**按钮 ▸ 每一行都会自动变成可直接在界面上打钩的复选框列表项（底层源码对应标准的 `- [ ]`）。

## 多格式本地导出

所有导出功能均位于顶部菜单栏的**文件**菜单下，全部由本机引擎离线完成，绝不上传云端，并在导出前让你自由指定保存路径：

- **导出为 Word… 与 导出为 PDF…**：将当前 Markdown 文档的标题层级、表格、代码块、公式与图片直接排版转换为标准的 `.docx` Word 文档或分页整齐的 `.pdf` 文件。
- **导出为图片…**：按打印分页将整篇文档渲染输出为一张或多张高清 `.png` 图片，保存在你挑选的目标文件夹里。
- **转换为 Docs 文档并打开**：如果你想在 Markdown 初稿的基础上继续使用 Word 的复杂页眉页脚、分栏或修订追踪功能，点这一项就会在本地直接把当前文档转换成一份 `.docx` 文件，并立即在旁边开启一个新的 **Docs 文字编辑器标签页**加载它；转换生成的副本存放在本机临时缓存目录中（约一周后自动清理），你可以随时在 Docs 里把它另存到正式工作目录下。

## 纯净源码视图（Source View）

工具条右侧配有一个**源码**切换按钮（或按快捷键 `⌘E` / `Ctrl+E`）。点亮它之后，画布上的渲染排版会立即切换为最原始的纯文本 Markdown 源码编辑器：你在里面看到的每一个字符，就是按下保存时真正写入磁盘的字节，编辑器绝不会在背后自作主张替你重新折行、「美化」缩进或偷改你的语法符号。

- **两个视图下保存均保持字节级忠实**：无论你是在渲染编辑视图还是在纯源码视图下按下保存，写回磁盘的字节流都完全一致——文件原有的 UTF-8 BOM、换行符制式（`CRLF` 或 `LF`）以及文末换行符都会被一丝不苟地保留下来。
- **操作的是同一份底层文档**：你可以在渲染视图和源码视图之间随时无缝来回切换，因为源码视图直接展示的就是编辑器底层的同一份内存文本，而不是需要来回合并、容易丢改动的平行副本。
- **源码模式下格式按钮自动避让**：当你处于纯源码视图时，顶部工具条里那些依赖富文本节点的排版按钮会暂时置灰停用，防止在源码里插入不合时宜的编辑器构造；一旦你再次点击「源码」关掉源码视图，整排格式工具就会立刻恢复可用。
- **`.txt` 与 `.json` 文件的默认归宿**：当你用 GenOffice 打开 `.txt` 纯文本或 `.json` 配置文件时，因为它们本身没有任何需要渲染成富文本的 Markdown 标记，系统会贴心地直接以这个干净的**源码视图**将它们打开，让你能直接享受代码级查找替换与字节级无损保存。
