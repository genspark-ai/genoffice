# เริ่มต้นอย่างรวดเร็ว: ส่วนติดต่อผู้ใช้และพื้นฐาน

GenOffice เป็นชุดโปรแกรมสำนักงานที่ทำงานบนเครื่องของคุณทั้งหมด: หน้าต่างเดียว มีแถบแท็บแถวเดียว ภายในมีตัวแก้ไขหกตัวคือ Docs (ประมวลผลคำ), Sheets (สเปรดชีต), Slides (งานนำเสนอ), PDF, Markdown และ HTML ไฟล์ที่เปิดและบันทึกเป็น .docx / .xlsx / .pptx / .pdf ของจริง ใช้งานร่วมกับ Word, Excel และ PowerPoint ได้อย่างสมบูรณ์ ไม่ต้องต่ออินเทอร์เน็ต

## ภาพรวมของหน้าต่าง

![หน้าแรก](img/home-screen.png)

หน้าต่างแบ่งเป็นสามส่วน:

- **แถบแท็บ (ด้านบน)**: ไฟล์ที่เปิดอยู่ทุกไฟล์เป็นหนึ่งแท็บ แท็บหน้าแรกที่อยู่ซ้ายสุดจะมีอยู่เสมอและปิดไม่ได้ ส่วนแท็บอื่นคือเอกสารของคุณ ดับเบิลคลิกที่แท็บเพื่อเปลี่ยนชื่อไฟล์แบบอินไลน์
- **พื้นที่เนื้อหา**: ตัวแก้ไข (หรือหน้าแรก) ของแท็บที่เลือกอยู่
- **แถบเมนู**: บน macOS จะอยู่ในแถบเมนูของระบบ ส่วนบน Windows/Linux จะอยู่ที่ด้านบนของหน้าต่าง เมนูไฟล์/แก้ไข/มุมมองจะสลับให้ตรงกับตัวแก้ไขที่ใช้งานอยู่

## การสร้างเอกสาร

เลือกวิธีใดวิธีหนึ่ง:

- คลิกการ์ดสร้างด่วนในส่วน [เริ่มต้นอย่างรวดเร็ว](help://getting-started) ของ **หน้าแรก** (AI Docs, AI Sheets, AI Slides ฯลฯ)
- เมนู **ไฟล์ ▸ สร้างใหม่**: Docs (⌘N/ctrl+N), Sheets, Slides, Markdown, HTML หรือ PDF
- ลากไฟล์มาวางในหน้าต่าง หรือดับเบิลคลิกไฟล์ในโปรแกรมจัดการไฟล์ของคุณ (ถ้า GenOffice เป็นแอปเริ่มต้น)

เอกสารใหม่จะเปิดขึ้นโดยยังไม่มีชื่อ ไฟล์บนดิสก์จะถูกสร้างขึ้นจริงเมื่อบันทึกครั้งแรกเท่านั้น

## การเปิดไฟล์

- เมนู **ไฟล์ ▸ เปิด…** (⌘O/ctrl+O) จะเปิดกล่องเลือกไฟล์ของระบบ: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html
- คลิกรายการใดก็ได้ในรายการ **ล่าสุด** บนหน้าแรก
- รัน `genoffice <ไฟล์>` จากเทอร์มินัลก็เปิดไฟล์ได้เช่นกัน

## รูปแบบการบันทึก

- **บันทึกด้วยตนเอง**: ⌘S/ctrl+S หรือ ไฟล์ ▸ บันทึก / บันทึกเป็น… การบันทึกครั้งแรกจะให้เลือกตำแหน่งและชื่อไฟล์
- **บันทึกอัตโนมัติ** จะเริ่มทำงานหลังจากคุณบันทึกไฟล์ด้วยตนเองอย่างน้อยหนึ่งครั้งเท่านั้น ไฟล์ PDF ที่คุณแค่เปิดอ่านจะไม่ถูกเขียนทับเงียบ ๆ บันทึกอัตโนมัติจะทำงานหลังจากเนื้อหาเปลี่ยนไปไม่นาน
- การปิดแท็บที่มีการแก้ไขที่ยังไม่บันทึก จะถามให้เลือก บันทึก / ทิ้ง / ยกเลิก ก่อน
- ทุกการเขียนเป็นแบบอะตอมิก (เขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ) ไฟล์ที่ค้างอยู่ครึ่งเดียวจึงไม่เกิดขึ้นแม้ไฟดับกลางคัน

## แป้นพิมพ์ลัดที่ใช้บ่อย

| การทำงาน      | macOS | Windows / Linux |
| ------------- | ----- | --------------- |
| เอกสารใหม่    | ⌘N    | ctrl+N          |
| เปิด          | ⌘O    | ctrl+O          |
| บันทึก        | ⌘S    | ctrl+S          |
| ปิดแท็บ       | ⌘W    | ctrl+W          |
| เปิดคู่มือนี้ | F1    | F1              |
| ยุบ Ribbon    | ⌥⌘R   | Ctrl+F1         |

**การยุบ Ribbon** ใช้ได้ในทุกตัวแก้ไข แถวแท็บจะยังอยู่ที่เดิม ส่วนแถบคำสั่งด้านล่างจะถูกซ่อน แท็บที่เลือกอยู่ทำหน้าที่เป็นปุ่มยุบไปด้วย เพราะฉะนั้นตราบใดที่ Ribbon ยังยุบอยู่ จะไม่มีแท็บใดถูกเลือก และการกดแท็บใดก็ตามจะทำให้แถบคำสั่งกลับมา การดับเบิลคลิกแท็บก็ให้ผลเหมือนกัน ว่าคุณปิดหรือเปิดไว้ จะถูกจดจำแยกต่างหากสำหรับแต่ละตัวแก้ไข

แป้นพิมพ์ลัดภายในแต่ละตัวแก้ไข (ตัวคัดวางรูปแบบ, ค้นหาและแทนที่, การจัดการตาราง ฯลฯ) อยู่ในบทของตัวนั้น และ Docs ยังมีกล่องแป้นพิมพ์ลัดที่ค้นหาได้อีกด้วย (**⌘/**) (ดูบทของ Docs)

## แป้นพิมพ์ลัด Option+Command

Option+Command คือชั้นที่ Word กันไว้สำหรับการกระโดดแบบมีโครงสร้าง และ GenOffice ก็เติมชั้นนี้ในแบบเดียวกัน ส่วนใหญ่อยู่ในมือ Docs ส่วน Sheets เก็บไว้สองตัวของตัวเองเพื่อให้เท่ากับ Excel และมีแป้นหนึ่งตัวที่ใช้ได้ทุกที่

**Docs**

| แป้น (macOS)    | ทำอะไร                | Windows / Linux    |
| --------------- | --------------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | หัวเรื่อง 1 / 2 / 3   | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | ปกติ                  | Ctrl+Alt+0         |
| ⌥⌘M             | ย่อหน้า               | Ctrl+Alt+M         |
| ⌥⌘A             | ข้อคิดเห็นใหม่        | Ctrl+Alt+A         |
| ⌥⌘F             | แทรกเชิงอรรถ          | Ctrl+Alt+F         |
| ⌥⌘E             | แทรกอ้างอิงท้ายเรื่อง | Ctrl+Alt+D         |
| ⌥⌘G             | ไปที่                 | Ctrl+G             |

สองรายการเปลี่ยนไปบน Windows ด้วยเหตุผลเดียวกับที่ Word แยกมันออกจากกัน **macOS ถือ ⌥⌘D** ไว้ เพราะใช้แสดงและซ่อน Dock ดังนั้นการแทรกอ้างอิงท้ายเรื่องจึงใช้ ⌥⌘E บน Mac และ Ctrl+Alt+D ที่อื่น และ **ไปที่** ตัด Alt ออกไป เป็น Ctrl+G ตรงที่แป้นฝั่ง Mac ยังถือ Alt ไว้

**Sheets** เมื่อช่องตารางมีโฟกัส

| แป้น (macOS) | ทำอะไร         | Windows / Linux |
| ------------ | -------------- | --------------- |
| ⌥⌘0          | เส้นขอบด้านนอก | Ctrl+Shift+7    |
| ⌥⌘−          | ไม่มีเส้นขอบ   | Ctrl+Shift+−    |

Windows ไม่ได้เป็นการเขียนแป้นคู่บน Mac ใหม่ Excel for Mac ให้ Sheets **ทั้งสองอย่าง** คือ ⌘⇧7 และ ⌥⌘0 ซึ่งเป็นสองปุ่มสำหรับเส้นขอบด้านนอกชุดเดียวกัน คำสั่งบน Windows จึงยังคงตำแหน่ง Ctrl+Shift ที่มีอยู่เดิมไว้ ส่วนชั้น Option นั้นไม่มีอยู่เลย

สังเกตว่า **⌥⌘0 หมายถึง ปกติ ใน Docs และ เส้นขอบด้านนอก ใน Sheets** ทั้งสองอย่างไม่เคยปรากฏในตัวแก้ไขเดียวกัน จึงไม่ชนกันในการใช้งานจริง แต่ ⌥⌘0 ถูกจองไว้แล้วและใช้เป็นแป้นลัดระดับทั้งระบบไม่ได้

**ทุกตัวแก้ไข**: **⌥⌘R / Ctrl+F1** ยุบ Ribbon ตามที่อธิบายไว้ข้างต้น

เช่นนั้น ⌥⌘D จึงยังว่างให้ GenOffice ใช้บน macOS ได้ หากในอนาคตมีคำสั่งใดต้องการมัน
