# 设置、语言、主题与 MCP 集成

## 打开设置

主屏左下角的账号行打开设置面板（未登录时显示为「登录」）。面板共六个分区：账户、AI 模型、生图、媒体与搜索、通用、集成、关于。

![设置 ▸ 通用：语言、主题、自动保存与使用统计开关都在这里](img/settings-general.png)

模型配置另有专门一章；**生图、媒体与搜索**是按服务商分别开启图像生成、图像解析、视频解析、网络搜索和本机文件搜索的地方。

## 语言

- 设置里可选 **21 种界面语言**：简体中文、English、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt。
- 切换立即生效并持久化；菜单栏（主进程菜单）随语言重建。

## 主题

浅色 / 深色 / 跟随系统三种。跟随系统时随 OS 外观自动切换，编辑器区域同步换肤，无闪白。

## 通用

- **发送匿名使用统计** —— 默认开启。使用 Google Analytics 4，会发送你的公网 IP 地址和传输元数据；文档内容和文件名绝不收集，每个事件只带一个类型，比如「打开了一个 .docx」。随时可以在这里关闭。
- **AI 侧边栏位置**（左或右）、**AI 面板文字大小**和**AI 对话拼写检查**。
- **新文档中打开 AI 面板** —— 关闭，新文档开始时面板是收起的，点一下就到。
- **所有文档自动保存** 会让每个编辑器默认开启自动保存；单个窗口仍然可以关掉。
- **默认保存位置**配**更改**按钮，以及**设为 Office 文档默认程序**，把 .docx / .xlsx / .pptx 交给 GenOffice 处理。

## 生图、媒体与搜索

这些不是开关——每项能力自己挑提供它的服务商，服务商的密钥和基础地址只填一次，之后各行共用：

- **网络搜索**、**生图**、**图片解析**和**视频解析**，每项都有服务商、模型、密钥和基础地址。
- **本机文件搜索**跑在这台机器上。它下面的**Jev 搜索重排**默认关闭。打开后，本机搜索前 20 条命中的片段——每份文档最多 1,200 个字符，外加文件名和文件夹名——会发给 TypeSafe 的 Jev 模型按相关性重新排序。关闭时不会有任何东西离开本机。

## 关于

- **版本**、项目的 GitHub 链接，以及**去 GitHub 点 Star**按钮。
- **更新通道**：稳定版或 Beta 版。改完立即生效并检查更新；它不会把 Beta 版安装退回稳定版。

## 默认应用绑定

设置里可以把 .docx / .xlsx / .pptx / .pdf 等格式关联为「由 GenOffice 打开」（写入系统级别的默认应用注册，按平台提示确认）。

## 第三方声明与更新

- 帮助菜单 ▸ 第三方软件声明：随包附带的完整开源组件许可清单。
- 帮助菜单 ▸ 检查更新：手动触发一次更新检查；有新版本时提示安装。

## Genspark 登录

- 设置或云端项目列表里的登录入口走**设备码**流程：GenOffice 显示验证码并在浏览器打开登录页，完成后自动继续。
- 登录只用于：云端项目列表、Genspark 官方模型服务。不登录时本地功能与自定义模型完全可用。
- 登出在设置里一键完成。

## MCP 集成（面向高级用户 / AI 客户端）

**集成**是把 GenOffice 接到编程代理上的面板，它也有专门一章：连接编程代理。简单说就是——选一条路子（命令行或 MCP），照那一节做，然后开一个新对话直接问。

![设置 ▸ 集成：先三步走，再是技能行和 MCP 选项](img/settings-integrations.png)

在**本地 HTTP 服务**下，应用也可以自己来跑这个服务——一个启用开关、一个端口——而**高级**会再加上健康检查的网址和日志文件——而不是交给助手去做。它只监听 localhost。

## 命令行速查

| 命令               | 作用                |
| ------------------ | ------------------- |
| `genoffice <file>` | 打开文件            |
| `genoffice mcp`    | 启动本机 MCP 服务器 |
| `genoffice --help` | 全部命令与参数      |
