# 设置、语言、主题与 MCP 集成

## 打开设置面板

点击主屏左下角的账户栏（尚未登录 Genspark 账号时会显示为「登录」按钮），即可打开全局设置面板。整个设置窗口按职责划分为六个标签页：**账户**、**AI 模型**、**生图、媒体与搜索**、**通用**、**集成**以及**关于**。

![设置 ▸ 通用：语言、主题、自动保存与使用统计开关都在这里](img/settings-general.png)

对话大模型的端点与密钥配置在「AI 模型与设置」一章中有专门介绍；而**生图、媒体与搜索**页签则是用来为图像生成、图片理解、视频解析、联网搜索以及本机文件搜索分别指定服务提供商与独立密钥的地方。

## 界面语言

- GenOffice 内置支持 **23 种完整本地化的界面语言**，包括简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、Tiếng Việt、Türkçe 与 Magyar。
- 在下拉框中选择新语言后会立即在全局生效并自动写入本机配置，无需重启应用；操作系统顶部的原生菜单栏、右键菜单以及内置说明书都会同步切换为所选语言。

## 外观主题

提供**浅色**、**深色**和**跟随系统**三种外观模式。选择「跟随系统」时，GenOffice 会实时监听操作系统的日夜外观变化，所有打开的编辑器工具栏、侧边栏与对话框都会在同一帧内平滑换肤，不会出现刺眼的白屏闪烁，也不会擅自篡改你文档纸张原本的印刷底色。

## 通用设置

- **发送匿名使用统计**：默认处于开启状态，底层通过 Google Analytics 4 仅上报应用级的基础操作事件（例如「打开了一个 .docx 文档」）以及网络连接本身携带的公网 IP 与传输元数据；你的文档正文、表格数据、幻灯片内容和本地文件名等隐私信息绝不会被采集或上传，你也可以随时在这里一键关闭统计。
- **AI 助手界面偏好**：可以在这里自由调整 **AI 侧边栏位置**（靠窗口左侧或右侧停靠）、**AI 面板文字大小**，以及是否开启 **AI 对话输入框的拼写检查**，让辅助写作区域更贴合你的阅读习惯。
- **新文档中打开 AI 面板**：默认处于关闭状态，这样每次新建空白文档时都会先给你留出干净宽敞的编辑画布，需要 AI 帮忙时再点一下功能区按钮即可唤出侧边栏；如果你习惯每次都让 AI 先起草初稿，可以把它设为默认开启。
- **所有文档自动保存**：开启后会让每个编辑器默认处于自动保存激活状态（首次手动落盘后自动持续写盘）；即便开启了全局自动保存，你依然可以在某个具体窗口的顶部工具排上临时关掉该文档的自动保存。
- **默认保存位置与文件关联**：你可以通过**默认保存位置**旁边的**更改**按钮指定新建文档首次存盘时的默认目录，也可以使用**设为 Office 文档默认程序**一键把系统里的 `.docx`、`.xlsx`、`.pptx` 等常用办公格式交给 GenOffice 打开。

## 生图、媒体与搜索

这几项多模态与检索能力并不是简单的「开/关」按钮，而是允许你为每一项能力单独挑选最合适的服务商；同一家服务商的 API 密钥和基础地址（Base URL）只需要填写一次，就能在下面各个能力行之间直接复用：

- **联网搜索、图像生成、图片解析与视频解析**：每一行都可以独立选择服务提供商、具体模型名称、API Key 和自定义端点地址，因此你完全可以用一家服务商跑正文对话，同时用另一家专精视觉或生图的模型来处理配图与视频理解。
- **本机文件搜索与相关性重排**：本机文件全文检索默认完全在你的电脑本地运行；它下方的 **Jev 搜索重排** 默认处于**关闭**状态，关闭时没有任何一个字节会离开本机。只有当你主动开启该开关时，本机搜索初步命中的前 20 条结果摘要（每份文档最多截取 1,200 个字符的匹配片段，外加文件名与所在文件夹名称）才会发送给你所选的决策重排端点（支持通过 OpenRouter 或 TypeSafe 调用 Jev、Perplexity、Liquid AI d1、Cloudflare、本地重排引擎或自定义 URL），按语义相关度重新排序后再呈现给你。

## 关于与更新渠道

- **版本信息与开源仓库**：展示当前已安装的精确版本号、项目的 GitHub 仓库入口，以及方便支持开发团队的**去 GitHub 点 Star** 快捷按钮。
- **更新通道切换**：支持在**稳定版（Stable）**与 **Beta 预览版**之间切换；更改通道后会立即生效并马上触发一次更新检查，但出于配置与数据兼容性保护，切回稳定版通道不会把当前已经安装的 Beta 版本强行降级回旧版。

## 系统默认应用绑定

除了在「通用」页签中一键关联 Office 三件套外，设置面板还支持将 `.docx`、`.xlsx`、`.pptx`、`.pdf` 等格式在操作系统层面注册为默认由 GenOffice 处理；点击绑定后按 macOS、Windows 或 Linux 桌面环境的系统提示确认即可生效。

## 第三方开源声明与手动检查更新

- **帮助菜单 ▸ 第三方软件声明**：随时查看随安装包一起发行的全部开源组件清单及其完整许可证文本。
- **帮助菜单 ▸ 检查更新**：在自动检查之外手动触发一次版本检测，一旦发现当前通道上有更新的构建发布，就会弹出提示引导你下载并安装。

## Genspark 账号登录与退出

- **设备码安全登录**：无论从设置面板还是从主屏的「云端项目」列表点击登录，都采用标准的**设备码（Device Code）**授权流程——GenOffice 会在窗口里显示一串一次性验证码并自动在你的默认浏览器中打开登录页，在浏览器中确认授权后应用会自动完成对接，全程无需在客户端内直接输入账号密码。
- **账号的作用范围**：登录 Genspark 账号仅用于同步网页端的**云端项目列表**以及直接调用 **Genspark 官方托管模型**；即使完全不登录账号，所有本地文档编辑、格式转换、PDF 批注涂黑以及你自己配置的自定义模型（BYOK）都照常完整可用。
- **带确认保护的退出登录**：在设置面板中点击退出登录时，系统会先弹出一个确认对话框以防误触；确认退出后，会一次性断开所有依赖 Genspark 账号的云端 AI 功能（包括云端项目列表与官方托管模型），而你正在编辑的本地文档和自定义端点配置不会受到任何影响。

## MCP 集成（面向高级用户与外部 AI 编程助手）

**设置 ▸ 集成**面板专门用来把 GenOffice 的文档读写与排版引擎接入 Claude Code、Cursor、Codex、OpenCode 等外部编程代理，更完整的命令行用法可参阅专门的「连接编程助手」一章。日常接入只需要三步：选择接入方式（安装技能或启用 MCP）、按界面提示一键注册、然后在你的编程助手里新开一个对话直接用自然语言交代文档任务。

![设置 ▸ 集成：先三步走，再是技能行和 MCP 选项](img/settings-integrations.png)

如果你希望由 GenOffice 桌面端自己常驻运行服务而不是交由外部助手按需拉起，可以在面板下方的**本地 HTTP 服务**区域打开启用开关并指定端口号；展开**高级**选项后，还可以查看健康检查地址（Health-check URL）并打开本地运行日志。出于安全考虑，该 HTTP 服务仅绑定并监听本机回环地址（`localhost`）。
