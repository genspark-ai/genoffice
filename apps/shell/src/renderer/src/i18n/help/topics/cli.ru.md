# Командная строка и агенты

Каждая установка включает команду `genoffice`, которая задействует те же движки, что и окно, — те же разборщики, тот же исполнитель записи, тот же рендерер. Файл, сохранённый приложением, и файл, записанный командой, — это один и тот же файл, а проверка, которую проходит панель ИИ, проходит и команда.

```sh
genoffice --help          # every command
genoffice guide slides    # the op reference, for writing your own
```

Вот и вся поверхность на одном экране — каждая команда со строкой о том, что она делает, а затем глобальные параметры и коды выхода:

![Реальный вывод genoffice --help: баннер версии, каждая команда с описанием в одну строку, а также глобальные параметры и коды выхода](img/cli.png)

## Как получить команду

macOS и Windows поставляют её внутри пакета приложения. Чтобы обращаться к ней по имени, один раз выполните `genoffice install-cli`: команда создаст символическую ссылку на вложенный бинарный файл в `/usr/local/bin`, а в Windows — в пользовательском `PATH`.

## Команды, о которых стоит знать

| Команда           | Что делает                                                                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open`            | Открывает документ в приложении; запускает приложение, если оно не работает.                                                                                                                                                                      |
| `selection`       | Что пользователь выделил в этом файле прямо сейчас, пока приложение запущено, — указатель на «это» / «здесь». Возвращает диапазон блоков, диапазон ячеек листа, элементы слайда или страницу — в зависимости от редактора, в котором открыт файл. |
| `convert`         | Конвертирует между форматами средствами собственных движков приложения.                                                                                                                                                                           |
| `create`          | Создаёт документ из структурированного содержимого.                                                                                                                                                                                               |
| `render`          | По одному PNG на страницу — ровно так, как их раскладывает рендерер.                                                                                                                                                                              |
| `pdf`             | Читает текстовый слой PDF постранично, без процесса приложения.                                                                                                                                                                                   |
| `info`            | Метаданные и сводка структуры документа.                                                                                                                                                                                                          |
| `search`          | Поиск в вебе или по изображениям через провайдера, настроенного в приложении.                                                                                                                                                                     |
| `image` / `media` | Создаёт изображение либо описывает файл изображения, видео или аудио и отвечает на вопросы о нём.                                                                                                                                                 |
| `merge`           | Заполняет подстановки `{{key}}` в шаблоне `.docx`, `.pptx` или `.xlsx`.                                                                                                                                                                           |
| `capabilities`    | Сообщает, какие облачные функции настроены на этой машине.                                                                                                                                                                                        |
| `guide`           | Справка по op и руководства по дизайну, сгенерированные из тех же определений, по которым исполнитель проверяет допустимость, — поэтому она не может разойтись с тем, что принимает `apply`. `--json` возвращает её вместе со схемой каждой op.   |
| `install-cli`     | Помещает `genoffice` в `PATH`.                                                                                                                                                                                                                    |
| `skill`           | Показывает найденных на этой машине агентов для программирования и ставит или обновляет в них skill GenOffice.                                                                                                                                    |
| `mcp`             | Отдаёт каждую команду как инструмент Model Context Protocol. См. **Подключение агента для программирования**.                                                                                                                                     |

## Правка: документы, таблицы, презентации

`genoffice docs`, `genoffice sheet` и `genoffice slides` читают и пишут по тому же пути записи, что и приложение, и у них общий словарь: одна **op** — это отдельная правка, а **spec** — это список op, применяемых по порядку.

```sh
genoffice sheet read report.xlsx
genoffice slides apply deck.pptx --ops ops.json --dry-run
genoffice docs apply brief.docx --ops ops.json
```

`--dry-run` сообщает, что сделала бы пакетная операция, и ничего не пишет — это дешёвый способ проверить spec до того, как он применится. Панель ИИ в приложении работает ровно на этих op, поэтому всё, что можно попросить у неё, можно и запрограммировать.

## Model Context Protocol

`genoffice mcp` отдаёт каждую команду как инструмент MCP, а `genoffice mcp install <agent|all>` регистрирует его в собственной конфигурации агента для программирования. Об этой стороне — см. **Подключение агента для программирования**.

## Чего команда не делает

Она читает и пишет файл. Это не приложение: окна нет, а диалог обновления внутри приложения здесь не действует. Всё, что требует окна — панель ИИ, проверка качества отрендеренного слайда, — должно дождаться, пока вы откроете файл. `genoffice render` даёт вам пиксели и без окна, а `genoffice slides` сама проверяет вёрстку презентации.
