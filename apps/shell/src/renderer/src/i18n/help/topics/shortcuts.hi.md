# कीबोर्ड शॉर्टकट

हर एडिटर के अपने की-बाइंडिंग होते हैं, और उनमें से केवल कुछ ही हर जगह काम करते हैं। यह पूरी सूची है, एप्लिकेशन के हिसाब से बँटी हुई, जिसमें macOS और Windows / Linux के शॉर्टकट साथ-साथ दिए गए हैं।

## पहले यह पढ़ें

**यहाँ लगभग कुछ भी वैश्विक नहीं है।** नीचे दिए तीन एक्सेस की वे हैं; इसके बाद का सब कुछ उस एप्लिकेशन से संबंधित है जो आपके सामने खुला है, और टैब बदलने पर बदल जाता है।

| क्रिया                                   | macOS | Windows / Linux |
| ---------------------------------------- | ----- | --------------- |
| उपयोगकर्ता गाइड खोलें — ऐप में कहीं भी   | F1    | F1              |
| रिबन संक्षिप्त / विस्तार करें — हर एडिटर | ⌥⌘R   | Ctrl+F1         |
| कीबोर्ड शॉर्टकट शीट खोलें — केवल Wयाd    | ⌘/    | Ctrl+/          |

- **F1 यह मैनुअल खोलता है**, शॉर्टकट शीट नहीं। यह एप्लिकेशन मेन्यू का हिस्सा है, इसलिए Wयाd, Sheets, Slides, PDF या होम टैब — किसी से भी यह काम करता है।
- **रिबन का टॉगल `Ctrl+F1` है, या macOS पर `⌥⌘R`।** सिर्फ `F1` दबाने से कुछ नहीं होता — F1 मैनुअल है, और रिबन की कुंजी जानबूझकर उसे साझा नहीं करती। macOS पर `Ctrl+F1` भी स्वीकार्य है, हालाँकि Office fया Mac `⌥⌘R` का उपयोग करता है।
- **कीबोर्ड शॉर्टकट शीट अकेले Wयाd की है** (`⌘/`)। यह ठीक वही Wयाd तालिका सूचीबद्ध करती है जो नीचे दी गई है। किसी दूसरे एडिटर के पास ऐसी शीट नहीं है।

![Word का अपना कीबोर्ड शॉर्टकट शीट: बाईं ओर क्रिया, दाईं ओर कुंजी संयोजन, और फ़ाइल, संपादन, पाठ स्वरूपण, अनुच्छेद स्वरूपण, सम्मिलित करें, समीक्षा और उपकरण, दृश्य के समूहों में बँटा हुआ](img/word-shortcuts.png)

- **`⌘O`, `⌘S` और `⌘P` हर एडिटर के पीछे अलग-अलग लागू होते हैं**, और उनका व्यवहार एक जैसा नहीं है। Wयाd का `⌘P` पहले प्रिंट पूर्वावलोकन बनाता है, ताकि एक छपा हुआ पन्ना एक स्क्रीन पन्ने के बराबर हो; PDF वाला PDF प्रिंट संवाद खोलता है; Sheets और Slides के अपने अलग संवाद हैं।
- **बाकी सब प्रति-एप्लिकेशन है।** Wयाd टैब सक्रिय होने पर `⌘B` Wयाd का बोल्ड है। Slides सक्रिय होने पर `⌘B` Slides का बोल्ड है, और वह जिस मेन्यू में रहता है वह वही नहीं जिसके आप आदि हैं। जहाँ कोई बाइंडिंग केवल कुछ चुने होने पर ही चलती है, या किसी विशेष फ़लक में, क्रिया कॉलम यह बताता है।

## परिपाटियाँ

- macOS कॉलम परिचित चिह्नों का उपयोग करता है: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control।
- Windows / Linux कॉलम उनके पूरे नाम लिखता है: `Ctrl`, `Alt`, `Shift`।
- जहाँ GenOffice को दोनों प्लेटफ़ॉर्म पर सचमुच अलग कुंजियों की ज़रूरत होती है, तालिका वह दिखाती है। सामान्य मामले हैं: खोजें और बदलें के लिए `⌃H` (macOS में `⌘H` छिपाने के लिए सुरक्षित है), जाएँ के लिए `⌥⌘G`, और Slides की बंद करने की कुंजी।
- जो शॉर्टकट केवल चयन के साथ चलता है, उसे अलग कॉलम देने के बजाय क्रिया कॉलम में लिखा जाता है, ताकि तालिका तीन कॉलम चौड़ी ही रहे।

## Wयाd

Wयाd में पूरी मेन्यू पट्टी होती है, इसलिए नीचे दिए फ़ाइल और स्वरूपण शॉर्टकट तब काम करते हैं जब कोई Wयाd टैब फ़ोकस में हो, चाहे कौन-सा दस्तावेज़ खुला हो। संपादन शॉर्टकट के लिए एक लोड हुआ, संपादन योग्य दस्तावेज़ चाहिए जिसमें कैरेट टेक्स्ट में हो; वे तब नहीं चलते जब आप खोज बॉक्स, AI प्रॉम्प्ट या किसी दूसरे फ़ील्ड में टाइप कर रहे हों।

### फ़ाइल

| क्रिया             | macOS | Windows / Linux |
| ------------------ | ----- | --------------- |
| नया                | ⌘N    | Ctrl+N          |
| नई विंडो           | ⇧⌘N   | Ctrl+Shift+N    |
| खोलें…             | ⌘O    | Ctrl+O          |
| सहेजें             | ⌘S    | Ctrl+S          |

`⌘P` ब्राउज़र का प्रिंट नहीं है। Wयाd पहले प्रिंट पूर्वावलोकन बनाता है, इसलिए एक छपा हुआ पन्ना ठीक एक स्क्रीन पन्ने के बराबर होता है, फिर वह अपना प्रिंट संवाद खोलता है।

## Sheets

GenOffice Sheets एक Excel-संगत ग्रिड है। नीचे दिए अधिकांश शॉर्टकट वही Excel वाले हैं जिन्हें आप पहले से जानते हैं।

> **संपादन की जीत होती है।** Sheets के लगभग हर शॉर्टकट तब अनदेखा रहता है जब आप कोई सेल संपादित कर रहे हों या **सूत्र पट्टी** में टाइप कर रहे हों, ताकि टाइप करना, कैरेट हिलाना और Backspace अपना सामान्य टेक्स्ट-संपादन अर्थ बनाए रखें। यदि कोई कुंजी कुछ न करती लगे, तो जाँचें कि आप बीच में संपादन कर रहे हैं या नहीं: पहले Esc या Enter दबाएँ, फिर दोबारा कोशिश करें। चयन पर काम करने वाले आदेश भी खुले संवाद के समय कुछ नहीं करते। जहाँ कोई शॉर्टकट इस नियम का अपवाद है, तालिका वह बताती है।

ये दोनों परिपाटियाँ Sheets के लिए विशेष हैं। `⌘` और `⌃` एक ही मॉडिफ़ायर स्लॉट हैं — दोनों हर प्लेटफ़ॉर्म पर स्वीकार्य हैं, इसलिए `⌘1` और `Ctrl+1` एक ही शॉर्टकट हैं। **Windows / Linux का खाली सेल इसका मतलब है कि वह शॉर्टकट केवल macOS पर मौजूद है।**

## Slides

GenOffice Slides एक PowerPoint-शैली का प्रस्तुति एडिटर है। अधिकांश कुंजियाँ जहाँ भी आप हों वही करती हैं, पर कुछ फ़ोकस के साथ अर्थ बदल लेती हैं — टेक्स्ट बॉक्स के भीतर, या जब **थंबनेल रेल**, **रूपरेखा** या **स्लाइड सॉर्टर** को कीबोर्ड फ़ोकस मिला हो। वे मामले क्रिया कॉलम में चिह्नित हैं।

### फ़ाइल और ऐप

| क्रिया                         | macOS | Windows / Linux |
| ------------------------------ | ----- | --------------- |
| सहेजें                         | ⌘S    | Ctrl+S          |
| इस रूप में सहेजें              | ⇧⌘S   | Ctrl+Shift+S    |
| खोलें                          | ⌘O    | Ctrl+O          |
| मौजूदा टैब बंद करें            | ⌘W    | Ctrl+Q          |
| प्रिंट                         | ⌘P    | Ctrl+P          |
| पूर्ववत करें                   | ⌘Z    | Ctrl+Z          |
| फिर से करें                    | ⇧⌘Z   | Ctrl+Shift+Z    |
| फिर से करें (वैकल्पिक शॉर्टकट) | ⌘Y    | Ctrl+Y          |

टैब बंद करना वही एक जगह है जहाँ दोनों प्लेटफ़ॉर्म पूरी तरह अलग होते हैं: macOS पर ⌘W, और Windows तथा Linux पर Ctrl+Q, जो पूरे ऐप से बाहर निकलता है, टैब से नहीं।

### संपादन

| ---------------------------------------------------- | ------ | --------------- |

नई स्लाइड दूसरा प्लेटफ़ॉर्म बँटवारा है। हर प्लेटफ़ॉर्म की अपनी कुंजी है और दूसरी की कुछ नहीं करती: macOS पर ⇧⌘N, Windows और Linux पर Ctrl+M। macOS पर `⌘M` यह काम नहीं कर सकता क्योंकि वह सिस्टम का मिनिमाइज़ कुंजी है।

सब चुनें फ़ोकस का अनुसरण करता है: थंबनेल रेल, रूपरेखा या स्लाइड सॉर्टर के फ़ोकस में होने पर यह हर स्लाइड चुनता है, और कहीं और यह मौजूदा स्लाइड का हर तत्व चुनता है। Tab स्लाइड की आकृतियों के बीच चक्र लगाता है, और केवल जब स्लाइड कैनवास को ही फ़ोकस मिला हो।

| चुनी हुई स्लाइड हटाएँ                | ⌫ / Delete                     | Backspace / Delete                             |
| स्लाइड कॉपी करें                     | ⌘C                             | Ctrl+C                                         |
| स्लाइड काटें                         | ⌘X                             | Ctrl+X                                         |

तीर कुंजियों से स्लाइडों के बीच जाना अपवाद है — यह कैनवास से भी काम करता है, जब कुछ भी चुना न हो। पेन उपकरण सक्रिय होने पर या **पठन दृश्य** में स्लाइड हटाना लागू नहीं होता।

### टेक्स्ट बॉक्स के भीतर

| क्रिया                                                     | macOS                                   | Windows / Linux                             |
| ---------------------------------------------------------- | --------------------------------------- | ------------------------------------------- |
| चुनी हुई टेक्स्ट आकृति में टेक्स्ट संपादन शुरू करें        | कोई भी प्रिंट करने योग्य वर्ण, ⏎, या F2 | कोई भी प्रिंट करने योग्य वर्ण, Enter, या F2 |
| टेक्स्ट दर्ज करें और आकृति फिर से चुनें                    | Esc या F2                               | Esc या F2                                   |
| टेक्स्ट दर्ज करें और आकृति फिर से चुनें (वैकल्पिक शॉर्टकट) | ⌘⏎                                      | Ctrl+⏎                                      |
| अगले प्लेसहोल्डर पर जाएँ                                   | ⌃⏎                                      | Ctrl+⏎                                      |
| सूची स्तर घटाएँ / बढ़ाएँ                                   | ⇥ / ⇧⇥                                  | Tab / Shift+Tab                             |
| अगला / पिछला तालिका सेल                                    | ⇥ / ⇧⇥                                  | Tab / Shift+Tab                             |
| मृदु पंक्ति ब्रेक                                          | ⇧⏎                                      | Shift+⏎                                     |

Tab के दो अर्थ हैं: तालिका के भीतर अगला सेल, और टेक्स्ट आकृति के भीतर सूची स्तर घटाना।

### स्लाइड शो

| क्रिया                        | macOS              | Windows / Linux                      |
| ----------------------------- | ------------------ | ------------------------------------ |
| शुरुआत से शुरू करें           | F5                 | F5                                   |
| मौजूदा स्लाइड से शुरू करें    | ⇧F5 या ⌘⏎          | ⇧F5                                  |
| अगली स्लाइड                   | → ↓ ␣ ⏎ Page Down  | Right, Down, Space, Enter, Page Down |
| पिछली स्लाइड                  | ← ↑ Page Up        | Left, Up, Page Up                    |
| पहली स्लाइड                   | Home               | Home                                 |
| अंतिम स्लाइड                  | End                | End                                  |
| स्लाइड N पर जाएँ              | N टाइप करें, फिर ⏎ | N टाइप करें, फिर Enter               |
| काली स्क्रीन                  | B या .             | B या .                               |
| सफ़ेद स्क्रीन                 | W या ,             | W या ,                               |
| काली स्क्रीन के बाद बहाल करें | कोई भी कुंजी       | कोई भी कुंजी                         |
| शो समाप्त करें                | Esc                | Esc                                  |

मौजूदा स्लाइड से शुरू करना macOS पर ⌘⏎ के साथ-साथ ⇧F5 भी लेता है। Windows पर वही कुंजी प्लेसहोल्डर के बीच जाने के लिए सुरक्षित रहती है।

### पठन दृश्य

| क्रिया                   | macOS             | Windows / Linux                      |
| ------------------------ | ----------------- | ------------------------------------ |
| अगली स्लाइड              | → ↓ ␣ ⏎ Page Down | Right, Down, Space, Enter, Page Down |
| पिछली स्लाइड             | ← ↑ Page Up       | Left, Up, Page Up                    |
| पठन दृश्य से बाहर निकलें | Esc               | Esc                                  |

**Esc** दबाकर जिस भी चीज़ में हों उससे बाहर निकलें — एक कट, कोई आकृति जो बना रहे हों, **बिंदु संपादन**, कोई समूह, पेन, हाइलाइटर या रबर उपकरण, मीडिया प्लेयर, या **पठन दृश्य** — और चयन भी हटाने के लिए।

दो और मॉडिफ़ायर हैं, शॉर्टकट नहीं: आकृति बनाते समय उसके अनुपात बनाए रखने के लिए **Shift** दबाए रखें, और घुमाते समय 15° के कदमों पर चिपकने के लिए **Shift** दबाए रखें।

## PDF

PDF का अपना कोई मेन्यू नहीं है, इसलिए नीचे दिया हर शॉर्टकट सक्रिय टैब का अनुसरण करता है और केवल तब काम करता है जब कोई PDF टैब सामने हो।

### फ़ाइल और संपादन

| क्रिया            | macOS | Windows / Linux |
| ----------------- | ----- | --------------- |
| सहेजें            | ⌘S    | Ctrl+S          |
| पूर्ववत करें      | ⌘Z    | Ctrl+Z          |
| फिर से करें       | ⇧⌘Z   | Ctrl+Shift+Z    |
| खोजें (खोज खोलें) | ⌘F    | Ctrl+F          |
| प्रिंट            | ⌘P    | Ctrl+P          |

पूर्ववत और फिर से दस्तावेज़ के इतिहास में आगे-पीछे ले जाते हैं; कर्सर किसी टेक्स्ट फ़ील्ड में हो तो वे `⌘Z` उसी फ़ील्ड को छोड़ देते हैं। `⌘P` वही ऐप-अंतर्गत प्रिंट संवाद खोलता है जो टूलबार का प्रिंट बटन खोलता है।

### दृश्य

| क्रिया               | macOS          | Windows / Linux   |
| -------------------- | -------------- | ----------------- |
| ज़ूम इन              | ⌘=             | Ctrl+=            |
| ज़ूम आउट             | ⌘-             | Ctrl+-            |
| चौड़ाई में फ़िट करें | ⌘0             | Ctrl+0            |
| ज़ूम (निरंतर)        | ⌘ + माउस व्हील | Ctrl + माउस व्हील |

ज़ूम इन ⌘+ और Ctrl++ को भी स्वीकार करता है।

### पेज नेविगेशन

| क्रिया                       | macOS             | Windows / Linux   |
| ---------------------------- | ----------------- | ----------------- |
| अगला पेज                     | →                 | →                 |
| पिछला पेज                    | ←                 | ←                 |
| एक स्क्रीन नीचे स्क्रॉल करें | PageDown या Space | PageDown या Space |
| एक स्क्रीन ऊपर स्क्रॉल करें  | PageUp            | PageUp            |
| नीचे स्क्रॉल करें            | ↓                 | ↓                 |
| ऊपर स्क्रॉल करें             | ↑                 | ↑                 |
| पहले पेज पर जाएँ             | Home              | Home              |
| अंतिम पेज पर जाएँ            | End               | End               |

इनमें कोई मॉडिफ़ायर नहीं है, इसलिए दोनों प्लेटफ़ॉर्म एक जैसा पढ़ते हैं। ↓ और ↑ ही वे पंक्तियाँ हैं जो फ़ोकस के साथ बदलती हैं: दस्तावेज़ में वे पेज को खिसकाती हैं, पर थंबनेल साइडबार में फ़ोकस होने पर पूरा एक पेज आगे-पीछे लेती हैं। फ़ील्ड में टाइप करते समय वे कुछ नहीं करतीं।

### चयन और संपादन

| क्रिया                 | macOS               | Windows / Linux     |
| ---------------------- | ------------------- | ------------------- |
| चुनी हुई टिप्पणी हटाएँ | Delete या Backspace | Delete या Backspace |

केवल तब सक्रिय होता है जब कोई टिप्पणी, मुहर, कालापन या छवि चुनी हो।

### Escape और संवाद

| क्रिया                     | macOS  | Windows / Linux |
| -------------------------- | ------ | --------------- |
| सबसे ऊपरी स्थिति रद्द करें | Escape | Escape          |
| खुले संवाद की पुष्टि करें  | Enter  | Enter           |

Escape एक बार में एक परत हटाता है — पहले खुला हुआ संवाद, फिर AI का पॉप-ओवर, टेक्स्ट का मसौदा, खोज पैनल, और अंत में चयन स्वयं। कर्सर खोज बॉक्स में हो तो Enter और ⇧Enter अगले और पिछले मिलान पर ले जाते हैं, और Escape पैनल बंद करता है; कर्सर नए टेक्स्ट नोट में हो तो `⌘⏎` उसे दर्ज करता है।

## Markdown

GenOffice Markdown बगल में लाइव पूर्वावलोकन के साथ Markdown संपादित करता है।

### फ़ाइल और दृश्य

| क्रिया                        | macOS    | Windows / Linux  |
| ----------------------------- | -------- | ---------------- |
| सहेजें                        | ⌘S       | Ctrl+S           |
| इस रूप में सहेजें             | ⇧⌘S      | Ctrl+Shift+S     |
| प्रिंट                        | ⌘P       | Ctrl+P           |
| खोजें                         | ⌘F       | Ctrl+F           |
| स्रोत / पूर्वावलोकन टॉगल करें | ⌘E       | Ctrl+E           |
| ज़ूम इन                       | ⌘= या ⌘+ | Ctrl+= या Ctrl++ |
| ज़ूम आउट                      | ⌘-       | Ctrl+-           |
| वास्तविक आकार (100%)          | ⌘0       | Ctrl+0           |

ज़ूम आउट ⌘_ और Ctrl+_ भी लेता है। ट्रैकपैड को चुना, या ⌘ या Ctrl दबाकर दस्तावेज़ पर स्क्रॉल करना भी ज़ूम करता है।

### ब्लॉक

| क्रिया                                        | macOS | Windows / Linux      |
| --------------------------------------------- | ----- | -------------------- |
| चुने हुए ब्लॉकों की प्रतिलिपि बनाएँ           | ⌘D    | Ctrl+D               |
| चुने हुए ब्लॉक हटाएँ                          | ⇧⌘⌫   | Ctrl+Shift+Backspace |
| चुना हुआ ब्लॉक ऊपर ले जाएँ                    | ⇧⌘↑   | Ctrl+Shift+ArrowUp   |
| चुना हुआ ब्लॉक नीचे ले जाएँ                   | ⇧⌘↓   | Ctrl+Shift+ArrowDown |
| चयन पर लिंक सम्मिलित करें                     | ⌘K    | Ctrl+K               |
| लिंक हटाएँ (लिंक सक्रिय होने पर दोबारा दबाएँ) | ⌘K    | Ctrl+K               |

### गणित ब्लॉक के भीतर

ये केवल तब लागू होते हैं जब तैरता LaTeX एडिटर खुला हो।

| क्रिया                       | macOS | Windows / Linux |
| ---------------------------- | ----- | --------------- |
| सूत्र लागू करें              | ⌘⏎    | Ctrl+⏎          |
| लागू किए बिना एडिटर बंद करें | Esc   | Esc             |

खाली सूत्र लागू करने से ब्लॉक मिट जाता है। दस्तावेज़ में कोई भी बदलाव होने पर एडिटर भी बंद हो जाता है, और बाहर क्लिक करने से भी।

## HTML

GenOffice HTML लाइव पूर्वावलोकन के बगल में एक कोड एडिटर दिखाता है। पेज के किसी तत्व पर काम करने वाली कुंजियाँ केवल तब लागू होती हैं जब पूर्वावलोकन को ही कीबोर्ड फ़ोकस मिला हो।

### फ़ाइल और स्रोत दृश्य

| क्रिया                                       | macOS    | Windows / Linux  |
| -------------------------------------------- | -------- | ---------------- |
| सहेजें                                       | ⌘S       | Ctrl+S           |
| इस रूप में सहेजें                            | ⇧⌘S      | Ctrl+Shift+S     |
| दृश्य बदलें (संपादन / विभाजित / पूर्वावलोकन) | ⌘\       | Ctrl+\           |
| खोजें                                        | ⌘F       | Ctrl+F           |
| ज़ूम इन                                      | ⌘= या ⌘+ | Ctrl+= या Ctrl++ |
| ज़ूम आउट                                     | ⌘-       | Ctrl+-           |
| वास्तविक आकार (100%)                         | ⌘0       | Ctrl+0           |

ज़ूम आउट ⌘_ और Ctrl+_ भी लेता है।

### स्वरूपण और इतिहास

| क्रिया                         | macOS | Windows / Linux |
| ------------------------------ | ----- | --------------- |
| बोल्ड                          | ⌘B    | Ctrl+B          |
| इटैलिक                         | ⌘I    | Ctrl+I          |
| पूर्ववत करें                   | ⌘Z    | Ctrl+Z          |

कोड एडिटर या फ़ॉर्म फ़ील्ड के भीतर, उस फ़ील्ड की अपनी संपादन कुंजियाँ उसका स्थान ले लेती हैं।

### पूर्वावलोकन फ़्रेम में, किसी तत्व के चुने होने पर

| क्रिया                             | macOS      | Windows / Linux    |

| पिछला सह-तत्व                      | ↑          | ArrowUp            |
| अगला सह-तत्व                       | ↓          | ArrowDown          |
| मूल तत्व चुनें                     | ←          | ArrowLeft          |
| पहला चाइल्ड तत्व चुनें             | →          | ArrowRight         |
| तत्व को दस्तावेज़ में ऊपर ले जाएँ  | ⌥↑         | Alt+ArrowUp        |

इनमें से हर एक के लिए पहले से कोई तत्व चुना होना चाहिए; कुछ भी चुना न हो तो कुंजी कुछ नहीं करती।

### पूर्वावलोकन फ़्रेम में, टेक्स्ट को उसी स्थान पर संपादित करना

दर्ज करने पर आपका लिखा हुआ बना रहता है और तत्व वापस चयन की हालत में लौट आता है।
