# 首頁（Home）：檔案都在哪裡

首頁是 GenOffice 的起始頁：左側是導覽側邊欄，右側是檔案清單與快速建立卡片。

![首頁畫面](img/home-screen.png)

## 側邊欄導覽

- **最近**：你最近開啟過的檔案。每一列都標著時間——今天、昨天或日期。
- **收藏**：你加過星號的檔案。將滑鼠停在檔案列上，按一下星號即可加入或移除。
- **使用手冊**：開啟本手冊。
- **Genspark Projects**：登入 Genspark 帳號後，會顯示你在網頁上用 Genspark AI 建立的專案；點一下即可在瀏覽器中繼續編輯。支援搜尋、依時間排序、重新整理與載入更多。
- **資料夾**：用「加入資料夾…」加到側邊欄，或從檔案總管拖進來的目錄。每一個都會成為一個根目錄，可以開啟、在其中建立子資料夾、重新命名與移除；離線的根目錄會顯示為「無法使用」，也可從清單中移除。「新增資料夾」可以再建立一個。

這裡沒有「垃圾桶」項目。刪除的檔案都會進入系統垃圾桶，如何還原是作業系統的事。

## 檔案清單

每一列會顯示圖示、檔案名稱、修改時間等資訊。該列的 **⋯ 選單** 提供：

- **開啟**，以及** 開啟所在資料夾**，在檔案總管中找出這個檔案。
- **複製路徑**。
- **移至資料夾…**：開啟資料夾選取器並真正移動檔案；當目的地已有同名檔案時，可以選擇略過、覆寫或重新命名。
- **重新命名**：就地改名（副檔名會自動保留）。
- **收藏／取消收藏** — 星號在重新啟動後依然保留，改名後也會跟著檔案走。
- **建立副本**：在同一個資料夾中建立一份副本。
- **刪除**：將檔案移到系統垃圾桶，並非永久刪除。
- **從清單中移除**，在頂層的「最近」檢視中，只移除這個項目而不動檔案本身。

### 一次處理多個檔案

勾選某一列的核取方塊，或按住 ⌘/ctrl 點選，即可建立選取範圍；標題列的核取方塊會全選目前列出來的項目，列表上方的工具列會顯示已選取的數量（**已選 {n} 項**），並為整組提供** 移至資料夾…**與** 刪除檔案**。多選之後也可以直接拖到側邊欄的某個資料夾上。

## 搜尋

頂端的搜尋方塊會同時比對兩種內容：

- **檔案名稱**：依名稱快速篩選。
- **檔案內容**：GenOffice 會在背景為你的檔案建立索引（docx/xlsx/pptx/pdf/md/html 內的文字），所以搜尋內文也找得到檔案。搜尋範圍與開關可在搜尋設定中調整。

## 快速開始卡片

清單上方的卡片一步就能建立新文件。點一下卡片會建立該類型的檔案並開啟對應的編輯器——你可以馬上開始寫，也可以交給 AI 起草（每個編輯器的功能區都有 **AI 按鈕**，選取內容後的右鍵選單也有 ** 問 AI**）。

新檔案會存放在側邊欄目前選取的資料夾；沒有選取時則存入預設資料夾。

各卡片的作用：

- **AI Docs**（.docx）：在 Docs 編輯器中開啟一份空白文字文件。檔案要到** 第一次儲存**時才真正寫入磁碟；新文件預設會展開 AI 面板，不需要時可在 設定 →「在新文件中開啟 AI 面板」關掉。
- **AI Sheets**（.xlsx）：在 Sheets 編輯器中開啟一份空白試算表。在你儲存之前，磁碟上其實還沒有這個檔案——檔名是先替第一次儲存保留的；首次由 AI 產生內容後，檔名還可以依內容自動更改。
- **AI Slides**（.pptx）：在 Slides 編輯器中開啟一份空白簡報。
- **AI Markdown**（.md）：在 Markdown 編輯器中開啟一份空白 Markdown 文件。
- **AI HTML**（.html）：在 HTML 編輯器中開啟一份空白網頁。
- **AI PDF**（.pdf）：與其他卡片不同——它會在目標資料夾中** 立即**建立一個真正的空白單頁 PDF，並以一般檔案的方式開啟（PDF 編輯器處理的是真實檔案）。適合用來加註解、塗黑或加入文字；檔名在第一次儲存時可依內容自動更改。
- **開啟本機檔案**：開啟系統檔案選擇視窗，支援 Word（.docx/.doc）、Excel（.xlsx/.xlsm/.xls/.csv/.tsv）、PowerPoint（.pptx/.ppt）、PDF、Markdown（.md/.markdown）與網頁（.html/.htm）。可複選；每個檔案各自開一個分頁。

> 提示：選單列的 檔案 ▸ 新增 也能建立相同類型的文件（⌘N/Ctrl+N 預設建立文字文件）；把檔案直接拖進視窗等同於開啟它。

## 雲端專案（Genspark Projects）

- 第一次使用需要登入 Genspark 帳號（裝置碼流程：GenOffice 會顯示一組碼，你在瀏覽器中完成登入）。
- 專案清單會與網頁端同步；「在瀏覽器中開啟」可跳回網頁繼續編輯。
- 不登入也不影響任何本機功能。
