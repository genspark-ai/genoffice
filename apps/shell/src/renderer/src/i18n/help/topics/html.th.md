# ตัวแก้ไข HTML

ตัวแก้ไข HTML เปิดไฟล์ .html / .htm ได้สองโหมด: **ตัวอย่าง** (หน้าที่เรนเดอร์แล้ว) และ **ซอร์ส**

- **ตัวอย่าง**: เรนเดอร์ตามจริง สไตล์ชีตและรูปภาพที่อ้างอิงแบบสัมพัทธ์จะโหลดจากตำแหน่งข้างไฟล์
- **ตัวตรวจสอบในตัวอย่าง**: คลิกเพื่อเลือกองค์ประกอบ ดับเบิลคลิกเพื่อแก้ข้อความของมันในตำแหน่ง, ลบจากแถบเครื่องมือ และ ถาม AI กับสิ่งที่เลือก
- **โหมดซอร์ส**: แก้ไข HTML, ctrl+F เพื่อค้นหา และ แทนที่ทั้งหมด จะบันทึกมาร์กอัปที่เขียนใหม่ลงไฟล์
- **การบันทึก**: รักษาไฟล์แบบ byte-faithful (BOM/CRLF/บรรทัดใหม่ท้ายไฟล์ยังคงไว้) การบันทึกที่ไม่ได้แก้อะไรจะไม่เขียนไฟล์ซ้ำ
- **ซูม**: ctrl+ล้อเลื่อน / การบีบนิ้วสองนิ้วปรับขนาดตัวอย่าง และ ctrl+Z ในตัวอย่างจะเลิกทำการแก้ไขล่าสุด

## แถบเครื่องมือ

คลิกองค์ประกอบใดก็ได้ในตัวอย่าง แถบเครื่องมือจะลอยขึ้นมาเหนือมัน:

![แถบเครื่องมือแบบลอยเหนือองค์ประกอบที่เลือก](img/html-toolbar.png)

- **ไฟล์และประวัติ**: บันทึก, บันทึกเป็น…, เลิกทำ, ทำซ้ำ, ค้นหา สวิตช์ **บันทึกอัตโนมัติ** เขียนการเปลี่ยนแปลงตามเวลาที่กำหนด
- สวิตช์ **ตัวอย่าง / ซอร์ส** และ **นำเสนอ** เพื่อแสดงหน้าเต็มหน้าจอ
- **การจัดรูปแบบ**: ตัวหนา, ตัวเอียง, เพิ่ม/ลดขนาดตัวอักษร และ **แผงสไตล์** สำหรับองค์ประกอบที่เลือก (สีและอื่น ๆ)
- **แทรก**: หัวเรื่อง, ย่อหน้า, ตาราง, รูปภาพ (จากลิงก์), เพิ่มเติม
- **การทำงานกับรูปภาพ** (เมื่อเลือกรูปภาพ): ครอบตัด, **ลบพื้นหลัง**, แทนที่, ล็อกสัดส่วน
- **การทำงานกับองค์ประกอบ** (เมื่อเลือกองค์ประกอบในตัวตรวจสอบ): ลบ, สร้างสำเนา, ย้ายขึ้น/ลง
- **ปุ่ม AI**: เปิดแผง AI และถามเกี่ยวกับองค์ประกอบที่เลือกได้ทันที
