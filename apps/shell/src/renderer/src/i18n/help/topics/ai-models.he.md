# מודלים של AI והגדרות

## ספקים ומודלים

מודלים ומפתחות מוגדרים בהגדרות (כפתור גלגל השיניים במסך הבית):

![חלון ההגדרות](img/settings-integrations.png)

- **Genspark מתארח**: התחברות (תהליך קוד מכשיר) ומשתמשים בזה — ללא שום הגדרה.
- **נקודות קצה מותאמות (BYOK)**: הגדרות ▸ AI לוקחות Base URL ומפתח API לכל פרוטוקול — OpenAI תואם, Anthropic, Gemini, DeepSeek, DashScope (qwen) ועוד. המפתחות קיימים רק בכותרות הבקשה — לעולם לא בדיסק, לא ביומנים ולא בסביבת תהליכי-צאצא.
- אפשר לבחור מודל אחר לכל יכולת: צ׳אט/יצירה, יצירת תמונות, ניתוח תמונות.
- **בדיקת חיבור**: אימות שהנקודה נגישה ושהמודלים גלויים לפני השמירה.
- ל- Base URL יכול להיות גם נתיב ומחרוזת שאילת (בסגנון gateway); נתיבי נקודות הקצה מתווספים בצורה נכונה.

## אינטגרציית CLI (מסוג Codex)

- ההגדרות מקבלות נתיב לתוכנית CLI מקומית (ספריות בית בגופנים שאינם ASCII וקידומת ~ נתמכים; ~ מורחב אוטומטית); "זיהוי מודלים" בודק אילו מודלים זמינים ל-CLI.
- האימות בודק רק קיום — ללא הגבלות על מערך התווים.

## מתי השינויים חלים

- שינויים במודל ובנקודת הקצה חלים מיד; שיחה שכבר בעיצומה ממשיכה להשתמש בהגדרה הישנה עד לסבב הבא שלה.
