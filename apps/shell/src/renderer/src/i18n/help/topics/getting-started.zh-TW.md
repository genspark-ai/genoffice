# 快速上手：介面與基本操作

GenOffice 是一套完全在你電腦上運作的辦公套件：單一視窗、一排分頁，裡面裝著六個編輯器——Docs（文字處理）、Sheets（試算表）、Slides（簡報）、PDF、Markdown 與 HTML。檔案就是真正的 .docx / .xlsx / .pptx / .pdf，與 Word、Excel、PowerPoint 完全互通，不需要連網。

## 介面總覽

![首頁畫面](img/home-screen.png)

視窗分成三塊：

- **分頁列（上方）**：每個開啟中的檔案都是一個分頁。最左邊的「首頁」分頁永遠存在、無法關閉；其餘分頁就是你開啟的文件。在分頁上按兩下可直接重新命名檔案。
- **內容區**：作用中分頁所對應的編輯器（或首頁）。
- **選單列**：macOS 上位於系統選單列，Windows/Linux 上位於視窗頂端。檔案／編輯／檢視等選單會隨作用中的編輯器切換。

## 建立文件

以下任一方式：

- 按一下**首頁**的[快速開始](help://getting-started)區卡片（AI Docs、AI Sheets、AI Slides⋯）。
- 選單 **檔案 ▸ 新增**：Docs（⌘N/ctrl+N）、Sheets、Slides、Markdown、HTML 或 PDF。
- 把檔案拖進視窗，或在檔案總管中按兩下（前提是 GenOffice 已設為預設應用程式）。

新文件會以未命名狀態開啟；磁碟上的檔案要到第一次儲存時才會建立。

## 開啟檔案

- 選單 **檔案 ▸ 開啟**（⌘O/ctrl+O）會開啟系統選擇視窗：.docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 直接點首頁「最近」的任一項目。
- 終端機裡執行 `genoffice <file>` 也能開啟檔案。

## 儲存模式

- **手動儲存**：⌘S/ctrl+S，或 檔案 ▸ 儲存／另存新檔。第一次儲存時會請你選擇位置與檔名。
- **自動儲存**只有在同一個檔案上手動儲存過至少一次之後才會開啟——只閱讀不做修改的 PDF 絕不會被悄悄改寫。自動儲存會在內容變動後的短暫停頓觸發。
- 關閉有未儲存變更的分頁時，會先詢問 儲存／捨棄／取消。
- 所有寫入都是原子操作（先寫暫存檔再改名），因此斷電也不會留下半個檔案。

## 常用快捷鍵

| 操作       | macOS | Windows / Linux |
| ---------- | ----- | --------------- |
| 新增文件   | ⌘N    | ctrl+N          |
| 開啟       | ⌘O    | ctrl+O          |
| 儲存       | ⌘S    | ctrl+S          |
| 關閉分頁   | ⌘W    | ctrl+W          |
| 開啟本手冊 | F1    | F1              |
| 摺疊功能區 | ⌥⌘R   | Ctrl+F1         |

**摺疊功能區**在每個編輯器裡都適用：分頁列照常保留，下方的指令列會收起來；選取的分頁同時就是摺疊控制項，所以功能區摺疊期間不會有分頁處於選取狀態，按下任一分頁就會讓指令列重新出現。連點兩下一個分頁也一樣。摺疊與否會按編輯器分別記住。

各編輯器內部的快捷鍵（格式刷、尋找與取代、表格操作⋯）請見各章；Docs 另外還提供可搜尋的鍵盤快速鍵對話框（**⌘/**）（見該章）。

## Option+Command 這一組快速鍵

Option+Command 是 Word 留給結構化跳轉的層級，GenOffice 也用同樣的方式填滿。以下全部是 Docs 自己的快速鍵：

| 快速鍵（macOS） | 作用           | Windows / Linux    |
| --------------- | -------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 標題 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 內文           | Ctrl+Alt+0         |
| ⌥⌘M             | 段落           | Ctrl+Alt+M         |
| ⌥⌘A             | 新增註解       | Ctrl+Alt+A         |
| ⌥⌘F             | 插入註腳       | Ctrl+Alt+F         |
| ⌥⌘E             | 插入章節附註   | Ctrl+Alt+D         |
| ⌥⌘G             | 到             | Ctrl+G             |

其中兩個在 Windows 上會變，理由跟 Word 把它們拆開一樣。**macOS 佔用了 ⌥⌘D**——它用來顯示與隱藏 Dock——所以章節附註在 Mac 上是 ⌥⌘E，在其他地方則是 Ctrl+Alt+D。而**到**則省掉 Alt：Mac 上的組合鍵帶著 Alt，Windows 上只要 Ctrl+G 就好。

這樣一來，macOS 上的 ⌥⌘D 就空著留給 GenOffice，將來哪個指令想用，就可以直接拿去用。
