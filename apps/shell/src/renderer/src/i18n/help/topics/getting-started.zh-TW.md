# 快速上手：介面與基本操作

GenOffice 是一套完全執行在你自己電腦上的本機辦公套件，它將文字處理（Docs）、試算表（Sheets）、簡報（Slides）、PDF、Markdown 和網頁（HTML）六款編輯器整合在同一個視窗和同一排頂部分頁裡。所有編輯器讀寫的都是標準的 .docx、.xlsx、.pptx 與 .pdf 檔案，與微軟 Word、Excel、PowerPoint 保持原生互通，日常開啟、編輯和儲存文件完全不需要連線。

## 介面總覽

![首頁一覽](img/home-screen.png)

開啟應用程式後，整個主視窗由三個核心部分加上全域介面縮放控制組成：

- **頂部分頁列**：你開啟的每一個文件都會在這裡顯示為一個獨立的分頁，可以像使用瀏覽器一樣隨時點擊切換、拖曳排序或拉出成新視窗。最左邊的「首頁」分頁永遠常駐且不可關閉，方便你隨時回到檔案清單；其餘文件分頁只要雙擊標題（或按右鍵選擇「重新命名」），就能在原地直接修改磁碟上的檔案名稱。
- **中央內容區**：佔據視窗絕大部分面積的主工作區，會根據你目前啟用的分頁自動切換成對應的編輯器畫布（或者在切回「首頁」分頁時顯示最近檔案、收藏夾與本機目錄清單）。
- **系統與視窗選單列**：在 macOS 上位於螢幕頂部的系統選單列，在 Windows 和 Linux 上則嵌在視窗最上方。這裡的「檔案」「編輯」「檢視」等下拉選單並不是靜態不變的，而是會隨著你目前切換到的文件類型，動態替換成該編輯器專屬的命令集合。
- **介面整體縮放**：如果你在高解析度螢幕、外接大顯示器或緊湊型筆電螢幕上覺得整個軟體的按鈕、文字和側邊欄偏小或偏大，可以透過頂部選單 **檢視 ▸ 放大／縮小／重設**（macOS 快捷鍵為 `⌘⌃=`／`⌘⌃-`／`⌘⌃0`，Windows 與 Linux 為 `Ctrl+Alt+=`／`Ctrl+Alt+-`／`Ctrl+Alt+0`）把整個應用程式視窗的 UI 比例在 80% 到 150% 之間依檔位縮放，而且無論是 macOS 左上角的紅黃綠視窗按鈕還是 Windows 右上角的最小化與關閉按鈕，在縮放時都會自動留出安全間距，絕不會與分頁列發生遮擋。

## 新增文件

想要建立一份空白文件時，可以根據你目前所處的位置任選以下三種最順手的方式：

- 在**首頁**頂部的[快速上手](help://getting-started)區域，直接點擊對應的文件卡片（包括 AI 文件、AI 試算表、AI 簡報、AI Markdown、AI 網頁和 AI PDF），系統會立即建立對應格式的檔案並切入編輯器。
- 在任何介面開啟頂部選單列的 **檔案 ▸ 新增**，從下拉選單中選擇 Docs 文字文件（也可以直接按快捷鍵 `⌘N`／`Ctrl+N`）、試算表、簡報、Markdown、網頁或空白 PDF。
- 直接從作業系統的 Finder 或檔案總管裡把已有的本機檔案拖進 GenOffice 視窗，或者在將 GenOffice 設為系統預設辦公軟體後直接雙擊桌面上和資料夾裡的文件圖示。

除了空白 PDF 需要立即寫入磁碟以外，新增的各類文件一開始都會以「未命名」的記憶體草稿狀態在分頁裡開啟，只有當你第一次按下儲存鍵時，才會在磁碟上真正建立出檔案。

## 開啟檔案

- 點擊頂部選單 **檔案 ▸ 開啟**（或按下快捷鍵 `⌘O`／`Ctrl+O`）會喚起作業系統的原生檔案選擇視窗，原生支援開啟 `.docx`、`.doc`、`.xlsx`、`.xls`、`.csv`、`.tsv`、`.pptx`、`.ppt`、`.pdf`、`.md`、`.html` 以及 `.txt`、`.json` 等常見辦公與文字格式，並且支援按住 Shift 或 Command／Ctrl 一次框選多個檔案同時開啟到不同分頁。
- 切到首頁的「最近使用」或「收藏」清單，直接單擊任意一行檔案即可在目前視窗的新分頁裡開啟它；如果該檔案已經在某個分頁裡開著，則會直接幫你切到那個分頁而不會重複開啟兩份。
- 如果你習慣使用終端機或編寫自動化腳本，也可以直接在命令列裡執行 `genoffice <檔案路徑>`，把指定文件直接推送到正在執行的 GenOffice 視窗中開啟。

## 檔案的儲存與自動儲存機制

- **手動儲存與另存新檔**：在任何編輯器裡按下 `⌘S`／`Ctrl+S`（或透過選單 **檔案 ▸ 儲存／另存新檔**）即可把目前修改寫入磁碟；如果是剛新增的「未命名」文件，第一次儲存時會先彈出系統儲存對話框讓你挑好存放目錄並輸入檔名。
- **安全的自動儲存策略**：為了防止你只是開啟一份他人傳來的文件或 PDF 隨便翻看幾眼、卻被背景悄悄改寫了檔案時間戳記甚至覆蓋了原件，某個檔案的自動儲存只有在你對該檔案執行過**至少一次手動儲存**之後才會正式接管；接管後，每當你輸入內容並短暫停頓，最新改動就會自動同步到磁碟。
- **關閉前的未儲存保護**：只要目前分頁裡存在還沒寫入磁碟的改動，無論是點擊分頁上的 `×` 還是按快捷鍵關閉視窗，系統都會先彈出提示框讓你明確選擇「儲存」「放棄變更」或「取消」，絕不會悄無聲息地丟掉你的心血。
- **防斷電原子寫入**：GenOffice 的每一次存檔都採用嚴格的「先寫入同目錄暫存檔、校驗完整後再原子重新命名替換原檔案」機制，哪怕在儲存瞬間遇到電腦斷電、當機或磁碟滿載，磁碟上也絕不會留下損壞了一半的廢檔案。

## 常用全域快捷鍵

| 操作       | macOS | Windows / Linux |
| ---------- | ----- | --------------- |
| 新增文件   | ⌘N    | ctrl+N          |
| 開啟       | ⌘O    | ctrl+O          |
| 儲存       | ⌘S    | ctrl+S          |
| 關閉分頁   | ⌘W    | ctrl+W          |
| 開啟本手冊 | F1    | F1              |
| 摺疊功能區 | ⌥⌘R   | Ctrl+F1         |

**摺疊與精簡功能區**在所有帶功能區（Ribbon）的編輯器裡都可以使用：按下 `⌥⌘R`（Windows 與 Linux 為 `Ctrl+F1`）或者直接雙擊目前選取的功能區分頁標題（如「常用」「插入」），下方的整排工具按鈕就會收起，只保留最上面薄薄一行分頁名稱，從而給內文畫布騰出更大的縱向視野；收起期間只需單擊任意一個分頁名稱就能重新展開命令面板，而且每個編輯器都會各自記住你上次離開時是展開還是摺疊狀態。此外，Docs 文字編輯器還額外提供了一檔介於完整展開與徹底摺疊之間的**緊湊模式**：按下 **⌥⌘K**（Windows 與 Linux 為 `Ctrl+Alt+K`）即可把命令列上的文字標籤隱去、只保留一排緊湊的圖示按鈕，這個偏好同樣會在下次啟動時自動保留。

至於各個編輯器內部專屬的操作快捷鍵（比如複製格式、尋找取代、表格操作、簡報放映等），可以在對應編輯器的章節或完整的「快捷鍵一覽」章節中查閱；在 Docs 文字編輯器中，你還可以隨時按下 **⌘/**（或 `Ctrl+/`，也可從「檢視」與「說明」選單進入）呼出一個支援即時搜尋的「鍵盤快捷鍵」速查視窗。

## Option+Command（Ctrl+Alt）結構化快捷鍵組

在桌面版微軟 Word 中，`Option+Command`（Windows 上對應 `Ctrl+Alt`）這一層組合鍵專門留給了標題樣式切換、插入註解與註腳等結構化編輯命令；GenOffice 完全沿用了這套肌肉記憶設計。其中絕大部分組合鍵歸 Docs 文字編輯器使用，Sheets 試算表也利用這一層補齊了兩個與 Excel for Mac 對齊的框線快捷鍵，外加一個在所有編輯器裡通用的功能區摺疊鍵。

**Docs 文字編輯器**

| 快捷鍵（macOS） | 作用           | Windows / Linux    |
| --------------- | -------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 標題 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 內文           | Ctrl+Alt+0         |
| ⌥⌘M             | 段落           | Ctrl+Alt+M         |
| ⌥⌘A             | 新增註解       | Ctrl+Alt+A         |
| ⌥⌘F             | 插入註腳       | Ctrl+Alt+F         |
| ⌥⌘E             | 插入章節附註   | Ctrl+Alt+D         |
| ⌥⌘G             | 到             | Ctrl+G             |

仔細看上面這張表會發現，有兩項在 macOS 與 Windows 上的按鍵字母並不完全呈鏡像關係，這同樣是為了與桌面版 Word 保持一致：因為 **macOS 系統自身佔用了 `⌥⌘D`** 用來切換 Dock 的自動隱藏，所以「插入章節附註」在 Mac 上改用 `⌥⌘E`，而在 Windows 與 Linux 上則保持大家熟悉的 `Ctrl+Alt+D`；另外「到（定位）」對話框在 Mac 上使用帶 Option 的 `⌥⌘G`（把 `⌘G`／`⇧⌘G` 留給尋找與字數統計），而在 Windows 上直接使用更簡短的 `Ctrl+G`。

**Sheets 試算表**（當表格網格處於焦點狀態時）

| 快捷鍵（macOS） | 作用     | Windows / Linux |
| --------------- | -------- | --------------- |
| ⌥⌘0             | 外側框線 | Ctrl+Shift+7    |
| ⌥⌘−             | 無框線   | Ctrl+Shift+−    |

這裡的平台差異同樣源於 Excel 的歷史設計：在 Excel for Mac 中，加上外側框線同時支援 `⌘⇧7` 和 `⌥⌘0` 兩套按鍵，而在 Windows 版 Excel 中一直使用的是 `Ctrl+Shift+7` 和 `Ctrl+Shift+-`。因此 GenOffice 在兩個平台上分別保留了各自最地道的按鍵習慣，不必強行去記另一套陌生組合。

需要注意的是，**`⌥⌘0` 在 Docs 裡代表「套用內文樣式」，而在 Sheets 裡代表「加上外側框線」**。由於這兩個編輯器分別執行在各自的分頁中、永遠不會同時爭搶焦點，日常使用時完全不會發生衝突；這也意味著 `⌥⌘0` 已經被具體編輯器認領，不再作為跨應用程式的全域快捷鍵。

**所有編輯器通用**：如前文所述，按下 **`⌥⌘R`／`Ctrl+F1`** 可以在任何編輯器裡一鍵收起或展開頂部功能區。

這樣分配下來，macOS 上除了被系統 Dock 佔走的 `⌥⌘D` 以外，整套 `Option+Command` 快捷鍵層既保留了老使用者的習慣，又做到了各司其職、互不打架。

## 接下來可以看哪裡

- 想弄清楚最近檔案、收藏夾、本機目錄和知識庫問答都在哪裡管理：請看[首頁（Home）](help://home-screen)一章。
- 想了解同時開啟十幾個檔案時如何重新命名、分割畫面、拖曳拆窗與合併視窗：請看[分頁與視窗管理](help://tabs-and-windows)。
- 想了解如何讓內建 AI 助理幫你起草文件、改寫段落、寫公式和自動排版：請看[AI 助理面板](help://ai-panel)。
- 想切換介面語言、深淺色主題、設定模型金鑰或把 GenOffice 接入外部程式設計代理：請看[設定、語言、主題與 MCP 整合](help://settings-integrations)。
