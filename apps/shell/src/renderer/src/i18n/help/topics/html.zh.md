# HTML 编辑器

GenOffice 的 HTML 编辑器专门用来查看和修改 `.html` / `.htm` 网页文件，提供**可视化预览模式**（直接渲染真实网页并支持点选改字）与**源码模式**（直接编辑底层 HTML 标签与样式脚本）双模式无缝切换，非常适合用来制作和微调数据报告网页、邮件模板、单页落地页或交互式简报。

- **真实网页预览模式**：直接渲染完整的 HTML 页面，网页里通过相对路径引用的本地 CSS 样式表、脚本与同目录图片资源都会自动按文件所在位置正常加载并呈现。
- **可视化预览检查器（Inspector）**：在预览模式下无需去翻几千行源码——直接用鼠标单击页面上的任意一个标题、段落、卡片或图片就能选中该 DOM 元素，**双击文字即可直接在网页画布上就地改字**，也可以用浮出的工具条一键删除、复制、上下移动该元素，或者点 **Ask AI（问 AI）** 直接让 AI 助手针对你选中的这一个网页局部做修改。
- **纯净源码编辑模式**：切换到源码模式后即可直接编写或修改底层 HTML、内联 CSS 与 JavaScript 代码；按下 `⌘F` / `Ctrl+F` 支持在源码中全文查找并一键「全部替换」后落盘保存。
- **字节级无损保存**：与 Markdown 编辑器一样，保存 `.html` 文件时严格保持字节级忠实——文件原本的 BOM 头、`CRLF` / `LF` 换行符制式以及结尾换行均原样保留，未发生修改时按下保存不会无故重写磁盘文件。
- **自由缩放与可视化撤销**：在预览画布上按住 `Ctrl`（或 macOS 上的 `⌘`）滚动鼠标滚轮，或者在触控板上双指捏合即可平滑缩放网页预览比例；在预览模式下做出的任何双击改字或元素删改，都可以随时按 `⌘Z` / `Ctrl+Z` 逐步撤销。
- **对 AI 隐藏网页敏感字段**：在源码模式下框选任意一段不想暴露给大模型的源码片段——无论是页面元素的正文文字、标签属性值（如真实链接、邮箱）还是 `<script>` 里的字符串字面量——右键选择**把选中的内容对 AI 隐藏**并命名占位符后，AI 助手读到的源码里就只会看到占位符，而左侧渲染出来的真实网页画面与保存后的文件则分毫不受影响（详见「AI 助手面板」一章）。

## 顶部工具条与元素浮动工具条

在可视化预览画布上用鼠标单击选中任意一个网页元素时，该元素正上方会自动浮出一排上下文快捷工具条，与窗口顶部的固定工具条配合使用：

![选中元素后的浮动工具条](img/html-toolbar.png)

- **文件与操作历史**：顶部工具条最左侧提供保存（`⌘S` / `Ctrl+S`）、另存为、多级撤销、重做与查找按钮，右侧配有**自动保存**开关，开启后会在编辑停顿后自动将最新网页写入磁盘。
- **预览 / 源码切换与全屏演示**：随时在**预览**、**分屏**与**源码**视图之间切换（快捷键 `⌘\` / `Ctrl+\`）；点击旁边的**演示**按钮则可以收起所有工具栏，进入全屏纯净展示模式来演示你的交互式网页。
- **文字格式与元素样式面板**：支持对选中文字一键设置**加粗**、**斜体**、增大或减小字号；当你在预览中点中某个元素时，还可以展开**样式面板**直观修改它的文字颜色、背景色与外观属性。
- **快速插入网页构件**：无需手写标签，直接点击工具条上的**插入**分组即可往网页里放各级标题、正文段落、结构化表格、图片（或超链接）以及更多常见 HTML 元素。
- **网页图片专属操作**（当在预览中点击选中一张 `<img>` 图片时浮现）：可以直接在网页上拉框**裁剪**图片、调用内置算法一键**去除图片背景（抠图）**、从本地挑选新图**替换**原图，或者开关**锁定宽高比**防止缩放变形。
- **DOM 元素结构操作**（当预览检查器选中任意一个网页块时）：支持一键**删除**该元素、在原地**复制（克隆）**一份相同的元素块，或者点击**上移 / 下移**直接调整它在父容器里的前后排列顺序（也可直接使用快捷键 `⌥↑` / `⌥↓` 或 `Alt+↑` / `Alt+↓`）。
- **AI 按钮与局部改页**：点击顶部 **AI 按钮**（或在选中元素后按 `⌘K` / `Ctrl+K`）即可展开右侧 AI 面板，直接让 AI 帮你重写选中的这块网页组件、调整 CSS 布局或生成新的图表卡片。

## 导出为 Word、PDF 与单文件 HTML

所有导出命令均集成在顶部菜单栏的**文件**菜单中，全部在本机离线执行，并在导出时弹窗询问保存位置：

- **导出为 Word… 与 导出为 PDF…**：将当前渲染出来的网页内容连同排版样式直接转换为真正可编辑的 `.docx` Word 文档，或者按页面版式输出为标准的 `.pdf` 文件。
- **导出为单文件 HTML…**：当你做的网页引用了多张本地相对路径图片、想把它打包发给别人且避免出现「裂图」时，选择此项就会自动把网页里引用的所有本地图片编码内嵌（Inline Data URL）并写出为一个独立自包含的 `.html` 文件；它总是另存为新文件而绝不会覆盖你当前正在编辑的工程原稿，并且在导出完成时还会明确汇报是否有外部图片未能成功内嵌。

## 一键插入标准 HTML5 文档骨架

当你新建或打开一份完全空白的 `.html` 文件并切到源码编辑模式时，点击顶部菜单 **插入 ▸ 插入骨架**，编辑器就会立即为你写入一份最精简、最规范的现代 HTML5 标准文档骨架：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

这段看似简短的骨架里，每一行都承担着避免网页排版踩坑的关键职责——这也正是为什么要把它做成一个一键命令，而不是让你每次凭记忆手敲：

- **`<!DOCTYPE html>` 声明**：一旦漏写这一行，浏览器的渲染引擎就会退化进古老的「怪异模式（Quirks Mode）」，导致 CSS 盒模型宽度计算、表格尺寸与弹性布局全都按非标准规则跑偏；
- **`lang` 语言属性**：如果没有声明页面语种，无障碍屏幕阅读器就不知道该用哪国发音规则朗读页面，渲染引擎也容易在中日韩多文种混排时挑错默认回退字体或拼写检查词典；
- **`<meta charset="UTF-8" />` 字符集声明**：没有显式指定 UTF-8 编码时，网页里的中文、日文或特殊符号在其他人的浏览器里打开极易被按旧编码解码成满屏乱码。

细心的读者可能会注意到，这份默认骨架里刻意没有塞入移动端常见的 `<meta name="viewport">` 标签：因为 GenOffice 的 HTML 编辑器渲染在桌面端宽幅面板里，本身不存在需要缩放适配的手机视口。

此外，`<html>` 标签上的 `lang` 属性值在插入时会自动跟随你当前 GenOffice 设置的界面语言（例如中文界面下会自动生成对应的语言标记），生成之后你随时可以在源码里按需修改。

为了防止不小心冲掉已有代码，**插入骨架**这个菜单项只有在你处于源码编辑模式、并且当前文档**完全为空**时才会显示出来；一旦文档里已经有了哪怕一个字符的内容，该菜单项就会自动隐去。
