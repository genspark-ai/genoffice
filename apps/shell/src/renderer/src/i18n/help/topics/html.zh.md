# HTML 编辑器

HTML 编辑器打开 .html / .htm，双模式：**预览**（渲染的页面）与**源码**。

- **预览模式**：页面真实渲染；相对路径的样式表和图片随文档加载。
- **预览检查器**：点击选中元素、双击就地编辑文字、工具条删除、Ask AI 直接针对选中内容提问。
- **源码模式**：编辑 HTML 源码；ctrl+F 查找、全部替换后保存。
- **保存**：字节级忠实（BOM/CRLF/结尾换行原样保留），未改动不重写。
- **缩放**：ctrl+滚轮 / 双指捏合调整预览比例；预览内 ctrl+Z 撤销上一步编辑。

## 工具条

在预览里点选任意元素，它上方会浮出工具条：

![选中元素后的浮动工具条](img/html-toolbar.png)

- **文件与历史**：保存、另存为、撤销、重做、查找；**自动保存**开关定时写盘。
- **预览 / 源码**切换；**演示**模式全屏展示页面。
- **格式**：粗体、斜体、字号增减；选中元素时的**样式面板**（颜色等）。
- **插入**：标题、段落、表格、图片（链接）、「更多」。
- **图片操作**（选中图片时）：裁剪、**去除背景**、替换、锁定宽高比。
- **元素操作**（预览检查器选中元素时）：删除、复制、上移/下移。
- **AI 按钮**：展开 AI 面板，可对选中元素提问。
