# HTML 编辑器

HTML 编辑器打开 .html / .htm，双模式：**预览**（渲染的页面）与**源码**。

- **预览模式**：页面真实渲染；相对路径的样式表和图片随文档加载。
- **预览检查器**：点击选中元素、双击就地编辑文字、工具条删除、Ask AI 直接针对选中内容提问。
- **源码模式**：编辑 HTML 源码；ctrl+F 查找、全部替换后保存。
- **保存**：字节级忠实（BOM/CRLF/结尾换行原样保留），未改动不重写。
- **缩放**：ctrl+滚轮 / 双指捏合调整预览比例；预览内 ctrl+Z 撤销上一步编辑。

## 工具条

在预览里点选任意元素，它上方会浮出工具条：

![选中元素后的浮动工具条](img/html-toolbar.png)

- **文件与历史**：保存、另存为、撤销、重做、查找；**自动保存**开关定时写盘。
- **预览 / 源码**切换；**演示**模式全屏展示页面。
- **格式**：粗体、斜体、字号增减；选中元素时的**样式面板**（颜色等）。
- **插入**：标题、段落、表格、图片（链接）、「更多」。
- **图片操作**（选中图片时）：裁剪、**去除背景**、替换、锁定宽高比。
- **元素操作**（预览检查器选中元素时）：删除、复制、上移/下移。
- **AI 按钮**：展开 AI 面板，可对选中元素提问。

## 导出

均在“文件”菜单中，全部是本地操作，并且都会询问结果要保存到哪里：

- **导出为 Word…** 和 **导出为 PDF…** 会写出真正的 .docx 或 .pdf 文件。
- **导出为单文件 HTML…** 会写出一个内嵌了图片的 .html 文件。它不会覆盖你当前打开的文件，并且会告诉你有多少张图片没能内嵌。

## 插入骨架

面对一张空白页面，**插入 ▸ 插入骨架** 会写入一份最小的标准模式文档：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

每一部分都有存在的理由——所以它是一个命令，而不是要你手打的东西：

- **doctype**：没有它，预览会跑在怪异模式下，盒模型和表格布局会按和你预期不同的规则走；
- **`lang`**：没有它，屏幕阅读器不知道该用哪种语言朗读页面，浏览器也会挑错字体和拼写检查器；
- **charset**：没有它，一整页非拉丁文字都可能被解码成乱码。

这里刻意不加 viewport meta：它渲染在桌面端面板里，没有移动端视口可影响。

`lang` 跟随应用的界面语言，所以你插入的骨架正是你的工具链已经适配好的那一个。之后可以随意修改。

这个菜单项只在编辑模式下出现，而且只在文档为空时出现——一旦有了内容，就没有可以往里插入骨架的东西了。
