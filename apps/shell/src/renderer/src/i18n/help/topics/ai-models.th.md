# โมเดล AI และการตั้งค่า

## ผู้ให้บริการและโมเดล

ตั้งค่าโมเดลและคีย์ได้ในหน้า การตั้งค่า (แถวบัญชีที่มุมล่างซ้ายของหน้าแรก):

![หน้าต่างการตั้งค่า](img/settings-general.png)

- **Genspark อย่างเป็นทางการ**: ลงชื่อเข้าใช้ (ขั้นตอนแบบรหัสอุปกรณ์) แล้วใช้ได้ทันที ไม่ต้องตั้งค่าอะไร
- **ปลายทางที่กำหนดเอง (BYOK)**: ใน การตั้งค่า ▸ AI ให้กรอก base URL และคีย์ API แยกตามโปรโตคอลของแต่ละเจ้า — ที่ใช้ร่วมกับ OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen) และอื่น ๆ คีย์มีอยู่เฉพาะในส่วนหัวของคำขอ ไม่เคยอยู่บนดิสก์ ในบันทึก หรือในสภาพแวดล้อมของกระบวนการย่อย
- เลือกโมเดลคนละตัวตามความสามารถได้: การสนทนา/การสร้างเนื้อหา, การสร้างภาพ, การวิเคราะห์ภาพ
- **ทดสอบการเชื่อมต่อ**: ตรวจว่าปลายทางเข้าถึงได้และมองเห็นโมเดลหรือไม่ ก่อนบันทึก
- base URL อาจมีพาธและ query string ติดมาด้วย (แบบเกตเวย์) และพาธของปลายทางจะถูกต่อท้ายอย่างถูกต้อง

## การผสานรวมกับ CLI (แบบ Codex)

- การตั้งค่ารับพาธของโปรแกรม CLI ในเครื่องได้ (รองรับไดเรกทอรีบ้านที่ไม่ใช่ ASCII และพาธที่ขึ้นต้นด้วย ~ โดยขยาย ~ ให้อัตโนมัติ) ส่วน ค้นหาอัตโนมัติ จะตรวจสอบโมเดลที่ CLI มีให้ใช้
- การตรวจสอบเช็กเพียงว่าพาธมีอยู่จริง ไม่มีข้อจำกัดด้านชุดอักขระ

## การเปลี่ยนแปลงมีผลเมื่อไร

- การเปลี่ยนโมเดลและปลายทางมีผลทันที ส่วนบทสนทนาที่กำลังดำเนินอยู่จะยังใช้การตั้งค่าเดิมไปจนถึงรอบถัดไป
