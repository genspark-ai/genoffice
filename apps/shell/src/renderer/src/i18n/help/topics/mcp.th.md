# การเชื่อมต่อเอเจนต์เขียนโค้ด

GenOffice สื่อสารด้วย Model Context Protocol เอเจนต์เขียนโค้ดจึงอ่าน เขียน และเรนเดอร์เอกสารของคุณด้วยเอนจินชุดเดียวกับที่แอปใช้ เอเจนต์ไม่ได้เดารูปแบบไฟล์มันได้สคีมาของแต่ละ op จากนิยามชุดเดียวกับที่ตัว executor ใช้ตรวจ

## การลงทะเบียน

กรณีปกติมีแค่คำสั่งเดียว

```sh
genoffice mcp install all
```

คำสั่งนี้จะหาเอเจนต์เขียนโค้ดที่อยู่บนเครื่องนี้ ได้แก่ Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode และ Windsurf แล้วเขียนรายการเซิร์ฟเวอร์แบบ stdio ลงในค่าตั้งของแต่ละตัว ส่วนที่เหลือของไฟล์นั้นจะยังคงเดิม

```sh
genoffice mcp list             # where each agent stands
genoffice mcp install cursor    # just one
genoffice mcp uninstall cursor  # take it back out
```

ถ้าติดตั้งเอเจนต์ไว้ในตำแหน่งที่ไม่ปกติ ให้ใช้ `--dir <path>` ส่วน `--force` จะเขียนรายการที่มีอยู่แล้วทับ

## ถ้ารันเอง

สำหรับไคลเอ็นต์ที่อยู่คนละเครื่อง ให้เปิดเป็น HTTP แทน

```sh
genoffice mcp --http 8765 --token <secret>
```

`--host <addr>` กำหนดที่ที่เซิร์ฟเวอร์จะรับ และต้องส่งโทเคนเดียวกันนั้นให้ไคลเอ็นต์

ผ่าน HTTP ไฟล์ก็เดินทางมาได้ `PUT /files/<name>` ใช้อัปโหลดหนึ่งไฟล์ เครื่องมือทุกตัวรับ URL แบบ `http(s)` แทนพาธได้ ผลลัพธ์จะกลับมาเป็น URL สำหรับดาวน์โหลด และถ้าเล็กพอก็กลับมาเป็น resource ที่ฝังอยู่ในตัว ส่วน op, spec และ Markdown ส่งเป็นข้อความตรง ๆ ทั้งสองแบบ

## สิ่งที่เอเจนต์ได้

ทุกคำสั่งเป็นเครื่องมือหนึ่งชิ้น ตัวที่น่าสนใจคือ

- **`docs`, `sheet`, `slides`** — อ่านและแก้ไขไฟล์ผ่านช่องทางเขียนของตัวแอปเอง ทีละหนึ่ง **op** งานนำเสนอใหม่จะไล่ไปตาม `deck_start`, `deck_page`, `deck_build`
- **`render`** — ได้ PNG หนึ่งไฟล์ต่อหนึ่งหน้า จัดวางโดยตัวเรนเดอร์ของแอป เอเจนต์จึงมองเห็นสไลด์จริงแทนที่จะเดา
- **`pdf`** — ชั้นข้อความของ PDF ทีละหน้า โดยไม่ต้องเปิดโปรแกรม
- **`info`** — ข้อมูลเมตาดาต้าและสรุปโครงสร้าง มักเป็นคำสั่งแรกที่ถูกที่สุดเวลาเจอไฟล์ที่ยังไม่คุ้นเคย
- **`search`, `image`, `media`** — ผู้ให้บริการที่ตั้งค่าไว้ในแอป เอเจนต์จึงไม่ต้องมีคีย์ของตัวเอง
- **`merge`** — เติมค่าในเทมเพลต `{{key}}`

## สคีมาและงบที่เล็กลง

`apply` และ `create` ประกาศพารามิเตอร์ `ops`, `cells` และ `data` พร้อมสคีมาที่มีชนิดของแต่ละ op ซึ่งสร้างจาก `genoffice guide <domain> --json` แบบนี้แม่นยำแต่ไม่เล็ก ไคลเอ็นต์ที่หน้าต่างบริบทแคบสามารถขอเป็นอาร์เรย์ธรรมดาแทนได้

```sh
genoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 genoffice mcp
```

## skill

เอเจนต์ที่ไม่รู้จักศัพท์ของ op ก็จะเดา `genoffice skill` จะติดตั้ง skill ของ GenOffice เข้าไปในเอเจนต์ที่มันหาเจอ พร้อมคู่มืออ้างอิงและแนวทางการออกแบบ ซึ่งเป็นเนื้อหาเดียวกับที่ `genoffice guide` พิมพ์ออกมา

## สิ่งที่มันไม่ใช่

เซิร์ฟเวอร์ MCP อ่านและเขียนไฟล์ได้ แต่มันไม่ใช่หน้าต่าง ไม่มีแผง AI และกล่องอัปเดตในแอปก็ใช้ไม่ได้ ถ้าขั้นตอนไหนต้องใช้หน้าต่าง ให้เปิดไฟล์นั้นเลย
