# Markdown 編輯器

Markdown 編輯器開啟 .md / .markdown，提供「原始碼＋算繪預覽」的編輯體驗。

- **開啟**：從首頁或 檔案 ▸ 開啟；命令列也可以。
- **編輯**：純文字編輯；GFM 擴充語法（表格、待辦清單、刪除線、自動連結）會在預覽中算繪。
- **預覽**：即時算繪；像圖片這類相對路徑的資源會依文件位置解析。
- **儲存**：位元組忠實——BOM、CRLF 以及結尾是否保留換行都會原樣保留；沒有修改時儲存不會重寫檔案。
- **尋找與取代**：ctrl+F 搜尋原始碼；全部取代後寫回。
- **AI**：預設按鈕可讓助手改寫、擴寫或翻譯整份文件。

## 工具列

編輯器上方一排按鈕（滑鼠停留可看說明）：

![Markdown 工具列](img/md-toolbar.png)

- **檔案與歷史**：儲存、另存新檔、復原、重做、尋找；右側的**自動儲存**開關會定時把變更寫入磁碟。
- **AI 按鈕**：開啟 AI 面板；旁邊是改寫／擴寫／翻譯等預設按鈕。
- **段落樣式**（下拉）：在內文與各級標題之間切換。
- **行內格式**：**粗體**、_斜體_、~~刪除線~~、`行內程式碼`、連結。
- **清單**：項目符號清單、編號清單、工作清單。
- **插入**：表格、圖片、水平線。
- **屬性**：在檔案開頭插入或跳至 YAML front matter 區塊。
- **大綱**：依標題層級跳轉。
- **拼字檢查**：切換本文件的拼字檢查。

三個快速範例：

- **標題**：把游標放到該行 ▸ 段落樣式下拉 ▸ 選「標題 1」。
- **表格**：按一下 **插入表格** ▸ 拖曳決定列／欄數 ▸ 在儲存格中輸入；預覽會立刻算繪出來。
- **工作清單**：選取幾行 ▸ 按一下 **工作清單** ▸ 每行都變成 `- [ ]`，在預覽中會呈現為可勾選的方塊。

## 匯出

都在「檔案」選單中，全部是本機作業，而且都會詢問結果要存到哪裡：

- **匯出為 Word…** 與 **匯出為 PDF…** 會寫出真正的 .docx 或 .pdf 檔案。
- **匯出為圖片…** 會把每一頁各寫成一張 PNG，放進您選取的資料夾。
- **轉換為 Docs 文件並開啟** 會轉換為 .docx，並在這個 App 內建的 Docs 分頁中開啟——它不是交給雲端的任何服務，轉換後的副本放在快取資料夾中，約一週後會清除。

## 原始碼檢視

工具列上有一個 **原始碼** 開關（隨應用程式一起當地化）。打開之後，編輯器會被原始的 Markdown 取代：就是儲存時寫入的那份文字，不做美化，也不會在你背後做正規化。

- **編輯是位元組忠實的。** 在原始碼檢視中儲存，產生的位元組與在編輯器中儲存完全相同——BOM、CRLF 以及結尾是否保留換行都原樣保留。
- **還是同一份文件。** 隨時來回切換；原始碼就是編輯器自己的文字，不是需要另外合併的複本。
- **格式工具列在這段期間無法使用**，因為那些按鈕大多插入的是編輯器構造，只在算繪側才有意義。關閉檢視後它會回來。
- **JSON 等原始碼模式的檔案**會直接在此開啟：沒有東西需要算繪，原始碼*就是*文件本身。
