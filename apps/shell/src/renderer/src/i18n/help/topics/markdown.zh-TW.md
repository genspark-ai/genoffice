# Markdown 編輯器

GenOffice 的 Markdown 編輯器專門用於開啟和編輯 `.md`／`.markdown` 文件——同時也負責直接以純淨原始碼檢視開啟 `.txt` 純文字與 `.json` 資料檔——採用現代輕量的所見即所得與原始碼切換體驗，讓你既能享受直觀的排版渲染，又能隨時掌控底層的每一行純文字字元。

- **多種開啟途徑**：既可以從首頁檔案清單或頂部選單 **檔案 ▸ 開啟** 點選檔案進入，也支援直接在終端機命令列裡透過 `genoffice <檔名.md>` 快速喚起。
- **完整支援 GFM 擴充語法**：在基礎 Markdown 語法之上，完整支援 GitHub Flavored Markdown（GFM）擴充，包括多欄表格、可點擊勾選的待辦工作清單（`- [ ]`／`- [x]`）、刪除線、程式碼區塊語法高亮、數學公式區塊（LaTeX）以及網址自動辨識連結。
- **所見即所得即時渲染**：輸入語法符號的同時畫布即刻渲染出排版效果；文件中引用的相對路徑本機圖片等資源會自動相對於目前 `.md` 檔案所在的磁碟目錄解析並直接顯示出來。
- **位元組級忠實儲存**：儲存檔案時嚴格尊重你原有檔案的底層編碼細節——無論是檔案開頭的 UTF-8 BOM 簽章、Windows 風格的 `CRLF` 還是 Unix 風格的 `LF` 換行符號，乃至檔案末尾是否留有空換行，都會原封不動地保留；如果你開啟檔案後沒有做任何實質修改就按儲存，編輯器甚至不會去重寫磁碟檔案以保護原始時間戳記。
- **原始碼級尋找與批次取代**：按下 `⌘F`／`Ctrl+F` 即可開啟尋找與取代面板，支援在整篇文件中快速定位關鍵字並一鍵「全部取代」後寫入磁碟。
- **AI 輔助寫作與隱私隱藏**：頂部工具列內建了一排 AI 快捷預設按鈕，點一下就能讓 AI 助理幫你潤飾改寫、順著下文續寫或翻譯目前文件；如果文件裡包含不想傳給雲端大模型的密碼、金鑰或私密段落，同樣支援選取後**對 AI 隱藏**（詳見「AI 助理面板」一章）。

## 頂部快捷工具列

在編輯區正上方常駐著一排高頻排版與檔案操作按鈕（把滑鼠游標懸停在任意圖示上都會顯示對應的功能提示與快捷鍵）：

![Markdown 工具列](img/md-toolbar.png)

- **檔案與操作歷史**：最左側依序排列著儲存（`⌘S`／`Ctrl+S`）、另存新檔、多層級復原、取消復原以及全文尋找按鈕；工具列右側則配有**自動儲存**獨立開關，開啟後會在你打字停頓期間自動把最新內容安全寫回磁碟。
- **AI 助理與快捷預設**：點擊醒目的 **AI 按鈕**即可展開或收起右側 AI 對話面板，緊挨在它旁邊的則是**改寫、續寫、翻譯**等一鍵式預設操作按鈕。
- **段落樣式下拉選單**：無需手動敲 `#` 號，直接從下拉清單裡就能把目前游標所在行在「內文」與「標題 1 至標題 6」之間快速切換。
- **行內文字格式**：選取文字後一鍵套用或取消**粗體**、_斜體_、~~刪除線~~、`行內程式碼`高亮，或者為選取範圍綁定跳轉超連結（快捷鍵 `⌘K`／`Ctrl+K`）。
- **三種清單切換**：一鍵將目前段落或選取的多行轉換為無序圓點清單、自動遞增的有序數字清單，或是帶核取方塊的互動式待辦工作清單。
- **常用區塊級插入**：支援透過網格選擇器一鍵插入多列多欄的標準 Markdown 表格、從本機挑選插入圖片，或者插入一條橫向水平分隔線（`---`）。
- **文件屬性（YAML Front Matter）**：點擊**屬性**按鈕即可在文件最頂部自動插入（或直接跳轉到已有的）YAML Front Matter 中繼資料區塊，方便使用 Hugo、Hexo、Jekyll 或 Obsidian 的使用者管理文章標題、日期與標籤屬性。
- **章節大綱跳轉**：點擊展開側邊大綱面板，系統會自動擷取全文各級標題生成目錄樹，點擊任意標題即可在長篇技術文件中瞬間定位。
- **文件拼字檢查**：隨時開啟或關閉針對目前這篇 Markdown 文件的拼字錯誤波浪線提示。
- **自訂圖床自動上傳設定**：寫技術部落格或團隊文件最頭疼本機圖片傳給別人看不了——在**圖床設定**裡設定好你自己的雲端儲存後，每當你往編輯器裡貼上截圖或拖入本機圖片時，GenOffice 都會自動先把圖片上傳到你指定的圖床（原生支援 Cloudflare R2、阿里雲 OSS、騰訊雲 COS、MinIO 等所有 **S3 相容物件儲存**，以及 **SM.MS** 和 **GitHub 倉庫圖床**）並自動插入線上圖片連結，同時還會在本機 `assets` 資料夾保留一份原圖副本作為離線保底。

三個最常用的上手小例子：

- **快速設標題**：把游標放到某一行文字裡 ▸ 點開工具列上的**段落樣式**下拉選單 ▸ 選擇「標題 1」，該行就會立即變成一級大標題。
- **視覺化插表格**：點擊工具列上的**插入表格**圖示 ▸ 用滑鼠在彈出的小網格上滑過需要的列數與欄數並單擊 ▸ 直接在渲染好的表格儲存格裡填字即可，無需自己手敲繁瑣的直線 `|` 和對齊橫線。
- **製作待辦清單**：用滑鼠框選寫好的幾行計畫 ▸ 點擊工具列上的**工作清單**按鈕 ▸ 每一行都會自動變成可直接在介面上打勾的核取方塊清單項（底層原始碼對應標準的 `- [ ]`）。

## 多格式本機匯出

所有匯出功能皆位於頂部選單列的**檔案**選單下，全部由本機引擎離線完成，絕不上傳雲端，並在匯出前讓你自由指定儲存路徑：

- **匯出為 Word… 與 匯出為 PDF…**：將目前 Markdown 文件的標題層級、表格、程式碼區塊、公式與圖片直接排版轉換為標準的 `.docx` Word 文件或分頁整齊的 `.pdf` 檔案。
- **匯出為圖片…**：依列印分頁將整篇文件渲染輸出為一張或多張高畫質 `.png` 圖片，儲存在你挑選的目標資料夾裡。
- **轉換為 Docs 文件並開啟**：如果你想在 Markdown 初稿的基礎上繼續使用 Word 的複雜頁首頁尾、分欄或追蹤修訂功能，點這一項就會在本機直接把目前文件轉換成一份 `.docx` 檔案，並立即在旁邊開啟一個新的 **Docs 文字編輯器分頁**載入它；轉換生成的副本存放在本機暫存快取目錄中（約一週後自動清理），你可以隨時在 Docs 裡把它另存到正式工作目錄下。

## 純淨原始碼檢視（Source View）

工具列右側配有一個**原始碼**切換按鈕（或按快捷鍵 `⌘E`／`Ctrl+E`）。點亮它之後，畫布上的渲染排版會立即切換為最原始的純文字 Markdown 原始碼編輯器：你在裡面看到的每一個字元，就是按下儲存時真正寫入磁碟的位元組，編輯器絕不會在背後自作主張替你重新折行、「美化」縮排或偷改你的語法符號。

- **兩個檢視下儲存皆保持位元組級忠實**：無論你是在渲染編輯檢視還是在純原始碼檢視下按下儲存，寫回磁碟的位元組流都完全一致——檔案原有的 UTF-8 BOM、換行符號制式（`CRLF` 或 `LF`）以及文末換行符號都會被一絲不苟地保留下來。
- **操作的是同一份底層文件**：你可以在渲染檢視和原始碼檢視之間隨時無縫來回切換，因為原始碼檢視直接展示的就是編輯器底層的同一份記憶體文字，而不是需要來回合併、容易丟改動的平行副本。
- **原始碼模式下格式按鈕自動避讓**：當你處於純原始碼檢視時，頂部工具列裡那些依賴富文本節點的排版按鈕會暫時反灰停用，防止在原始碼裡插入不合時宜的編輯器構造；一旦你再次點擊「原始碼」關掉原始碼檢視，整排格式工具就會立刻恢復可用。
- **`.txt` 與 `.json` 檔案的預設歸宿**：當你用 GenOffice 開啟 `.txt` 純文字或 `.json` 設定檔時，因為它們本身沒有任何需要渲染成富文本的 Markdown 標記，系統會貼心地直接以這個乾淨的**原始碼檢視**將它們開啟，讓你能直接享受程式碼級尋找取代與位元組級無損儲存。
