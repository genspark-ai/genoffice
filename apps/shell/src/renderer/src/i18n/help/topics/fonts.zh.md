# 字体：系统字体与可下载字体

## 字体选择器与跨平台识别

在各个编辑器的顶部功能区「开始」页签下，都可以找到完整的字体家族与字号选择器（下图展示的是 Slides 演示文稿功能区中的字体分组）：

![Slides 功能区的字体分组](img/fonts.png)

打开字体下拉列表时，各编辑器会将**你电脑操作系统里已经安装的本地字体**与**跨平台常见办公字体候选库**合并呈现出来——无论是 Windows 上常见的宋体、黑体、楷体、微软雅黑、等线，还是 macOS 上常见的苹方（PingFang SC）、华文黑体、华文宋体、Hiragino（ヒラギノ）与 Apple SD Gothic Neo，包括这些中日韩字体在不同语言系统下显示的中文名与英文别名，GenOffice 都能准确识别并归入同一字体槽位。当操作系统允许枚举本地字体时，下拉框会按你机器上的实际可用状态清晰分组；在受限环境无法枚举时，也会平稳回退展示完整的标准办公字体列表，确保打开跨平台文档时字形属性不会丢失。

## 从内置开源字体目录一键下载字体（Slides）

- **精选多语种开源（OFL）字体库**：在 Slides 演示文稿编辑器中打开字体选择器时，可以直接点开内置的**字体目录（Font Catalog）**——这里收录了一份经过精心挑选、采用 SIL Open Font License（OFL）开源授权的高品质多文种字体清单，每个字体家族都配齐了实用的**常规（Regular）**与**粗体（Bold）**两个标准字重。
- **固定校验和，一键装入应用即刻可用**：在目录里挑中喜欢的字体后点击下载，GenOffice 就会从官方 CDN 拉取字体文件（内置严格的 SHA 校验和比对，确保下载的字体包未被篡改）并直接安装到应用自己的字体库中；下载完成的瞬间，所有打开的文档标签页就能立即选用这套新字体，全程不需要管理员权限，也不用去折腾操作系统的系统字体册。
- **独立私有目录，不污染系统**：通过字体目录下载安装的字体全部存放在 GenOffice 的应用私有数据目录下，保持你的操作系统字体目录干干净净；将来如果你卸载应用，这些私有字体也会随之一起清理干净。

## 中日韩（CJK）排版与字形覆盖

- **对齐桌面版 Word 的中文排版规则**：中文字体在 Docs 文字编辑器中配合完整的中文排版引擎工作，原生支持行首行尾标点避头尾（禁则处理）、连续标点符号字距挤压、中西文混排间距以及初号到八号的传统中文字号体系（详细排版规则可参阅「Docs：文字处理」一章）。
- **全面覆盖简繁中日韩衬线与无衬线体**：内置可下载字体目录中的 CJK 字体家族完整覆盖了简体中文、繁体中文、日文与韩文的衬线体（宋体/明朝体风格）与无衬线体（黑体/哥特体风格），哪怕在一台刚装好系统、缺少美观商用字体的电脑上做汇报 PPT，也能一键补齐端庄大方的多语种排版字体。

## 导入与管理你自己的本地字体文件

- **一键导入本地 `.ttf` / `.otf` 字体文件**：如果你手里有公司品牌规定的专用企业字体或自己下载的 `.ttf`、`.otf` 字体包，无需安装到整个操作系统，直接点击字体管理面板里的**安装本地字体文件**入口，就能把磁盘上的字体文件直接导入 GenOffice 的应用字体库中使用。
- **按字体家族自动归档合并**：导入后的字体会自动按照底层字体家族（Font Family）名称整齐归档，同一个字体家族下的常规、粗体、斜体等多个不同字重文件会自动合并在同一个家族条目下协同工作。
