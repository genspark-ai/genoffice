# 字体：系统字体与可下载字体

## 字体列表

字体控件在各编辑器功能区的「开始」页签（下图是 Slides 的字体分组）：

![Slides 功能区的字体分组](img/fonts.png)

各编辑器的字体选择器合并显示：本机已安装字体 + 平台常见候选（Windows 与 macOS 的常见中西文家族都认得，包括中日韩字体在各自系统上的本地化名字）。系统能枚举本地字体时按实际结果分组；不能枚举时退化为完整候选列表。

## 下载字体（Slides）

- Slides 的字体选择器可打开**字体目录**：一个精选的开源（OFL）字体清单，含多文种家族；每个家族提供常规与粗体两个字重。
- 选中即从 CDN 下载安装到应用字体库（校验和固定），之后所有文档可用，无需系统级安装。
- 安装的是应用私有目录，卸载应用即清除。

## 中文排版

- 中文字体在 Docs 中支持标点压缩、避头尾等 Word 对齐的排版规则（详见 Docs 章）。
- 下载目录中的 CJK 家族覆盖简繁中文、日文、韩文衬线与无衬线。

## 管理本地字体

- 「安装本地字体文件」入口可把磁盘上的 .ttf/.otf 装入应用字体库。
- 字体库按家族归档，同家族多字重共存。
