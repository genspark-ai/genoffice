# Sheets: स्प्रेडशीट

Sheets, Excel जैसा एडिटर है; गणना एक अलग Rust इंजन प्रक्रिया में चलती है (वहाँ क्रैश होने पर ऐप कभी नहीं गिरता)। यह असली .xlsx खोलता और सहेजता है; .csv और .tsv तालिकाओं के रूप में खुलते हैं।

## इंटरफ़ेस

- **रिबन**: आठ टैब, नीचे एक-एक करके बताए गए हैं।
- **सूत्र पट्टी**: सक्रिय सेल का सूत्र दिखाती और संपादित करती है; सामान्य फ़ंक्शन समर्थित हैं।
- **शीट टैब** (नीचे): शीट जोड़ना / नाम बदलना / हटाना / स्थानांतरित करना।
- **सेल संपादन**: डबल-क्लिक करें या सीधे टाइप करें; Enter पुष्टि करता है और नीचे जाता है, Tab दाईं ओर जाता है, Escape रद्द करता है (Excel की आदत)।
- **शॉर्टकट**: Excel परिवार के अनुरूप (ctrl+C/V/X, ctrl+Z/Y, ctrl+F, ...)।

## रिबन टैब

- **होम**: फ़ॉन्ट, भरण, बॉर्डर, संख्या प्रारूप (मुद्रा/प्रतिशत/हज़ार, दशमलव घटाएँ-बढ़ाएँ), संरेखण, मर्ज, पंक्ति/स्तंभ सम्मिलित करना और आकार, सशर्त स्वरूपण, तालिका के रूप में स्वरूपित करना, सेल शैलियाँ, क्लिपबोर्ड और फ़ॉर्मेट पेंटर, क्रमबद्धता और फ़िल्टर।
- **सम्मिलित करें**: आकृतियाँ, आइकन, प्रतीक, समीकरण, स्क्रीनशॉट और अन्य।
- **पृष्ठ लेआउट**: थीम रंग और फ़ॉन्ट, ग्रिडलाइन/शीर्षक मुद्रण टॉगल, पेज ब्रेक पूर्वावलोकन।
- **सूत्र**: स्वतः योग और फ़ंक्शन सम्मिलित करना, नाम परिभाषित करना (चयन से भी), पूर्ववर्ती/आश्रित ट्रेस करना, वॉच विंडो, शीट/कार्यपुस्तिका की पुनर्गणना।
- **डेटा**: क्रमबद्ध करना और फ़िल्टर (उन्नत फ़िल्टर, फ़िल्टर साफ़ करना सहित), पाठ से स्तंभ, वर्कबुक मर्ज, सभी ताज़ा करें।
- **समीक्षा**: टिप्पणियाँ देखना (दिखाएँ, पिछली/अगली), अनुवाद।
- **दृश्य**: ग्रिडलाइन और शीर्षक टॉगल, ज़ूम, सामान्य दृश्य / पेज ब्रेक पूर्वावलोकन।
- **चार्ट डिज़ाइन**: चार्ट चुनने पर दिखता है — चार्ट प्रकार, शैलियाँ और रंग, डेटा श्रेणी संपादित करना।

"डेटा" टैब, बटन-दर-बटन (चित्र में बाएँ से दाएँ):

![डेटा टैब](img/sheets-data.png)

- **पिवट टेबल**: वर्तमान श्रेणी से पिवट टेबल बनाता है; सारांश बनाने के लिए फ़ील्ड खींचें।
- **ताज़ा करें**: वर्तमान पिवट टेबल के डेटा की पुनर्गणना करता है।
- **पाठ/CSV से**: .csv/.txt को डिलीमीटर से विभाजित करके नई शीट के रूप में आयात करता है।
- **वर्कबुक मर्ज**: दूसरी .xlsx फ़ाइलों की शीट इसी में जोड़ता है।
- **सभी ताज़ा करें**: हर पिवट टेबल और बाहरी डेटा सेट की पुनर्गणना करता है।
- **क्रमबद्ध करें** (ड्रॉपडाउन): A → Z / Z → A / कस्टम क्रमबद्धता (कई स्तंभों के नियम)।
- **फ़िल्टर**: शीर्ष पंक्ति में ▼ ड्रॉपडाउन जोड़ता है; रखने योग्य मान चुनें।
- इसके बगल में छोटे ढेर से लगे बटन: **साफ़ करें** (हर पंक्ति वापस लाता है), **फिर से लागू करें** (वर्तमान फ़िल्टर दोबारा चलाता है), **उन्नत** (शर्त श्रेणी से फ़िल्टर)।
- **पाठ से स्तंभ** (ड्रॉपडाउन): एक स्तंभ को डिलीमीटर या निश्चित चौड़ाई से कई में बाँटता है।
- **फ़्लैश फ़िल**: एक उदाहरण दें, बाकी पंक्तियाँ उसी उदाहरण से भर जाती हैं (ctrl+E)।
- **डुप्लिकेट निकालें**: चयनित स्तंभों के आधार पर डुप्लिकेट पंक्तियाँ हटा देता है।
- **डेटा सत्यापन** (ड्रॉपडाउन): चयन के लिए इनपुट नियम (ड्रॉपडाउन सूचियाँ, संख्या श्रेणियाँ...)।
- **समेकित करें**: कई श्रेणियों को श्रेणी के अनुसार एक जगह इकट्ठा करता है।
- **क्या-यदि विश्लेषण** (ड्रॉपडाउन): लक्ष्य खोज / डेटा टेबल।
- **समूहित करें / समूह रद्द करें** (ड्रॉपडाउन): पंक्ति या स्तंभ समूह, संक्षिप्त और विस्तार के साथ।
- **उप-योग**: श्रेणी के अनुसार उप-योग पंक्तियाँ सम्मिलित करता है।

"सूत्र" टैब, बटन-दर-बटन:

![सूत्र टैब](img/sheets-formulas.png)

- **फ़ंक्शन सम्मिलित करें** (fx): तर्क विज़ार्ड के साथ फ़ंक्शन खोजें।
- **स्वतः योग** (ड्रॉपडाउन): एक क्लिक में SUM, साथ ही औसत/गिनती/अधिकतम/न्यूनतम।
- **हाल ही में उपयोग किए गए / वित्तीय / तार्किक / पाठ / दिनांक और समय / लुकअप और संदर्भ / गणित और त्रिकोणमिति / अधिक फ़ंक्शन**: श्रेणी के अनुसार फ़ंक्शन देखें और सम्मिलित करें।
- **नाम प्रबंधक**: नामित श्रेणियाँ देखना, बनाना और हटाना।
- **नाम परिभाषित करें** (ड्रॉपडाउन): चयन को नाम दें; **सूत्र में उपयोग करें** मौजूदा नाम डालता है; **चयन से बनाएँ** शीर्ष पंक्ति/स्तंभ से नाम बनाता है।
- **पूर्ववर्ती ट्रेस करें / आश्रित ट्रेस करें**: नीले तीर दिखाते हैं कि सूत्र का डेटा कहाँ से आता है और कहाँ जाता है; **तीर निकालें** उन्हें हटा देता है।
- **सूत्र दिखाएँ**: सेल परिणाम के बजाय सूत्र स्वयं दिखाते हैं।
- **त्रुटि जाँच**: सूत्र की त्रुटियाँ ढूँढता है और उन्हें समझाता है।
- **वॉच विंडो**: जिन सेलों की परवाह है उन्हें पिन करें और उनके मान लाइव देखें।
- **गणना विकल्प** (ड्रॉपडाउन): स्वचालित या मैन्युअल पुनर्गणना; मैन्युअल मोड में **अभी गणना करें / शीट की गणना करें** इसे हाथ से चलाते हैं।

## संख्याएँ और स्वरूपण

- संख्या प्रारूप: सामान्य, संख्या, मुद्रा, प्रतिशत, तिथि/समय, भिन्न, वैज्ञानिक और अन्य।
- संरेखण, रैप, मर्ज किए गए सेल, बॉर्डर और भरण।
- पंक्ति की ऊँचाई और स्तंभ की चौड़ाई खींचकर; सीमा पर डबल-क्लिक से स्वतः फ़िट।

## डेटा

**क्रमबद्ध करना और फ़िल्टर** (उदाहरण के लिए, एक स्तंभ से Z → A):

1. **उस स्तंभ के किसी भी सेल** पर क्लिक करें (पूरा स्तंभ चुनने की ज़रूरत नहीं)।
2. होम टैब ▸ **क्रमबद्ध और फ़िल्टर करें** ▸ **Z → A**; पूरी पंक्तियाँ साथ-साथ पुनर्क्रमित हो जाती हैं (क्षेत्र एक इकाई के रूप में क्रमबद्ध होता है)।
3. अपने नियमों के लिए (कई स्तंभ, रंग के अनुसार): वही रास्ता, **कस्टम क्रमबद्धता**।
4. फ़िल्टर: शीर्ष पंक्ति चुनें और **क्रमबद्ध और फ़िल्टर करें ▸ फ़िल्टर** दबाएँ — हर शीर्ष में ▼ ड्रॉपडाउन आता है जहाँ रखने योग्य मान चुनें; फ़िल्टर साफ़ करने पर सब कुछ वापस आ जाता है।

- क्रमबद्ध करना और फ़िल्टर।
- फ़्रीज़ किए गए फलक।
- .csv / .tsv: सीधे तालिका के रूप में खुलते हैं (टैब से अलग किया tsv एक ही तालिका के रूप में पढ़ा जाता है); सहेजने पर मूल प्रारूप वापस लिखा जाता है।

## राइट-क्लिक मेन्यू

- **ग्रिड में**: एडिटर (Univer) का अपना मेन्यू — काटें/कॉपी/पेस्ट, पंक्ति/स्तंभ सम्मिलित और हटाना, छिपाना, सेल मर्ज, फ़्रीज़ फलक और अन्य रोज़मर्रा के आइटम।
- **नीचे की स्थिति पट्टी पर**: चुनें कि स्थिति पट्टी कौन-से आँकड़े दिखाए (औसत / गिनती / योग, ...); चयन याद रहता है।
- **नीचे किसी शीट टैब पर**: शीट जोड़ना / नाम बदलना / हटाना / रंग / छिपाना (Univer का टैब मेन्यू)।
- ऊपर की टैब पट्टी का संदर्भ मेन्यू [टैब और विंडो प्रबंधन](help://tabs-and-windows) में है।

## स्क्रिप्ट एडिटर (उन्नत)

Sheets में एक **स्क्रिप्ट एडिटर** आता है जिसमें Google Apps Script जैसा API बैच काम के लिए मिलता है।

- खोलें: Tools ▸ Script editor (या संस्करण के अनुसार डेवलपर मेन्यू)।
- इंटरफ़ेस: बाईं ओर स्क्रिप्ट लाइब्रेरी (नया/हटाएँ), दाईं ओर कोड एडिटर और आउटपुट फलक; **रन / स्टॉप** बटन।
- API असिंक्रोनस है:

```js
const sheet = await SpreadsheetApp.getActiveSpreadsheet()
const active = await sheet.getActiveSheet()
const range = await active.getRange('A1:C10')
const values = await range.getValues() // 2D array
await range.setValues(values.map((row) => row.map((v) => v * 2)))
Logger.log('done')
```

- `SpreadsheetApp` (प्रवेश), `Sheet` (getName/getRange/getLastRow...), `Range` (getValue(s)/setValue(s)/clear...), `Logger.log`, `Utilities.sleep`।
- स्क्रिप्ट एक **सैंडबॉक्स कर्मचारी** में चलती हैं: कोई नेटवर्क नहीं, कोई फ़ाइल प्रणाली नहीं, कोई DOM नहीं — वे केवल ऊपर दिए API तक पहुँच सकती हैं, इसलिए कोई बगी या दुर्भावनापूर्ण स्क्रिप्ट किसी और चीज़ तक नहीं पहुँच सकती।
- आउटपुट फलक की पंक्तियों की सीमा होती है ताकि बहुत बड़े लॉग इंटरफ़ेस को अटकाएँ नहीं।
- **AI भी स्क्रिप्ट चला सकता है**: सहायक का `run_script` टूल वही सैंडबॉक्स API चलाता है — बैच और नियम-आधारित बदलावों के लिए बिल्कुल सही।

## AI

- किनारे का AI पैनल: कोई श्रेणी चुनें और साधारण भाषा में निर्देश दें (स्वरूप बदलें, डेटा बनाएँ, सूत्र लिखें)।
- AI के बदलाव पैनल से वापस लिए जा सकते हैं।

## सहेजना और निर्यात

- .xlsx सहेजता है (सूत्र और स्वरूप सुरक्षित रहते हैं); इस रूप में सहेजें; PDF निर्यात मुद्रण पेजिंग के अनुसार होता है।
- स्वतः सहेजना वैश्विक नियम का पालन करता है (पहली मैन्युअल सहेज के बाद चालू)।

## स्थिरता

- Rust गणना साइडकार UI से प्रक्रिया-स्तर पर अलग है: बेहद बड़ा डेटा उसे मार दे, तो आपको एक संदेश और सत्र पुनर्प्राप्ति का प्रयास मिलता है — ऐप क्रैश नहीं होता।
