# ホーム画面：ファイルの置き場所

ホームは GenOffice のスタートページです。左側にナビゲーションサイドバー、右側にファイル一覧とクイック作成カードが並びます。

![ホーム画面](img/home-screen.png)

## サイドバーのナビゲーション

- **最近使用**：最近開いたファイルです。各行には時刻が付きます — 今日、昨日、または日付。
- **お気に入り**：お気に入りに登録したファイルです。ファイル行にポインターを合わせて星マークをクリックすると、登録と解除ができます。
- **ユーザーガイド**：このマニュアルを開きます。
- **Genspark Projects**：Genspark アカウントでサインインすると、Web 版の Genspark AI で作成したプロジェクトが表示されます。クリックしてブラウザーで編集を続けられます。検索、時期順の並べ替え、更新、さらに読み込むにも対応しています。
- **フォルダー**：**フォルダーを追加…** でサイドバーに追加した、またはファイルマネージャーからドラッグしたディレクトリです。それぞれがルートになり、開いてサブフォルダーを作成したり、名前を変更したり、削除したりできます。オフラインになったルートは「利用不可」と表示され、一覧から外せます。**新しいフォルダー** を作るとさらに一つ追加されます。

ここにはゴミ箱の項目はありません。削除したファイルはシステムのごみ箱に入り、元に戻すのは OS の仕事です。

## ファイル一覧

各行にはアイコン、ファイル名、更新時刻などが表示されます。行の **⋯ メニュー** には次の項目があります。

- **開く**、および **フォルダーで表示** でファイルマネージャー内の場所を確認します。
- **パスをコピー**。
- **フォルダーに移動…**：フォルダーの選択画面を開き、実際にファイルを移動します。移動先に同じ名前のファイルが既にある場合は、スキップ・上書き・名前の変更を選べます。
- **名前の変更**：その場で改名します（拡張子は自動で保持されます）。
- **お気に入りに追加 / お気に入りから削除** — 星は再起動後も残り、名前を変更してもファイルに追従します。
- **複製を作成**：同じフォルダーにコピーを作ります。
- **削除**：ファイルをシステムのごみ箱に移します。完全削除ではありません。
- **リストから削除**：最上位の「最近使用」表示で、エントリだけを取り除きます。ファイル自体は変更されません。

### 複数のファイルをまとめて

行のチェックボックスをオンにするか、⌘/ctrl クリックで選択範囲を作れます。ヘッダーのチェックボックスは現在表示されているものをすべて選び、一覧の上のバーが選択件数（**{n} 件選択中**）を表示し、選択全体に対して **フォルダーに移動…** と **ファイルを削除** を使えます。複数選択したものをサイドバーのフォルダーへドラッグすることもできます。

## 検索

上部の検索ボックスは 2 種類をまとめて検索します。

- **ファイル名**：名前ですばやく絞り込みます。
- **ファイルの中身**：GenOffice はバックグラウンドでファイルにインデックスを張ります（docx/xlsx/pptx/pdf/md/html の中の文字、スキャンした PDF は OCR で補完）。そのため、本文の文字列で検索してもファイルが見つかります。検索対象の範囲と各スイッチは検索の設定で変更できます。

## クイックスタートのカード

一覧の上にあるカードから、1 ステップで新規文書を作れます。カードをクリックすると、その種類のファイルが作成されて対応するエディターが開くので、すぐに書き始められます。AI に下書きさせることもできます（各エディターのリボンに **AI ボタン**、選択後のコンテキストメニューに **AI に修正依頼** があります）。

新しいファイルはサイドバーで現在選択中のフォルダーに作られます。何も選択していない場合は既定のフォルダーに入ります。

各カードの内容：

- **AI Docs**（.docx）：Docs エディターの空の文書です。ファイルがディスクに書かれるのは**最初に保存したとき**です。新規文書では AI パネルが展開した状態で開くので、必要ない場合は 設定 →「新しいドキュメントで AI パネルを開く」で閉じられます。
- **AI Sheets**（.xlsx）：Sheets エディターの空の表です。保存するまではディスク上にファイルは存在せず、名前は最初の保存のために確保されています。最初に AI で内容を生成した後は、内容からファイル名を自動的に変更することもできます。
- **AI Slides**（.pptx）：Slides エディターの空のプレゼンテーションです。
- **AI Markdown**（.md）：Markdown エディターの空の Markdown 文書です。
- **AI HTML**（.html）：HTML エディターの空のウェブページです。
- **AI PDF**（.pdf）：他のカードとは違います。**即座に**対象フォルダーに本物の 1 ページ PDF を作り、通常のファイルとして開きます（PDF エディターは実ファイルを扱います）。注釈の追加、塗りつぶし、テキストの追加に向いています。最初の保存時に、内容からファイル名を自動的に変更することもできます。
- **ローカルファイルを開く**：システムのファイル選択ダイアログを開きます。Word（.docx/.doc）、Excel（.xlsx/.xlsm/.xls/.csv/.tsv）、PowerPoint（.pptx/.ppt）、PDF、Markdown（.md/.markdown）、ウェブページ（.html/.htm）に対応します。複数選択が可能で、選択したファイルはそれぞれ別のタブで開きます。

> ヒント：メニューの ファイル ▸ 新規作成 でも同じ種類の文書を作れます（⌘N/Ctrl+N の既定はテキスト文書です）。ファイルをウィンドウにドラッグすると、そのまま開きます。

## クラウドプロジェクト（Genspark Projects）

- 初めて使うときは Genspark アカウントへのサインインが必要です（デバイスコード方式：GenOffice がコードを表示し、ブラウザーでログインを完了します）。
- プロジェクト一覧は Web 版と同期します。「ブラウザーで開く」で移動して編集を続けられるようになります。
- サインインしていない場合も、ローカル機能のいずれにも影響しません。
