# 檔案操作：重新命名、刪除、匯出

這一章彙總介紹跨所有編輯器通用的底層檔案管理操作（包括重新命名、刪除進垃圾桶、建立副本、原子儲存以及跨格式匯出）；至於各個編輯器內部專屬的進階匯出選項，也可以在對應編輯器的專門章節中查閱。

在首頁（Home）的檔案清單中，把滑鼠游標懸停到任意一列檔案上，右側就會浮現出集中了絕大多數檔案管理命令的 **`⋯` 更多選單**（直接在檔案列上點擊滑鼠右鍵效果相同）：

## 重新命名檔案

GenOffice 提供了兩處最順手的重新命名入口，無論你當時是在首頁挑檔案還是已經在編輯器裡寫文章，都能隨手改名，而且兩邊走的是完全相同的一套安全校驗管線：

- 在首頁（Home）的「最近」「收藏」或「資料夾」清單裡，點擊目標檔案列右側的 **`⋯` ▸ 重新命名**。
- 在任何已經開啟並儲存過的檔案上，直接**雙擊頂部的檔案分頁標題**（或者右鍵點擊該分頁並選擇**重新命名**），讓分頁標題就地變成輸入框改名（詳見[分頁與視窗管理](help://tabs-and-windows)一章）。

重新命名時的貼心保護規則：如果你輸入新名字時省去了副檔名，系統會自動幫你保留原本的副檔名（如 `.docx`、`.xlsx`）；如果輸入的名字裡包含作業系統禁止的非法路徑字元（如 `/`、`\`、`:`、`*`、`?`）、以點號 `.` 結尾，或是撞上了 Windows 的系統裝置保留名（如 `CON`、`NUL`、`PRN`），系統都會當場攔截並彈出清晰的本地化錯誤提示；如果同一個資料夾下已經存在同名檔案（同時妥善處理大小寫不敏感磁碟上的僅大小寫改名），也會被安全攔下而絕不會靜默覆蓋別人的檔案。確認送出後，修改的是磁碟上的真實檔名，所有已開啟分頁的標題、首頁「最近」清單以及「收藏」清單都會在同一瞬間自動同步更新。

## 刪除檔案（移入系統垃圾桶／資源回收筒）

- 在首頁檔案列點擊 **`⋯` ▸ 刪除**（或多選檔案後點頂部工具列的批次刪除）時，系統會先彈出一個確認框明確列出即將刪除的檔案，經你確認後才會將它們移入作業系統的**原生垃圾桶（macOS）或資源回收筒（Windows／Linux）**。如果刪完發現誤刪了，直接打開桌面上的系統垃圾桶點「放回原處／還原」即可找回——GenOffice 刻意不在應用程式內部另搞一套只有幾秒鐘壽命的底部復原提示列，因為檔案復原本來就應該交由作業系統級垃圾桶穩妥託管。

## 建立檔案副本

在首頁檔案列點擊 **`⋯` ▸ 建立副本**，系統會立即在原檔案所在的同一個磁碟目錄下複製生成一份名為「`<原檔名> 副本`」的新檔案（如果目錄下已經有副本了，會自動遞增附加序號如 `副本 2`）。新生成的副本會自動出現在你的**最近**檔案清單最上方，但不會強行打斷你目前的工作替你直接彈開新分頁——它就安靜地躺在清單第一位，需要時點一下即可開啟。

## 儲存、另存新檔與防斷電保護

- **手動儲存（`⌘S`／`Ctrl+S`）**：將目前編輯器裡的最新內容寫回磁碟檔案；如果是一份剛新增、還沒存過檔的「未命名」文件，第一次按儲存時會先彈出系統儲存對話框讓你選定存放目錄並起好檔名。
- **另存新檔（`⇧⌘S`／`Ctrl+Shift+S`）**：將目前文件的完整狀態寫入你指定的新路徑或新檔名下，而磁碟上原有的舊檔案保持改動前的樣子不變；執行完「另存新檔」後，目前開啟的分頁會自動無縫切換到這份新檔案上繼續編輯。
- **防損壞的原子寫入機制**：GenOffice 中的每一次儲存都嚴格採用「先在目標目錄旁寫出完整暫存檔、寫入磁碟成功後再透過原子級重新命名替換原檔案」的策略，哪怕在存檔中途遭遇電腦斷電、程序被強制終止或磁碟空間耗盡，也絕不會把你原本好端端的舊檔案覆蓋成損壞了一半的空殼。
- **克制安全的自動儲存**：某個文件的自動儲存只有在你對它執行過**至少一次手動儲存**之後才會開啟（詳見[快速上手](help://getting-started)一章），確保唯讀檢視的外部檔案絕不會被背景靜默改寫。

## 匯出為 PDF

- **Docs 文字處理**：透過頂部選單 **檔案 ▸ 匯出為 PDF**（或功能區對應按鈕），直接依目前螢幕上所見即所得的分頁與頁首頁尾版式輸出為標準向量 PDF。
- **Slides 簡報**：選擇匯出為 PDF 時，系統會依每一張投影片對應一頁 PDF 的比例逐頁高畫質點陣化輸出，遇到上百頁的大型簡報時會顯示即時進度提示並帶有逾時保護。
- **Sheets 試算表**：按照你在「版面配置」分頁中設定好的紙張方向、列印格線開關與分頁預覽邊界，將工作表乾淨地匯出為分頁 PDF。
- 所有編輯器的 PDF 匯出都在本機背景的隱藏渲染視窗中獨立完成，既不需要連線上傳，也不會搶佔或閃爍你目前正在操作的編輯畫面，渲染完畢後直接落到你指定的磁碟位置。

## 匯出為 Word 文件與分頁圖片

- **PDF ▸ 匯出為 Word／PPT／Excel**：在 PDF 編輯器中透過「檔案」選單或功能區的「PDF 轉換」按鈕，可以在本機離線將 PDF 文件轉換成可編輯的 `.docx` Word 文件（盡最大可能還原複雜的雙欄、表格與段落排版）、每頁一張投影片的 `.pptx` 或每頁一張工作表的 `.xlsx`。
- **Docs／Slides／Markdown ▸ 匯出為圖片**：支援將整篇文件或整套簡報依頁批次渲染輸出為一組高畫質 `.png` 圖片檔案，儲存在你選擇的資料夾下。

## 列印文件

在任何一個編輯器裡按下快捷鍵 `⌘P`／`Ctrl+P`（或透過選單 **檔案 ▸ 列印**），都會喚起分頁列印預覽或作業系統的原生列印對話框；在 Docs 中列印預覽會自動定位到你游標目前所在的那一頁，而在 PDF 中則會嚴格按照你目前調整好的頁面排列順序與旋轉方向送印。

## 新增的「未命名」檔案在儲存前放在哪裡？

當你新增一份空白的 Docs、Sheets、Slides、Markdown 或 HTML 文件時，在你第一次按下儲存鍵並親自為它挑選磁碟目錄之前，這份草稿**純粹只存在於目前應用程式程序的記憶體裡**，不會在你的桌面或文件目錄裡偷偷留下一堆名叫「未命名 1、未命名 2」的垃圾檔案；一旦你完成了第一次手動儲存、給它在磁碟上安了家，自動儲存就會立刻接過接力棒，在後續編輯中替你持續守護每一次修改。
