# 檔案操作：重新命名、刪除、匯出

本章說明各編輯器共用的檔案操作；各編輯器自己的匯出選項請見對應章節。

檔案列的 **⋯ 選單**（滑鼠停留時出現）匯集了這些動作：

![檔案列的 ⋯ 選單](img/file-ops.png)

## 重新命名

兩個入口，同一套檢查：

- 首頁檔案列的 **⋯ ▸ 重新命名**。
- **在檔案分頁上按兩下**就地重新命名（見[分頁與視窗管理](help://tabs-and-windows)）。

規則：副檔名會自動保留；非法字元、結尾的點與保留名稱（CON／NUL 之類）會被拒絕並顯示訊息；同一資料夾內的同名衝突也會被擋下。實際的磁碟檔案會被重新命名，最近使用與收藏也會同步更新。

## 刪除

- 首頁 **⋯ ▸ 刪除**：把檔案移到**系統垃圾桶**，可從作業系統還原。
- 刪除後會出現帶有復原選項的提示，數秒內有效——復原會把檔案放回原來的位置。

## 建立副本

**⋯ ▸ 建立副本** 會在同一個資料夾中建立 `<名稱> 副本` 並以新分頁開啟；名稱衝突時會自動加上編號。

## 儲存與另存新檔

- **⌘S / ctrl+S** 儲存目前的檔案；未命名的檔案會先請你選擇位置與名稱。
- **另存新檔** 會寫入一個新檔案並保持原檔不變；之後的編輯都作用在新檔案上。
- 每次儲存都是原子操作（暫存檔＋改名）；寫到一半強制結束也不會讓檔案損毀。
- 自動儲存只會在第一次手動儲存之後才接手（見[快速上手](help://getting-started)）。

## 匯出為 PDF

- **Docs**：檔案 ▸ 匯出為 PDF（或功能區上的對應按鈕），依目前的版面分頁輸出。
- **Slides**：匯出時會逐頁點陣化，大型簡報有進度顯示。
- **Sheets**：匯出依列印分頁。
- 匯出都在隱藏視窗中算繪，輸出到你選擇的位置。

## 匯出為 Word／圖片

- **PDF ▸ 匯出為 Word…**：把 PDF 轉成 .docx（在本機轉換；複雜版面以盡力保留的方式處理）。
- **Docs** 可把頁面匯出為圖片（逐頁 PNG）。

## 列印

各編輯器的 檔案 ▸ 列印（⌘P/ctrl+P）會開啟系統列印對話方塊；PDF 會依目前的頁序與旋轉列印。

## 未命名檔案放在哪裡

第一次儲存時你選的位置就是它的家；在那之前，檔案只存在於記憶體中。自動儲存也要等過了那一次儲存才會接手。
