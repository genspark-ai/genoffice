# פעולות קבצים: שינוי שם, מחיקה, ייצוא

פרק זה מכסה את פעולות הקבצים המשותפות לכל העורכים; אפשרויות הייצוא של כל עורך נמצאות בפרק שלו.

תפריט **⋯** של שורת הקובץ (רחפו מעל שורת קובץ) מרכז את הפעולות האלה:

![תפריט ⋯ של שורת קובץ](img/file-ops.png)

## שינוי שם

שני נתיבי כניסה, אותה קבוצת בדיקות:

- **⋯ ▸ שינוי שם** בשורת הבית.
- **לחיצה כפולה על כרטיסיית קובץ** לשינוי שם במקום (ראו [כרטיסיות וניהול חלונות](help://tabs-and-windows)).

כללים: הסיומת נשמרת אוטומטית; תווים אסורים, נקודות בסוף ושמות שמורים (CON/NUL ודומיהם) נדחים עם הודעה; התנגשות שמות באותה תיקייה נחסמת אף היא. הקובץ האמיתי בדיסק משתנה, ורשימת האחרונים והכוכבים מתעדכנים בהתאם.

## מחיקה

- **⋯ ▸ מחיקה** בבית: שואל אילו קבצים, ואז מעביר אותם ל**אשפה של המערכת**, שם ניתן לשחזר אותם מהמערכת. ‏GenOffice לא שומר ביטול משלו לפעולה הזאת — השחזור הוא עניין של האשפה, לא של הודעה.

## יצירת עותק

**⋯ ▸ יצירת עותק** יוצר `<name> עותק` באותה תיקייה; בהתנגשות שמות נוסף מונה אוטומטית. העותק מתווסף ל**אחרונים** במקום להיפתח לעיניכם — במרחק לחיצה אחת, לא לפניכם.

## שמירה ושמירה בשם

- **⌘S / ctrl+S** שומר את הקובץ הנוכחי; קובץ ללא שם יבקש קודם מיקום ושם.
- **שמירה בשם** כותב קובץ חדש ומשאיר את המקורי ללא שינוי; עריכות הבאות ממוקדות בקובץ החדש.
- כל שמירה היא אטומית (קובץ זמני + שינוי שם); יציאה באמצע כתיבה לא תקורק את הקובץ.
- השמירה האוטומטית נכנסת לפעולה רק אחרי השמירה הידנית הראשונה (ראו [התחלה מהירה](help://getting-started)).

## ייצוא ל-PDF

- **Docs**: File ▸ ייצוא כ-PDF (או הכפתור בסרגל הכלים), מפוגל לפי הפריסה הקיימת.
- **Slides**: הייצוא מרסטר את העמודים אחד אחד, עם התקדמות למצגות גדולות.
- **Sheets**: הייצוא מפוגל לפי הדפסה.
- הייצוא מתרונדר בחלון מוסתר ונשמר במקום שבחרתם.

## ייצוא ל-Word / לתמונות

- **PDF ▸ המרה ל-Word…**: הופך את ה-PDF ל-.docx (המרה מקומית; פריסות מורכבות מטופלות במאמץ).
- **Docs** יכול לייצא עמודים כתמונות (PNG לכל עמוד).

## הדפסה

‏File ▸ הדפסה בכל עורך (⌘P/ctrl+P) פותח את תיבת הדפסה של המערכת; PDF נדפס בסדר העמודים והסיבוב הנוכחיים.

## איפה נמצאים קבצים ללא שם

המיקום שבחרתם בשמירה הראשונה הוא ביתו של הקובץ; עד אז המסמך קיים רק בזיכרון. השמירה האוטומטית מקבלת את הפיקוד רק אחרי אותה שמירה ראשונה.
