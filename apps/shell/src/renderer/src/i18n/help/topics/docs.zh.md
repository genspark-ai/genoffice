# Docs：文字处理

Docs 是类 Word 的文字处理器，读写真 .docx，分页排版所见即所得。

## 功能区（Ribbon）

标签：**开始 / 插入 / 绘图 / 布局 / 设计 / 引用 / 审阅 / 视图**，外加随选中对象出现的上下文标签（表格设计与布局、图片、页眉页脚）。

- **开始**：剪贴板、字体（含中日韩字号与着重号等）配 **清除所有格式** 与 **显示/隐藏编辑标记** 开关；段落（对齐/缩进/行距/列表）另有 **定义新项目符号 / 定义新的编号格式 / 多级列表**，可把你自己的列表样式存进文档；样式（标题 1-6/正文/引用，可修改），并有 **样式窗格** 列出全部样式。
- **插入**：分页符/分节符、表格（行 × 列网格，或用 **插入表格…** 指定精确大小）、图片、形状、文本框、预设库中的 **封面** 与 **空白页**、**图表**、**首字下沉**、**艺术字**、域（日期、时间、页码、总页数、文件名）、超链接、**书签** 与交叉引用、批注、页眉页脚与页码、符号与公式。
  - **图表**插入的是带自身数据的真正图表对象——柱形、折线或饼图——而不是一张图片。Word 的「编辑数据」会打开它背后的数字。
- **绘图**：在页面上用墨迹书写，工具集中在 **绘图工具** 组——**选择** 可回到文本编辑，然后是 **笔**、**荧光笔** 与 **橡皮擦**（点一下或一抹即去掉整笔）。旁边的 **笔样式**／**荧光笔样式** 是一个控件，同时装着颜色色板和一排粗细；它的名称跟随当前启用的工具。墨迹以浮在文字上方的批注形式存进文档，所以保存后重新打开依然在，而下一组的 **全部清除** 会把它们一次清空。
- **布局**：页边距、纸张方向与大小、分栏、段落缩进与间距。
- **设计**：主题、颜色集、水印、页面边框。
- **引用**：目录（可更新）、脚注/尾注、题注、交叉引用。

  ![引用页签](img/docs-references.png)

- **审阅**：**编辑器** 通读全文检查拼写、语法与标点；**翻译**；拼写检查；批注（**AI 处理批注** 会处理尚未解决的批注）；修订追踪（所有标记/简单标记视图）、接受/拒绝，以及 **AI 总结修订**；字数统计；与另一文件 **比较**；**保护文档**。
- **视图**：查看文件有五种方式——**页面视图**、**Web 版式**、**大纲**、**阅读视图** 与 **分页预览**；缩小/放大/百分比/页宽/整页；**AI 面板**；**深色模式**；标尺、网格线与导航窗格；**新建标签**、**拆分** 与 **切换标签**；以及可搜索全部快捷键的 **键盘快捷键** 对话框。
  - **深色模式** 只把页面和周围的画布变暗，绝不动功能区——这正是 Word 在深色编辑面与深色窗口之间的取舍。这个选择会被记住，而且无论应用主题是什么都以它为准。
  - **拆分** 会在下方开第二个窗格，独立滚动并与第一个保持同步；用窗格边缘的 × 关掉它。

## 导航窗格

**视图 ▸ 导航窗格**会打开一个侧边窗格，里面放三样东西：文档的标题大纲、覆盖整篇文档的查找框，以及每页一张的缩略图。窗格是否打开会在两次启动之间记住，所以习惯靠大纲翻文档的人，下次打开还是能这么翻。

**大纲**就是标题树。在大纲里右键某个标题，既能折叠它，也能改结构，而不只是用来导航：

- 标题上的**折叠 / 展开**会把该标题的整个子树收起来——章节不见了，正文还留在文档里。
- **全部折叠 / 全部展开**一键收放整棵树。碰上长报告，这就是「能扫一遍的大纲」和「一堵字墙」的区别。
- **显示标题级别**按你关心的深度过滤这棵树，于是*显示标题 1* 留下的就是一张真能扫的目录。
- **升级 / 降级**改变标题的级别，下面所有标题跟着继承这个级别——一章就这样变成一节。
- **在前面新建标题 / 在后面新建标题**在光标处插入标题，不用离开窗格。
- **删除**会把标题*连同它下面的全部内容*一起删掉，这是最需要小心的一项：它删的是子树，不是某一行。
- **选择标题和内容**从标题一直选到子树末尾，正好可以整节编辑。

## 右键菜单

在正文任意位置右键，菜单随你点中的对象变化。主要分组：

- **剪贴板**：剪切 / 复制 / 粘贴 / **只粘贴文本**。
- **字体、段落**：就地改字体字号、加粗斜体下划线、对齐/缩进/行距，不用去功能区。
- **同义词**：给选中词列同义词，点一个即替换。
- **翻译**（AI）：选中文字后按目标语言翻译（英/简中/日/韩/法/德/西等），走 AI 面板。
- **新建批注**：在选中处添加批注。
- **拼写**（有拼错的词时）：建议替换、全部忽略、加入词典、设置校对语言。
- **超链接**：打开 / 编辑 / 复制链接 / 取消超链接。
- **图片**：查看图片、图片另存为、**环绕文字**（嵌入 / 四周型左右 / 上下型 / 衬于文字下方 / 浮于文字上方）、排列层级（上移/下移一层等）。
- **域**（目录、页码等）：更新域 / 切换域代码 / 编辑域。
- **列表编号**（光标在列表里）：重新开始编号 / 继续编号 / 更改列表级别 / 设置编号值。
- **表格**（光标在表格里）：插入行列、合并 / 拆分单元格、拆分表格、自动调整、单元格对齐、分布行列、表格属性、删除菜单、选择。

## 编辑

- 查找替换（ctrl+F / ctrl+H）：支持区分大小写、全字匹配、正则。
- 格式刷；多级撤销重做；富文本粘贴选项。
- 表格：合并/拆分单元格、行列增删、边框底纹、排序、公式。
- 图片：环绕方式、裁剪、压缩；绘图画布。

## 中文排版细节

- 标点压缩与行首行尾规则（避头尾）与 Word 对齐；全角/半角、简繁转换。
- 中文字体候选覆盖 Windows 与 macOS 常见字体名。

## AI

- 功能区 AI 按钮与右侧 AI 面板：改写、扩写、翻译、摘要、插入表格等预设 + 自由指令。
- AI 每轮修改前自动留快照，可从版本列表回滚；回滚本身可撤销。

## 保存与导出

- 保存 .docx；只重写变更段落，未改动内容字节级不变。
- 导出 PDF（按当前分页）与逐页图片。

## 打印

ctrl+P 系统打印，所见即所得分页。
