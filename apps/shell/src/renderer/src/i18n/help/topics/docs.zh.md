# Docs：文字处理

GenOffice 的 Docs 是一款与微软 Word 深度兼容的文字处理器，直接读写标准的 `.docx` 文档格式，并采用真实的所见即所得分页排版引擎，你在屏幕上看到的每一行折行、每一张跨页表格和每一处页眉页脚，打印或导出为 PDF 时都会分毫不差地呈现出来。

## 功能区（Ribbon）全览

顶部功能区共设有八个常驻主标签：**开始 / 插入 / 绘图 / 布局 / 设计 / 引用 / 审阅 / 视图**；当你用鼠标点中文档里的特定对象时，右侧还会自动浮现对应的专属上下文标签（比如点进表格时出现「表格设计」与「表格布局」，选中图片或形状时出现格式页签，双击进入页眉或页脚区域时出现「页眉和页脚」页签）。此外，Docs 的功能区还独享一档介于完整展开与彻底折叠之间的**紧凑密度模式**：按下快捷键 `⌥⌘K`（Windows 与 Linux 为 `Ctrl+Alt+K`）即可隐去按钮旁边的文字说明、只留下一排清爽的图标，腾出更多纵向视野，而且你的选择会在下次打开时自动记住。

- **开始**：包含剪贴板与格式刷；完整的字体设置（涵盖初号、小初、一号等全套中文传统字号、着重号、上下标与字符底纹），旁边配有**清除所有格式**按钮与**显示/隐藏编辑标记**（段落回车符、空格点等）开关；段落排版区除了四种对齐、左右缩进、行距与常规项目符号外，还提供**定义新项目符号 / 定义新的编号格式 / 多级列表**，允许你定制符合公文或论文规范的列表样式并直接存进当前文档；右侧则是快速样式库（标题 1–6、正文、引用等，均支持右键修改）以及列出全文所有样式的**样式窗格**。在修改任意样式时，你都可以为它**分别指定中文字体（东亚字体）与西文字体**（比如让中文显示为宋体或微软雅黑，而同一段里的英文与数字自动使用 Times New Roman），这套中西文字体搭配会完整写入 `.docx` 文件，在桌面版 Word 与 GenOffice 之间来回编辑保存都不会丢失。
- **插入**：支持在光标处插入分页符与分节符；拉出任意行 × 列的表格网格（或打开**插入表格…**对话框输入精确行列数与列宽模式）；插入本地图片、几何形状与自由文本框；从预设模板库中一键套用精美的**封面**或补入**空白页**；插入内置的**图表**、报刊风格的**首字下沉**与**艺术字**；插入会自动更新的动态域（当前日期、时间、当前页码、总页数、文件名）；添加超链接、在正文里埋设**书签**并建立指向它的交叉引用；新建页边批注、编辑不同节的页眉页脚与页码样式，以及插入特殊符号与专业数学公式。
  - **图表**插入到文档里的是带有独立底层数据表的真正原生图表对象（支持柱形图、折线图、饼图等），而绝不是一张死板的静态截图；无论在 GenOffice 里还是把文件发给同事用微软 Word 打开点击「编辑数据」，都能随时调出它背后的数字表修改数值并实时重绘图表。
- **绘图**：让你能直接用鼠标、触控板或手写笔在文档页面上方自由批注圈画，所有工具都集中在**绘图工具**分组下——点**选择**按钮可随时退回普通的正文打字状态，点**笔**或**荧光笔**即可开始手写或半透明涂抹标记，点**橡皮擦**后只需在任意一笔线条上单击或轻轻扫过就能把整根笔迹干净擦除。紧挨在旁边的**笔样式 / 荧光笔样式**是一个二合一面板，里面同时装着调色板和一排笔尖粗细供你随手切换（按钮名称会自动跟随你当前拿的是钢笔还是荧光笔）。所有手写墨迹都以浮动在正文文字上方的标准批注层形式保存在 `.docx` 文件里，保存重开后依然原样保留，如果想一次性清空整篇文档的涂鸦，点一下旁边分组里的**全部清除**即可。
- **布局**：集中管理整篇文档或当前节的纸张规格（A4、Letter、16 开等）、纵向与横向纸张方向、上下左右页边距、单栏与多栏排版，以及精确到磅或行的段落缩进与段前段后间距。
- **设计**：提供多套精心调校的文档整体主题、配套色彩方案与标题正文字体组合，同时支持在页面底层添加斜向文字或图片**水印**，以及设置整页四周的**页面边框**。
- **引用**：专为长篇报告、学术论文和标书设计，支持一键自动提取各级标题生成可点击跳转、可随时刷新页码的**自动目录**，在当前页底或文末插入自动编号的**脚注与尾注**，为图表添加规范的**题注**，以及插入指向标题、书签、脚注或图表编号的动态**交叉引用**。

  ![引用页签](img/docs-references.png)

- **审阅**：点开**编辑器（Editor）**即可通读全文，一次性排查拼写错误、语法病句与标点不当；内置多语种**翻译**与实时拼写检查；提供完整的页边**批注**协作流（点击 **AI 处理批注** 可以让 AI 助手自动读取尚未解决的批注意见并逐条帮你改好对应正文）；支持标准的**修订追踪（Track Changes）**，可在「所有标记」与清爽的「简单标记」视图之间切换，逐条或全部接受/拒绝他人修改，还能点 **AI 总结修订** 让 AI 用几句话帮你概括这份文档被改了哪些地方；此外还提供实时字数统计、拿当前文档与另一份版本逐字对比差异的**比较**功能，以及防止他人乱改的**保护文档**。
- **视图**：提供五种不同侧重点的文档阅读与排版视角——最常用的所见即所得**页面视图**、铺满窗口宽度的 **Web 版式**、专注章节层级结构的**大纲视图**、适合长文沉浸阅读的**阅读视图**以及检查分页位置的**分页预览**；右侧配有画面缩小、放大、100%、适应页宽与整页显示控制，以及开关右侧 **AI 面板**、切换页面**深色模式**、勾选显示标尺、网格线与左侧导航窗格的复选框；窗口组支持为同一份文档开**新建标签**、上下**拆分**对比以及快速**切换标签**；最后还能随时呼出支持搜索全部按键的**键盘快捷键**速查对话框。
  - **深色模式**采用与新版微软 Word 相同的贴心设计：开启后只会把中间的纸张页面和四周画布底色变成护眼的深色（正文墨水颜色也会在屏幕显示时智能反转为浅色，但底层真实的字体颜色属性绝不被篡改，打印和导出 PDF 时依然是白纸黑字），而顶部的彩色功能区则保持原样不变；这个开关会被独立记住，并且优先级高于应用全局的深浅色主题。
  - **拆分视图**会在当前编辑区正下方再拉开第二个独立的滚动窗格，上下两个窗格显示的是同一份实时同步的文档，让你能一边在上面看着第一章的背景数据、一边在下面写第五章的结论，省去上下翻滚几十页的奔波；用完后点击分隔条边缘的 `×` 即可合拢。
- **无样式文档的智能推断大纲**：很多法务合同、行政公文或从外部导入的老文档在排版时并没有规范套用「标题 1 / 标题 2」样式，而是单纯用一行简短的加粗文字、全大写字母或带罗马数字/阿拉伯数字编号的独立短行（如 `I. BACKGROUND` 或 `一、项目背景`）来充当章节小标题；当整篇文档没有任何正式标题样式时，Docs 会自动根据这些段落特征在不改动原文档任何字节的前提下为您**智能推断出章节大纲**，并以半透明的推断标记呈现在**大纲视图**与**故事视图**中，让你照样能点击跳转章节，而一旦你给某行推断标题套上了正式的标题样式，它就会立刻转正为真实的文档标题。

## 左侧导航窗格与大纲重构

在顶部菜单或功能区勾选 **视图 ▸ 导航窗格**，即可在窗口左侧展开一个多功能导航侧边栏，里面整合了三样阅读长文最离不开的工具：**文档标题大纲树**、覆盖全文并实时列出所有匹配上下文的**搜索框**，以及一页一张的**页面缩略图**。导航窗格的开合状态会在关闭应用后自动保存，习惯靠左侧目录树写长文档的人下次打开软件时它依然在原位候命。

其中的**大纲**页签绝不仅仅是一张只能点着跳页的静态目录表——在大纲树里的任意一条标题上点击鼠标右键，你就可以直接对整篇文档的章节骨架做折叠或结构重组：

- **折叠 / 展开当前章节**：在某条标题上选择折叠后，该标题连同它下属的所有子章节都会在大纲树里收拢起来，让你能把写完的章节先收好、专心盯着正在写的这一章，而正文内容本身依然完好留在文档里。
- **全部折叠 / 全部展开**：只需点一下就能把整棵大纲树一次性收拢到顶层或全部摊开；在面对动辄几十页、上百个小节的长篇调查报告或技术手册时，这能让你瞬间从密密麻麻的子标题里抽身出来看清全篇主脉络。
- **按级别过滤显示标题（显示标题级别）**：你可以指定大纲树只展示到第几级标题——比如选择*显示标题 1* 或 _显示标题 2_，就能立刻筛掉细枝末节的三四级小标题，留下一张真正适合快速扫读的骨干目录。
- **升级 / 降级章节（连带子树一起升降）**：右键选择升级或降级时，不仅当前标题本身的层级会改变（如从「标题 2」变成「标题 1」），挂在它下面的所有子标题也会自动跟着同步升降一级，把一整节升格为一整章只需点一下鼠标。
- **在前面新建标题 / 在后面新建标题**：无需先把视线移回正文去找光标位置，直接在大纲树里右键就能在指定章节的前方或后方原地插入一个同级的新标题并开始输入。
- **删除标题及其全部下属内容**：这是大纲右键菜单里威力最大、最需要留意的一项——它删除的不是正文中孤零零的一行标题文字，而是**把该标题连同它统领的整节正文与所有子章节（整棵子树）一次性彻底删掉**，非常适合在改稿时整段砍掉某个废弃章节（如果误删，随时可以按 `⌘Z` / `Ctrl+Z` 完整撤销）。
- **选择标题和内容**：点击后会直接帮你在正文画布中从该标题开头一直框选到它整个子章节的末尾，方便你紧接着执行整章复制、剪切搬家或统一交给 AI 改写。

## 随点击对象智能变化的右键菜单

在正文画布的任何位置点击鼠标右键，弹出的菜单都会根据你鼠标落点处的具体对象自动组合出最趁手的命令，主要分为以下几大类：

- **剪贴板操作**：提供最常用的剪切、复制、带格式粘贴，以及在从网页或 PDF 复制内容过来时极其好用的**只粘贴纯文本**（自动洗掉乱七八糟的背景色与外网字号）。
- **就地修改字体与段落**：在选中的文字上右键就能直接改字体家族、字号大小、加粗、斜体、下划线，或者调整段落对齐、缩进与行距，手指完全不用跑到窗口最顶部的「开始」功能区去点。
- **同义词替换**：对着某个英文或中文词汇右键展开**同义词**子菜单，系统会列出若干语境相近的候选词，单击任意一个即可原地替换掉原词，帮你避免在一页文章里反复出现同一个词。
- **AI 多语种划词翻译**：选中一段文字后右键选择**翻译**，即可在子菜单里直接指定目标语言（支持简体中文、英语、日语、韩语、法语、德语、西班牙语等主流语种），自动唤起右侧 AI 面板给出地道译文。
- **新建批注**：直接针对当前划选的词句在页边挂上一条审阅批注气泡。
- **拼写纠错菜单**（当右键点在带有红色波浪线的疑似拼写错误单词上时浮现）：会在菜单最上方直接列出拼写修正建议供你一键替换，也可以选择**全部忽略**、将该专有名词**加入本地词典**，或为当前选区重新指定**校对语言**。
- **超链接管理**（当点在链接上时）：支持直接在浏览器中**打开超链接**、**编辑超链接**地址与显示文字、一键**复制链接地址**，或者**取消超链接**恢复为普通正文。
- **图片排版与环绕**（当右键点中图片时）：支持全屏**查看图片**、将文档内嵌的图片**另存为**本地文件、切换五种经典的 Word **文字环绕方式**（嵌入型、四周型左右环绕、上下型环绕、衬于文字下方、浮于文字上方），以及调整多张浮动对象重叠时的上下**排列层级**（置于顶层/底层、上移/下移一层）。
- **动态域控制**（当光标位于自动目录、页码或日期等域对象内部时）：支持立即**更新域**以刷新最新页码或标题、在计算结果与底层域代码之间**切换域代码显示**，以及打开对话框**编辑域**属性。
- **列表编号控制**（当光标位于有序编号列表中时）：可以随时让当前行**重新开始编号**（重置为 1）、与上方断开的列表**继续编号**、**更改列表级别**，或者打开**设置编号值**强制从任意指定数字开始往下排。
- **表格全方位操作**（当光标位于表格内部时）：无需去顶部找表格页签，右键就能直接在上下左右**插入行或列**、**合并或拆分单元格**、从当前行把一张大表**拆分为两张表格**、设置**自动调整**（按内容、按窗口或固定列宽）、调整单元格内部九宫格**对齐方式**、**平均分布各行高与各列宽**、打开**表格属性**对话框、呼出**删除单元格/行/列/整表**子菜单以及快速选中行列。

## 核心编辑与排版能力

- **强大的查找与替换（`⌘F` / `Ctrl+F` 与 `⌃H` / `Ctrl+H`）**：除了普通关键词搜索外，完整支持**区分大小写**、**全字匹配**以及高阶的**正则表达式（Regex）**查找与批量替换，让你能轻松批量清洗复杂的公文格式或编号。
- **格式刷、深度撤销与智能粘贴**：支持单击刷一次或双击连续刷多处的格式刷、不限步数的多级撤销与重做，以及粘贴外部富文本时自由选择保留源格式、合并格式或仅保留纯文本。
- **与 Word 排版一致的专业表格**：完整支持单元格合并与拆分、行列增删、内外边框线型与底纹填色、按列排序以及表格内嵌公式计算。遇到内容很长的跨页表格时，长行会在纸张底部自然切分并跨页续排；如果你希望在某个表格单元格内部指定位置强制换到下一页，只需在单元格里按下 `Ctrl+Enter`（macOS 为 `⌘⏎`）即可从该处精准翻页，打印与导出 PDF 时同样严格生效。
- **图片修饰与绘图画布**：支持自由裁剪图片边缘、按分辨率压缩文档内图片体积以减小文件大小、设置图文环绕，以及插入独立的绘图画布来统一组织复杂的流程图形状。

## 中日韩（CJK）专业排版细节

- **标点挤压与避头尾规则（Kinsoku）**：严格对齐桌面版 Word 的中文排版规范，句号、逗号、右括号等行尾禁则标点绝不会孤零零掉到下一行开头，左引号、左括号等行首禁则标点也绝不会留在上一行末尾，连续标点之间会自动执行恰当的字距压缩；同时内置一键全角/半角转换与简繁中文互转工具。
- **跨平台中文字体智能匹配**：内置的字体候选与度量表完整覆盖了 Windows 与 macOS 上常见的中、日、韩字体家族名称（包括宋体/SimSun、微软雅黑/Microsoft YaHei、苹方/PingFang SC、思源黑体/宋体等的中英文别名），跨系统打开同事发来的文档时版面行距与折行位置依然稳固。

## AI 写作与审校助手

- **预设动作与自由指令结合**：点击功能区上的 **AI 按钮**或展开右侧 AI 面板后，你既可以直接点选**润色改写、扩写篇幅、多语种翻译、提炼摘要、从文字生成表格**等高频预设卡片，也可以在输入框里用自然语言提出任何排版或写作要求。
- **自动留存快照，随时无损回滚**：AI 助手对你的文档动手做每一轮修改之前，都会先在后台为当前文档自动拍下一份完整的版本快照；你随时可以在 AI 面板的**版本历史列表**里一键回滚到任意一轮修改前的状态，而且即便点了回滚，回滚这个动作本身也同样支持按 `⌘Z` / `Ctrl+Z` 再次撤销，让你能毫无顾虑地让 AI 尝试各种大刀阔斧的改稿方案。

## 保存与导出

- **字节级保守的 `.docx` 增量保存**：当你保存一份修改过的 `.docx` 文档时，Docs 的写入引擎**只会重写你真正改动过的那几个段落**，而文档里没有被你碰过的其他段落、复杂域、内嵌对象与原始 XML 属性都会保持**字节级原封不动（byte-identical）**，彻底杜绝了「打开别人的复杂合同只改了一个错别字、保存后却把整篇排版搞乱」的行业痛点。
- **高保真导出为 PDF 与逐页图片**：无需借助外部虚拟打印机，直接按当前所见即所得的分页结果导出为标准 PDF 文件，或者把每一页分别导出为高清 PNG 图片。

## 打印

按下 `⌘P` / `Ctrl+P` 即可进入内置的所见即所得分页打印预览，确认纸张、页码范围与份数后直接调用操作系统打印服务输出。

- **打印预览自动定位到当前光标所在页**：当你正在编辑一份几十页长文档的中间某页、按下 `⌘P` / `Ctrl+P`（或从文件菜单打开打印预览）想要检查当前这一页的排版效果时，打印预览窗口会**直接跳转到你正文光标当前所在的那一页**，省去了每次打开打印预览都只能从第 1 页重新往后翻找的麻烦。
