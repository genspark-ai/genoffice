# Модели ИИ и настройки

## Провайдеры и модели

Модели и ключи настраиваются в Настройках (строка аккаунта в левом нижнем углу «Главной»):

![Окно настроек](img/settings-general.png)

- **Genspark на их серверах**: войдите (схема с кодом устройства) и пользуйтесь — настройки не нужны.
- **Собственные адреса (BYOK)**: в Настройки ▸ ИИ указывается базовый URL и API-ключ для каждого протокола — совместимый с OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen) и другие. Ключи сохраняются в файле настроек приложения на этом компьютере и отправляются только в заголовках запросов.
- Для каждой способности можно выбрать свою модель: общение и генерация, создание изображений, анализ изображений.
- **Проверить подключение**: убеждается, что адрес доступен и модель видна, до сохранения.
- Базовый URL может содержать путь и строку запроса (в стиле шлюза); путь конечной точки добавляется корректно.

## Интеграция с CLI (в духе Codex)

- В настройках указывается путь к локальной программе CLI (домашние каталоги с не-ASCII именами и префикс ~ работают; ~ разворачивается автоматически); «Автоопределение» опрашивает у CLI доступные модели.
- Проверка смотрит только на существование файла — никаких ограничений по набору символов.

## Когда изменения вступают в силу

- Смена модели и адреса применяется сразу; уже идущий разговор продолжает использовать прежнюю конфигурацию до следующего захода.
