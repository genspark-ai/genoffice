# 파일 작업: 이름 바꾸기, 삭제, 내보내기

이 장에서는 모든 편집기에 공통인 파일 작업을 설명합니다. 편집기마다 따로 있는 내보내기 선택지는 각 장에서 다룹니다.

파일 줄의 **⋯ 메뉴**(파일 줄에 마우스를 올리면 나타납니다)에 다음 작업이 모여 있습니다.

![파일 줄의 ⋯ 메뉴](img/file-ops.png)

## 이름 바꾸기

진입점은 두 개, 검사는 같습니다.

- 홈 줄의 **⋯ ▸ 이름 바꾸기**.
- **파일 탭을 더블클릭**해 그 자리에서 이름을 바꿉니다([탭과 창 관리](help://tabs-and-windows) 참고).

규칙: 확장자는 자동으로 유지됩니다. 잘못된 문자, 끝의 점, 예약 이름(CON/NUL 등)은 메시지와 함께 거부됩니다. 같은 폴더의 이름 충돌도 막힙니다. 디스크의 실제 파일 이름이 바뀌고 최근 목록과 즐겨찾기도 함께 갱신됩니다.

## 삭제

- 홈 **⋯ ▸ 삭제**: 파일을 **시스템 휴지통**으로 옮깁니다. OS에서 되돌릴 수 있습니다.
- 몇 초 동안 "삭제됨 · 실행 취소" 알림이 뜨며, 그동안 되돌릴 수 있습니다(되돌리면 파일이 원래 자리로 돌아갑니다).

## 복제

**⋯ ▸ 복사본 만들기**는 같은 폴더에 "<이름> 사본"을 만들고 새 탭으로 엽니다. 이름이 겹치면 자동으로 번호가 붙습니다.

## 저장과 다른 이름으로 저장

- **⌘S / ctrl+S** 는 현재 파일을 저장합니다. 이름 없는 파일은 먼저 위치와 이름을 묻습니다.
- **다른 이름으로 저장**은 새 파일을 쓰고 원본은 그대로 둡니다. 그 뒤의 편집은 새 파일을 대상으로 합니다.
- 모든 저장은 아토믹입니다(임시 파일에 쓴 뒤 이름 변경). 쓰는 도중 종료해도 파일이 깨지지 않습니다.
- 자동 저장은 처음 수동 저장 뒤에만 작동합니다([빠른 시작](help://getting-started) 참고).

## PDF로 내보내기

- **Docs**: 파일 ▸ PDF로 내보내기(또는 리본 버튼). 현재 쪽나누기대로 내보냅니다.
- **Slides**: PDF 내보내기는 한 장씩 래스터화하며, 큰 덱에는 진행률이 표시됩니다.
- **Sheets**: PDF 내보내기는 인쇄의 쪽나누기를 따릅니다.
- 내보내기는 숨겨진 창에서 렌더링되고 고른 자리에 저장됩니다.

## Word/이미지로 내보내기

- **PDF ▸ Word로 변환**: PDF를 .docx로 바꿉니다(로컬 변환. 복잡한 레이아웃은 최대한 옮겨 보냅니다).
- **Docs** 는 페이지를 이미지로 내보낼 수 있습니다(한 장씩 PNG).

## 인쇄

각 편집기의 파일 ▸ 인쇄(⌘P/ctrl+P)는 시스템 인쇄 대화상자를 엽니다. PDF는 현재 페이지 순서와 회전대로 인쇄됩니다.

## 이름 없는 파일은 어디에 두나

처음 저장할 때 고른 위치가 그 파일의 자리입니다. 그전에는 문서가 메모리에만 존재합니다. 자동 저장은 첫 저장을 마친 뒤부터 이어받습니다.
