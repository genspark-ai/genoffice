# 設定、言語、テーマと MCP 連携

## 設定を開く

ホームの左下のアカウントの行から設定パネルを開きます（サインアウトしているときは「サインイン」と表示されます）。セクションは 6 つあります。アカウント、AI モデル、AI メディアと検索、一般、連携、情報。

![設定 ▸ 一般（言語、テーマ、自動保存、利用統計のスイッチがある場所）](img/settings-general.png)

モデル設定には別の記事があります。**AI メディアと検索**では、プロバイダーごとに画像生成、画像解析、動画解析、Web 検索、ローカルファイル検索をオンにします。

## 言語

- 設定では **21 種類の UI 言語**から選べます：英語、簡体字中国語、日本語、韓国語、フランス語、ドイツ語、スペイン語、タイ語、インドネシア語、ロシア語、アラビア語、ポルトガル語、イタリア語、ポーランド語、チェコ語、オランダ語、マレー語、ヘブライ語、ヒンディー語、繁体字中国語、ベトナム語。
- 切り替えるとすぐに反映されて保存され、ネイティブのメニューもその言語で組み直されます。

## テーマ

ライト／ダーク／システムに従う の 3 種類です。システムに従う場合は OS の外観に合わせて変化し、エディターの配色も同期して切り替わり、ちらつきません。

## 一般

- **匿名の使用状況統計を送信** — 既定で有効です。Google Analytics 4 を使用し、公開 IP アドレスと通信メタデータを送信します。文書の内容やファイル名は収集されず、各イベントが持つのは「.docx を開いた」のような種類だけです。ここでいつでも無効にできます。
- **AI サイドバーの位置**（左または右）、**AI パネルの文字サイズ**、**AI チャットのスペルチェック**。
- **新しいドキュメントで AI パネルを開く** — オフにすると、新しいドキュメントはパネルを折りたたんだ状態で始まり、ワンクリックで開けます。
- **すべてのドキュメントを自動保存** は、すべてのエディターで自動保存を既定で有効にします。ウィンドウ単位で無効にすることもできます。
- **保存先**と**変更**ボタン、そして **Office 文書の既定のアプリ** により、.docx / .xlsx / .pptx を GenOffice の担当にします。

## AI メディアと検索

スイッチではありません。各機能がそれを提供するベンダーを選び、ベンダーのキーとベース URL は一度入力すれば共有されます：

- **Web 検索**、**画像生成**、**画像解析**、**動画解析** には、それぞれプロバイダー、モデル、キー、ベース URL があります。
- **ローカルファイル検索** はこのマシンで動作します。その下に **Jev 検索リランク** があり、**既定ではオフ**です。オンにすると、ローカル検索の上位 20 件の抜粋（各ドキュメント最大 1,200 文字に加え、ファイル名とフォルダー名）が TypeSafe の Jev モデルに送られ、関連度で並べ替えられます。オフのままなら、端末の外に何も送信されません。

## 情報

- **バージョン**、プロジェクトの GitHub リンク、**GitHub でスターを付ける** ボタン。
- **更新チャネル**：安定版またはベータ版。変更するとすぐに反映され、更新を確認します。ベータ版のインストールを安定版に戻すことはありません。

## 既定のアプリの関連付け

設定から、.docx／.xlsx／.pptx／.pdf などを GenOffice で開くように登録できます（プラットフォームレベルの既定アプリの登録。確認のダイアログが出たら承認してください）。

## 第三者製ソフトウェアの通知と更新

- ヘルプ ▸ サードパーティソフトウェアに関する通知：アプリに同梱されている OSS のライセンス一覧。
- ヘルプ ▸ 更新を確認：手動で更新を確認します。新しいバージョンがあればインストールを促します。

## Genspark へのサインイン

- サインインの入口（設定またはクラウドのプロジェクト一覧）は**デバイスコード**方式です。GenOffice がコードを表示してブラウザーのログインを開き、完了すれば自動的に続きます。
- サインインはクラウドのプロジェクト一覧と Genspark 公式のモデルにだけ使われます。サインインしなくても、ローカルの機能とカスタムモデルはすべて使えます。
- サインアウトは設定から 1 クリックでできます。

## MCP の連携（上級者／AI クライアント向け）

GenOffice をコーディングエージェントにつなぐのは **連携** ペインです。これには独立した記事「コーディングエージェントの接続」があります。要するに — 方法（コマンドラインか MCP）を選び、その節に従ってから、新しいチャットを開いて質問します。

![設定 ▸ 連携：まず 3 つの手順、次にスキル行と MCP のオプション](img/settings-integrations.png)

**ローカル HTTP サーバー** の下では、アシスタントに任せる代わりに、アプリ自身がサーバーを動かすこともできます（有効スイッチ、ポート）。そして **詳細** がヘルスチェックの URL とログファイルを追加します。localhost でのみ待ち受けます。

## コマンドライン早見表
