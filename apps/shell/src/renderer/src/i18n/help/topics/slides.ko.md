# Slides: 프레젠테이션

Slides는 PowerPoint와 비슷한 편집기입니다. 진짜 .pptx를 읽고 씁니다.

## 화면

- **리본**: 홈 탭에 삽입과 서식(텍스트 상자/도형/그림/표/차트), 글꼴과 단락, 맞춤과 배열(겹침 순서, 정렬, 균등 배치)이 모여 있습니다.
- **썸네일 레일**(왼쪽): 누르면 전환, 끌어 정렬 바꾸기, 오른쪽 클릭으로 새로 만들기/복제/삭제.
- **캔버스**: WYSIWYG로 편집합니다. 드래그, 크기 조절 핸들, 가이드선.
- **노트**: 슬라이드별 발표자 노트. 내보내기 과정에도 유지됩니다.

## 리본 탭

탭 바(macOS는 홈부터 시작합니다. Windows에는 파일 탭이 추가됩니다).

- **홈**: 삽입과 서식 — 텍스트 상자, 도형, 그림, 표, 차트. 글꼴과 단락. 맞춤과 배열(겹침 순서/정렬/균등 배치). 레이아웃.
- **삽입**: 텍스트 상자, 표(행과 열 선택 가능), 그림, 페이지 번호, 점프 버튼(슬라이드 쇼 중에 누르면 그 슬라이드로 이동) 등.
- **그리기**: **펜**(슬라이드에 손으로 그려 페이지 위 잉크로 저장)과 **형광펜**(반투명한 굵은 선), 선 굵기도 고를 수 있습니다. 도구를 다시 누르면 취소됩니다.
- **디자인**: 테마, 색 구성과 배경. 마스터와 레이아웃.
- **전환**: 현재 슬라이드에 전환 효과를 고릅니다(PowerPoint의 슬라이드 쇼에 반영됨). 모두에 적용할 수도 있고, 없애기로 지울 수도 있습니다.

  ![전환 탭](img/slides-transitions.png)

- **애니메이션**: 선택한 도형에 나타남/강조 효과를 주고, **이동 경로**(경로를 따라 움직임)를 설정합니다. **미리 보기**를 누르면 캔버스에서 슬라이드의 애니메이션이 재생됩니다. 없애기로 지울 수 있습니다.

  ![애니메이션 탭](img/slides-animations.png)

  해 보세요: 제목 텍스트 상자 선택 ▸ 애니메이션 탭 ▸ 나타남 효과 선택 ▸ **미리 보기**로 캔버스에서 재생됩니다.

- **슬라이드 쇼**: 처음부터 또는 현재 슬라이드부터 재생하며, 표시 설정도 바꿉니다.
- **검토**: 현재 슬라이드에 **새 메모**를 붙입니다(pptx에 기록되어 PowerPoint에서도 보입니다).
- **보기**: **기본**(썸네일과 캔버스), **개요 보기**(글자로 훑어보고 이동), **여러 슬라이드**(격자 전체 보기, 더블클릭하면 편집), **읽기용 보기**(전체 화면으로 한 장씩, Esc로 종료).

## 오른쪽 클릭 메뉴

메뉴는 오른쪽 클릭한 위치에 따라 달라집니다.

- **빈 캔버스에서**: 새 슬라이드(레이아웃 선택 가능), 슬라이드 잘라내기/복사/붙여넣기(**이미지로 붙여넣기**와 **원본 서식 유지하여 붙여넣기**도 가능), 슬라이드 복제/삭제/숨기기, **구역 추가**(앞에), 구역 이름 바꾸기/위로 이동/아래로 이동/삭제/모두 접기/모두 펼치기, **배경 서식**/**배경 이미지 바꾸기**, 슬라이드 레이아웃 다시 설정.
- **요소를 선택한 상태**: 텍스트 편집, 하이퍼링크, 크기와 위치, **맞춤**(왼쪽/가로 가운데/오른쪽/위쪽/세로 가운데/아래쪽)과 가로·세로 균등 배치, 앞으로 보내기/뒤로 보내기, 그룹화/그룹 해제/다시 그룹화, 좌우 대칭/상하 대칭, 그림 자르기/바꾸기/이미지로 저장, 도형 변경, **기본 도형으로 설정**, 꼭짓점 편집. 텍스트 요소에는 굵게/기울임꼴/밑줄/글머리 기호/번호 매기기도 붙습니다.
- **표를 선택한 상태**: 행/열 삽입(위/아래/왼쪽/오른쪽), 행/열 삭제, 셀 병합/오른쪽으로 병합/아래로 병합, 셀 분할, **셀 음영**, 셀 내용의 정렬(위/가운데/아래).

## 내용

- 텍스트 상자, 도형(채우기/테두리/그림자), 그림(자르기/교체), 표, 차트(세로 막대/가로 막대/꺾은선/원형 등, 데이터 편집 가능).
- 마스터와 레이아웃: 글꼴, 자리 표시자, 배경을 통일합니다. 새 슬라이드는 선택한 레이아웃을 물려받습니다.
- 테마 색과 글꼴은 테마를 따릅니다.

## AI 생성

- 홈의 AI Slides 카드: 주제나 개요를 주면 AI가 슬라이드 한 벌을 만듭니다. 클라우드 생성이 실패하면 로컬 생성으로 넘어갑니다.
- 만든 뒤에도 AI 패널로 계속 다듬을 수 있습니다(AI는 제어된 스크립트 샌드박스를 통해 서식을 바꿉니다. [Sheets](help://sheets) 장의 샌드박스와 같은 방식입니다).

## 재생과 내보내기

- **PDF로 내보내기**: 숨겨진 창에서 한 장씩 래스터화하며, 큰 덱에는 진행률과 시간 초과 보호가 있습니다.
- 이미지로 내보내기: 한 장씩 PNG.
- 버전에 따라 전체 화면 슬라이드 쇼를 지원합니다.

## 저장

.pptx로 완전히 왕복합니다. 건드리지 않은 페이지는 바이트 단위로 그대로 남고, 노트와 마스터, 주석도 유지됩니다.
