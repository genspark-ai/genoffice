# 字型：系統字型與可下載字型

## 字型清單

字型控制項位於各編輯器的「常用」分頁（下圖是 Slides 中的字型群組）：

![Slides 功能區中的字型群組](img/fonts.png)

每個編輯器的字型選擇器都會合併顯示：本機已安裝的字型＋平台常見的候選字型（Windows 與 macOS 上常見的西文與中日韓字型家族，包含中日韓字型在各自系統上回報的本機化名稱）。當系統能列舉本機字型時，清單會依實際存在的內容分組；無法列舉時則退回完整的候選清單。

## 可下載字型（Slides）

- Slides 的字型選擇器可以開啟**字型目錄**：一份精心挑選的 OFL 開放字型清單，涵蓋多種文字系統；每個字型家族都提供 Regular（標準）與粗體兩種字重。
- 選取其中一個，就會從 CDN 下載並安裝（以校驗和鎖定）到應用程式的字型庫——之後所有文件都能使用，不必在系統層級安裝。
- 安裝內容位於應用程式的私有目錄，移除應用程式時一併消失。

## 中文排版

- Docs 中的中文字型支援與 Word 對齊的標點壓縮與避頭尾斷行規則（見 Docs 章）。
- 字型目錄中的中日韓家族涵蓋簡體／繁體中文、日文與韓文的襯線與無襯線字型。

## 管理本機字型

- 「安裝本機字型檔」入口可把磁碟上的 .ttf/.otf 檔載入應用程式的字型庫。
- 字型庫依家族歸檔，同一家族的多種字重可以並存。
