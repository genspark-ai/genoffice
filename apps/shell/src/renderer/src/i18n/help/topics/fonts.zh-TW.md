# 字型：系統字型與可下載字型

## 字型選擇器與跨平台辨識

在各個編輯器的頂部功能區「常用」分頁下，都可以找到完整的字型家族與字級選擇器（下圖展示的是 Slides 簡報功能區中的字型群組）：

![Slides 功能區的字型群組](img/fonts.png)

開啟字型下拉清單時，各編輯器會將**你電腦作業系統裡已經安裝的本機字型**與**跨平台常見辦公字型候選庫**合併呈現出來——無論是 Windows 上常見的新細明體、標楷體、微軟正黑體、宋體、黑體、微軟雅黑，還是 macOS 上常見的蘋方（PingFang TC／SC）、華文黑體、華文宋體、Hiragino（ヒラギノ）與 Apple SD Gothic Neo，包括這些中日韓字型在不同語言系統下顯示的中文名與英文別名，GenOffice 都能準確辨識並歸入同一字型槽位。當作業系統允許列舉本機字型時，下拉選單會依你機器上的實際可用狀態清晰分組；在受限環境無法列舉時，也會平穩回退展示完整的標準辦公字型清單，確保開啟跨平台文件時字形屬性不會遺失。

## 從內建開源字型目錄一鍵下載字型（Slides）

- **精選多語種開源（OFL）字型庫**：在 Slides 簡報編輯器中開啟字型選擇器時，可以直接點開內建的**字型目錄（Font Catalog）**——這裡收錄了一份經過精心挑選、採用 SIL Open Font License（OFL）開源授權的高品質多文種字型清單，每個字型家族都配齊了實用的**標準（Regular）**與**粗體（Bold）**兩個標準字重。
- **固定校驗和，一鍵裝入應用程式即刻可用**：在目錄裡挑中喜歡的字型後點擊下載，GenOffice 就會從官方 CDN 拉取字型檔案（內建嚴格的 SHA 校驗和比對，確保下載的字型包未被篡改）並直接安裝到應用程式自己的字型庫中；下載完成的瞬間，所有開啟的文件分頁就能立即選用這套新字型，全程不需要管理員權限，也不用去折騰作業系統的系統字型冊。
- **獨立私有目錄，不污染系統**：透過字型目錄下載安裝的字型全部存放在 GenOffice 的應用程式私有資料目錄下，保持你的作業系統字型目錄乾乾淨淨；將來如果你解除安裝應用程式，這些私有字型也會隨之一起清理乾淨。

## 中日韓（CJK）排版與字形涵蓋

- **對齊桌面版 Word 的中文排版規則**：中文字型在 Docs 文字編輯器中配合完整的中文排版引擎工作，原生支援行首行尾標點避頭尾（禁則處理）、連續標點符號字距擠壓、中西文混排間距以及初號到八號的傳統中文字級體系（詳細排版規則可參閱「Docs：文字處理」一章）。
- **全面涵蓋繁簡中日韓襯線與無襯線體**：內建可下載字型目錄中的 CJK 字型家族完整涵蓋了繁體中文、簡體中文、日文與韓文的襯線體（明體／宋體風格）與無襯線體（黑體風格），哪怕在一台剛裝好系統、缺少美觀商用字型的電腦上做簡報 PPT，也能一鍵補齊端莊大方的多語種排版字型。

## 匯入與管理你自己的本機字型檔案

- **一鍵匯入本機 `.ttf`／`.otf` 字型檔案**：如果你手裡有公司品牌規定的專用企業字型或自己下載的 `.ttf`、`.otf` 字型包，無需安裝到整個作業系統，直接點擊字型管理面板裡的**安裝本機字型檔案**入口，就能把磁碟上的字型檔案直接匯入 GenOffice 的應用程式字型庫中使用。
- **依字型家族自動歸檔合併**：匯入後的字型會自動按照底層字型家族（Font Family）名稱整齊歸檔，同一個字型家族下的標準、粗體、斜體等多個不同字重檔案會自動合併在同一個家族項目下協同工作。
