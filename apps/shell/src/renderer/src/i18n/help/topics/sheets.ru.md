# Sheets: электронные таблицы

Sheets — редактор, похожий на Excel; вычисления выполняет отдельный процесс движка на Rust (если он упадёт, само приложение не упадёт). Открывает и сохраняет настоящие .xlsx; .csv и .tsv открываются как таблицы.

## Интерфейс

- **Лента**: восемь вкладок, разобранные по очереди ниже.
- **Строка формул**: показывает и редактирует формулу активной ячейки; поддерживаются обычные функции.
- **Вкладки листов** (внизу): добавить / переименовать / удалить / переместить лист.
- **Правка ячейки**: дважды щёлкните или просто печатайте; Enter подтверждает и идёт вниз, Tab — вправо, Escape отменяет (как принято в Excel).
- **Сочетания клавиш**: в духе семейства Excel (ctrl+C/V/X, ctrl+Z/Y, ctrl+F, ...).

## Вкладки ленты

- **Главная**: шрифт, заливка, границы, числовые форматы (денежный/процентный/разделитель, увеличить-уменьшить число знаков), выравнивание, объединение, вставка строк/столбцов и их размер, условное форматирование, форматирование как таблицы, стили ячеек, буфер обмена и формат по образцу, сортировка и фильтр.
- **Вставка**: рисунки, фигуры, надписи, гиперссылки, примечания, флажок, колонтитулы, символы, уравнения; **девять типов диаграмм** (гистограмма, линейчатая, график, с областями, круговая, точечная, лепестковая, кольцевая, а также гистограмма + график) плюс **Рекомендуемые диаграммы**, которые ранжируют типы по выделению и показывают их предпросмотр; **Сводная диаграмма** из той ячейки, в которой вы находитесь; **Спарклайны** (график, гистограмма, выигрыш/проигрыш); **Срез** и **Временная шкала** для фильтрации сводной таблицы.
  - Диаграммы, сводные диаграммы и спарклайны — настоящие объекты в сохранённой книге.
  - **Срез** и **Временная шкала** — элементы управления текущего сеанса: сделанная ими фильтрация сохраняется, и Excel показывает ту же отфильтированную сводную таблицу, но сама кнопка среза в файл не входит.
- **Разметка страницы**: цвета и шрифты темы, переключатели печати сетки и заголовков, страничный режим.
- **Формулы**: автосумма и вставка функций, присвоение имён (в том числе по выделению), влияющие и зависимые ячейки, окно контрольного значения, пересчёт листа/книги.
- **Данные**: сортировка и фильтр (включая расширенный фильтр и сброс фильтра), текст по столбцам, объединение книг, обновить все.
- **Рецензирование**: просмотр примечаний (показать, предыдущее/следующее), перевод и группа **Защита** — **Защитить лист**, **Защитить книгу** и **Разрешить изменение диапазонов**.
  - Защита записывается в файл .xlsx, и на то, что применяет это приложение, пароля нет, поэтому та же кнопка превращается в **Снять защиту…** и отменяет её. Защиту, заданную другой программой, у которой _действительно_ есть пароль, отсюда снять нельзя.
  - Обе кнопки защиты применяются сразу — диалогового окна, которое можно отменить, нет, есть только заметка в строке состояния, что это будет записано при сохранении.
  - **Разрешить изменение диапазонов** помечает ячейки, которые остаются редактируемыми, пока остальная часть листа заблокирована.
- **Вид**: переключатели сетки, **строки формул**, заголовков и подсветки активной строки и столбца; масштаб; **Обычный** и **Страничный режим**. Сетка и заголовки сохраняются вместе с листом; подсветка — это ваша личная настройка.
- **Конструктор диаграмм**: появляется при выбранной диаграмме — тип диаграммы, стили и цвета, изменение диапазона данных.

Вкладка «Данные», кнопка за кнопкой (слева направо на рисунке):

![Вкладка «Данные»](img/sheets-data.png)

- **Сводная таблица**: строит сводку по текущему диапазону; перетаскивайте поля для агрегации.
- **Обновить**: пересчитывает данные текущей сводной таблицы.
- **Из текстового/CSV-файла**: импортирует .csv/.txt как новый лист с разделением по разделителю.
- **Объединить книги**: затягивает листы из других файлов .xlsx в этот.
- **Обновить все**: пересчитывает все сводные таблицы и внешние наборы данных.
- **Сортировка** (раскрывающийся список): по возрастанию / по убыванию / пользовательская сортировка (правила по нескольким столбцам).
- **Фильтр**: добавляет к строке заголовков выпадающие списки ▼; отметьте значения, которые оставить.
- Мелкие кнопки, составленные стопкой рядом: **Очистить** (вернуть все строки), **Повторить** (снова применить текущий фильтр), **Дополнительно** (фильтр по диапазону условий).
- **Текст по столбцам** (раскрывающийся список): разбивает один столбец на несколько по разделителю или фиксированной ширине.
- **Экспресс-заполнение**: дайте один пример — остальные ячейки столбца заполнятся по образцу (ctrl+E).
- **Удалить дубликаты**: убирает повторяющиеся строки по выбранным столбцам.
- **Проверка данных** (раскрывающийся список): правила ввода для выделения (выпадающие списки, числовые диапазоны, ...).
- **Консолидация**: сводит несколько диапазонов в одно место по категориям.
- **Анализ «что если»** (раскрывающийся список): подбор параметра — подбирает значение одной ячейки с исходными данными, чтобы ячейка с формулой достигла заданного значения.
- **Группировать / Разгруппировать** (раскрывающийся список): группы строк и столбцов со сворачиванием и разворачиванием.
- **Промежуточный итог**: вставляет строки промежуточных итогов по категориям.

Вкладка «Формулы», кнопка за кнопкой:

![Вкладка «Формулы»](img/sheets-formulas.png)

- **Вставить функцию** (fx): поиск функций с помощником аргументов.
- **Автосумма** (раскрывающийся список): SUM в один клик, а также среднее/количество/максимум/минимум.
- **Последние использованные / Финансовые / Логические / Текстовые / Дата и время / Ссылки и массивы / Математические / Ещё**: просмотр и вставка функций по категориям.
- **Диспетчер имён**: просмотр, создание и удаление именованных диапазонов.
- **Присвоить имя** (раскрывающийся список): дать имя выделению; **Использовать в формуле** вставляет существующее имя; **Создать из выделения** именует диапазоны по их строке или столбцу заголовков.
- **Влияющие ячейки / Зависимые ячейки**: синие стрелки показывают, откуда формула берёт данные и куда она их передаёт; **Убрать стрелки** очищает их.
- **Показать формулы**: в ячейках видны сами формулы, а не результаты.
- **Проверка наличия ошибок**: находит и объясняет ошибки в формулах.
- **Окно контрольного значения**: закрепляет важные ячейки и следит за их текущими значениями.
- **Параметры вычислений** (раскрывающийся список): автоматический или ручной пересчёт; в ручном режиме **Пересчитать** и **Произвести вычисления** запускают его вручную.

## Числа и форматирование

- Числовые форматы: общий, числовой, денежный, процентный, дата/время, дробный, экспоненциальный и прочие.
- Выравнивание, перенос строк, объединённые ячейки, границы и заливка.
- Высота строк и ширина столбцов перетаскиванием; дважды щёлкните по границе, чтобы подобрать размер.

## Данные

**Сортировка и фильтр** (пример: одна колонка по убыванию):

1. Щёлкните **по любой ячейке этого столбца** (выделять весь столбец не нужно).
2. Вкладка Главная ▸ **Сортировка и фильтр** ▸ **По убыванию**; целые строки переставятся вместе (сортируется вся область как единое целое).
3. Для своих правил (несколько столбцов, по цвету): тот же путь, **Пользовательская сортировка**.
4. Фильтр: выделите строку заголовков и щёлкните **Сортировка и фильтр ▸ Фильтр** — у каждого заголовка появится список ▼, где отмечаются нужные значения; сброс фильтра возвращает всё.

- Сортировка и фильтр.
- Закрепление областей.
- .csv / .tsv: открываются сразу как таблица (tsv с разделителем-табуляцией разбирается как одна таблица); при сохранении формат записывается обратно.

## Меню по правому щелчку

- **В сетке**: собственное меню редактора (Univer) — вырезать/копировать/вставить, вставить и удалить строки и столбцы, скрыть, объединить ячейки, закрепить области и прочие повседневные пункты.
- **На нижней строке состояния**: выберите, какую статистику показывать в строке состояния (среднее / количество / сумма, ...); выбор запоминается.
- **На вкладке листа внизу**: добавить / переименовать / удалить / окрасить / скрыть лист (меню вкладок Univer).
- Меню панели вкладок сверху описано в главе [Вкладки и управление окнами](help://tabs-and-windows).

## ИИ

- Боковая панель ИИ: выделите диапазон и дайте команду обычными словами (переформатировать, создать данные, написать формулу).
- Прикрепите файлы к запросу кнопкой 📎 или перетащите их на панель; они уходят вместе с вопросом, а изображения возвращаются миниатюрами.
- Ответ может сослаться на ячейку — щёлкните по ссылке, и сетка перейдёт туда.
- Изменения ИИ можно откатить прямо с панели.

## Сохранение и экспорт

- Сохранение в .xlsx (формулы и форматирование сохраняются); «Сохранить как…»; экспорт в PDF следует разбивке на страницы при печати.
- Автосохранение подчиняется общему правилу (включается после первого ручного сохранения).

## Устойчивость

- Вычислительный процесс на Rust изолирован от интерфейса на уровне процесса: если его убьют чрезмерные данные, вы получите сообщение и попытку восстановить сеанс, а не падение приложения.
