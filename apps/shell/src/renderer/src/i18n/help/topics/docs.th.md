# Docs: การประมวลผลคำ

Docs คือโปรแกรมประมวลผลคำที่ทำงานคล้าย Word: อ่านและเขียนไฟล์ .docx ของจริง พร้อมการแบ่งหน้าแบบสิ่งที่เห็นคือสิ่งที่ได้อย่างแท้จริง

## แถบเครื่องมือ

แท็บ: **หน้าแรก / แทรก / เค้าโครง / ออกแบบ / การอ้างอิง / รีวิว / มุมมอง** รวมถึงแท็บเฉพาะหน้าที่ที่ปรากฏตามวัตถุที่เลือกอยู่ (การออกแบบตาราง รูปภาพ)

- **หน้าแรก**: คลิปบอร์ด, แบบอักษร (รวมขนาดตัวอักษรสำหรับภาษาจีน ญี่ปุ่น เกาหลี และเครื่องหมายเน้น), ย่อหน้า (จัดแนว/เยื้อง/ระยะ/รายการ), สไตล์ (หัวเรื่อง 1-6/ปกติ/ข้อความอ้างอิง แก้ไขได้)
- **แทรก**: ตัวแบ่งหน้า/ตัวแบ่งส่วน, ตาราง (รวมตารางด่วน), รูปภาพ, รูปร่าง, ไฮเปอร์ลิงก์, หัวกระดาษ/ท้ายกระดาษ, หมายเลขหน้า, วันที่, กล่องข้อความ
- **เค้าโครง**: ขอบกระดาษ, การวางแนวกระดาษและขนาดกระดาษ, คอลัมน์, การเยื้องและระยะห่างของย่อหน้า
- **ออกแบบ**: ธีม, ชุดสี, ลายน้ำ, เส้นขอบหน้า
- **การอ้างอิง**: สารบัญ (อัปเดตได้), เชิงอรรถ/หมายเหตุท้ายเรื่อง, คำอธิบายภาพ, การอ้างอิงโยง

  ![แท็บการอ้างอิง](img/docs-references.png)

- **รีวิว**: ตรวจการสะกด, ข้อคิดเห็น, ติดตามการเปลี่ยนแปลง (มุมมมการแสดงทั้งหมด/แบบง่าย), นับจำนวนคำ
- **มุมมอง**: ไม้บรรทัด, เส้นตาราง, บานหน้าต่างนำทาง, ซูม และ **กล่องแป้นพิมพ์ลัด**ที่ค้นหาได้

## บานหน้าต่างนำทาง

**มุมมอง ▸ บานหน้าต่างนำทาง** เปิดบานหน้าต่างด้านข้างที่เก็บโครงเรื่องของหัวเรื่องในเอกสาร ช่องค้นหาที่ครอบคลุมทั้งเอกสาร และภาพย่อหนึ่งภาพต่อหนึ่งหน้า ว่าบานหน้าต่างนี้เปิดอยู่หรือไม่จะถูกจดจำไว้ระหว่างการเปิดแต่ละครั้ง เอกสารที่คุณใช้โครงเรื่องนำทางจึงยังนำทางต่อได้

**โครงเรื่อง** คือต้นไม้ของหัวเรื่อง คลิกขวาบนหัวเรื่องในโครงเรื่องเพื่อยุบหรือจัดโครงสร้างใหม่ ไม่ใช่แค่นำทาง

- **ยุบ / ขยาย** บนหัวเรื่องจะยุบทรงต้นย่อยทั้งหมดของหัวเรื่องนั้น ทั้งที่บทหายไป แต่ข้อความยังอยู่ในเอกสาร
- **ยุบทั้งหมด / ขยายทั้งหมด** จะยุบหรือขยายทั้งต้นไม้ในครั้งเดียว ในรายงานยาว นี่คือความต่างระหว่างโครงเรื่องที่อ่านได้กับกำแพงของข้อความ
- **แสดงระดับหัวเรื่อง** กรองต้นไม้ให้เหลือแค่ความลึกที่คุณสนใจ *แสดงหัวเรื่อง 1* จึงเหลือสารบัญที่คุณกวาดสายตาอ่านได้จริง
- **เลื่อนระดับขึ้น / เลื่อนระดับลง** เปลี่ยนระดับของหัวเรื่อง และเปลี่ยนระดับที่หัวเรื่องทุกอันด้านล่างรับไปด้วย ทั้งนี้คือวิธีที่บทกลายเป็นส่วน
- **หัวเรื่องใหม่ก่อนหน้า / หัวเรื่องใหม่ถัดไป** แทรกหัวเรื่องหนึ่งอันตรงตำแหน่งเคอร์เซอร์ โดยไม่ต้องออกจากบานหน้าต่าง
- **ลบ** ลบหัวเรื่องพร้อม *ทุกอย่างใต้หัวเรื่องนั้น* และนี่คือข้อที่ต้องระวังที่สุด เพราะเป็นการลบทรงต้นย่อย ไม่ใช่การลบหนึ่งบรรทัด
- **เลือกหัวเรื่องและเนื้อหา** เลือกตั้งแต่หัวเรื่องจนถึงท้ายทรงต้นย่อยของมัน พร้อมแก้ทั้งส่วนในครั้งเดียว

## เมนูคลิกขวา

คลิกขวาที่ใดก็ได้ในเนื้อหา เมนูจะเปลี่ยนตามสิ่งที่คุณคลิก กลุ่มหลัก ๆ คือ:

- **คลิปบอร์ด**: ตัด / คัดลอก / วาง / **วางเป็นข้อความธรรมดา**
- **แบบอักษรและย่อหน้า**: เปลี่ยนตระกูลและขนาดตัวอักษร ตัวหนา/ตัวเอียง/ขีดเส้นใต้ จัดแนว/เยื้อง/ระยะ โดยไม่ต้องไปที่แถบเครื่องมือ
- **คำพ้องความหมาย**: แสดงคำที่มีความหมายเหมือนกันสำหรับคำที่เลือก คลิกคำใดคำหนึ่งเพื่อแทนที่
- **แปล** (AI): แปลข้อความที่เลือกเป็นภาษาเป้าหมาย (อังกฤษ จีนตัวย่อ ญี่ปุ่น เกาหลี ฝรั่งเศส เยอรมัน สเปน ฯลฯ) ผ่านแผง AI
- **ข้อคิดเห็นใหม่**: แนบข้อคิดเห็นไว้ที่ข้อความที่เลือก
- **ตรวจการสะกด** (เมื่อคลิกคำที่สะกดผิด): คำที่แนะนำให้แทนที่, ข้ามทั้งหมด, เพิ่มลงในพจนานุกรม, กำหนดภาษาสำหรับการตรวจทาน
- **ไฮเปอร์ลิงก์**: เปิด / แก้ไข / คัดลอกลิงก์ / ยกเลิกไฮเปอร์ลิงก์
- **รูปภาพ**: ดูรูปภาพ, บันทึกรูปภาพเป็น…, **การตัดข้อความ** (แทรกในบรรทัด / ชิดซ้ายและขวาแบบสี่เหลี่ยม / บนและล่าง / อยู่หลังข้อความ / อยู่หน้าข้อความ), ลำดับการจัดวาง
- **ฟิลด์** (สารบัญ, หมายเลขหน้า): อัปเดตฟิลด์ / สลับการแสดงรหัสฟิลด์ / แก้ไขฟิลด์
- **การลำดับเลขรายการ** (เมื่ออยู่ในรายการ): เริ่มการนับใหม่ / นับต่อ / เปลี่ยนระดับรายการ / ตั้งค่าลำดับเลข
- **ตาราง** (เมื่อเคอร์เซอร์อยู่ในตาราง): แทรกแถว/คอลัมน์, ผสาน / แยกเซลล์, แยกตาราง, ปรับขนาดอัตโนมัติ, การจัดแนวเซลล์, กระจายแถว/คอลัมน์, คุณสมบัติของตาราง, เมนูลบ, เลือก

## การแก้ไข

- ค้นหาและแทนที่ (ctrl+F / ctrl+H): แยกแยะตัวพิมพ์, คำทั้งคำ, นิพจน์ทั่วไป
- ตัวคัดวางรูปแบบ, เลิกทำ/ทำซ้ำแบบลึก, ตัวเลือกการวาง
- ตาราง: ผสาน/แยกเซลล์, เพิ่มลบแถว/คอลัมน์, เส้นขอบและการลงสีพื้น, เรียงลำดับ, สูตร
- รูปภาพ: การตัดข้อความ, ครอบตัด, บีบอัด, แคนวาสวาด

## การจัดหน้าเอกสารภาษาจีน ญี่ปุ่น เกาหลี

- การบีบอัดเครื่องหมายวรรคตอนและกฎห้ามขึ้นบรรทัด/ห้ามลงท้ายบรรทัดทำงานเหมือน Word พร้อมการแปลงความกว้างเต็ม/ครึ่ง
- รายการแบบอักษรที่เสนอครอบคลุมชื่อตระกูลแบบอักษรจีน ญี่ปุ่น เกาหลีที่พบบ่อยใน Windows และ macOS

## AI

- ปุ่ม AI ในแถบเครื่องมือและแผงด้านข้าง: ข้อเสนอสำหรับการเขียนใหม่, ขยายข้อความ, แปล, สรุป, แทรกตาราง รวมถึงคำสั่งอิสระ
- ทุกรอบของ AI จะเก็บสแนปช็อตก่อนเสมอ เลื่อนกลับได้จากรายการเวอร์ชัน และการเลื่อนกลับนั้นเองก็เลิกทำได้

## การบันทึกและการส่งออก

- การบันทึก .docx จะเขียนใหม่เฉพาะย่อหน้าที่เปลี่ยนไป เนื้อหาที่ไม่ถูกแตะต้องยังคงเหมือนเดิมทุกไบต์
- ส่งออกเป็น PDF (ตามการแบ่งหน้าปัจจุบัน) และเป็นรูปภาพรายหน้า
