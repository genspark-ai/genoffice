# ربط وكيل برمجي

يتحدث GenOffice بروتوكول Model Context Protocol، فيستطيع وكيل البرمجة قراءة مستنداتك وكتابتها وتحويلها إلى صور عبر المحركات نفسها التي يستخدمها التطبيق. الوكيل لا يخمّن صيغة الملف: فهو يحصل على مخططات العمليات مُنمَّطة من التعريفات نفسها التي يتحقق منها المحرك المنفّذ.

## تسجيله

الحالة المعتادة هي أمر واحد:

```sh
genoffice mcp install all
```

فيجد وكلاء البرمجة الموجودين على هذا الجهاز — Claude Code، وCodex، وCursor، وGemini CLI، وCopilot CLI، وOpenCode، وWindsurf — ويكتب مدخل خادم stdio في إعداد كل واحد منهم، تاركًا بقية ذلك الملف كما وجدها.

```sh
genoffice mcp list             # where each agent stands
genoffice mcp install cursor    # just one
genoffice mcp uninstall cursor  # take it back out
```

الوكيل الذي ثبّتّه في مكان غير معتاد يحتاج إلى `--dir <path>`؛ وعلامة `--force` تعيد كتابة مدخل موجود بالفعل.

## تشغيله بنفسك

لعميل على جهاز آخر، قدّمه عبر HTTP بدلًا من ذلك:

```sh
genoffice mcp --http 8765 --token <secret>
```

تغيّر `--host <addr>` موضع الاستماع. ومرّر الرمز نفسه إلى العميل.

والملفات تنتقل عبر HTTP أيضًا: `PUT /files/<name>` يرفع ملفًا واحدًا، وكل أداة تقبل رابط `http(s)` بدل المسار، وتعود المخرجات كروابط تنزيل — وحين تكون صغيرة بما يكفي، كمصادر مضمّنة. أما العمليات والمواصفات وMarkdown فتُمرَّر داخل الطلب في الحالتين.

## ما الذي يحصل عليه الوكيل

كل أمر أداة. وأهمها:

- **`docs` و`sheet` و`slides`** — قراءة ملف وتحريره عبر مسار الكتابة نفسه في التطبيق، **عملية** (op) واحدة في كل مرة. ويبدأ العرض الجديد بـ `deck_start` ثم `deck_page` ثم `deck_build`.
- **`render`** — صورة PNG لكل صفحة، يخطّطها محرّك التطبيق، فيستطيع الوكيل النظر إلى الشريحة بدلًا من التخمين بشأنها.
- **`pdf`** — الطبقة النصية لملف PDF، صفحةً بصفحة، دون أي عملية تطبيق.
- **`info`** — البيانات الوصفية وملخّص البنية، وهو عادةً أرخص نداء أول لملف غير مألوف.
- **`search` و`image` و`media`** — المزوّدات المهيّأة في التطبيق، فلا يحتاج الوكيل إلى مفاتيح خاصة به.
- **`merge`** — ملء قالب `{{key}}`.

## المخططات، وميزانية أصغر

يُعلن `apply` و`create` معاملي `ops` و`cells` و`data` مع مخطط مُنمَّط لكل عملية، مولَّدًا من `genoffice guide <domain> --json`. هذا دقيق لكنه ليس صغيرًا. والعميل الذي له نافذة سياق ضيقة يمكنه أن يطلب المصفوفات البسيطة بدلًا من ذلك:

```sh
genoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 genoffice mcp
```

## المهارة

الوكيل الذي لا يعرف مفردات العمليات سيخمّن. و`genoffice skill` يثبّت مهارة GenOffice في الوكلاء الذين يجدهم، حاملًا معها المرجع وأدلة التصميم — وهي المادة نفسها التي يطبعها `genoffice guide`.

## ما ليس هو

خادم MCP يقرأ الملفات ويكتبها. لكنه ليس النافذة: لا توجد لوحة ذكاء اصطناعي، ولا ينطبق حوار التحديث داخل التطبيق. وإذا احتاجت خطوة ما إلى النافذة، فافتح الملف.
