# 設定、語言、主題與 MCP 整合

## 開啟設定

首頁左下角的帳戶列會開啟設定面板（未登入時顯示為「登入」）。面板共六個分區：帳戶、AI 模型、生圖、媒體與搜尋、一般、整合、關於。

![設定 ▸ 一般：語言、主題、自動儲存與使用統計開關都在這裡](img/settings-general.png)

模型配置另有專門一章；**生圖、媒體與搜尋**是依服務商分別開啟圖像生成、圖片解析、影片解析、網路搜尋與本機檔案搜尋的地方。

## 語言

- 設定中提供 **21 種介面語言**：English、简体中文、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt。
- 切換後立即生效並會保留；原生選單列也會隨語言重建。

## 主題

淺色／深色／跟隨系統三種。跟隨系統時會依作業系統的外觀切換，編輯器區域同步換膚且不會閃白。

## 預設應用程式關聯

設定中可以把 .docx / .xlsx / .pptx / .pdf 等格式註冊為由 GenOffice 開啟（作業系統層級的預設應用程式註冊；出現提示時請確認）。

## 第三方聲明與更新

- 說明 ▸ 第三方軟體聲明：隨附於應用程式的完整 OSS 授權清單。
- 說明 ▸ 檢查更新：手動觸發一次更新檢查；有新版本時會提示安裝。

## Genspark 登入

- 登入入口（設定或雲端專案清單）採用**裝置碼**流程：GenOffice 顯示一組碼並開啟瀏覽器登入頁；完成後會自動繼續。
- 登入只用於：雲端專案清單，以及 Genspark 的官方模型服務。不登入時，所有本機功能與自訂模型都照常運作。
- 在設定中一鍵即可登出。

## MCP 整合（供進階使用者／AI 用戶端使用）

**整合**是把 GenOffice 接上程式開發代理的面板，它也有專門一章：連接程式開發代理。簡單說就是——選一條路（命令列或 MCP），照那一節做，然後開一個新對話直接問。

![設定 ▸ 整合：先三個步驟，再是技能列與 MCP 選項](img/settings-integrations.png)

在**本機 HTTP 服務**之下，應用程式也可以自己跑這個服務——一個啟用開關、一個連接埠——而**進階**會再加上健康檢查的網址和日誌檔案——而不是丟給助理處理。它只監聽 localhost。

## 命令列速查

| 命令               | 用途                |
| ------------------ | ------------------- |
| `genoffice <file>` | 開啟檔案            |
| `genoffice mcp`    | 啟動本機 MCP 伺服器 |
| `genoffice --help` | 全部命令與參數      |
