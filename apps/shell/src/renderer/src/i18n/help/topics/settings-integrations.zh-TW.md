# 設定、語言、主題與 MCP 整合

## 開啟設定面板

點擊首頁左下角的帳戶列（尚未登入 Genspark 帳號時會顯示為「登入」按鈕），即可開啟全域設定面板。整個設定視窗依職責劃分為六個分頁：**帳戶**、**AI 模型**、**生圖、媒體與搜尋**、**一般**、**整合**以及**關於**。

![設定 ▸ 一般：語言、主題、自動儲存與使用統計開關都在這裡](img/settings-general.png)

對話大模型的端點與金鑰設定在「AI 模型與設定」一章中有專門介紹；而**生圖、媒體與搜尋**分頁則是用來為圖像生成、圖片解析、影片解析、網路搜尋以及本機檔案搜尋分別指定服務供應商與獨立金鑰的地方。

## 介面語言

- GenOffice 內建支援 **23 種完整本地化的介面語言**，包括繁體中文、简体中文、English、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、Tiếng Việt、Türkçe 與 Magyar。
- 在下拉選單中選擇新語言後會立即在全域生效並自動寫入本機設定，無需重啟應用程式；作業系統頂部的原生選單列、右鍵選單以及內建說明書都會同步切換為所選語言。

## 外觀主題

提供**淺色**、**深色**和**跟隨系統**三種外觀模式。選擇「跟隨系統」時，GenOffice 會即時監聽作業系統的日夜外觀變化，所有開啟的編輯器工具列、側邊欄與對話框都會在同一影格內平滑換膚，不會出現刺眼的白屏閃爍，也不會擅自篡改你文件紙張原本的印刷底色。

## 一般設定

- **傳送匿名使用統計**：預設處於開啟狀態，底層透過 Google Analytics 4 僅回報應用程式級的基礎操作事件（例如「開啟了一個 .docx 文件」）以及網路連線本身攜帶的公網 IP 與傳輸中繼資料；你的文件內文、試算表數據、簡報內容和本機檔名等隱私資訊絕不會被蒐集或上傳，你也可以隨時在這裡一鍵關閉統計。
- **AI 助理介面偏好**：可以在這裡自由調整 **AI 側邊欄位置**（靠視窗左側或右側停靠）、**AI 面板文字大小**，以及是否開啟 **AI 對話輸入框的拼字檢查**，讓輔助寫作區域更貼合你的閱讀習慣。
- **新文件中開啟 AI 面板**：預設處於關閉狀態，這樣每次新增空白文件時都會先給你留出乾淨寬敞的編輯畫布，需要 AI 幫忙時再點一下功能區按鈕即可喚出側邊欄；如果你習慣每次都讓 AI 先起草初稿，可以把它設為預設開啟。
- **所有文件自動儲存**：開啟後會讓每個編輯器預設處於自動儲存啟用狀態（首次手動存檔後自動持續寫入磁碟）；即便開啟了全域自動儲存，你依然可以在某個具體視窗的頂部工具列上臨時關掉該文件的自動儲存。
- **預設儲存位置與檔案關聯**：你可以透過**預設儲存位置**旁邊的**變更**按鈕指定新增文件首次存檔時的預設目錄，也可以使用**設為 Office 文件預設程式**一鍵把系統裡的 `.docx`、`.xlsx`、`.pptx` 等常用辦公格式交給 GenOffice 開啟。

## 生圖、媒體與搜尋

這幾項多模態與檢索能力並不是簡單的「開／關」按鈕，而是允許你為每一項能力單獨挑選最合適的服務商；同一家服務商的 API 金鑰和基礎位址（Base URL）只需要填寫一次，就能在下面各個能力列之間直接共用：

- **網路搜尋、圖像生成、圖片解析與影片解析**：每一列都可以獨立選擇服務供應商、具體模型名稱、API Key 和自訂端點位址，因此你完全可以用一家服務商跑內文對話，同時用另一家專精視覺或生圖的模型來處理配圖與影片理解。
- **本機檔案搜尋與相關性重排**：本機檔案全文檢索預設完全在你的電腦本機執行；它下方的 **Jev 搜尋重排** 預設處於**關閉**狀態，關閉時沒有任何一個位元組會離開本機。只有當你主動開啟該開關時，本機搜尋初步命中的前 20 條結果摘要（每份文件最多截取 1,200 個字元的符合片段，外加檔名與所在資料夾名稱）才會傳送給你所選的決策重排端點（支援透過 OpenRouter 或 TypeSafe 呼叫 Jev、Perplexity、Liquid AI d1、Cloudflare、本機重排引擎或自訂 URL），依語意相關度重新排序後再呈現給你。

## 關於與更新通道

- **版本資訊與開源倉庫**：展示目前已安裝的精確版本號、專案的 GitHub 倉庫入口，以及方便支持開發團隊的**去 GitHub 點 Star** 快捷按鈕。
- **更新通道切換**：支援在**穩定版（Stable）**與 **Beta 預覽版**之間切換；變更通道後會立即生效並馬上觸發一次更新檢查，但出於設定與資料相容性保護，切回穩定版通道不會把目前已經安裝的 Beta 版本強行降級回舊版。

## 系統預設應用程式綁定

除了在「一般」分頁中一鍵關聯 Office 三件套外，設定面板還支援將 `.docx`、`.xlsx`、`.pptx`、`.pdf` 等格式在作業系統層面註冊為預設由 GenOffice 處理；點擊綁定後依 macOS、Windows 或 Linux 桌面環境的系統提示確認即可生效。

## 第三方開源聲明與手動檢查更新

- **說明選單 ▸ 第三方軟體聲明**：隨時檢視隨安裝包一起發行的全部開源元件清單及其完整授權條款文字。
- **說明選單 ▸ 檢查更新**：在自動檢查之外手動觸發一次版本檢測，一旦發現目前通道上有更新的組建發布，就會彈出提示引導你下載並安裝。

## Genspark 帳號登入與登出

- **裝置碼安全登入**：無論從設定面板還是從首頁的「雲端專案」清單點擊登入，都採用標準的**裝置碼（Device Code）**授權流程——GenOffice 會在視窗裡顯示一串一次性驗證碼並自動在你的預設瀏覽器中開啟登入頁，在瀏覽器中確認授權後應用程式會自動完成對接，全程無需在用戶端內直接輸入帳號密碼。
- **帳號的作用範圍**：登入 Genspark 帳號僅用於同步網頁端的**雲端專案清單**以及直接呼叫 **Genspark 官方託管模型**；即使完全不登入帳號，所有本機文件編輯、格式轉換、PDF 註解塗黑以及你自己設定的自訂模型（BYOK）都照常完整可用。
- **帶確認保護的登出**：在設定面板中點擊登出時，系統會先彈出一個確認對話框以防誤觸；確認登出後，會一次性斷開所有依賴 Genspark 帳號的雲端 AI 功能（包括雲端專案清單與官方託管模型），而你正在編輯的本機文件和自訂端點設定不會受到任何影響。

## MCP 整合（面向進階使用者與外部 AI 程式設計助手）

**設定 ▸ 整合**面板專門用來把 GenOffice 的文件讀寫與排版引擎接入 Claude Code、Cursor、Codex、OpenCode 等外部程式設計代理，更完整的命令列用法可參閱專門的「連接程式設計助手」一章。日常接入只需要三步：選擇接入方式（安裝技能或啟用 MCP）、依介面提示一鍵註冊、然後在你的程式設計助手裡新開一個對話直接用自然語言交代文件任務。

![設定 ▸ 整合：先三步走，再是技能列和 MCP 選項](img/settings-integrations.png)

如果你希望由 GenOffice 桌面端自己常駐執行服務而不是交由外部助手按需拉起，可以在面板下方的**本機 HTTP 服務**區域打開啟用開關並指定連接埠號；展開**進階**選項後，還可以檢視健康檢查網址（Health-check URL）並開啟本機執行日誌。出於安全考量，該 HTTP 服務僅綁定並監聽本機迴路位址（`localhost`）。
