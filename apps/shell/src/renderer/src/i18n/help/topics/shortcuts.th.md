# คีย์ลัด

ตัวแก้ไขแต่ละตัวมีการผูกคีย์ของตัวเอง และมีเพียงบางรายการที่ใช้ได้ทุกที่ หน้านี้คือรายการทั้งหมด แยกตามแอป พร้อมวางคีย์ของ macOS กับ Windows / Linux ไว้เคียงกัน

## อ่านหัวนี้ก่อน

**เกือบทุกอย่างในที่นี้ไม่ใช่คีย์ระดับทั้งแอป** มีเพียงสามคีย์เข้าถึงด้านล่างเท่านั้นที่เป็นระดับทั้งแอป ที่เหลือทั้งหมดเป็นของแอปที่อยู่หน้าสุด และเปลี่ยนไปเมื่อคุณสลับแท็บ

| การทำงาน                              | macOS | Windows / Linux |
| ------------------------------------- | ----- | --------------- |
| เปิดคู่มือผู้ใช้ — ใช้ได้ทุกที่ในแอป  | F1    | F1              |
| ยุบ／ขยายแถบเครื่องมือ — ทุกตัวแก้ไข  | ⌥⌘R   | Ctrl+F1         |
| เปิดแผ่นคีย์ลัดคีย์บอร์ด — เฉพาะ Word | ⌘/    | Ctrl+/          |

- **F1 เปิดคู่มือนี้** ไม่ใช่แผ่นคีย์ลัด คีย์นี้อยู่ในเมนูของแอป จึงใช้ได้จาก Word, Sheets, Slides, PDF หรือแท็บ Home เหมือนกัน
- **คีย์สลับแถบเครื่องมือคือ `Ctrl+F1` หรือ `⌥⌘R` บน macOS** กด `F1` เปล่า ๆ แล้วไม่มีอะไรเกิดขึ้น — F1 คือคู่มือ และคีย์ของแถบเครื่องมือตั้งใจไม่ใช้ร่วมกับมัน บน macOS ก็ยังรับ `Ctrl+F1` ได้ แต่คีย์ที่ Office for Mac ใช้จริงคือ `⌥⌘R`
- **แผ่นคีย์ลัดคีย์บอร์ดมีเฉพาะ Word** (`⌘/`) โดยแสดงรายการในตารางของ Word ด้านล่างตรง ๆ ตัวแก้ไขอื่นไม่มี

![แผ่นคีย์ลัดคีย์บอร์ดของ Word เอง: การทำงานอยู่ทางซ้าย คีย์ลัดอยู่ทางขวา แบ่งเป็นกลุ่มไฟล์ แก้ไข รูปแบบข้อความ รูปแบบย่อหน้า แทรก ตรวจทานและเครื่องมือ และมุมมอง](img/word-shortcuts.png)

- **`⌘O`, `⌘S` และ `⌘P` ถูกทำขึ้นแยกส่วนในแต่ละตัวแก้ไข** และพฤติกรรมก็ไม่เหมือนกันเป๊ะ `⌘P` ของ Word จัดหน้าตัวอย่างการพิมพ์ก่อน เพื่อให้กระดาษหนึ่งแผ่นเท่ากับหน้าจอหนึ่งหน้า `⌘P` ของ PDF เปิดกล่องโต้ตอบพิมพ์ PDF ส่วน Sheets และ Slides มีของตัวเองอีกชุด
- **ที่เหลือเป็นเรื่องของแต่ละแอป** เมื่อแท็บ Word ทำงานอยู่ `⌘B` คือตัวหนาของ Word เมื่อ Slides ทำงานอยู่ `⌘B` คือตัวหนาของ Slides และเมนูที่คีย์นี้อยู่ก็ไม่ใช่เมนูที่คุณคุ้นเคย ส่วนคีย์ที่ทำงานเฉพาะเมื่อมีการเลือกอยู่ หรือเฉพาะในบานหน้าต่างบางอัน จะเขียนไว้ในคอลัมน์การทำงาน

## ข้อตกลงทั่วไป

- คอลัมน์ macOS ใช้สัญลักษณ์ที่คุ้นเคย: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control
- คอลัมน์ Windows / Linux เขียนชื่อเต็ม: `Ctrl`, `Alt`, `Shift`
- ในกรณีที่ GenOffice ต้องใช้คีย์ต่างกันจริง ๆ ระหว่างสองแพลตฟอร์ม ตารางจะแสดงให้เห็น กรณีที่พบบ่อยคือ `⌃H` สำหรับค้นหาและแทนที่ (macOS ใช้ `⌘H` เป็นคำสั่งซ่อนหน้าต่าง), `⌥⌘G` สำหรับคำสั่งไปที่ และคีย์ปิดของ Slides
- คีย์ที่ใช้ได้เฉพาะเมื่อมีการเลือกอยู่จะเขียนไว้ในคอลัมน์การทำงานแทนที่จะเพิ่มคอลัมน์ใหม่ ตารางจึงกว้างสามคอลัมน์เสมอ

## Word

Word มีแถบเมนูเต็มรูปแบบ คีย์ไฟล์และรูปแบบด้านล่างจึงใช้ได้ตราบใดที่แท็บ Word มีโฟกัส ไม่ว่าจะเปิดเอกสารใดอยู่ ส่วนคีย์การแก้ไขต้องมีเอกสารที่โหลดแล้วและแก้ไขได้ และเครื่องหมายแทรกต้องอยู่ในข้อความ คีย์เหล่านั้นจะไม่ทำงานขณะที่คุณพิมพ์อยู่ในช่องค้นหา ช่องพิมพ์ AI หรือช่องรับข้อมูลอื่น ๆ

### ไฟล์

| การทำงาน     | macOS | Windows / Linux |
| ------------ | ----- | --------------- |

| หน้าต่างใหม่ | ⇧⌘N   | Ctrl+Shift+N    |

⌘P ไม่ใช่คำสั่งพิมพ์ของเบราว์เซอร์ Word จะจัดหน้าตัวอย่างการพิมพ์ก่อน เพื่อให้กระดาษหนึ่งแผ่นเท่ากับหน้าจอหนึ่งหน้าพอดี แล้วจึงเปิดกล่องโต้ตอบพิมพ์ของตัวเอง

## Sheets

GenOffice Sheets คือตารางที่เข้ากับได้กับ Excel คีย์ลัดส่วนใหญ่ด้านล่างคือคีย์ลัดของ Excel ที่คุณรู้จักอยู่แล้ว

> **การแก้ไขมาก่อน** คีย์ลัดเกือบทุกอันใน Sheets จะไม่มีผลระหว่างที่คุณกำลังแก้ไขเซลล์หรือพิมพ์อยู่ใน**แถบสูตร** เพื่อให้การพิมพ์ การเลื่อนเครื่องหมายแทรก และปุ่ม Backspace ยังคงความหมายเดิมของการแก้ไขข้อความ หากคีย์ใดดูเหมือนไม่มีอะไรเกิดขึ้น ให้ดูว่าคุณอยู่ระหว่างแก้ไขหรือไม่: กด Esc หรือ Enter ก่อน แล้วลองใหม่ คำสั่งที่ทำงานกับขอบเขตที่เลือกก็ไม่มีผลเช่นกันขณะที่กล่องโต้ตอบเปิดอยู่ คีย์ที่เป็นข้อยกเว้นของข้อกำหนดนี้จะเขียนไว้ในตาราง

มีข้อตกลงสองข้อที่เฉพาะ Sheets: `⌘` และ `⌃` ใช้ตำแหน่งปุ่มดัดแปลงเดียวกัน — ทั้งคู่ได้รับการยอมรับทุกแพลตฟอร์ม ดังนั้น `⌘1` และ `Ctrl+1` จึงเป็นคีย์เดียวกัน **ช่อง Windows / Linux ที่ว่างเปล่าหมายความว่าคีย์นั้นมีเฉพาะบน macOS**

## Slides

GenOffice Slides คือโปรแกรมนำเสนอแบบ PowerPoint คีย์ส่วนใหญ่ทำงานเหมือนกันทุกที่ แต่บางคีย์เปลี่ยนความหมายตามจุดโฟกัส — ภายในกล่องข้อความ หรือขณะที่**แถบภาพย่อ** **แถบโครงเรื่อง** หรือ**แถบเรียงสไลด์** มีโฟกัสคีย์บอร์ด กรณีเหล่านี้กำกับไว้ในคอลัมน์การทำงาน

| การทำงาน             | macOS | Windows / Linux |

การปิดแท็บเป็นจุดเดียวที่สองแพลตฟอร์มแยกกันอย่างสิ้นเชิง: ⌘W บน macOS และบน Windows กับ Linux คือ Ctrl+Q ซึ่งออกจากทั้งแอป ไม่ใช่แค่แท็บ

| ตัดสไลด์                                    | ⌘X                             | Ctrl+X                                         |

การใช้ปุ่มลูกศรเลื่อนระหว่างสไลด์เป็นข้อยกเว้น — ใช้ได้แม้บนแคนวาสและไม่ได้เลือกอะไรไว้เลย การลบสไลด์ไม่มีผลขณะที่เครื่องมือปากกาใช้งานอยู่ หรือใน**มุมมองการอ่าน**

### ภายในกล่องข้อความ

| การทำงาน                                             | macOS                               | Windows / Linux                         |
| ---------------------------------------------------- | ----------------------------------- | --------------------------------------- |
| เริ่มแก้ไขข้อความในรูปร่างข้อความที่เลือก            | อักขระที่พิมพ์ได้ใดก็ได้, ⏎ หรือ F2 | อักขระที่พิมพ์ได้ใดก็ได้, Enter หรือ F2 |
| บันทึกข้อความแล้วเลือกรูปร่างอีกครั้ง                | Esc หรือ F2                         | Esc หรือ F2                             |
| บันทึกข้อความแล้วเลือกรูปร่างอีกครั้ง (คีย์ลัดสำรอง) | ⌘⏎                                  | Ctrl+⏎                                  |
| ข้ามไปยังตัวแทนสถานถัดไป                             | ⌃⏎                                  | Ctrl+⏎                                  |
| ลด／เพิ่มระดับรายการ                                 | ⇥ / ⇧⇥                              | Tab / Shift+Tab                         |
| ไปยังเซลล์ตารางถัดไป／ก่อนหน้า                       | ⇥ / ⇧⇥                              | Tab / Shift+Tab                         |
| ขึ้นบรรทัดใหม่แบบอ่อน                                | ⇧⏎                                  | Shift+⏎                                 |

Tab มีสองความหมาย: เซลล์ถัดไปภายในตาราง และลดระดับรายการภายในรูปร่างข้อความ

### การแสดงสไลด์

| การทำงาน                | macOS             | Windows / Linux                      |
| ----------------------- | ----------------- | ------------------------------------ |
| เริ่มจากต้น             | F5                | F5                                   |
| เริ่มจากสไลด์ปัจจุบัน   | ⇧F5 หรือ ⌘⏎       | ⇧F5                                  |
| สไลด์ถัดไป              | → ↓ ␣ ⏎ Page Down | Right, Down, Space, Enter, Page Down |
| สไลด์ก่อนหน้า           | ← ↑ Page Up       | Left, Up, Page Up                    |
| สไลด์แรก                | Home              | Home                                 |
| สไลด์สุดท้าย            | End               | End                                  |
| ข้ามไปยังสไลด์หมายเลข N | พิมพ์ N แล้วกด ⏎  | พิมพ์ N แล้วกด Enter                 |
| จอดำ                    | B หรือ .          | B หรือ .                             |
| จอขาว                   | W หรือ ,          | W หรือ ,                             |
| ออกจากจอดำ              | ปุ่มใดก็ได้       | ปุ่มใดก็ได้                          |
| จบการแสดงสไลด์          | Esc               | Esc                                  |

การเริ่มจากสไลด์ปัจจุบันใช้ ⌘⏎ ได้ด้วยบน macOS เพิ่มจาก ⇧F5 บน Windows คีย์เดียวกันนี้ยังถูกสงวนไว้สำหรับการเลื่อนระหว่างตัวแทนสถาน

### มุมมองการอ่าน

| การทำงาน            | macOS             | Windows / Linux                      |
| ------------------- | ----------------- | ------------------------------------ |
| สไลด์ถัดไป          | → ↓ ␣ ⏎ Page Down | Right, Down, Space, Enter, Page Down |
| สไลด์ก่อนหน้า       | ← ↑ Page Up       | Left, Up, Page Up                    |
| ออกจากมุมมองการอ่าน | Esc               | Esc                                  |

กด **Esc** เพื่อออกจากสิ่งที่คุณอยู่ — การครอป รูปร่างที่กำลังวาด **การแก้ไขจุดยอด** กลุ่ม ปากกา ไฮไลต์ หรือยางลบ เครื่องเล่นสื่อ หรือ**มุมมองการอ่าน** — และเพื่อล้างการเลือก

อีกสองรายการเป็นปุ่มปรับมือที่ต้องกดค้าง ไม่ใช่คีย์ผสม: กด **Shift** ค้างขณะวาดเพื่อคงสัดส่วนของรูปร่างใหม่ และกด **Shift** ค้างขณะหมุนเพื่อให้ติดหมุดทุก 15°

## PDF

PDF ไม่มีเมนูของตัวเอง คีย์ทุกรายการด้านล่างจึงทำงานตามแท็บที่ใช้งานอยู่ และใช้ได้เฉพาะเมื่อแท็บ PDF อยู่หน้าสุด

### ไฟล์และการแก้ไข

| การทำงาน             | macOS | Windows / Linux |
| -------------------- | ----- | --------------- |
| บันทึก               | ⌘S    | Ctrl+S          |
| เลิกทำ               | ⌘Z    | Ctrl+Z          |
| ทำซ้ำ                | ⇧⌘Z   | Ctrl+Shift+Z    |
| ค้นหา (เปิดการค้นหา) | ⌘F    | Ctrl+F          |
| พิมพ์                | ⌘P    | Ctrl+P          |

คำสั่งเลิกทำและทำซ้ำเดินไปตามประวัติเอกสาร เมื่อเครื่องหมายแทรกอยู่ในช่องข้อความ คีย์เหล่านั้นจะปล่อยให้ ⌘Z เป็นของช่องนั้นแทน ส่วน ⌘P เปิดกล่องโต้ตอบพิมพ์ในแอปเดียวกับปุ่มพิมพ์บนแถบเครื่องมือ

### มุมมอง

| การทำงาน             | macOS        | Windows / Linux |
| -------------------- | ------------ | --------------- |
| ขยาย                 | ⌘=           | Ctrl+=          |
| ย่อ                  | ⌘-           | Ctrl+-          |
| พอดีกับความกว้างหน้า | ⌘0           | Ctrl+0          |
| ซูม (ต่อเนื่อง)      | ⌘ + ล้อเมาส์ | Ctrl + ล้อเมาส์ |

คำสั่งขยายยังตอบรับ ⌘+ และ Ctrl++ ด้วย

### การเลื่อนหน้า

| การทำงาน              | macOS               | Windows / Linux     |
| --------------------- | ------------------- | ------------------- |
| หน้าถัดไป             | →                   | →                   |
| หน้าก่อนหน้า          | ←                   | ←                   |
| เลื่อนลงหนึ่งหน้าจอ   | PageDown หรือ Space | PageDown หรือ Space |
| เลื่อนขึ้นหนึ่งหน้าจอ | PageUp              | PageUp              |
| เลื่อนลง              | ↓                   | ↓                   |
| เลื่อนขึ้น            | ↑                   | ↑                   |
| ข้ามไปหน้าแรก         | Home                | Home                |
| ข้ามไปหน้าสุดท้าย     | End                 | End                 |

คีย์เหล่านี้ไม่มีปุ่มปรับมือ จึงอ่านเหมือนกันทั้งสองแพลตฟอร์ม ↓ และ ↑ เป็นแถวเดียวที่เปลี่ยนตามจุดโฟกัส: ในเอกสารจะเลื่อนทีละนิด แต่เมื่อโฟกัสอยู่ที่แถบด้านข้างภาพย่อจะเลื่อนทีละหน้า และไม่มีผลขณะที่พิมพ์อยู่ในช่องรับข้อมูล

### การเลือกและการแก้ไข

| การทำงาน           | macOS                 | Windows / Linux       |
| ------------------ | --------------------- | --------------------- |
| ลบคำอธิบายที่เลือก | Delete หรือ Backspace | Delete หรือ Backspace |

ใช้งานได้เฉพาะเมื่อเลือกคำอธิบาย ตราประทับ ส่วนปิดบังข้อมูล หรือรูปภาพ

### การยกเลิกและกล่องโต้ตอบ

| การทำงาน                     | macOS  | Windows / Linux |
| ---------------------------- | ------ | --------------- |
| ยกเลิกสถานะชั้นบนสุด         | Escape | Escape          |
| ยืนยันกล่องโต้ตอบที่เปิดอยู่ | Enter  | Enter           |

Escape จะย้อนออกทีละชั้น — เริ่มจากกล่องโต้ตอบที่เปิดอยู่ จากนั้นแผงเลื่อนของ AI ข้อความร่าง แผงค้นหา และสุดท้ายคือการเลือกเอง เมื่อเครื่องหมายแทรกอยู่ในช่องค้นหา Enter และ ⇧Enter จะไปยังรายการที่ตรงกันถัดไปและก่อนหน้า ส่วน Escape จะปิดแผงนั้น เมื่อเครื่องหมายแทรกอยู่ในบันทึกข้อความใหม่ ⌘⏎ จะบันทึกข้อความนั้น
