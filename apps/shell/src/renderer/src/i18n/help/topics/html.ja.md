# HTML エディター

HTML エディターは .html／.htm を、2 つのモードで開きます。**プレビュー**（描画されたページ）と**ソース**です。

- **プレビュー**：実際に描画されます。相対パスのスタイルシートと画像は、ファイルの隣から読み込まれます。
- **プレビューインスペクター**：クリックで要素を選択し、ダブルクリックでその場で文字を編集し、ツールバーから削除し、選択した内容に対して AI に質問できます。
- **ソースモード**：HTML を編集します。ctrl+F で検索し、すべて置換すると書き直したマークアップを保存します。
- **保存**：バイト単位で忠実に保存します（BOM／CRLF／末尾の改行は保持）。変更がなければ書き直されません。
- **拡大縮小**：ctrl＋ホイール／ピンチでプレビューの比率を変えます。プレビュー内で ctrl+Z すると直前の編集を元に戻します。

## ツールバー

プレビュー内の要素をクリックすると、その上にツールバーが浮かびます。

![選択した要素の上に浮かぶツールバー](img/html-toolbar.png)

- **ファイルと履歴**：保存、名前を付けて保存、元に戻す、やり直し、検索。**自動保存**トグルが変更を定期的に書き込みます。
- **プレビュー／ソース**の切り替え。**全画面表示**でページを全画面に表示します。
- **書式**：太字、斜体、フォントサイズの増減。選択した要素の**スタイルパネル**（色など）。
- **挿入**：見出し、段落、表、画像（リンクを指定）、その他。
- **画像の操作**（画像を選択しているとき）：トリミング、**背景の削除**、差し替え、縦横比の固定。
- **要素の操作**（プレビューインスペクターで要素を選択しているとき）：削除、複製、上へ／下へ移動。
- **AI ボタン**：AI パネルを開きます。選択した要素についてそのまま質問できます。

## スケルトンを挿入

空のページなら **挿入 ▸ スケルトンを挿入** で、最小限の標準モードの文書が書き込まれます：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title></title>
  </head>
  <body></body>
</html>
```

どの部分にも理由があるため、これは入力するものではなく、コマンドになっています：

- **doctype** がないと、プレビューが quirks モードで動き、ボックスサイズや表のレイアウトが思われるのとは別の規則に従います。
- **`lang`** がないと、スクリーンリーダーがページを読む言語を持てず、ブラウザーは別の言語のフォントとスペルチェッカーを選んでしまいます。
- **charset** がないと、非ラテン文字のページが文字化けとしてデコードされることがあります。

ビューポートの meta は意図的にありません。デスクトップのペインで描画されるもので、モバイルのビューポートが影響する場所ではないからです。

`lang` はアプリの UI 言語に従うので、挿入されるスケルトンは手元のツールがすでに設定されているものになります。あとは自由に編集してください。

この項目は編集モードのときだけ、文書が空のときだけ表示されます。内容があれば、スケルトンを挿入する*対象*がなくなるからです。
