# Установка GenOffice

Каждая сборка опубликована на [странице релизов](https://github.com/genspark-ai/genoffice/releases/latest). Все они собраны из `main`; установщики для macOS и Windows подписаны.

## Выберите файл для своего компьютера

| Платформа                            | Требования                                            | Файл                    |
| ------------------------------------ | ----------------------------------------------------- | ----------------------- |
| **macOS** — Apple Silicon            | macOS 11+                                             | `.dmg` (arm64)          |
| **macOS** — Intel                    | macOS 11+                                             | `.dmg` (x64)            |
| **Windows** — большинство ПК         | Windows 10+, Intel/AMD                                | установщик `-x64.exe`   |
| **Windows** на Arm                   | Windows 11 на Arm (Snapdragon X и подобные)           | установщик `-arm64.exe` |
| **Linux** — Debian / Ubuntu          | x86_64, glibc 2.34+ (Ubuntu 22.04 или новее)          | `.deb`                  |
| **Linux** — Fedora / RHEL / openSUSE | x86_64, glibc 2.34+ (Fedora 35+, RHEL 9+, Leap 15.6+) | `.rpm`                  |
| **Linux** — всё остальное            | x86_64, glibc 2.34+, FUSE 2                           | `.AppImage`             |

Более старые версии остаются на странице релизов.

## В macOS

Откройте `.dmg` и перетащите **GenOffice** в «Программы». В сборке для Intel первый запуск попросит подтвердить открытие: щёлкните по приложению в «Программах» правой кнопкой ▸ «Открыть». Это Gatekeeper столкнулся с образом диска, который выглядит неподписанным, а не повреждённая загрузка.

## В Windows

Запустите установщик `.exe`. Он помещает GenOffice в меню «Пуск» и регистрирует `.docx`, `.xlsx`, `.pptx`, `.pdf` и подобные форматы как приложения по умолчанию, так что двойной щелчок по файлу открывает его в GenOffice.

## В Linux

**Debian / Ubuntu**

```sh
sudo apt install ./genoffice_<version>_amd64.deb
```

**Fedora / RHEL / openSUSE**

```sh
sudo dnf install ./genoffice-<version>.x86_64.rpm     # Fedora / RHEL family
sudo zypper install ./genoffice-<version>.x86_64.rpm  # openSUSE
```

**AppImage** — запускается оттуда, где лежит, без шага установки:

```sh
chmod +x GenOffice-<version>.AppImage
./GenOffice-<version>.AppImage
```

Ему нужна среда выполнения FUSE 2. Если ставить её не хочется, запустите его с `--appimage-extract-and-run` — и песочница будет работать из распакованного каталога.

## Сборка, которую вы запускаете

**Настройки ▸ О программе** — место, где приложение сообщает, какая у вас сборка, за каким каналом оно следит и где находится проект. Когда на этом канале выходит новая сборка, та же панель предлагает обновление; установка через Flatpak, Nix или Docker этого не делает, потому что её заменяет инструмент, который её туда поставил.

## Ещё три пути

Все три оборачивают уже опубликованные файлы, а не пересобирают приложение, поэтому следуют за официальными бинарными сборками.

- **Flatpak** — ставит `.deb` через механизм `extra-data` во Flatpak и запускает его под Zypak, который подстраивает собственную песочницу Electron. Дерево `/app` доступно только для чтения, поэтому обновления идут через Flatpak, а не через диалог обновления в приложении.
- **Nix** — выражение пакета, которое собирается из локальной копии репозитория командой `nix-build packaging/nix`; см. `packaging/nix`.
- **Docker** — образ для пакетной конвертации без интерфейса (`packaging/docker`). Он переводит в PDF целое дерево документов Office, Markdown и HTML через собственный конвейер экспорта приложения, поэтому результат совпадает с тем, что дал бы Файл ▸ Экспортировать. Это утилита командной строки, а не сервер.

## Командная строка идёт в комплекте

Каждая установка включает команду `genoffice`, которая работает через те же движки, что и окно, поэтому они никогда не расходятся во мнении о файле. В macOS и Windows она лежит внутри пакета приложения; `genoffice install-cli` помещает её в ваш `PATH`. Что она умеет — см. **Командная строка и агенты**.
