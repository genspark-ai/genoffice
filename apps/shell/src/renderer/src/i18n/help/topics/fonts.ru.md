# Шрифты: системные и загружаемые семейства

## Списки шрифтов

Управление шрифтом находится на вкладке Главная каждого редактора (ниже — группа шрифтов в Slides):

![Группа шрифтов на ленте Slides](img/fonts.png)

Выбор шрифта в каждом редакторе объединяет: установленные локально шрифты и обычные для платформы кандидаты (типичные семейства Windows и macOS, западные и CJK, включая локализованные имена, которые CJK-шрифты сообщают в своих системах). Когда система умеет перечислить локальные шрифты, список группируется по тому, что действительно есть; иначе он сводится к полному списку кандидатов.

## Загружаемые шрифты (Slides)

- Выбор шрифта в Slides открывает **каталог шрифтов**: подобранную коллекцию OFL, охватывающую много письменностей; в каждом семействе есть обычное и полужирное начертание.
- Выбор шрифта скачивает его с CDN и устанавливает (с фиксированной контрольной суммой) в хранилище шрифтов приложения — он доступен всем последующим документам, без установки на уровне системы.
- Установленные шрифты лежат в закрытом для других приложений каталоге и исчезают вместе с приложением.

## Типографика CJK

- CJK-шрифты в Docs получают сжатие знаков препинания и правила переноса кинсоку, согласованные с Word (см. главу про Docs).
- CJK-семейства в каталоге охватывают упрощённый и традиционный китайский, японский и корейский, с засечками и без.

## Управление локальными шрифтами

- Пункт install-local-font-files загружает файлы .ttf/.otf с диска в хранилище шрифтов приложения.
- Хранилище архивирует шрифты по семействам; несколько начертаний одного семейства могут сосуществовать.
