# Docs：文書処理

Docs は Microsoft Word と高い互換性を持つ本格的な文書処理エディターです。標準の `.docx` ファイルを直接読み書きし、画面上で見たままの改ページ・表の分割・ヘッダーとフッターが印刷や PDF 書き出しでもそのまま再現される WYSIWYG 組版エンジンを備えています。

## リボン

タブは **ホーム／挿入／描画／レイアウト／デザイン／参考資料／校閲／表示** で、選択中のオブジェクトに応じてコンテキストタブ（表の形式とレイアウト、画像、ヘッダーとフッターなど）が加わります。 Docs のコマンド帯には独自の密度があります：**コンパクト**（⌥⌘K / Ctrl+Alt+K）はアイコンのみを残しラベルを消して縦方向の作業領域を広げます。選択は次回起動時にも記憶されます。

- **ホーム**：クリップボードと書式のコピー、フォント（中日韓の伝統的な文字サイズや圏点・強調線を含む）に **すべての書式をクリア** と **編集記号の表示/非表示** の切り替え、段落（配置／インデント／行間／箇条書き）に **新しい行頭文字の定義／新しい番号書式の定義／アウトライン**（独自のリスト形式をドキュメントに保存）、スタイル（見出し 1-6／標準／引用文。すべてカスタマイズ可能）と全リストを表示する **スタイル ウィンドウ**。 スタイルでは東アジアフォントと欧文フォントを別々に指定できます（例：日本語・中国語フォントに Times New Roman を組み合わせる）。このペア設定は `.docx` の保存と Word との往復でも完全に保たれます。
- **挿入**：改ページ／セクション区切り、表（行 × 列のグリッド、または正確なサイズと列幅モードを指定できる **表の挿入…**）、画像、図形、テキストボックス、プリセットギャラリーからの **表紙** と **空白のページ**、**グラフ**、**ドロップ キャップ**、**ワードアート**、動的フィールド（日付、時刻、ページ番号、総ページ数、ファイル名）、ハイパーリンク、**ブックマーク** と相互参照、コメント、セクションごとのヘッダーとフッターとページ番号、特殊記号と数式。
  - **グラフ** は単なる静止画像ではなく、独自の数値データテーブルを内包した本物のグラフ オブジェクト（棒・折れ線・円など）を挿入します。GenOffice でも Word の _データの編集_ でも、いつでも背後の数値を編集してグラフを再描画できます。
- **描画**：ページ上への自由な手書きインク描画は、**描画ツール** グループで行います — **選択** で通常のテキスト編集に戻り、続いて **ペン**、**蛍光ペン**、**消しゴム**（ワンクリックまたはなぞるだけでストローク全体がきれいに消えます）。その横の **ペンのスタイル**／**蛍光ペンのスタイル** は、カラーパレットと太さの一覧をまとめた 1 つのコントロールで、ラベルは現在有効なツールに追従します。インクはテキストの上に浮いた標準注釈としてドキュメントに保存されるため、保存して開き直してもそのまま残り、隣のグループの **すべてクリア** でページ上の手書きを一括削除できます。
- **レイアウト**：ページ余白、用紙の向き（縦／横）と標準用紙サイズ、単段・多段の段組み、段落のインデントと段落前後の間隔を精密に設定します。
- **デザイン**：文書全体のテーマ、配色セット、斜め文字や画像の透かし（ウォーターマーク）、ページ全体を囲むページ罫線を構成します。
- **参考資料**：クリックで移動できページ番号も随時更新できる自動目次、脚注／文末脚注、図表番号キャプション、見出しやブックマークへの動的な相互参照を挿入します。

  ![参考資料タブ](img/docs-references.png)

- **校閲**：**エディター** はドキュメント全体のスペル、文法、句読点を一括で校閲します。多言語への**翻訳**、スペルチェック、コメント（**AI でコメント処理** を使うと、未解決のレビューコメントを AI が読み取って本文の修正まで進めます）、変更履歴の記録（すべての変更履歴／シンプルな変更履歴の表示切り替え、個別の承諾／元に戻す）、変更点を自然言語でまとめる **AI で変更履歴を要約**、リアルタイムの文字カウント、別のファイルとの差分 **比較**、および編集を制限する **文書の保護** を備えています。
- **表示**：ファイルを見る方法は 5 つ — **印刷レイアウト**、**Web レイアウト**、**アウトライン**、**閲覧モード**、**ページ プレビュー**。縮小／拡大／100 %／ページ幅を基準に表示／1 ページ全体表示、右側の **AI パネル**、**ダーク モード**、ルーラー、グリッド線、左側のナビゲーション ウィンドウ、**新しいタブ**、上下画面**分割**、**タブの切り替え**、および全ショートカットをライブ検索できる **キーボードショートカット**（⌘/ または Ctrl+/）のダイアログ。
- **スタイル未設定文書のアウトライン自動推定**：契約書や古いインポート文書など、正式な「見出し 1／2」スタイルが使われておらず、短い太字の行や全大文字の行、ローマ数字・算用数字の番号付き短文（例：`I. BACKGROUND` や `1. 業務範囲`）で章節を区切っている文書では、Docs が元のファイルを 1 バイトも書き換えることなく見出し構造を自動的に推定し、ナビゲーション ウィンドウのアウトラインツリーやアウトライン表示に控えめな「推定」マーカー付きで一覧表示してクリック移動できるようにします。推定された行に正式な見出しスタイルを適用すると、その場で本物の見出しに昇格します。
  - **ダーク モード** は編集中のページ面とその周囲のキャンバスだけを落ち着いた暗色にし、上部のリボンは通常のテーマのまま維持します — Word と同じ「暗い編集キャンバスとウィンドウテーマの分離」であり、印刷や PDF 書き出し時の実際の文字色や紙面の色が勝手に書き換わることはありません。この選択は記憶され、アプリの全体テーマより優先されます。
  - **分割** は現在の編集画面のすぐ下に、独立してスクロールできる 2 つめのペインを開き、同じ文書の離れた 2 か所を同時に見比べながら編集できるようにします。境界線の縁にある × ボタンでいつでも閉じられます。

## ナビゲーション ウィンドウ

**表示 ▸ ナビゲーション ウィンドウ**を開くと、文書の見出しのアウトライン、文書全体を対象とする検索ボックス、ページごとのサムネイルを収めたサイドペインが開きます。開いているかどうかは起動のたびに記憶されるので、アウトラインで移動する文書は移動しやすいまま引き継がれます。

**アウトライン**は見出しのツリーです。アウトラインの見出しを右クリックすると、折りたためるだけでなく構成も変えられます。

- 見出しで **折りたたむ／展開** を選ぶと、その見出しのサブツリー全体が折りたたまります。章は消えますが、本文のテキストは文書に残ります。
- **すべて折りたたむ／すべて展開** は、一度にツリー全体を折りたためたり広げたりします。長いレポートではこれが、読みやすいアウトラインと文字の壁との違いになります。
- **見出しレベルの表示**は、必要な深さだけにツリーを絞り込むので、_見出し 1 を表示_ にすれば実際に目を通せる目次の一覧が残ります。
- **レベル上げ／レベル下げ**は見出しのレベルを変え、その下にあるすべての見出しが受け継ぐレベルも一緒に変えます。章が節になるのと同じ仕組みです。
- **前に新しい見出し／後に新しい見出し**は、ペインを離れずにカーソル位置に見出しを 1 つ挿入します。
- **削除**は見出しと*その下にあるものをすべて*取り除きます。ここだけは注意が必要です。行の削除ではなく、サブツリー全体の削除です。
- **見出しと内容を選択**は見出しからサブツリーの終わりまでを選ぶので、節全体をまとめて編集できます。

## 右クリックメニュー

本文のどこかで右クリックすると、メニューはクリックした対象に応じて変わります。主なグループは次のとおりです。

- **クリップボード**：切り取り／コピー／貼り付け／**書式なしで貼り付け**。
- **フォント、段落**：リボンに移動しなくても、フォントとサイズ、太字／斜体／下線、配置／インデント／行間を変更します。
- **類義語**：選択した語の類義語を一覧表示します。クリックすると置き換わります。
- **翻訳**（AI）：選択した文字列を対象言語（英語、簡体字中国語、日本語、韓国語、フランス語、ドイツ語、スペイン語など）に、AI パネル経由で翻訳します。
- **新しいコメント**：選択範囲にコメントを付けます。
- **文章校正**（綴りの誤った語の上）：候補の置換、すべて無視、辞書に追加、校正用の言語を設定。
- **ハイパーリンク**：開く／編集／リンクをコピー／ハイパーリンクを削除。
- **画像**：画像の表示、名前を付けて保存、**文字列の折り返し**（行を揃える／左右に回り込む／上下に回り込む／文字の背面／文字の前面）、重ねる順序の変更。
- **フィールド**（目次、ページ番号など）：フィールド更新／フィールドコードの表示切り替え／フィールドの編集。
- **段落番号**（リスト内）：番号を振り直す／番号を継続する／リストレベルの変更／番号の値を設定。
- **表**（カーソルが表の中）：行／列の挿入、セルの結合／分割、表の分割、セルに合わせて列数を変更、セル内の配置、行／列の幅を均等にする、表のプロパティ、削除メニュー、選択。

## 編集

- 検索と置換（ctrl+F／ctrl+H）：大文字と小文字を区別する、完全一致のみ、正規表現に対応します。
- 書式のコピー、多段階の元に戻す／やり直し、貼り付けのオプション。
- 表：セルの結合／分割、行／列の操作、罫線と網かけ、並べ替え、数式。 行は必要に応じてページをまたいで分割され、セル内で Ctrl+Enter を押すとその位置で改ページされます — 印刷と PDF も同じ結果になります。
- 画像：文字列の折り返し、トリミング、圧縮、描画キャンバス。

## 中日韓の組版

- 約物圧縮と行頭行尾の禁則は Word と揃っています。全角／半角の変換も可能です。
- フォント候補は、Windows と macOS の一般的な中日韓のファミリー名をカバーしています。

## AI

- リボンの AI ボタンとサイドパネル：書き換え、書き足し、翻訳、要約、表の挿入のプリセットに加えて、自由な指示も渡せます。
- AI の変更は毎回スナップショットを撮ります。バージョン一覧から巻き戻せます。巻き戻し自体も元に戻せます。

## 保存と書き出し

- **変更段落のみを書き換える高忠実な `.docx` 保存**：保存時には実際に編集した段落の XML だけを書き直すため、触っていない段落・複雑なフィールド・既存の構造はバイト単位で元のファイルと完全に同一のまま保たれ、他人の文書のレイアウトを崩す心配がありません。
- **PDF とページ画像への書き出し**：現在の画面上の改ページ結果そのままに標準 PDF ファイルへ書き出せるほか、各ページを個別の高解像度 PNG 画像として書き出すこともできます。
- **印刷プレビューはカーソルのあるページから開始**：何十ページもある長い文書の途中を編集しているときに `⌘P`／`Ctrl+P`（または「ファイル ▸ 印刷」）で印刷プレビューを開くと、毎回 1 ページ目に戻るのではなく、現在テキストカーソルが置かれているそのページが最初から直接表示されるため、その場の組版結果をすぐに確認できます。

## 印刷

`⌘P`／`Ctrl+P` で内蔵の WYSIWYG 改ページ印刷プレビューを開き、用紙サイズやページ範囲を確認したうえでシステムの印刷ダイアログへ送ります。
