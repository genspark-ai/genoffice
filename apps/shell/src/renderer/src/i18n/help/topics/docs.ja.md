# Docs：文書処理

Docs は Word に似た文書処理ソフトです。本物の .docx を読み書きし、改ページも所见即所得で行います。

## リボン

タブは **ホーム／挿入／描画／レイアウト／デザイン／参考資料／校閲／表示** で、選択中のオブジェクトに応じてコンテキストタブ（表の形式とレイアウト、画像、ヘッダーとフッターなど）が加わります。

- **ホーム**：クリップボード、フォント（中日韓の文字サイズや圏点を含む）に **すべての書式をクリア** と **編集記号の表示/非表示** の切り替え、段落（配置／インデント／行間／箇条書き）に **新しい行頭文字の定義／新しい番号書式の定義／アウトライン**（自分のリスト形式をドキュメントに保存）、スタイル（見出し 1-6／標準／引用文。変更できます）と全リストを表示する **スタイル ウィンドウ**。
- **挿入**：改ページ／セクション区切り、表（行 × 列のグリッド、または正確なサイズ指定には **表の挿入…**）、画像、図形、テキストボックス、プリセットギャラリーからの **表紙** と **空白のページ**、**グラフ**、**ドロップ キャップ**、**ワードアート**、フィールド（日付、時刻、ページ番号、総ページ数、ファイル名）、ハイパーリンク、**ブックマーク** と相互参照、コメント、ヘッダーとフッターとページ番号、記号と数式。
  - **グラフ** は画像ではなく、実際のグラフ オブジェクトを挿入します。棒・折れ線・円いずれかのデータを持ち、Word の _データの編集_ でその裏の数値が開きます。
- **描画**：ページ上へのインク描画は、**描画ツール** グループで行います — **選択** でテキスト編集に戻り、続いて **ペン**、**蛍光ペン**、**消しゴム**（ワンクリックまたはなぞると線全体が消えます）。その横の **ペンのスタイル**／**蛍光ペンのスタイル** は、色のスウォッチと太さの一覧をまとめた 1 つのコントロールで、ラベルは有効なツールに従います。インクはテキストの上に浮いた注釈としてドキュメントに保存されるため、保存して開き直しても残り、次のグループの **すべてクリア** でまとめて削除できます。
- **レイアウト**：余白、印刷の向きとサイズ、段組み、段落のインデントと行間。
- **デザイン**：テーマ、配色、透かし、ページの罫線。
- **参考資料**：目次（更新できます）、脚注／文末脚注、図表番号、相互参照。

  ![参考資料タブ](img/docs-references.png)

- **校閲**：**エディター** はドキュメント全体のスペル、文法、句読点を校閲します。**翻訳**、スペルチェック、コメント（**AI でコメント処理** は未解決のコメントを処理します）、変更履歴（すべての変更履歴／シンプルな変更履歴の表示、承諾／元に戻す）、**AI で変更履歴を要約**、文字カウント、別のファイルとの **比較**、**文書の保護**。
- **表示**：ファイルを見る方法は 5 つ — **印刷レイアウト**、**Web レイアウト**、**アウトライン**、**閲覧モード**、**ページ プレビュー**。縮小／拡大／100 %／ページ幅を基準に表示／1 ページ、**AI パネル**、**ダーク モード**、ルーラー、グリッド線、ナビゲーション ウィンドウ、**新しいタブ**、**分割**、**タブの切り替え**、および検索できる **キーボードショートカット** のダイアログ。
  - **ダーク モード** はページとその周囲のキャンバスを暗くしますが、リボンは決して暗くしません — Word の、暗い編集画面と暗いウィンドウを分ける考え方です。この選択は記憶され、どの場合でもアプリのテーマより優先されます。
  - **分割** は下部に独立してスクロールし、最初のパネルを鏡のように映す 2 つめのパネルを開きます。パネルの縁の × で閉じられます。

## ナビゲーション ウィンドウ

**表示 ▸ ナビゲーション ウィンドウ**を開くと、文書の見出しのアウトライン、文書全体を対象とする検索ボックス、ページごとのサムネイルを収めたサイドペインが開きます。開いているかどうかは起動のたびに記憶されるので、アウトラインで移動する文書は移動しやすいまま引き継がれます。

**アウトライン**は見出しのツリーです。アウトラインの見出しを右クリックすると、折りたためるだけでなく構成も変えられます。

- 見出しで **折りたたむ／展開** を選ぶと、その見出しのサブツリー全体が折りたたまります。章は消えますが、本文のテキストは文書に残ります。
- **すべて折りたたむ／すべて展開** は、一度にツリー全体を折りたためたり広げたりします。長いレポートではこれが、読みやすいアウトラインと文字の壁との違いになります。
- **見出しレベルの表示**は、必要な深さだけにツリーを絞り込むので、_見出し 1 を表示_ にすれば実際に目を通せる目次の一覧が残ります。
- **レベル上げ／レベル下げ**は見出しのレベルを変え、その下にあるすべての見出しが受け継ぐレベルも一緒に変えます。章が節になるのと同じ仕組みです。
- **前に新しい見出し／後に新しい見出し**は、ペインを離れずにカーソル位置に見出しを 1 つ挿入します。
- **削除**は見出しと*その下にあるものをすべて*取り除きます。ここだけは注意が必要です。行の削除ではなく、サブツリー全体の削除です。
- **見出しと内容を選択**は見出しからサブツリーの終わりまでを選ぶので、節全体をまとめて編集できます。

## 右クリックメニュー

本文のどこかで右クリックすると、メニューはクリックした対象に応じて変わります。主なグループは次のとおりです。

- **クリップボード**：切り取り／コピー／貼り付け／**書式なしで貼り付け**。
- **フォント、段落**：リボンに移動しなくても、フォントとサイズ、太字／斜体／下線、配置／インデント／行間を変更します。
- **類義語**：選択した語の類義語を一覧表示します。クリックすると置き換わります。
- **翻訳**（AI）：選択した文字列を対象言語（英語、簡体字中国語、日本語、韓国語、フランス語、ドイツ語、スペイン語など）に、AI パネル経由で翻訳します。
- **新しいコメント**：選択範囲にコメントを付けます。
- **文章校正**（綴りの誤った語の上）：候補の置換、すべて無視、辞書に追加、校正用の言語を設定。
- **ハイパーリンク**：開く／編集／リンクをコピー／ハイパーリンクを削除。
- **画像**：画像の表示、名前を付けて保存、**文字列の折り返し**（行を揃える／左右に回り込む／上下に回り込む／文字の背面／文字の前面）、重ねる順序の変更。
- **フィールド**（目次、ページ番号など）：フィールド更新／フィールドコードの表示切り替え／フィールドの編集。
- **段落番号**（リスト内）：番号を振り直す／番号を継続する／リストレベルの変更／番号の値を設定。
- **表**（カーソルが表の中）：行／列の挿入、セルの結合／分割、表の分割、セルに合わせて列数を変更、セル内の配置、行／列の幅を均等にする、表のプロパティ、削除メニュー、選択。

## 編集

- 検索と置換（ctrl+F／ctrl+H）：大文字と小文字を区別する、完全一致のみ、正規表現に対応します。
- 書式のコピー、多段階の元に戻す／やり直し、貼り付けのオプション。
- 表：セルの結合／分割、行／列の操作、罫線と網かけ、並べ替え、数式。
- 画像：文字列の折り返し、トリミング、圧縮、描画キャンバス。

## 中日韓の組版

- 約物圧縮と行頭行尾の禁則は Word と揃っています。全角／半角の変換も可能です。
- フォント候補は、Windows と macOS の一般的な中日韓のファミリー名をカバーしています。

## AI

- リボンの AI ボタンとサイドパネル：書き換え、書き足し、翻訳、要約、表の挿入のプリセットに加えて、自由な指示も渡せます。
- AI の変更は毎回スナップショットを撮ります。バージョン一覧から巻き戻せます。巻き戻し自体も元に戻せます。

## 保存と書き出し

- .docx として保存します。変更した段落だけを書き直すので、触っていない部分はバイト単位で同一のままです。
- PDF（現在の改ページどおし）と、ページごとの画像に書き出せます。

## 印刷

ctrl+P でシステムのダイアログを開き、所见即所得のページで印刷します。
