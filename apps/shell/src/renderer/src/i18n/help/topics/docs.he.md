# Docs: עיבוד תמלילים

‏Docs הוא מעבד התמלילים דמוי Word: קורא וכותב .docx אמיתי עם פיגול WYSIWYG אמיתי.

## סרגל הכלים

כרטיסיות: **בית / הוספה / פריסה / עיצוב / הפניות / סקירה / תצוגה**, ובנוסף כרטיסיות הקשר לפי האובייקט שנבחר (עיצוב טבלה, תמונות).

- **בית**: לוח; גופן (כולל גודלי CJK וסימני הדגשה); פסקה (יישור/כניסה/רווח/רשימות); סגנונות (כותרת 1-6/רגיל/ציטוט, ניתנים לשינוי).
- **הוספה**: מעברי עמוד/מקטע, טבלאות (כולל טבלאות מהירות), תמונות, צורות, קישורים, כותרת עליונה ותחתונה, מספרי עמודים, תאריך, תיבות טקסט.
- **פריסה**: שוליים, כיוון וגודל הנייר, טורים, כניסות ורווחים של פסקה.
- **עיצוב**: ערכות נושא, ערכות צבעים, סימן מים, מסגרת עמוד.
- **הפניות**: תוכן העניינים (ניתן לעדכון), הערות שוליים/אחריות, כיתובים, הפניות צולבות.

  ![כרטיסיית הפניות](img/docs-references.png)

- **סקירה**: בדיקת איות, הערות, מעקב שינויים (תצוגות All/Simple markup), ספירת מילים.
- **תצוגה**: סרגל, קווי רשת, חלונית ניווט, זום, ו**תיבת הדיאלוג הניתנת לחיפוש של קיצורי המקלדת**.

## תפריט הקשר

לחצו פעמיים עם הכפתור הימני בכל מקום בגוף המסמך — התפריט מותאם למה שלחצתם עליו. קבוצות עיקריות:

- **לוח**: גזור / העתק / הדבק / **הדבק כטקסט רגיל**.
- **גופן, פסקה**: שינוי משפחת וגודל הגופן, מודגש/נטוי/קו תחתון, יישור/כניסה/רווח בלי להיכנס לסרגל הכלים.
- **מילים נרדפות**: מציג מילים נרדפות למילה שנבחרה; לחצו על אחת כדי להחליף.
- **תרגום** (AI): מתרגם את הבחירה לשפת היעד (אנגלית, סינית פשוטה, יפנית, קוריאנית, צרפתית, גרמנית, ספרדית, ...) דרך חלונית ה-AI.
- **הערה חדשה**: מצרפת הערה לבחירה.
- **איות** (על מילה שכתובה שגוי): הצעות להחלפה, התעלם מהכול, הוספה למילון, הגדרת שפת ההגהה.
- **קישור**: פתיחה / עריכה / העתקת הקישור / הסרת הקישור.
- **תמונה**: הצגת התמונה, שמירת התמונה בשם, **גלישת טקסט** (בתוך השורה / ריבוע משמאל ומימין / למעלה ולמטה / מאחורי הטקסט / לפני הטקסט), סדר הסידור.
- **שדות** (תוכן העניינים, מספרי עמודים): עדכון שדה / הצגת קודי שדה / עריכת השדה.
- **מספור רשימה** (בתוך רשימה): התחלת מספור מחדש / המשך המספור / שינוי רמת הרשימה / קביעת ערך המספור.
- **טבלה** (הסמן בתוך טבלה): הוספת שורות/עמודות, מיזוג / פיצול תאים, פיצול הטבלה, התאמה אוטומטית, יישור תאים, פיזור שורות/עמודות, מאפייני טבלה, תפריט המחיקה, בחירה.

## עריכה

- חיפוש והחלפה (ctrl+F / ctrl+H): רגיש לאותיות גדולות וקטנות, התאמה מילה שלמה, ביטוי רגול.
- משחל עיצוב; ביטול/ביצוע עמוק; אפשרויות הדבקה.
- טבלאות: מיזוג/פיצול תאים, פעולות שורות ועמודות, מסגרות וריצוף, מיון, נוסחאות.
- תמונות: גלישת טקסט, חיתוך, דחיסה; משטחת ציור.

## טיפוגרפיית CJK

- דחיסת סימני פיסוק וכללי שבירת שורה (kinsoku) תואמים ל-Word; המרה בין רוחב מלא לחצי רוחב.
- מועמדי הגופן מכסים את שמות משפחות ה-CJK הנפוצים ב-Windows וב-macOS.

## AI

- כפתור ה-AI בסרגל הכלים והחלונית בצד: ניסוח מחדש, הרחבה, תרגום, סיכום, תבניות להוספת טבלה, וכן הוראות חופשיות.
- כל סבב AI יוצר תמונת מצב לפני; אפשר לחזור אחורה מרשימת הגרסאות, וגם החזרה עצמה ניתנת לביטול.

## שמירה וייצוא

- שמירת .docx כותבת מחדש רק את הפסקאות שהשתנו — תוכן שלא נגעו בו נשאר זהה בבת אחת.
- ייצוא ל-PDF (לפי הפיגול) ולתמונות ברמת העמוד.

## הדפסה

‏ctrl+P דרך הדיאלוג של המערכת, עמודים ב-WYSIWYG.
