# AI 助手面板

在 GenOffice 的所有六个编辑器里，你都可以随时唤出内置的 AI 助手面板：只需在画布上框选一段文字、一片表格或一个网页元素，用平常说话的方式交代任务，就能看着 AI 实时流式输出分析并直接帮你把修改落到文档里。

## 如何唤起与日常对话流

![Docs 中的 AI 面板](img/ai-panel.png)

- **三种顺手的唤起入口**：你既可以随时点击任意编辑器顶部功能区右侧醒目的 **AI 按钮**展开侧边栏，也可以在正文或表格中选中一段内容后点击鼠标右键选择**问 AI**，或者在 PDF 与 HTML 选中内容后浮出的快捷条上直接点 **Ask AI（问 AI）**。
- **用自然语言直接交代任务**：在面板底部的输入框里用大白话写下你想做的事（比如「把这段会议纪要改写成正式的立项通知」「给右边加一列算出每个人的销售额占比」「把这一页 PPT 重新排成左右对比卡片」），按下回车键（`Enter`）即可发送。
- **流式输出与自动调用文档工具**：AI 的思考与回复会以**实时流式（Streaming）**方式逐字呈现；当任务需要读取文档上下文、搜索知识库或直接动手修改段落、单元格和幻灯片时，助手会自动在后台依序调用对应的文档操作工具并继续往下推进，直到把整套任务妥善做完。
- **随时一键喊停**：如果看到一半发现方向不对或者已经拿到了想要的信息，随时点击输入框旁边的**停止**按钮（或按 `Esc` 键）即可立即中断当前这一轮生成。
- **边跑边发的指令排队队列**：当 AI 正在流式输出或忙着执行上一轮长任务时，你完全不需要干等着它跑完——直接在输入框里继续敲入你的下一条补充指令并按回车（`Enter`），新指令不会被丢弃也不会打断当前轮，而是会自动进入**待发队列**。此时输入框正上方会浮现一条队列状态条，显示当前有几条消息在排队；点开状态条，你随时可以修改排队中的消息文字、删掉某条、拖拽调整发送先后顺序、暂停自动发送或一键清空队列。只要上一轮回答一结束，队列里的下一条指令就会自动接力发出；而按下 `Esc` 键则依然是终止当前正在运行的这一轮。

## AI 助手在各个编辑器里都能做什么

- **Docs 文字处理**：润色改写文风、扩写章节篇幅、多语种精准翻译、提炼长文摘要、根据文字描述自动生成并插入结构化表格或配图，以及批量调整各级标题与正文排版格式；而且每一轮动手修改文档前都会自动留存一份版本快照。
- **Sheets 电子表格**：根据自然语言编写复杂的嵌套函数与正则公式、按规律自动填充或清洗脏数据、批量改写单元格文本，以及自动设置条件格式、边框与数字显示样式。
- **Slides 演示文稿**：根据一句话主题或大纲从零生成整套多页演示文稿、对现有幻灯片重新调整图文版式布局、精简或扩写页面上的演讲文案。
- **PDF 文档**：针对你用鼠标划选的某一段专业术语、外文段落或整页财报合同进行深度问答、多语种翻译与核心要点总结。
- **Markdown 与 HTML 编辑器**：对技术文档或网页文案进行润色改写、顺着上下文续写新章节、多语种翻译，或针对预览检查器选中的网页 DOM 组件直接修改样式与结构。
- **跨文档个人知识库问答（主页 ▸ AI 问答）**：自动从你标了星标（收藏）的所有本地文档里检索事实依据并给出带有出处引用的回答——该功能在「主屏（Home）」一章中有专门介绍，而且你在 **Docs 文字编辑器**里打开右侧 AI 面板时，同样可以直接调用这项跨文件知识库技能来边查资料边写报告。

## 版本回滚与编辑安全边界

- **Docs 持久化版本快照列表**：在 Docs 文字编辑器的 AI 面板顶部设有一个**版本列表**——AI 每动手修改一次文档，系统都会先自动拍下一张完整快照；你随时可以从列表里挑中之前的任意一轮一键回滚过去，而且「回滚」这个动作本身也支持按 `⌘Z` / `Ctrl+Z` 撤销。更贴心的是，这些快照会持久化保存，哪怕你关掉文档明天再重新打开，之前的 AI 修改快照依然在列表里随时可退。
- **与手动编辑完全一致的安全管线**：AI 对文档、表格或幻灯片做出的任何修改，走的全都是和你自己敲键盘一模一样的标准编辑管线——每一步都支持常规撤销（`⌘Z` / `Ctrl+Z`），并且都受文档保存机制管辖，绝不会绕过你的确认在后台悄悄篡改磁盘上的原文件。

## 把敏感选区对 AI 隐藏（隐私占位符）

- **给机密内容戴上「隐形面具」**：在 **Slides、HTML 和 Markdown** 编辑器里，如果文档中某几处包含不想发给云端大模型的客户真名、未公开财务数字或内部密钥，你可以先选中那段内容，点击鼠标右键选择**把选中的内容对 AI 隐藏**，然后为它起一个好认的占位符名称（如 `客户甲` 或 `核心营收`）——设置完毕后，AI 助手在读取文档时读到的就只是 `{{客户甲}}` 这样的无害占位符，而看不到背后的真实文字。（在 Markdown 编辑器中，需先点亮顶部工具条上的「闭眼」隐私开关来启用该右键菜单项；在 HTML 编辑器中，该右键入口位于源码编辑面板内。）
- **完全不影响真实文件、打印与导出**：隐藏标记只作用于发往 AI 模型的上下文视图，而你文档底层依然完整保留着真实的原始文字——因此无论是平时在屏幕上阅读、按下保存落盘、导出为 PDF/Word，还是连接打印机打出来，看到的都是百分之百完整的真实内容；保存关闭后再重新打开文档，之前设好的隐藏保护标记也依然稳稳保留。想解除隐藏时，只需再次右键点击同一个菜单项即可（Markdown 编辑器里会清晰显示为**把选中的内容重新对 AI 显示**）。
- **HTML 支持全方位语法级隐藏**：在 HTML 源码模式下，你不仅可以把页面元素的正文文字对 AI 隐藏，还能把 HTML 标签的属性值（如私密 `href` 链接、接口地址）乃至 `<script>` 脚本里的字符串字面量一并隐藏起来，而右侧渲染出来的网页预览画面不会发生丝毫改变。
- **Slides 支持整图隐藏与防截图泄露**：在 Slides 演示文稿中，除了隐藏文本框里的文字外，还可以把**整张图片、视频或音频元素**对 AI 隐藏；更严谨的是，一旦某一页幻灯片上包含任何被设为对 AI 隐藏的内容，系统在后台执行自动版式视觉检查时就会**严禁将该页渲染成截图发给多模态模型**，而是会自动跳过该页的截图检查并在界面上向你明确说明，堵住「文字藏住了、却被整页截图拍出去」的漏洞。
- **清楚了解隐藏的作用边界**：需要提醒的是，这套「对 AI 隐藏」机制专门用于拦截**GenOffice 应用内置 AI 面板**发往大模型的上下文；而当你在终端里直接运行 `genoffice` 命令行工具、通过 MCP 协议让外部本地编程代理直接读取磁盘文件、或是执行无头批量导出时，由于这些工具直接操作磁盘上的真实文件，它们依然能够读到文件中的完整原文。

## 数据隐私与密钥存储

- **只发往你自己选定的模型服务**：你在 AI 面板里输入的指令以及当前任务涉及的那部分文档上下文，只会发送给**你在设置里亲自配置或登录的模型服务商**（Genspark 官方托管服务，或你自己填写的 BYOK 自定义端点，详见下一章「AI 模型与设置」）；如果你既没有登录也没有配置任何端点，GenOffice 就不会对外发出任何 AI 请求。
- **本地文档与密钥绝不乱传**：你的本地文件绝不会被后台偷偷打包上传到任何与当前请求无关的服务器；你自己填写的 BYOK API 密钥也只保存在你本机的应用配置文件中，仅在向你指定的端点发请求时作为 HTTP 请求头字段传出。
