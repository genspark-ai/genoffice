# แผงผู้ช่วย AI

ทุกตัวแก้ไขเรียกใช้แผง AI ได้: เลือกสิ่งที่ต้องการ สั่งงาน แล้วดูผลลัพธ์ที่ทยอยทีละส่วน

## การเปิดและใช้งาน

![แผง AI ใน Docs](img/ai-panel.png)

- จุดเข้าใช้งาน: **ปุ่ม AI** ในแถบเครื่องมือของแต่ละตัวแก้ไข, **ถาม AI** ในเมนูคลิกขวา หรือ ถาม AI บนแถบเครื่องมือทำเครื่องหมาย
- อธิบายงานเป็นภาษาธรรมชาติ (เขียนส่วนนี้ใหม่ / ทำให้คอลัมน์นี้เป็นเปอร์เซ็นต์ / จัดหน้านี้ใหม่…) แล้วกด Enter
- คำตอบจะเรนเดอร์แบบ **สตรีม** เมื่อ AI ต้องใช้เครื่องมือ (อ่านเอกสาร แก้เอกสาร) มันจะทำงานแล้วทำต่อจนเสร็จ
- **หยุด**: ขัดจังหวะรอบปัจจุบันได้ทุกเมื่อ
- **คิวข้อความ**: ระหว่างที่คำตอบกำลังสตรีม Enter จะเก็บข้อความของคุณเข้าคิวแทนที่จะทิ้ง — แถบเหนือช่องพิมพ์บอกจำนวนที่รออยู่ เปิดออกเพื่อแก้ไข ลบ สลับลำดับ พัก หรือล้าง ข้อความถัดไปส่งเองเมื่อจบรอบปัจจุบัน ส่วน Esc ยังหยุดรอบเช่นเดิม

## สิ่งที่ทำได้

- **Docs**: เขียนใหม่/ขยาย/แปล/สรุป, แทรกตารางและรูปภาพ, ปรับรูปแบบ; ทุกรอบจะเก็บสแนปช็อตก่อน
- **Sheets**: สูตร, เติมข้อมูล, แปลงข้อมูลเป็นชุด, จัดรูปแบบ
- **Slides**: สร้างทั้งชุด, ปรับเค้าโครง, เขียนข้อความใหม่
- **PDF**: ถามตอบและสรุปจากข้อความหรือหน้าที่เลือก
- **Markdown / HTML**: เขียนใหม่, ขยาย, แปล
- **หน้าแรก ▸ ถาม AI** ตอบคำถามจากไฟล์ที่คุณติดดาวพร้อมอ้างอิง — แผงฐานความรู้มีหัวข้อของตัวเองในบทหน้าแรก และแผง AI ของ Docs ก็มีทักษะเดียวกัน

## การย้อนกลับและความปลอดภัย

- แผงของ Docs เก็บ **รายการเวอร์ชัน**: หนึ่งสแนปช็อตต่อหนึ่งรอบ เลื่อนกลับไปที่รอบใดก็ได้ และการเลื่อนกลับนั้นเองก็ยกเลิกด้วย Ctrl+Z สแนปช็อตยังอยู่แม้ปิดแล้วเปิดเอกสารใหม่
- การแก้ไขของ AI เดินผ่านขั้นตอนการแก้ไขชุดเดียวกับการแก้ไขด้วยตนเอง (เลิกทำได้ และต้องบันทึกเอง) ไม่มีอะไรข้ามการยืนยันการบันทึกของคุณ

## ซ่อนส่วนที่เลือกจาก AI

- ใน Slides, HTML และ Markdown ซ่อนส่วนที่เลือกให้พ้นสายตาโมเดลได้: คลิกขวา ▸ **ซ่อนส่วนที่เลือกจาก AI** ตั้งชื่อตัวแทน แล้วโมเดลจะอ่านเจอ `{{ชื่อ}}` แทนข้อความจริง (Markdown เปิดใช้รายการนี้ด้วยสวิตช์รูปตาขีดฆ่าบนริบบิ้น ส่วนของ HTML อยู่ในแผงซอร์ส)
- ไฟล์ยังเก็บข้อความจริงไว้ — บันทึก ส่งออก และพิมพ์ไม่กระทบ เครื่องหมายอยู่คงเมื่อเปิดใหม่ รายการเมนูเดิมใช้ยกเลิกการซ่อนได้ (Markdown มีรายการแยก **แสดงส่วนที่เลือกให้ AI อีกครั้ง**)
- HTML ซ่อนได้ทั้งเนื้อหาอิลิเมนต์ ค่าแอตทริบิวต์ และสตริงในสคริปต์ หน้าที่เรนเดอร์ไม่เปลี่ยนเลย
- Slides ซ่อนรูปภาพ วิดีโอ และเสียงทั้งรายการได้ด้วย สไลด์ที่มีเนื้อหาซ่อนจะไม่ถูกส่งเป็นภาพหน้าจอ: การตรวจเลย์เอาต์อัตโนมัติจะข้ามหน้านั้นและแจ้งให้ทราบ
- นี่ใช้กับ AI ในแอปเท่านั้น — CLI, เครื่องมือ MCP และการส่งออกแบบ headless อ่านไฟล์ตรง ๆ ยังเห็นข้อความเหมือนเดิม

## ความเป็นส่วนตัว

- คำสั่งและเนื้อหาเอกสารที่เกี่ยวข้องจะถูกส่งไปยัง **บริการโมเดลที่คุณตั้งค่าไว้** (Genspark หรือปลายทางที่กำหนดเอง ดูบทถัดไป) ถ้าไม่ตั้งค่าก็ไม่มีการส่ง
- ไฟล์ในเครื่องไม่ถูกอัปโหลดไปที่ใดที่อื่น คีย์แบบ BYOK ถูกเก็บไว้ในไฟล์การตั้งค่าของแอปบนเครื่องนี้ และส่งไปเฉพาะในส่วนหัวของคำขอ
