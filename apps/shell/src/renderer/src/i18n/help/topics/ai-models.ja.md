# AI モデルと設定

## プロバイダーとモデル

モデルとキーは 設定（ホームの左下のアカウントの行）で構成します。

![設定ウィンドウ](img/settings-general.png)

- **Genspark 公式**：サインインする（デバイスコード方式）だけで使えます。設定は不要です。
- **カスタムエンドポイント（BYOK）**：設定 ▸ AI で、プロトコルごとにベース URL と API キーを入力します。OpenAI 互換、Anthropic、Gemini、DeepSeek、DashScope（qwen）など。キーはリクエストのヘッダーにだけ入り、ディスクにも、ログにも、子プロセスの環境変数にも残りません。
- 機能ごとに別のモデルを選べます。会話／生成、画像生成、画像解析。
- **接続テスト**：保存する前に、エンドポイントへの到達性とモデルの見える範囲を確認できます。
- ベース URL にはパスとクエリ文字列を含められるので（ゲートウェイ形式）、エンドポイントのパスは正しく連結されます。

## CLI の連携（Codex 系）

- 設定でローカルの CLI プログラムのパスを指定できます（ASCII 以外のホームディレクトリや ~ 接頭辞も動作し、~ は自動的に展開されます）。モデルの検出は、その CLI が使えるモデルを調べます。
- 検証は存在を確認するだけです。文字セットの制限はありません。

## 変更が反映されるタイミング

- モデルとエンドポイントの変更はすぐに反映されます。進行中の会話は、次の応答まで古い設定を使います。
