# AI モデルと設定

## プロバイダーとモデルの構成

すべての AI モデルプロバイダー、カスタムエンドポイント、および API キーは、**設定**ダイアログ（ホーム画面左下のアカウント行から開きます）で一元管理します。

![設定ウィンドウ](img/settings-general.png)

- **Genspark 公式ホステッドモデル**：ブラウザを使ったデバイスコード方式で Genspark アカウントにサインインするだけで、API キーの取得やエンドポイント URL の入力を一切行わずに、公式のチャットモデルやマルチモーダル機能をすぐ使い始められます。
- **カスタムエンドポイント（BYOK / 独自キーの持ち込み）**：ご自身の API キーや社内ゲートウェイを利用したい場合は、**設定 ▸ AI モデル**（および**画像生成・メディア・検索**）でプロトコルごとにベース URL と API キーを登録できます。OpenAI 互換プロトコル、Anthropic（Claude）、Google Gemini、DeepSeek、DashScope（Qwen）、MiniMax、Atlas Cloud など主要なプロトコルを標準で内蔵しています。入力した API キーはこのマシンの所有者専用の設定ファイルにのみ保存され、通信時には設定したエンドポイント宛てのリクエストヘッダーにのみ載せて送信されます。
- **機能ごとに最適なモデルを自由に組み合わせ**：チャット／文書作成、**画像生成**、**画像・動画解析（ビジョン）**の各機能に対して、それぞれ異なるプロバイダーや専用モデルを個別に割り当てることができます。
- **MiniMax H3-Image と MiniMax H3-Image Highspeed による画像生成**：画像生成プロバイダーの MiniMax では、従来の `image-01` に加えて、高精細な既定モデルである **MiniMax H3-Image** と、高速生成向けの **MiniMax H3-Image Highspeed** の両方が利用可能になりました（国際エンドポイントおよび中国国内の `api.minimax.cn` の双方に対応）。どちらの H3 モデルも既定で鮮明な **2K 解像度相当**の画像をリクエストし、既存画像を元にした画像編集（Image-to-Image）では一度に**最大 16 枚の参照画像**を渡すことができます。
- **保存前のワンクリック接続テスト**：新しいエンドポイントやキーを保存する前に**接続テスト**ボタンを押すことで、その場でベース URL への到達性、API キーの有効性、および選択したモデルの応答を確認できます。
- **ゲートウェイ形式のベース URL にも対応**：ベース URL にはサブパスやクエリ文字列（社内プロキシや API ゲートウェイの URL など）を含めることができ、GenOffice は既存のパス構造やクエリパラメータを損なわずに各エンドポイントのパスを正しく連結します。

## ローカル CLI の連携（Codex 系ツール）

- **ローカル CLI 実行ファイルのパス指定**：クラウド API だけでなく、ローカルマシンにインストールされた Codex 系 CLI プログラムのパスを設定で直接指定することもできます（日本語など非 ASCII 文字を含むホームディレクトリや `~` 接頭辞にも完全対応し、`~` は自動的に展開されます）。**モデルを検出**をクリックすると、その CLI で利用可能なモデル一覧を自動的にプローブして取得します。
- **存在確認のみの柔軟なパス検証**：パスの検証はディスク上にファイルが実在するかどうかの確認のみを行い、フォルダ名に対して不必要な ASCII 文字制限を課すことはありません。

## 設定変更が反映されるタイミング

- **進行中の応答を妨げずに即時反映**：設定画面でモデルやエンドポイント、API キーを変更して保存すると、開いているすべてのエディターに即座に反映されます。保存した瞬間に AI パネルでストリーミング応答が進行中だった場合は、そのターンだけ前の設定で最後まで完了し、次の質問から新しいモデル設定に切り替わります。
