# 分頁與視窗管理

所有開啟中的檔案共用同一個視窗；上方的分頁列像瀏覽器一樣在它們之間切換。

![分頁列：首頁加兩個文件](img/tabs.png)

## 基本操作

- **切換**：點一下分頁，或在分頁列上滾動滑鼠滾輪依序切換。
- **關閉**：分頁上的 ×，或 ⌘W/ctrl+W。有未儲存的變更時會先詢問。
- **新增**：分頁列右端的 + 號。
- **啟用立即生效**：按下一個分頁（哪怕尚未放開滑鼠）就已切換，不會等到點擊動作完成。

## 重新命名：按兩下分頁

**在任何檔案分頁上按兩下**，標題就會就地變成輸入方塊：Enter 送出、Escape 取消、移開焦點亦送出；輸入法選字時的 Enter 不會被誤判為送出。改名會走與首頁檔案列重新命名相同的安全檢查（非法字元、同名衝突），實際檔案會在磁碟上重新命名，最近使用的清單也會隨之更新。

## 拖曳重新排序

按住分頁左右拖曳即可重新排列，鄰近的分頁會即時讓位，放開後順序就定位。4 像素的死區可避免一般點擊讓分頁晃動。

## 右鍵選單

在分頁上按右鍵只有兩個項目：**在新視窗中開啟**（每個可分離的文件分頁都有）和**關閉**（無法關閉的分頁會呈灰色）。兩者都會隨應用程式語系當地化。

## 拖出成獨立視窗

**把分頁拖出分頁列**（或使用「在新視窗中開啟」），它就會變成帶著同一份文件的獨立視窗；拖回去即可重新併入分頁列。分離出來的視窗與主視窗完全對等，可以繼續在那裡編輯與儲存。

## 「全部分頁」清單

分頁多到溢出時，分頁列右端的小分頁列圖示會開啟完整清單（原生選單，不會被內容區蓋住）；用方向鍵選擇。

## 每個編輯器上方的工具列

每個編輯器分頁頂端都有一排工具（各編輯器的排列略有差異）：

- **儲存**（⌘S/ctrl+S）與**另存新檔**。
- **復原／重做**：多層級；每個編輯器各自維護自己的歷史紀錄。
- **尋找**（ctrl+F）：開啟該編輯器的尋找面板。
- **自動儲存**開關：開啟時會定時把變更寫入磁碟；關閉時只有手動儲存才會寫入（分頁／標題上的未儲存標記會提醒你）。

## 首頁分頁

最左邊的首頁分頁無法關閉；要從任何編輯器回到首頁，點一下它或使用 檔案 ▸ **返回首頁**。
