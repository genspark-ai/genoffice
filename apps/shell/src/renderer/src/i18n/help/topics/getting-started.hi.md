# त्वरित प्रारंभ: इंटरफ़ेस और बुनियादी बातें

GenOffice एक ऑफ़िस सूट है जो पूरी तरह आपकी मशीन पर चलता है: एक विंडो, टैब की एक पंक्ति, और उसमें छह एडिटर — Docs (शब्द प्रसंस्करण), Sheets (स्प्रेडशीट), Slides (प्रस्तुतियाँ), PDF, Markdown और HTML। फ़ाइलें असली .docx / .xlsx / .pptx / .pdf होती हैं, जो Word, Excel और PowerPoint से पूरी तरह आदान-प्रदान योग्य हैं। नेटवर्क की ज़रूरत नहीं।

## इंटरफ़ेस की झलक

![होम स्क्रीन](img/home-screen.png)

विंडो के तीन हिस्से हैं:

- **टैब पट्टी (ऊपर)**: हर खुली फ़ाइल एक टैब है। सबसे बाईं ओर का होम टैब हमेशा मौजूद रहता है और बंद नहीं हो सकता; बाकी टैब आपके दस्तावेज़ हैं। किसी टैब पर डबल-क्लिक करके उसकी फ़ाइल का नाम बदला जा सकता है।
- **सामग्री क्षेत्र**: सक्रिय टैब से जुड़ा एडिटर (या होम)।
- **मेन्यू पट्टी**: macOS पर सिस्टम मेन्यू पट्टी में, Windows/Linux पर विंडो के ऊपर। File/Edit/View मेन्यू सक्रिय एडिटर के अनुसार बदल जाते हैं।

## नया दस्तावेज़ बनाना

इनमें से कोई भी तरीका:

- **होम** के [त्वरित प्रारंभ](help://getting-started) अनुभाग में कोई त्वरित-निर्माण कार्ड दबाएँ (AI Docs, AI Sheets, AI Slides, ...)।
- मेन्यू **File ▸ नया**: Docs (⌘N/ctrl+N), Sheets, Slides, Markdown, HTML या PDF।
- कोई फ़ाइल विंडो पर खींचें, या अपने फ़ाइल प्रबंधक में उस पर डबल-क्लिक करें (यदि GenOffice डिफ़ॉल्ट ऐप है)।

नया दस्तावेज़ बिना शीर्षक के खुलता है; डिस्क पर फ़ाइल पहली बार सहेजने पर ही बनती है।

## फ़ाइलें खोलना

- मेन्यू **File ▸ खोलें** (⌘O/ctrl+O) सिस्टम चयरकर्ता खोलता है: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html।
- होम की **हाल के** सूची में किसी भी वस्तु पर क्लिक करें।
- टर्मिनल से `genoffice <file>` भी फ़ाइलें खोलता है।

## सहेजने का मॉडल

- **मैन्युअल सहेजना**: ⌘S/ctrl+S, या File ▸ सहेजें / इस रूप में सहेजें। पहली बार सहेजते समय स्थान और नाम पूछा जाता है।
- **स्वतः सहेजना** तभी चालू होता है जब आपने किसी फ़ाइल को कम से कम एक बार मैन्युअल रूप से सहेजा हो — जिस PDF को आपने केवल पढ़ा है, उसे कभी चुपचाप दोबारा लिखा नहीं जाता। सामग्री बदलने के कुछ देर बाद यह चलता है।
- असहेजे बदलाव वाला टैब बंद करने पर पहले पूछा जाता है: सहेजें / छोड़ें / रद्द करें।
- हर लेखन परमाणु रूप से होता है (अस्थायी फ़ाइल + नाम बदलना), इसलिए बिजली जाते ही आधा फ़ाइल नहीं रह जाती।

## सामान्य शॉर्टकट

| कार्रवाई            | macOS | Windows / Linux |
| ------------------- | ----- | --------------- |
| नया दस्तावेज़       | ⌘N    | ctrl+N          |
| खोलें               | ⌘O    | ctrl+O          |
| सहेजें              | ⌘S    | ctrl+S          |
| टैब बंद करें        | ⌘W    | ctrl+W          |
| यह मैन्युअल खोलें   | F1    | F1              |
| रिबन संक्षिप्त करें | ⌥⌘R   | Ctrl+F1         |

**रिबन संक्षिप्त करना** हर एडिटर में काम करता है। टैब की पंक्ति बनी रहती है और उसके नीचे का कमांड बैंड छिप जाता है; चयनित टैब ही संक्षिप्त करने का नियंत्रण भी है, इसलिए जब तक रिबन संक्षिप्त है कोई टैब चयनित नहीं होता, और किसी भी टैब पर क्लिक करने से बैंड वापस आ जाता है। टैब पर डबल-क्लिक भी वही करता है। आपने इसे जिस हालत में छोड़ा, वह हर एडिटर के लिए अलग याद रहता है।

हर एडिटर के भीतर के शॉर्टकट (फ़ॉर्मेट पेंटर, खोजें और बदलें, तालिका कार्रवाइयाँ, ...) उनके अध्यायों में हैं; Docs में एक खोजने योग्य कीबोर्ड-शॉर्टकट संवाद भी है (**⌘/**) (उसका अध्याय देखें)।

## Option+Command शॉर्टकट

Option+Command वह परत है जिसे Word संरचित ज़िब्रों के लिए सुरक्षित रखता है, और GenOffice उसे उसी तरह भरता है। इनमें से ज़्यादातर Docs के पास हैं, Sheets के पास Excel से मेल खाने वाले दो अपने हैं, और एक शॉर्टकट हर जगह काम करता है.

**Docs**

| शॉर्टकट (macOS) | यह क्या करता है           | Windows / Linux    |
| --------------- | ------------------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | शीर्षक 1 / 2 / 3          | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | सामान्य                   | Ctrl+Alt+0         |
| ⌥⌘M             | अनुच्छेद                  | Ctrl+Alt+M         |
| ⌥⌘A             | नई टिप्पणी                | Ctrl+Alt+A         |
| ⌥⌘F             | पाद टिप्पणी सम्मिलित करें | Ctrl+Alt+F         |
| ⌥⌘E             | अंत टिप्पणी सम्मिलित करें | Ctrl+Alt+D         |
| ⌥⌘G             | यहाँ जाएँ                 | Ctrl+G             |

इनमें से दो Windows पर बदल जाते हैं, ठीक उसी कारण से जिसके लिए Word उन्हें अलग रखता है। **macOS के पास ⌥⌘D है** — यह Dock को दिखाता और छिपाता है — इसलिए अंत टिप्पणि Mac पर ⌥⌘E है और बाकी हर जगह Ctrl+Alt+D। और **यहाँ जाएँ** Alt छोड़ देता है: Ctrl+G, जहाँ Mac वाला शॉर्टकट उसे साथ ले जाता है।

**Sheets**, जब ग्रिड पर फ़ोकस हो

| शॉर्टकट (macOS) | यह क्या करता है | Windows / Linux |
| --------------- | --------------- | --------------- |
| ⌥⌘0             | बाहरी बॉर्डर    | Ctrl+Shift+7    |
| ⌥⌘−             | कोई बॉर्डर नहीं | Ctrl+Shift+−    |

Windows, Mac वाले उस जोड़े का दोबारा लिखा हुआ रूप नहीं है. Excel for Mac, Sheets को **दोनों** देता है — ⌘⇧7 और ⌥⌘0 एक ही बाहरी बॉर्डर के दो कुंजी-संयोजन हैं — इसलिए Windows पर कमांड वही Ctrl+Shift जगह बनाए रखता है जो पहले से थी, और Option परत बस मौजूद ही नहीं है.

ध्यान दें कि **⌥⌘0 का मतलब Docs में सामान्य और Sheets में बाहरी बॉर्डर है**. वे कभी एक ही एडिटर में नहीं आते, इसलिए इस्तेमाल में कोई टकराव नहीं होता, पर ⌥⌘0 अब पहले से लिया जा चुका है और ग्लोबल शॉर्टकट के रूप में उपलब्ध नहीं.

**हर एडिटर**: **⌥⌘R / Ctrl+F1** रिबन को संक्षिप्त करता है, जैसा ऊपर बताया गया.

इससे macOS पर ⌥⌘D GenOffice के लिए खाली बचा रहता है, अगर कोई भविष्य का कमांड उसे चाहे।
