# PDF: การอ่าน การใส่คำอธิบาย และการปิดบังข้อมูล

ตัวแก้ไข PDF มีแท็บในแถบเครื่องมือห้าแท็บ: **หน้าแรก / คำอธิบายประกอบ / แก้ไข / หน้า / มุมมอง** และอ่านเขียนได้จริง: แก้ไขข้อความได้ ปิดบังเนื้อหาได้ ลงนามได้ และกรอกแบบฟอร์มได้

## การอ่านและการนำทาง

- แถบด้านซ้าย: **ภาพขนาดย่อ** (คลิกเพื่อกระโดด ช่วงที่มองเห็นจะถูกไฮไลต์) หรือ **สารบัญ** (บุ๊กมาร์ก ถ้ามี)
- ซูม: ตัวควบคุมอัตราส่วนที่มุมล่างขวา ctrl+ล้อเลื่อนปรับทีละขั้น
- การหมุน: ทีละหน้าหรือทั้งหมดจากเมนูหน้า และการหมุนจะถูกเขียนกลับเมื่อบันทึก
- ค้นหา: ctrl+F ค้นทั้งข้อความพร้อมไฮไลต์ทุกจุดที่พบ
- PDF ที่เข้ารหัส: จะมีกล่องขอรหัสผ่าน (หน้าต่างย่อยของตัวเอง) เปิดขึ้นมาให้ใส่ รหัสผ่านนั้นใช้เฉพาะเซสชันนี้

## การเลือกข้อความและการทำเครื่องหมาย (คำอธิบายประกอบ)

ลองทำดูกับย่อหน้าใดก็ได้:

1. **ลากเมาส์ผ่านประโยคหนึ่ง** — เมื่อปล่อยเมาส์ แถบเครื่องมือจะลอยขึ้นมาเหนือข้อความนั้น:

![แถบเครื่องมือหลังเลือกข้อความ](img/pdf-highlight.png)

2. เลือก **ไฮไลต์** (แผ่นสีเหลืองจะเปิดชุดสีขึ้นมา), **ขีดเส้นใต้** หรือ **ขีดฆ่า**; กด **ถาม AI** เพื่อส่งข้อความที่เลือกพร้อมคำถามของคุณไปยังแผง AI
3. ถ้าต้องการยกเลิกเครื่องหมาย ให้ลากเลือกข้อความช่วงเดิมอีกครั้งแล้วกดปุ่มที่กำลังทำงานอยู่บนแถบ (สวิตช์แบบ Word) หรือเลือกข้อความแล้วกด Delete

ข้อควรทราบ:

- เมื่อลากผ่านข้อความ แถบเล็กจะปรากฏขึ้น: **ไฮไลต์ / ขีดเส้นใต้ / ขีดฆ่า / คัดลอก / ถาม AI**
- สีมาจากชุดสี และ **การใช้เครื่องหมายเดิมกับช่วงที่ทำเครื่องหมายไว้แล้วจะเอาออก** (สวิตช์แบบ Word)
- เครื่องหมายที่บันทึกลงไฟล์ไว้แล้วสามารถเลือกและลบได้ (เมนู ⋯ หรือ Delete)
- **หมายเหตุ**: ขณะที่เครื่องมือวาดยังติดอาวุธอยู่ ชั้นข้อความจะเลือกไม่ได้ เครื่องมือจะปลดตัวเองหลังวางกราฟเสร็จหนึ่งชิ้น คุณจึงกลับมาอยู่ในโหมดเลือกเพื่อทำงานถัดไป

## เครื่องมือวาด (คำอธิบายประกอบ)

หกเครื่องมือ: **วาดมือ, สี่เหลี่ยม, วงรี, ลูกศร, โน้ต** และ **กล่องปิดบังข้อมูล** บนแท็บคำอธิบายประกอบ

- แต่ละเครื่องมือเป็นสวิตช์: คลิกเพื่อเปิดใช้งาน และ **จะปลดตัวเองเมื่อวางกราฟเสร็จหนึ่งชิ้น** (ถ้าต้องการวาดต่อให้กดเครื่องมือซ้ำอีกครั้ง) การคลิกเครื่องมือที่เปิดอยู่ก็ปลดตัวมันเช่นกัน
- หมึกจะเปลี่ยนตามความกว้างของเส้น ส่วนสี่เหลี่ยม/วงรี/ลูกศรวาดออกมาโดยลาก สีมาจากชุดสีของเครื่องมือวาด
- กราฟที่วางแล้วเลือก ลบ ลากย้าย และปรับขนาดได้ (สี่เหลี่ยม/วงรี)
- **การปิดบังข้อมูล ขั้นตอนทั้งหมด** (การซ่อนบรรทัดข้อความ):

  1. แท็บคำอธิบายประกอบ ▸ คลิก **ปิดทับพื้นที่** (เครื่องมือจะเปิดใช้งาน)
  2. **ลากกรอบครอบเนื้อหาที่ต้องการ** — เนื้อหานั้นจะถูกปิดด้วยลายเส้น และแถบเครื่องมือจะมีปุ่ม **ล้างเครื่องหมาย / ใช้การปิดทับ** เพิ่มขึ้น:

  ![หน้าหลังทำเครื่องหมายปิดบัง](img/pdf-redact.png)

  3. คลิก **ใช้การปิดทับ** แล้วยืนยัน — ผลลัพธ์คือสำเนาใช้งานที่ข้อความและรูปภาพในพื้นที่นั้นถูกลบออกจริง (ไม่ใช่ถูกปิดทับ) และย้อนกลับไม่ได้ ส่วนเอกสารต้นฉบับยังคงไม่ถูกแตะ

  ทำผิดพลาดหรือเปล่า? ปุ่มล้างเครื่องหมายจะลบเครื่องหมายปัจจุบันทิ้งทั้งหมด เพื่อให้คุณวาดใหม่ได้

## โน้ตและชุดความคิดเห็น

- **เครื่องมือโน้ต** จะวางหมุดและเปิดการ์ดในส่วนขอบกระดาษเพื่อพิมพ์ข้อความ (ตั้งชื่อผู้เขียนได้) เมื่อยืนยัน จะบันทึกเป็นคำอธิบายข้อความมาตรฐานของ PDF
- คลิกที่หมุดเพื่อเปิดชุดความคิดเห็น: **ตอบกลับ** (ชุดความคิดเห็นแบนแบบ WPS/Acrobat), **แก้ไข** ความคิดเห็นของคุณ, **ลบ** ความคิดเห็นหนึ่งรายการหรือทั้งชุด
- รายการที่กำลังแก้ไขจะไม่หายไปจนกว่าการบันทึกจะเขียนข้อความใหม่กลับเข้าคำอธิบายเดิมในไฟล์ โดยรักษาสายการตอบกลับไว้ครบ

## การแก้ไขเนื้อหา PDF (แก้ไข)

- **แก้ไขข้อความ**: คลิกที่ข้อความเพื่อแก้ทีละบล็อก (เอนจิน pdfium; เลือกแบบอักษรให้ใกล้เคียงที่สุดเท่าที่ทำได้)
- **แทรกข้อความ**: วางข้อความที่ค้นหาได้ พร้อมแบบอักษร ขนาด และสีที่เลือกเอง
- **แทรกรูปภาพ / ประทับ**
- แบบฟอร์ม: ช่อง AcroForm กรอกได้โดยตรง และค่าที่กรอกจะถูกเขียนเมื่อบันทึก

## การลงนาม

- **ลายเซ็นด้วยหมึก**: วาดด้วยมือ และผูกกับช่องลายเซ็นของแบบฟอร์มได้
- **ลายเซ็นเป็นรูปภาพ**: วางรูปภาพในช่องลายเซ็น
- ลายเซ็นที่บันทึกไว้แล้วนำมาใช้ซ้ำได้

## การจัดการหน้า (หน้า)

- **หมุน / ลบ / จัดลำดับใหม่**: ลากรูปขนาดย่อเพื่อจัดลำดับใหม่ การลบจะมีการยืนยัน
- **นำเข้าหน้า**: ดึงหน้าจาก PDF อื่นเข้ามาในเอกสาร **แทรกหน้าว่าง** จะเพิ่มหน้าว่างหนึ่งหน้า
- **แทนที่หน้า** จะสลับทั้งช่วงหน้าด้วยหน้าที่นำเข้ามาจากที่อื่น ส่วน **ครอบตัดหน้า** จะตัดขอบ พร้อมตัวเลือกที่จะใช้กับทุกหน้า
- **ขนาดหน้า** จะปรับทุกหน้าให้เท่ากับขนาดกระดาษเดียวกัน ส่วน **เรียงย้อนกลับ** จะกลับลำดับเอกสารจากท้ายไปหัว
- **แยกหน้านี้**: ส่งออกหน้าที่เลือกไปเป็น PDF ใหม่
- **แยก PDF**: มีสองรูปแบบ คือแยกตามช่วงหน้าเป็นหลายไฟล์ หรือตัดหน้าแต่ละหน้าให้เป็นตารางของหน้าย่อย
- **รวม PDF**: มีสองรูปแบบ คือต่อท้ายด้วย PDF อื่น หรือรวมหลายหน้าไว้บนแผ่นเดียว ขนาดรวมจะถูกคำนวณ **ก่อน** อ่านเนื้อหาใด ๆ และถ้ารวมกันแล้ว **เกิน 1 GiB จะถูกปฏิเสธ** พร้อมข้อความที่อ่านได้ (เพื่อจำกัดการใช้หน่วยความจำ)
- การเปลี่ยนแปลงระดับหน้าจะเขียนกลับเมื่อบันทึกครั้งถัดไป ส่วนคำสั่งบันทึกเป็น… จะไม่แตะต้นฉบับ

## การส่งออกและการพิมพ์

- **ส่งออกเป็น Word… / PowerPoint… / Excel…** ในเมนูไฟล์ หรือเลือกสามรายการเดียวกันนี้จาก **แปลง PDF** บนแถบเครื่องมือ ทั้งหมดทำงานในเครื่อง ไม่มีการอัปโหลด ไฟล์ .pptx จะได้หนึ่งสไลด์ต่อหนึ่งหน้า และไฟล์ .xlsx จะได้หนึ่งแผ่นงานต่อหนึ่งหน้า แต่ละรายการจะถามว่าจะบันทึกที่ไหน
- **พิมพ์**: ลำดับหน้าและการหมุนปัจจุบันผ่านกล่องโต้ตอบของระบบ รองรับการเลือกช่วงหน้า

## การบันทึก

- การบันทึกปกติ/บันทึกอัตโนมัติ จะเขียนคำอธิบายและการแก้ไขกลับเข้าไฟล์ (แบบอะตอมิก)
- **การปิดบังข้อมูลใช้ขั้นตอนใช้การปิดทับของตัวเอง** ซึ่งสร้างสำเนาและปล่อยต้นฉบับไว้ไม่ให้ถูกแตะ เพื่อไม่ให้เนื้อหาอ่อนไหวค้างอยู่ในไฟล์เดิม
