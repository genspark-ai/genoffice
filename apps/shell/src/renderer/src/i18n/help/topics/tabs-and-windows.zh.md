# 标签页与窗口管理

在 GenOffice 中，无论你同时打开的是 Word 文档、Excel 表格、PPT 幻灯片还是 PDF 文件，所有文件默认都收纳在同一个主窗口里，通过窗口顶部的标签栏进行切换。整体交互逻辑与 Chrome 等现代浏览器非常接近，不需要在任务栏或程序坞的十几个独立窗口之间来回翻找。

![标签条：主页 + 两个文档](img/tabs.png)

## 基本操作

- **切换标签页**：直接用鼠标单击目标标签页即可切过去查看对应文档；如果打开的标签页比较多，也可以把鼠标指针停在顶部标签栏上方直接滚动鼠标滚轮，就能按顺序在各个打开的文档之间快速前后切换。
- **关闭标签页**：点击标签页右侧的 `×` 按钮，或者按下快捷键 `⌘W`（macOS）/ `Ctrl+W`（Windows 与 Linux）即可关闭当前文档；如果该文档还有尚未存盘的修改，系统会先弹出确认框让你选择保存、放弃更改还是取消关闭，防止误操作丢失内容。
- **新建标签页**：点击标签栏最右侧的 `+` 号按钮，即可在当前窗口中快速开启一个新的空白文档标签页，并直接进入对应的编辑器界面开始写作或排版。
- **按下即刻响应切换**：标签页的激活在鼠标按键按下的那一刻就会立即触发，不需要等到手指松开完成整次点击动作，因此在多个文档之间高频来回比对内容时响应非常干脆利落。
- **重命名当前文件**：如果你想直接修改某个已保存文档的文件名，可以双击该文档的标签页，或者右键点击标签页并在弹出菜单中选择**重命名**，标签标题就会就地变成输入框；而普通的单击只会用来激活和切换标签页，不会误触发改名状态。

## 重命名：双击或右键标签页

只要该文档已经在磁盘上保存过，你随时可以**双击它的文件标签页**（或者在标签右键菜单里点击**重命名**），标签上的文件名就会立刻变成一个可编辑的输入框。输入新名称后按回车键（`Enter`）或者用鼠标点击别处使输入框失去焦点，即可正式提交新文件名；如果改到一半想反悔，按 `Esc` 键就能放弃修改并恢复原名。在中文、日文等输入法拼写选词的过程中，用来确认候选词的回车键会被智能识别，绝不会被误当成提交文件名的指令。整个改名过程使用的是与主页文件列表完全一致的安全校验逻辑：如果不小心省略了后缀名，系统会自动帮你保留原来的扩展名；如果输入了操作系统禁止的非法字符，或者同一文件夹下已经存在同名文件，系统都会弹出明确提示并阻止覆盖。确认改名后，磁盘上的真实文件会同步更新，主页的「最近使用」和「收藏」列表也会自动刷新。

## 拖拽调整标签顺序

当窗口里打开了多个文档时，你可以按住任意一个文档标签页直接向左或向右拖动，旁边的标签页会随着你的拖动实时让出位置，松开鼠标后新的排列顺序就会固定下来。为了避免日常单击切换标签时因为手部轻微移动而导致标签乱跳，拖拽逻辑内置了 4 像素的防抖死区，只有真正拖动超过这个距离后才会开始排序。

## 标签页右键菜单

在任意文档标签页上点击鼠标右键，会弹出一个针对当前标签页和底层磁盘文件的完整快捷菜单。如果该文档已经在磁盘上保存过，菜单第一行会先以灰色字体列出它在磁盘上的路径摘要，方便你在同时打开多份同名文件时一眼看清当前标签对应的是哪个目录下的版本。

菜单上半部分集中了高频的文件与编辑操作：你无需先切进该标签页的功能区，直接在右键菜单里就能执行**保存**、**另存为…**或**打印…**；对于已落盘的文件，还能直接点击**重命名**（同样会激活标签页上的就地输入框）、**创建副本**、**复制路径**、**复制文件名**，或者选择**在访达 / 文件管理器中显示**以及**使用系统默认应用打开**（如果是尚未保存过的「未命名」新文档，这些依赖磁盘文件的选项会自动置灰）。菜单下半部分则负责窗口与标签布局管理，包括**在旁边分屏打开**、**在新窗口打开**（每个可分离的文档标签页均支持）、**固定标签页**（让该标签页在后台始终保持渲染进程活跃）、**向左移动 / 向右移动**，以及**关闭**、**关闭其他标签页**、**关闭右侧标签页**、**全部关闭**和**重新打开关闭的标签页**，所有菜单项都会随应用当前的界面语言自动本地化显示。

## 分离为独立窗口与重新合并

如果你需要把两份文档左右并排放在屏幕上对照阅读，可以直接按住某个文档标签页**向下拖出顶部标签栏区域**（或者在标签右键菜单中选择**在新窗口打开**），该标签页就会连同当前正在编辑的文档一起独立成一个全新的窗口。分离出去的窗口与主窗口拥有完全相同的编辑、保存和 AI 助手能力，所有未保存的修改和撤销历史都会原封不动地跟着过去；看完之后，只要把独立窗口的标签再次拖回主窗口的标签栏上方，它就会重新吸附并合并回原来的标签列中。

## 「全部标签」溢出列表

当同时打开的文档数量过多、超出了窗口顶部的横向空间时，标签栏最右端会出现一个小列表图标。点击该图标会弹出一个系统原生的完整标签页菜单（不会被下方编辑器的画布或悬浮面板遮挡），你可以直接用鼠标点选，或者用键盘上下方向键快速找到并跳转到目标文档。

## 编辑器顶部的快捷工具排

进入任何一个编辑器标签页后，在顶部区域都能看到一排常用的快捷工具按钮（具体排版位置与视觉样式会随不同编辑器略有调整）：

- **保存与另存为**：随时点击保存按钮（或按 `⌘S` / `Ctrl+S`）将当前修改写入磁盘，也可以点击「另存为」在不改动原文件的前提下将当前内容另存到新路径。
- **多级撤销与重做**：提供完整的撤销和重做按钮，而且每个打开的文档标签页都各自独立维护一套操作历史记录，切换标签页绝不会弄乱其他文档的撤销栈。
- **查找面板**：点击查找按钮（或按 `⌘F` / `Ctrl+F`）即可唤起当前编辑器专属的全文查找或查找替换工具条。
- **自动保存开关**：开启后，每当你编辑完内容停顿片刻，系统就会自动把最新改动安全写入磁盘；如果你关闭了自动保存，则只有手动触发保存时才会写盘，此时标签页和窗口标题栏上会显示醒目的未保存标记来提醒你。

## 主页标签

永远固定在标签栏最左端的「主页」标签页是整个办公套件的文件中心，因此它不能被关闭，也不会被「全部关闭」误伤。无论你当前正处于哪个编辑器里，只要想回到文件列表、查看最近打开的文档或搜索知识库，直接单击最左侧的「主页」标签页，或者在顶部菜单栏选择 **文件 ▸ 返回首页** 即可。
