# 快捷鍵一覽

每個編輯器都有自己的按鍵綁定，其中只有少數在任何地方都通用。本頁是完整清單，按應用程式分組，macOS 與 Windows / Linux 的組合鍵並排列出。

## 先讀這一節

**這裡幾乎沒有什麼是全域的。** 只有下面三個入口鍵是全域的；再往後的都屬於目前擺在面前的那個應用程式，切換標籤頁就會隨之改變。

| 操作                                     | macOS | Windows / Linux |
| ---------------------------------------- | ----- | --------------- |
| 開啟使用者手冊——在應用程式任何位置都可用 | F1    | F1              |
| 收合／展開功能區——所有編輯器通用         | ⌥⌘R   | Ctrl+F1         |
| 開啟「鍵盤快速鍵」表——僅 Word            | ⌘/    | Ctrl+/          |

- **F1 開啟的是本手冊**，不是快速鍵表。它屬於應用程式選單，所以在 Word、Sheets、Slides、PDF 或 Home 標籤頁中都能用。
- **切換功能區用 `Ctrl+F1`，macOS 上用 `⌥⌘R`。** 只按 `F1` 不會有任何反應——F1 是手冊，功能區組合鍵刻意不與它共用。macOS 上也接受 `Ctrl+F1`，不過 Office for Mac 實際使用的是 `⌥⌘R`。
- **「鍵盤快速鍵」表只有 Word 有**（`⌘/`）。它列出的正是下面那張 Word 表。其他編輯器都沒有。

![Word 自帶的「鍵盤快速鍵」面板：左側是操作，右側是組合鍵，按檔案、編輯、文字、段落、插入、審閱、檢視分組](img/word-shortcuts.png)

- **`⌘O`、`⌘S` 和 `⌘P` 在每個編輯器背後都是各自單獨實作的**，行為也不完全一致。Word 的 `⌘P` 會先排版列印預覽，讓一張列印紙正好對應一個螢幕頁面；PDF 的 `⌘P` 開啟 PDF 列印對話方塊；Sheets 和 Slides 又各有各的一套。
- **其餘的按鍵都按應用程式區分。** Word 標籤頁處於啟用狀態時，`⌘B` 是 Word 的粗體；Slides 啟用時，`⌘B` 是 Slides 的粗體，而它所屬的選單並不是你熟悉的那一個。只在有選取內容或某個特定窗格中才生效的綁定，「操作」列裡會寫明。

## 慣例

- macOS 一欄使用熟悉的符號：`⌘` Command、`⌥` Option、`⇧` Shift、`⌃` Control。
- Windows / Linux 一欄則拼寫出來：`Ctrl`、`Alt`、`Shift`。
- 在 GenOffice 確實需要兩個平台使用不同按鍵的地方，表格會如實標出。常見的有：`⌃H` 對應「尋找及取代」（macOS 把 `⌘H` 留給了「隱藏」）、`⌥⌘G` 對應「移至」，以及 Slides 的關閉鍵。
- 只在有選取範圍時才生效的組合鍵，寫在「操作」列裡而不另開一欄，這樣每張表都維持三欄寬。

## Word

Word 有完整的選單列，因此下面的檔案與格式組合鍵只要 Word 標籤頁取得焦點就可使用，無論目前開啟的是哪個文件。編輯類組合鍵需要文件已載入且可編輯，並且游標位於正文中；當你正在「尋找」方塊、AI 提示方塊或任何其他輸入方塊裡打字時，它們不會觸發。

### 檔案

| 操作           | macOS | Windows / Linux |
| -------------- | ----- | --------------- |
| 新增           | ⌘N    | Ctrl+N          |
| 新增視窗       | ⇧⌘N   | Ctrl+Shift+N    |

⌘P 不是瀏覽器的列印。Word 會先排版列印預覽，讓一張列印紙正好等於一個螢幕頁面，然後才開啟它自己的列印對話方塊。

## Sheets

GenOffice Sheets 是相容 Excel 的表格。下面大多數快速鍵就是你已經熟悉的 Excel 快速鍵。

> **編輯優先。** 當你正在編輯儲存格或在**公式列**中輸入時，Sheets 中幾乎所有快速鍵都不起作用，這樣打字、移動游標和退格鍵才保留文字編輯的原本意義。如果某個按鍵看起來毫無反應，先看看是不是正處於編輯狀態：按 Esc 或 Enter，再重試一次。對選取範圍生效的命令在對話方塊開啟時同樣不起作用。組合鍵是這條規則的例外時，表格裡會寫明。

有兩條慣例是 Sheets 特有的。`⌘` 和 `⌃` 共用同一個修正鍵位置——兩個在所有平台上都被接受，所以 `⌘1` 和 `Ctrl+1` 是同一個組合鍵。**Windows / Linux 一欄留空，表示該組合鍵僅存在於 macOS。**

## Slides

GenOffice Slides 是 PowerPoint 風格的簡報編輯器。大多數按鍵無論你在哪裡都做同樣的事，但少數幾個會隨焦點改變含義——在文字方塊內部，或者**縮圖窗格**、**大綱窗格**或**投影片瀏覽窗格**取得鍵盤焦點時。這些情況在「操作」列裡標出。

### 檔案與應用程式

| 操作               | macOS | Windows / Linux |
| ------------------ | ----- | --------------- |
| 儲存               | ⌘S    | Ctrl+S          |
| 另存新檔           | ⇧⌘S   | Ctrl+Shift+S    |
| 開啟               | ⌘O    | Ctrl+O          |
| 關閉目前標籤頁     | ⌘W    | Ctrl+Q          |
| 列印               | ⌘P    | Ctrl+P          |
| 復原               | ⌘Z    | Ctrl+Z          |
| 重做               | ⇧⌘Z   | Ctrl+Shift+Z    |
| 重做（備用組合鍵） | ⌘Y    | Ctrl+Y          |

關閉標籤頁是兩個平台唯一徹底分開的按鍵：macOS 上是 ⌘W，而 Windows 和 Linux 上是 Ctrl+Q，後者結束的是整個應用程式而不是標籤頁。

### 編輯

| 操作                                     | macOS  | Windows / Linux |
| ---------------------------------------- | ------ | --------------- |
| 新增投影片                               | ⇧⌘N    | Ctrl+M          |
| 尋找（在圖形中編輯文字時不可用）         | ⌘F     | Ctrl+F          |
| 以 AI 為選取範圍加上註解（需先選取圖形） | ⌘K     | Ctrl+K          |
| 放大                                     | ⌘=     | Ctrl+=          |
| 縮小                                     | ⌘-     | Ctrl+-          |
| 實際大小（100%）                         | ⌘0     | Ctrl+0          |
| 全選                                     | ⌘A     | Ctrl+A          |
| 向前／向後切換圖形選取                   | ⇥ / ⇧⇥ | Tab / Shift+Tab |

新增投影片是另一處平台分法。每個平台都有自己的按鍵，另一個什麼都不做：macOS 上是 ⇧⌘N，Windows 和 Linux 上是 Ctrl+M。⌘M 在 macOS 上辦不成這件事，因為那是系統的最小化鍵。

全選隨焦點而定：焦點在縮圖窗格、大綱窗格或投影片瀏覽窗格時，它選取所有投影片；在別處則選取目前投影片上的所有元素。Tab 在投影片上的各個圖形之間循環，而且只有投影片畫布本身取得焦點時才如此。

## PDF

PDF 沒有自己的選單，因此下面每個組合鍵都跟隨目前標籤頁，只有在 PDF 標籤頁位於最前時才能用。

### 檔案與編輯

| 操作             | macOS | Windows / Linux |
| ---------------- | ----- | --------------- |
| 儲存             | ⌘S    | Ctrl+S          |
| 復原             | ⌘Z    | Ctrl+Z          |
| 重做             | ⇧⌘Z   | Ctrl+Shift+Z    |
| 尋找（開啟搜尋） | ⌘F    | Ctrl+F          |
| 列印             | ⌘P    | Ctrl+P          |

復原和重做是在文件記錄裡前後移動；當游標位於某個文字輸入方塊時，它們會把 ⌘Z 讓給該方塊。⌘P 開啟的就是工具列上「列印」按鈕對應的那個應用程式內列印對話方塊。

| 縮小         | ⌘-       | Ctrl+-          |
| 符合頁寬     | ⌘0       | Ctrl+0          |
| 縮放（連續） | ⌘ + 滾輪 | Ctrl + 滾輪     |

放大也可以用 ⌘+ 和 Ctrl++。

### 頁面導覽

| 操作           | macOS             | Windows / Linux   |
| -------------- | ----------------- | ----------------- |
| 下一頁         | →                 | →                 |
| 上一頁         | ←                 | ←                 |
| 向下捲動一螢幕 | PageDown 或 Space | PageDown 或 Space |
| 向上捲動一螢幕 | PageUp            | PageUp            |
| 向下捲動       | ↓                 | ↓                 |
| 向上捲動       | ↑                 | ↑                 |
| 跳至第一頁     | Home              | Home              |
| 跳至最後一頁   | End               | End               |

這些按鍵不帶修正鍵，所以兩個平台的寫法相同。↓ 和 ↑ 是唯一會隨焦點變化的一行：在文件中它們微調頁面，但在縮圖側邊欄取得焦點時它們整頁翻動。你在輸入方塊裡打字時它們不起作用。

### 取消與對話方塊

| 操作               | macOS  | Windows / Linux |
| ------------------ | ------ | --------------- |
| 取消最上層狀態     | Escape | Escape          |
| 確認開啟的對話方塊 | Enter  | Enter           |

Escape 每次退出一層——先是對話方塊，然後是 AI 彈出面板、文字草稿、搜尋面板，最後才是選取本身。游標在搜尋方塊中時，Enter 和 ⇧Enter 跳到下一個和上一個相符項，Escape 關閉該面板；游標在新建的文字註解中時，⌘⏎ 提交它。
