# フォント：システムフォントとダウンロードできる書体

## フォントの一覧

フォントのコントロールは各エディターのホームタブにあります（下図は Slides のフォントグループ）。

![Slides のリボンのフォントグループ](img/fonts.png)

各エディターのフォント選択は次をまとめて表示します。ローカルにインストール済みのフォントと、プラットフォームで一般的な候補（Windows と macOS の一般的な欧字系・中日韓のファミリー、および CJK フォントが自分のシステムで報告するローカライズ名を含む）。システムがローカルのフォントを列挙できる場合は実際に存在するものでグループ化し、できない場合は候補の完全な一覧にフォールバックします。

## ダウンロードできるフォント（Slides）

- Slides のフォント選択は**フォントカタログ**を開けます。多岐にわたる書体系を覆う厳選された OFL の選択肢で、各ファミリーには標準と太的字重があります。
- 選ぶと、CDN からダウンロードして（チェックサム固定）アプリのフォントストアにインストールされます。その後はすべての文書で使えるようになり、システムレベルへのインストールは不要です。
- インストール先はアプリ専用のディレクトリで、アプリと一緒に消えます。

## 中日韓の組版

- Docs で CJK フォントを使うと、Word と揃った約物圧縮と行頭行尾の禁則が適用されます（Docs の章を参照）。
- カタログの CJK ファミリーは、簡体字中国語、繁体字中国語、日本語、韓国語の明朝体とゴシックをカバーしています。

## ローカルのフォントの管理

- 「フォントファイルをインストール…」の入口から、ディスク上の .ttf／.otf をアプリのフォントストアに読み込みます。
- ストアはファミリーごとに整理されるので、同じファミリーの複数の字重が併存できます。
