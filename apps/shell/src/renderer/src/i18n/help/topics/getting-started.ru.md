# Быстрый старт: интерфейс и основы

GenOffice — офисный пакет, который работает целиком на вашем компьютере: одно окно, один ряд вкладок и шесть редакторов — Docs (работа с текстом), Sheets (электронные таблицы), Slides (презентации), PDF, Markdown и HTML. Файлы настоящие: .docx / .xlsx / .pptx / .pdf, полностью совместимые с Word, Excel и PowerPoint. Сеть не требуется.

## Интерфейс с высоты птичьего полёта

![Главный экран](img/home-screen.png)

Окно состоит из трёх частей:

- **Панель вкладок (вверху)**: каждый открытый файл — это вкладка. Самая левая вкладка «Главная» есть всегда и не закрывается; остальные вкладки — ваши документы. Дважды щёлкните по вкладке, чтобы переименовать её файл прямо на месте.
- **Область содержимого**: редактор (или «Главная») активной вкладки.
- **Строка меню**: в системном меню на macOS, в верхней части окна на Windows/Linux. Меню Файл/Правка/Вид переключаются вслед за активным редактором.

## Создание документа

Любой из способов:

- Нажмите карточку быстрого создания в разделе [Быстрый старт](help://getting-started) на **Главной** (AI Docs, AI Sheets, AI Slides, ...).
- Меню **Файл ▸ Создать**: Docs (⌘N/ctrl+N), Sheets, Slides, Markdown, HTML или PDF.
- Перетащите файл в окно или дважды щёлкните его в файловом менеджере (если GenOffice назначен приложением по умолчанию).

Новый документ открывается без названия; файл на диске создаётся только при первом сохранении.

## Открытие файлов

- Меню **Файл ▸ Открыть…** (⌘O/ctrl+O) вызывает системный выбор файлов: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html.
- Нажмите любой элемент в списке **Недавние** на «Главной».
- `genoffice <файл>` в терминале тоже открывает файлы.

## Как устроено сохранение

- **Ручное сохранение**: ⌘S/ctrl+S или Файл ▸ Сохранить / Сохранить как…. При первом сохранении приложение спросит папку и имя.
- **Автосохранение** включается только после того, как вы хотя бы раз сохранили файл вручную, — PDF, который вы только читаете, никогда не будет молча перезаписан. Автосохранение срабатывает вскоре после изменения содержимого.
- При закрытии вкладки с несохранёнными изменениями сначала спрашивается Сохранить / Отменить изменения / Отмена.
- Каждая запись атомарна (временный файл + переименование), поэтому отключение питания не оставит наполовину записанный файл.

## Частые сочетания клавиш

| Действие                | macOS | Windows / Linux |
| ----------------------- | ----- | --------------- |
| Новый документ          | ⌘N    | ctrl+N          |
| Открыть                 | ⌘O    | ctrl+O          |
| Сохранить               | ⌘S    | ctrl+S          |
| Закрыть вкладку         | ⌘W    | ctrl+W          |
| Открыть это руководство | F1    | F1              |
| Свернуть ленту          | ⌥⌘R   | Ctrl+F1         |

**Сворачивание ленты** работает в каждом редакторе. Строка вкладок остаётся на месте, а полоса команд под ней скрывается; выбранная вкладка служит заодно и кнопкой сворачивания, поэтому, пока лента свёрнута, ни одна вкладка не выбрана, а нажатие любой вкладки возвращает полосу. Двойной щелчок по вкладке делает то же самое. В каком состоянии вы её оставили, запоминается для каждого редактора отдельно.

Сочетания клавиш внутри каждого редактора (формат по образцу, поиск и замена, операции с таблицами и т. д.) приведены в соответствующих главах; кроме того, в Docs есть диалог сочетаний клавиш с поиском (**⌘/**) (см. его главу).

## Сочетания Option+Command

Option+Command — это слой, который Word оставляет для структурированных переходов, и GenOffice заполняет его так же. Большую часть занимает Docs, Sheets — два собственных сочетания ради соответствия Excel, и одно сочетание работает везде.

**Docs**

| Сочетание (macOS) | Что делает               | Windows / Linux    |
| ----------------- | ------------------------ | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3   | Заголовок 1 / 2 / 3      | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0               | Обычный                  | Ctrl+Alt+0         |
| ⌥⌘M               | Абзац                    | Ctrl+Alt+M         |
| ⌥⌘A               | Создать примечание       | Ctrl+Alt+A         |
| ⌥⌘F               | Вставить сноску          | Ctrl+Alt+F         |
| ⌥⌘E               | Вставить концевую сноску | Ctrl+Alt+D         |
| ⌥⌘G               | Перейти                  | Ctrl+G             |

Два из них меняются на Windows — по той же причине, по которой Word их разделяет. **macOS занял ⌥⌘D**: он показывает и прячет Dock, поэтому концевая сноска на Mac — это ⌥⌘E, а во всех остальных местах — Ctrl+Alt+D. А **Перейти** просто убирает Alt: Ctrl+G, тогда как на Mac в сочетании он остаётся.

**Sheets**, когда сетка в фокусе

| Сочетание (macOS) | Что делает      | Windows / Linux |
| ----------------- | --------------- | --------------- |
| ⌥⌘0               | Внешние границы | Ctrl+Shift+7    |
| ⌥⌘−               | Нет границы     | Ctrl+Shift+−    |

Windows — это не переписывание пары с Mac. Excel для Mac даёт Sheets **оба** сочетания: ⌘⇧7 и ⌥⌘0 — два ключа для одних и тех же внешних границ, — поэтому в Windows команда сохраняет уже имевшуюся у неё позицию Ctrl+Shift, а слой Option просто отсутствует.

Обратите внимание: **⌥⌘0 означает «Обычный» в Docs и «Внешние границы» в Sheets**. Они никогда не появляются в одном редакторе, так что на практике ничего не конфликтует, но ⌥⌘0 уже занят и недоступен как глобальное сочетание.

**В каждом редакторе**: **⌥⌘R / Ctrl+F1** сворачивает ленту, как описано выше.

Так ⌥⌘D остаётся свободным, чтобы GenOffice использовала его на macOS, если какая-нибудь будущая команда его захочет.
