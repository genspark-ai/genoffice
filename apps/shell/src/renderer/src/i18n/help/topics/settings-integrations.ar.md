# الإعدادات واللغة والمظهر وتكاملات MCP

## فتح الإعدادات

صفّ الحساب في أسفل يسار الصفحة الرئيسية يفتح لوحة الإعدادات (ويقرأ «تسجيل الدخول» عندما تكون غير مسجّل الدخول). ولها ستة أقسام: الحساب، ونموذج الذكاء الاصطناعي، ووسائط الذكاء الاصطناعي والبحث، والعام، والتكاملات، وحول.

![الإعدادات ▸ عام، حيث تقع اللغة والمظهر والحفظ التلقائي ومفتاح إحصاءات الاستخدام](img/settings-general.png)

ولضبط النماذج فصل خاص به؛ أما **وسائط الذكاء الاصطناعي والبحث** فهو المكان الذي تشغّل من فيه، لكل مزوّد على حدة، توليد الصور وتحليل الصور وتحليل الفيديو والبحث في الويب والبحث في الملفات المحلية.

## اللغة

- تعرض الإعدادات **21 لغة للواجهة**: الإنجليزية، والصينية المبسّطة، واليابانية، والكورية، والفرنسية، والألمانية، والإسبانية، والتايلاندية، والإندونيسية، والروسية، والعربية، والبرتغالية، والإيطالية، والبولندية، والتشيكية، والهولندية، والماليزية، والعبرية، والهندية، والصينية التقليدية، والفيتنامية.
- يُطبَّق التبديل فورًا ويُحفظ؛ وتُعاد قائمة النظام بلغتها الجديدة.

## المظهر

فاتح / داكن / اتباع النظام. يتبع خيار اتباع النظام مظهر نظام التشغيل، وتتبدّل مظهر المحرّرات تزامنًا من دون وميض.

## ربط التطبيقات الافتراضية

يمكن في الإعدادات تسجيل GenOffice كتطبيق يفتح ملفات ‎.docx‎ و‎.xlsx‎ و‎.pptx‎ و‎.pdf‎ وما شابهها (تسجيل التطبيق الافتراضي على مستوى النظام؛ ويأكيد عند الطلب).

## إشعارات برامج الجهات الخارجية والتحديثات

- تعليمات ▸ إشعارات برامج الجهات الخارجية: قائمة كاملة برخص البرمجيات مفتوحة المصدر المرفقة مع التطبيق.
- تعليمات ▸ التحقق من التحديثات…: يشغّل فحصًا يدويًا؛ وإن توفّرت نسخة أحدث يعرض تثبيتها.

## تسجيل الدخول إلى Genspark

- مسار تسجيل الدخول (من الإعدادات أو من قائمة مشاريع السحابة) يتبع **رمز الجهاز**: يعرض GenOffice رمزًا ويفتح صفحة الدخول في المتصفح؛ ثم يتابع تلقائيًا بعد الانتهاء.
- لا يُستخدم تسجيل الدخول إلا لأمرين: قائمة مشاريع السحابة ونماذج Genspark المستضافة. وبدونه تبقى كل الميزات المحلية والنماذج المخصّصة تعمل.
- تسجيل الخروج بنقرة واحدة في الإعدادات.

## تكامل MCP (للمستخدمين المتقدمين / عملاء الذكاء الاصطناعي)

**التكاملات** هي اللوحة التي توصل GenOffice بوكيل برمجي، ولها مقال خاص بها: ربط وكيل برمجي. وباختصار — اختر مسارًا (سطر الأوامر، أو MCP)، واتبع ذلك القسم، ثم افتح محادثة جديدة واسأل.

![الإعدادات ▸ التكاملات: الخطوات الثلاث، ثم صفوف المهارات وخيارات MCP](img/settings-integrations.png)

وتحت **خادم HTTP محلي** تستطيع التطبيق أيضًا تشغيل الخادم بنفسه بدلًا من ترك ذلك للمساعد — مفتاح تشغيل ومنفذ — ويضيف قسم **متقدم** عنوان فحص الحالة وملف السجل. وهو يستمع على المضيف المحلي فقط.

## ورقة مرجعية لسطر الأوامر

| الأمر              | وظيفته                |
| ------------------ | --------------------- |
| `genoffice <file>` | فتح ملف               |
| `genoffice mcp`    | تشغيل خادم MCP المحلي |
| `genoffice --help` | كل الأوامر والخيارات  |
