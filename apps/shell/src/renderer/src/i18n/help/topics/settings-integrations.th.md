# การตั้งค่า ภาษา ธีม และการเชื่อมต่อ MCP

## การเปิดการตั้งค่า

แถวบัญชีที่มุมล่างซ้ายของหน้าแรกจะเปิดแผงการตั้งค่า (เมื่อยังไม่ได้ลงชื่อเข้าใช้ จะแสดงเป็น "ลงชื่อเข้าใช้") แผงนี้มีหกส่วน ได้แก่ บัญชี, โมเดล AI, สื่อ AI และการค้นหา, ทั่วไป, การเชื่อมต่อ และเกี่ยวกับ

![การตั้งค่า ▸ ทั่วไป ซึ่งเป็นที่ของภาษา ธีม การบันทึกอัตโนมัติ และสวิตช์สถิติการใช้งาน](img/settings-general.png)

การตั้งค่าโมเดลมีบทของตัวเอง ส่วนใน **สื่อ AI และการค้นหา** คุณจะเปิดใช้งานการสร้างภาพ การวิเคราะห์ภาพ การวิเคราะห์วิดีโอ การค้นหาเว็บ และการค้นหาไฟล์ในเครื่อง แยกตามผู้ให้บริการแต่ละราย

## ภาษา

- การตั้งค่ามี **ภาษาสำหรับส่วนติดต่อผู้ใช้ 21 ภาษา**: อังกฤษ, จีนตัวย่อ, ญี่ปุ่น, เกาหลี, ฝรั่งเศส, เยอรมัน, สเปน, ไทย, อินโดนีเซีย, รัสเซีย, อาหรับ, โปรตุเกส, อิตาลี, โปแลนด์, เช็ก, ดัตช์, มลายู, ฮีบรู, ฮินดี, จีนตัวเต็ม, เวียดนาม
- การเปลี่ยนภาษามีผลทันทีและคงอยู่ถาวร แถบเมนูของระบบจะสร้างใหม่ตามภาษานั้น

## ธีม

สว่าง / มืด / ตามระบบ โหมดตามระบบจะเปลี่ยนตามรูปลักษณ์ของระบบปฏิบัติการ และพื้นที่แก้ไขจะเปลี่ยนสีตามโดยไม่กะพริบ

## การผูกแอปเริ่มต้น

การตั้งค่าสามารถลงทะเบียนให้ GenOffice เป็นโปรแกรมที่เปิดไฟล์ .docx / .xlsx / .pptx / .pdf และไฟล์อื่น ๆ ได้ (การลงทะเบียนแอปเริ่มต้นระดับระบบปฏิบัติการ โดยต้องยืนยันเมื่อระบบถาม)

## การแจ้งซอฟต์แวร์ของบุคคลที่สามและการอัปเดต

- วิธีใช้ ▸ ประกาศเกี่ยวกับซอฟต์แวร์ของบุคคลที่สาม: รายการสัญญาอนุญาตโอเพนซอร์สทั้งหมดที่มาพร้อมแอป
- วิธีใช้ ▸ ตรวจหาการอัปเดต…: เรียกการตรวจสอบด้วยตนเอง หากมีเวอร์ชันใหม่จะแจ้งให้ติดตั้ง

## การลงชื่อเข้าใช้ Genspark

- จุดเข้าใช้งานการลงชื่อเข้าใช้ (ในการตั้งค่าหรือที่รายการโปรเจกต์บนคลาวด์) ใช้ขั้นตอนแบบ **รหัสอุปกรณ์**: GenOffice จะแสดงรหัสและเปิดหน้าเข้าสู่ระบบในเบราว์เซอร์ แล้วดำเนินต่ออัตโนมัติเมื่อเสร็จ
- การลงชื่อเข้าใช้มีไว้เพื่อ: รายการโปรเจกต์บนคลาวด์และโมเดลของ Genspark เท่านั้น หากไม่ลงชื่อเข้าใช้ คุณสมบัติในเครื่องทั้งหมดและโมเดลที่กำหนดเองยังทำงานได้ตามปกติ
- การออกจากระบบทำได้ในการตั้งค่าด้วยคลิกเดียว

## การเชื่อมต่อ MCP (สำหรับผู้ใช้ขั้นสูง / ไคลเอ็นต์ AI)

**การเชื่อมต่อ** คือแผงที่เชื่อม GenOffice เข้ากับเอเจนต์เขียนโค้ด และมีบทของตัวเองอยู่: การเชื่อมต่อเอเจนต์เขียนโค้ด สรุปสั้น ๆ คือ— เลือกเส้นทาง (บรรทัดคำสั่ง หรือ MCP) แล้วทำตามส่วนนั้น จากนั้นเริ่มแชทใหม่แล้วถาม

![การตั้งค่า ▸ การเชื่อมต่อ: สามขั้นตอน จากนั้นเป็นแถวสกิลและตัวเลือก MCP](img/settings-integrations.png)

ภายใต้ **เซิร์ฟเวอร์ HTTP ในเครื่อง** แอปยังสามารถสั่งให้เซิร์ฟเวอร์ทำงานเองได้ — สวิตช์เปิดใช้งานและพอร์ต — และ **ขั้นสูง** จะเพิ่ม URL ของการตรวจสอบสถานะกับไฟล์ปูม แทนที่จะปล่อยให้ผู้ช่วยเป็นผู้ทำ โดยรับฟังเฉพาะในเครื่อง

## ตารางคำสั่งแบบเรียบด่วน

| คำสั่ง             | ทำอะไร                         |
| ------------------ | ------------------------------ |
| `genoffice <file>` | เปิดไฟล์                       |
| `genoffice mcp`    | เริ่มเซิร์ฟเวอร์ MCP ในเครื่อง |
| `genoffice --help` | คำสั่งและตัวเลือกทั้งหมด       |
