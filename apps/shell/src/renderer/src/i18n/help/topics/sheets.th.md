# Sheets: สเปรดชีต

Sheets คือตัวแก้ไขที่ทำงานคล้าย Excel การคำนวณทำงานในกระบวนการแยกของเอนจิน Rust (ถ้าตัวนั้นล่มก็ไม่เคยทำให้ทั้งแอปล่ม) เปิดและบันทึกเป็น .xlsx ของจริง ส่วน .csv และ .tsv จะเปิดขึ้นมาเป็นตาราง

## ส่วนติดต่อผู้ใช้

- **แถบเครื่องมือ**: แปดแท็บ อธิบายทีละแท็บด้านล่าง
- **แถบสูตร**: แสดงและแก้ไขสูตรของเซลล์ที่เลือกอยู่ รองรับฟังก์ชันที่ใช้ทั่วไป
- **แท็บชีต** (ด้านล่าง): เพิ่ม / เปลี่ยนชื่อ / ลบ / ย้ายชีต
- **การแก้ไขเซลล์**: ดับเบิลคลิกหรือพิมพ์เข้าไปเลยก็ได้ Enter เพื่อยืนยันและเลื่อนลง Tab เพื่อเลื่อนขวา Esc เพื่อยกเลิก (ตามความเคยชินของ Excel)
- **แป้นพิมพ์ลัด**: จัดให้ตรงกับตระกูล Excel (ctrl+C/V/X, ctrl+Z/Y, ctrl+F, ...)

## แท็บในแถบเครื่องมือ

- **หน้าแรก**: แบบอักษร, สีเติม, เส้นขอบ, รูปแบบตัวเลข (สกุลเงิน/เปอร์เซ็นต์/หลักพัน, เพิ่ม-ลดจำนวนทศนิยม), การจัดแนว, ผสานเซลล์, เพิ่มแถว/คอลัมน์และปรับขนาด, การจัดรูปแบบตามเงื่อนไข, จัดรูปแบบเป็นตาราง, สไตล์เซลล์, คลิปบอร์ดและตัวคัดวางรูปแบบ, เรียงลำดับและกรอง
- **แทรก**: รูปร่าง, ไอคอน, สัญลักษณ์, สมการ, ภาพหน้าจอ และอื่น ๆ
- **เค้าโครงหน้ากระดาษ**: สีและแบบอักษรของธีม, สวิตช์เส้นตาราง/หัวข้อที่พิมพ์, ตัวอย่างตัวแบ่งหน้า
- **สูตร**: ผลรวมอัตโนมัติและการแทรกฟังก์ชัน, กำหนดชื่อ (รวมถึงจากส่วนที่เลือก), แกะรอยเซลล์ที่ถูกอ้าง/เซลล์ที่อ้างถึง, หน้าต่างเฝ้าดู, คำนวณชีต/สมุดงานใหม่
- **ข้อมูล**: เรียงลำดับและกรอง (รวมการกรองขั้นสูงและการล้างตัวกรอง), แปลงข้อความเป็นคอลัมน์, รวมเวิร์กบุ๊ก, รีเฟรชทั้งหมด
- **รีวิว**: เปิดดูข้อคิดเห็น (แสดง, ก่อนหน้า/ถัดไป), แปล
- **มุมมอง**: สวิตช์เส้นตารางและหัวข้อ, ซูม, มุมมองปกติ/ตัวอย่างตัวแบ่งหน้า
- **การออกแบบแผนภูมิ**: ปรากฏเมื่อเลือกแผนภูมิไว้ — ประเภทแผนภูมิ, สไตล์และสี, แก้ไขช่วงข้อมูล

แท็บข้อมูล ไล่ดูทีละปุ่ม (จากซ้ายไปขวาในภาพ):

![แท็บข้อมูล](img/sheets-data.png)

- **ตาราง Pivot**: สร้างตารางสรุปจากช่วงข้อมูลปัจจุบัน ลากฟิลด์มารวมค่า
- **รีเฟรช**: คำนวณข้อมูลของตาราง Pivot ปัจจุบันใหม่
- **จากข้อความ/CSV**: นำเข้าไฟล์ .csv/.txt เป็นชีตใหม่ โดยแยกตามตัวคั่น
- **รวมเวิร์กบุ๊ก**: ดึงชีตจากไฟล์ .xlsx อื่นเข้ามาในไฟล์นี้
- **รีเฟรชทั้งหมด**: คำนวณตาราง Pivot ทุกอันและชุดข้อมูลภายนอกใหม่ทั้งหมด
- **เรียงลำดับ** (เมนูแบบดรอปดาวน์): จากน้อยไปมาก / จากมากไปน้อย / เรียงลำดับแบบกำหนดเอง (กฎหลายคอลัมน์)
- **กรอง**: เพิ่มปุ่ม ▼ ในแถวหัวตาราง ให้ติ๊กค่าที่ต้องการคงไว้
- ปุ่มซ้อนกันขนาดเล็กข้าง ๆ: **ล้าง** (ดึงทุกแถวกลับมา), **นำไปใช้ใหม่** (รันตัวกรองปัจจุบันอีกครั้ง), **ขั้นสูง** (กรองด้วยช่วงเงื่อนไข)
- **ข้อความเป็นคอลัมน์** (เมนูแบบดรอปดาวน์): แยกหนึ่งคอลัมน์ออกเป็นหลายคอลัมน์ตามตัวคั่นหรือความกว้างคงที่
- **เติมข้อมูลอัตโนมัติ**: ให้ตัวอย่างหนึ่งรายการ ที่เหลือในคอลัมน์จะเติมตามรูปแบบ (ctrl+E)
- **เอาค่าที่ซ้ำกันออก**: ตัดแถวที่ซ้ำกันตามคอลัมน์ที่เลือก
- **การตรวจสอบความถูกต้องของข้อมูล** (เมนูแบบดรอปดาวน์): กำหนดกฎการป้อนค่าของส่วนที่เลือก (รายการแบบดรอปดาวน์, ช่วงตัวเลข...)
- **รวมข้อมูล**: รวมหลายช่วงเข้าด้วยกันตามหมวดหมู่
- **การวิเคราะห์แบบ What-If** (เมนูแบบดรอปดาวน์): ค้นหาค่าเป้าหมาย / ตารางข้อมูล
- **จัดกลุ่ม / ยกเลิกการจัดกลุ่ม** (เมนูแบบดรอปดาวน์): จัดกลุ่มแถว/คอลัมน์พร้อมพับและขยาย
- **ผลรวมย่อย**: แทรกแถวผลรวมย่อยแยกตามหมวดหมู่

แท็บสูตร ไล่ดูทีละปุ่ม:

![แท็บสูตร](img/sheets-formulas.png)

- **แทรกฟังก์ชัน** (fx): ค้นหาฟังก์ชันพร้อมตัวช่วยกรอกอาร์กิวเมนต์
- **ผลรวมอัตโนมัติ** (เมนูแบบดรอปดาวน์): SUM คลิกเดียว พร้อมค่าเฉลี่ย/จำนวนนับ/สูงสุด/ต่ำสุด
- **ใช้ล่าสุด / การเงิน / ตรรกะ / ข้อความ / วันที่และเวลา / การค้นหาและการอ้างอิง / คณิตศาสตร์และตรีโกณมิติ / อื่น ๆ**: เลือกดูและแทรกฟังก์ชันตามหมวด
- **ตัวจัดการชื่อ**: ดู สร้าง และลบช่วงข้อมูลที่ตั้งชื่อไว้
- **กำหนดชื่อ** (เมนูแบบดรอปดาวน์): ตั้งชื่อให้ส่วนที่เลือก **ใช้ในสูตร** จะแทรกชื่อที่มีอยู่ **สร้างจากส่วนที่เลือก** จะตั้งชื่อช่วงข้อมูลจากแถว/คอลัมน์หัวของช่วงนั้น
- **แกะรอยเซลล์ที่ถูกอ้าง / แกะรอยเซลล์ที่อ้างถึง**: ลูกศรสีฟ้าแสดงที่มาของข้อมูลในสูตรและปลายทางที่สูตรส่งไปเลี้ยง **เอาลูกศรออก** เพื่อลบ
- **แสดงสูตร**: เซลล์จะแสดงตัวสูตรเองแทนที่จะแสดงผลลัพธ์
- **การตรวจสอบข้อผิดพลาด**: ค้นหาและอธิบายข้อผิดพลาดของสูตร
- **หน้าต่างเฝ้าดู**: ตรึงเซลล์ที่คุณสนใจไว้แล้วดูค่าปัจจุบันแบบสด ๆ
- **ตัวเลือกการคำนวณ** (เมนูแบบดรอปดาวน์): คำนวณอัตโนมัติหรือด้วยตนเอง ในโหมดด้วยตนเองให้ใช้ **คำนวณทันที / คำนวณแผ่นงาน** เป็นตัวสั่งเอง

## ตัวเลขและรูปแบบ

- รูปแบบตัวเลข: ทั่วไป, ตัวเลข, สกุลเงิน, เปอร์เซ็นต์, วันที่และเวลา, เศษส่วน, วิทยาศาสตร์ และอื่น ๆ
- การจัดแนว, การตัดข้อความ, การผสานเซลล์, เส้นขอบและสีเติม
- ปรับความสูงแถวและความกว้างคอลัมน์ด้วยการลาก ดับเบิลคลิกที่เส้นแบ่งเพื่อให้พอดีกับเนื้อหาอัตโนมัติ

## ข้อมูล

**เรียงลำดับและกรอง** (ตัวอย่างเรียงคอลัมน์หนึ่งจากมากไปน้อย):

1. คลิกที่ **เซลล์ใดก็ได้ในคอลัมน์นั้น** (ไม่ต้องเลือกทั้งคอลัมน์)
2. แท็บหน้าแรก ▸ **เรียงลำดับและกรอง** ▸ **จากมากไปน้อย** แถวทั้งแถวจะเรียงใหม่พร้อมกัน (พื้นที่ทั้งก้อนถูกเรียงเป็นหนึ่งเดียว)
3. ถ้าต้องการกฎของตัวเอง (หลายคอลัมน์, ตามสี): ใช้เส้นทางเดียวกันแล้วเลือก **เรียงลำดับแบบกำหนดเอง**
4. การกรอง: เลือกแถวหัวตารางแล้วคลิก **เรียงลำดับและกรอง ▸ กรอง** แต่ละหัวตารางจะมีปุ่ม ▼ ให้ติ๊กค่าที่ต้องการคงไว้ ล้างตัวกรองเพื่อดึงทุกอย่างกลับมา

- เรียงลำดับและกรอง
- ตรึงแนว
- .csv / .tsv: เปิดเป็นตารางได้ทันที (ไฟล์ tsv ที่คั่นด้วยแท็บจะถูกตีความเป็นหนึ่งตาราง) การบันทึกจะเขียนกลับเป็นรูปแบบเดิม

## เมนูคลิกขวา

- **ในตาราง**: เมนูของตัวแก้ไขเอง (Univer) — ตัด/คัดลอก/วาง, แทรกและลบแถว/คอลัมน์, ซ่อน, ผสานเซลล์, ตรึงแนว และรายการใช้งานทั่วไปอื่น ๆ
- **ที่แถบสถานะด้านล่าง**: เลือกว่าจะให้แถบสถานะแสดงสถิติใด (ค่าเฉลี่ย / จำนวนนับ / ผลรวม, ...) ตัวเลือกจะถูกจดจำไว้
- **ที่แท็บชีตด้านล่าง**: เพิ่ม / เปลี่ยนชื่อ / ลบ / ตั้งสี / ซ่อนชีต (เมนูแท็บของ Univer)
- เมนูคลิกขวาของแถบแท็บด้านบนอยู่ในบท [แท็บและการจัดการหน้าต่าง](help://tabs-and-windows)

## ตัวแก้ไขสคริปต์ (ขั้นสูง)

Sheets มี **ตัวแก้ไขสคริปต์** ที่ใช้ API รูปแบบเดียวกับ Google Apps Script สำหรับงานเป็นชุด

- เปิดใช้งาน: เครื่องมือ ▸ ตัวแก้ไขสคริปต์ (หรือเมนูสำหรับนักพัฒนา ขึ้นอยู่กับเวอร์ชัน)
- หน้าจอ: คลังสคริปต์ทางซ้าย (สร้างใหม่/ลบ), ตัวแก้ไขโค้ดและบานผลลัพธ์ทางขวา พร้อมปุ่ม **เรียกใช้ / หยุด**
- API เป็นแบบอะซิงโครนัส:

```js
const sheet = await SpreadsheetApp.getActiveSpreadsheet()
const active = await sheet.getActiveSheet()
const range = await active.getRange('A1:C10')
const values = await range.getValues() // อาร์เรย์สองมิติ
await range.setValues(values.map((row) => row.map((v) => v * 2)))
Logger.log('done')
```

- `SpreadsheetApp` (จุดเริ่มต้น), `Sheet` (getName/getRange/getLastRow...), `Range` (getValue(s)/setValue(s)/clear...), `Logger.log`, `Utilities.sleep`
- สคริปต์ทำงานใน **เวิร์กเกอร์แบบแซนด์บ็อกซ์**: ไม่มีเครือข่าย ไม่มีระบบไฟล์ ไม่มี DOM — แตะได้แค่ API ข้างต้น สคริปต์ที่เขียนพลาดหรือไม่เป็นมิตรจึงเข้าถึงสิ่งอื่นไม่ได้
- บานผลลัพธ์จำกัดจำนวนบรรทัดไว้ เพื่อไม่ให้บันทึกจำนวนมากทำให้หน้าจอค้าง
- **AI เรียกสคริปต์ได้เช่นกัน**: เครื่องมือ `run_script` ของผู้ช่วยเรียกใช้ API แบบแซนด์บ็อกซ์ชุดเดียวกัน เหมาะกับการแก้ข้อมูลเป็นชุดตามกฎ

## AI

- แผง AI ด้านข้าง: เลือกช่วงข้อมูลแล้วสั่งงานเป็นภาษาธรรมชาติ (จัดรูปแบบใหม่, สร้างข้อมูล, เขียนสูตร)
- การแก้ไขของ AI เลื่อนกลับได้จากแผง

## การบันทึกและการส่งออก

- บันทึกเป็น .xlsx (สูตรและรูปแบบยังคงอยู่) มีคำสั่ง บันทึกเป็น… และการส่งออกเป็น PDF จะทำตามการแบ่งหน้าสำหรับพิมพ์
- บันทึกอัตโนมัติเป็นไปตามกฎรวม (เปิดหลังบันทึกด้วยตนเองครั้งแรก)

## เสถียรภาพ

- ส่วนประกอบเครื่องคำนวณของ Rust แยกกระบวนการออกจากส่วนติดต่อผู้ใช้ หากข้อมูลรุนแรงจนทำให้มันหยุดทำงาน คุณจะได้รับข้อความและความพยายามกู้คืนเซสชัน ไม่ใช่แอปที่ล่ม
