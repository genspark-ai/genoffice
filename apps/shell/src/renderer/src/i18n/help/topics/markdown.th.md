# ตัวแก้ไข Markdown

ตัวแก้ไข Markdown เปิดไฟล์ .md / .markdown แบบมีทั้งซอร์สและตัวอย่างที่เรนเดอร์แล้ว

- **เปิด**: จากหน้าแรกหรือเมนู ไฟล์ ▸ เปิด… และใช้บรรทัดคำสั่งก็ได้
- **แก้ไข**: แก้ไขเป็นข้อความธรรมดา ส่วนขยาย GFM (ตาราง, รายการงาน, ขีดฆ่า, ลิงก์อัตโนมัติ) จะเรนเดอร์ในตัวอย่าง
- **ตัวอย่าง**: เรนเดอร์แบบเรียลไทม์ ทรัพยากรที่อ้างอิงแบบสัมพัทธ์ เช่นรูปภาพ จะหาได้จากตำแหน่งข้างเอกสาร
- **การบันทึก**: รักษาไฟล์แบบ byte-faithful — BOM, CRLF และการมีบรรทัดใหม่ท้ายไฟล์จะถูกคงไว้ทั้งหมด การบันทึกที่ไม่ได้แก้อะไรจะไม่เขียนไฟล์ซ้ำ
- **ค้นหาและแทนที่**: ctrl+F ค้นหาในซอร์ส และ แทนที่ทั้งหมด จะเขียนกลับเข้าไฟล์
- **AI**: ปุ่มตั้งค่าล่วงหน้าให้ผู้ช่วยเขียนใหม่ ขยาย หรือแปลเอกสาร

## แถบเครื่องมือ

แถวปุ่มหนึ่งแถวเหนือพื้นที่แก้ไข (เอามาส์ชี้เหนือเพื่อดูคำอธิบาย):

![แถบเครื่องมือ Markdown](img/md-toolbar.png)

- **ไฟล์และประวัติ**: บันทึก, บันทึกเป็น…, เลิกทำ, ทำซ้ำ, ค้นหา สวิตช์ **บันทึกอัตโนมัติ** ทางขวาจะเขียนการเปลี่ยนแปลงลงดิสก์ตามเวลาที่กำหนด
- **ปุ่ม AI**: เปิดแผง AI ข้าง ๆ กันคือข้อเสนอสำหรับการเขียนใหม่/ขยาย/แปล
- **สไตล์ย่อหน้า** (เมนูแบบดรอปดาวน์): สลับระหว่างเนื้อความกับระดับหัวเรื่อง
- **รูปแบบในบรรทัด**: **ตัวหนา**, _ตัวเอียง_, ~~ขีดฆ่า~~, `โค้ดในบรรทัด`, ลิงก์
- **รายการ**: รายการสัญลักษณ์, รายการลำดับเลข, รายการงาน
- **แทรก**: ตาราง, รูปภาพ, เส้นคั่นแนวนอน
- **คุณสมบัติ**: แทรกหรือกระโดดไปยังบล็อก YAML front matter ที่ด้านบนของไฟล์
- **สารบัญ**: กระโดดตามลำดับชั้นของหัวเรื่อง
- **ตรวจการสะกด**: เปิดหรือปิดการตรวจการสะกดของเอกสารนี้

ตัวอย่างสามข้อที่ใช้บ่อย:

- **หัวเรื่อง**: วางเคอร์เซอร์ไว้ที่บรรทัดนั้น ▸ เมนูสไตล์ย่อหน้า ▸ "หัวเรื่อง 1"
- **ตาราง**: คลิก **แทรกตาราง** ▸ ลากเพื่อเลือกจำนวนแถว/คอลัมน์ ▸ พิมพ์ลงในเซลล์ ตัวอย่างจะเรนเดอร์ทันที
- **รายการงาน**: เลือกหลายบรรทัด ▸ คลิก **รายการงาน** ▸ แต่ละบรรทัดจะกลายเป็น `- [ ]` และในตัวอย่างจะแสดงเป็นช่องเครื่องหมายถูก
