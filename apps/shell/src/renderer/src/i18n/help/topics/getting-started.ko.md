# 빠른 시작: 인터페이스와 기본 조작

GenOffice는 전적으로 내 컴퓨터에서 동작하는 오피스 스위트입니다. 창 하나, 탭 한 줄에 6개의 편집기가 들어 있습니다. 문서(Docs), 스프레드시트(Sheets), 프레젠테이션(Slides), PDF, Markdown, HTML입니다. 다루는 파일은 진짜 .docx / .xlsx / .pptx / .pdf이며 Word, Excel, PowerPoint와 완전히 호환됩니다. 네트워크는 필요 없습니다.

## 화면 개요

![홈 화면](img/home-screen.png)

창은 세 부분으로 나뉩니다.

- **탭 바(위)**: 열려 있는 파일마다 탭 하나가 됩니다. 맨 왼쪽 홈 탭은 항상 있으며 닫을 수 없습니다. 나머지 탭은 내가 연 문서입니다. 탭을 더블클릭하면 파일 이름을 그 자리에서 바꿀 수 있습니다.
- **콘텐츠 영역**: 활성 탭에 해당하는 편집기(또는 홈).
- **메뉴**: macOS에서는 시스템 메뉴, Windows/Linux에서는 창 상단에 있습니다. 파일/편집/보기 메뉴는 현재 탭의 편집기에 맞춰 바뀝니다.

## 문서 만들기

아래 방법 중 하나를 쓰면 됩니다.

- **홈**의 [빠른 시작](help://getting-started) 영역에 있는 빠른 생성 카드(AI Docs, AI Sheets, AI Slides 등)를 누릅니다.
- 메뉴 **파일 ▸ 새로 만들기**: Docs(⌘N/ctrl+N), Sheets, Slides, Markdown, HTML, PDF.
- 파일을 창으로 끌어다 놓거나, 파일 관리자에서 더블클릭합니다(GenOffice가 기본 앱으로 설정된 경우).

새 문서는 이름 없는 상태로 열리고, 디스크의 파일은 처음 저장할 때 비로소 만들어집니다.

## 파일 열기

- 메뉴 **파일 ▸ 열기**(⌘O/ctrl+O)는 시스템 선택 창을 엽니다. .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html을 지원합니다.
- 홈의 **최근 사용** 목록에서 아무 항목이나 누릅니다.
- 터미널에서 `genoffice <file>`을 실행해도 열 수 있습니다.

## 저장 방식

- **수동 저장**: ⌘S/ctrl+S, 또는 파일 ▸ 저장 / 다른 이름으로 저장. 첫 저장에서는 위치와 이름을 묻습니다.
- **자동 저장**은 같은 파일을 한 번이라도 수동으로 저장한 뒤에만 켜집니다. 읽기만 하는 PDF가 조용히 다시 쓰이는 일은 없습니다. 자동 저장은 내용이 바뀐 뒤 잠시 지나면 실행됩니다.
- 저장하지 않은 변경이 있는 탭을 닫으려고 하면 먼저 저장/삭제/취소 중 무엇을 할지 묻습니다.
- 모든 쓰기는 아토믹입니다(임시 파일에 쓴 뒤 이름 변경). 전원이 끊겨도 반쪽짜리 파일이 남지 않습니다.

## 자주 쓰는 단축키

| 동작           | macOS | Windows / Linux |
| -------------- | ----- | --------------- |
| 새 문서        | ⌘N    | ctrl+N          |
| 열기           | ⌘O    | ctrl+O          |
| 저장           | ⌘S    | ctrl+S          |
| 탭 닫기        | ⌘W    | ctrl+W          |
| 이 매뉴얼 열기 | F1    | F1              |
| 리본 축소      | ⌥⌘R   | Ctrl+F1         |

**리본 축소**는 모든 편집기에서 동작합니다. 탭 행은 그대로 두고 그 아래 명령 밴드만 숨겨집니다. 선택된 탭이 축소 조작까지 겸하므로, 리본이 축소된 동안에는 선택된 탭이 없고 어떤 탭을 눌러도 밴드가 다시 나타납니다. 탭을 두 번 클릭해도 같습니다. 어느 쪽으로 남겨 두었는지는 편집기마다 따로 기억됩니다.

각 편집기 내부의 단축키(서식 복사, 찾아바꾸기, 표 조작 등)는 각 장에서 설명합니다. Docs에는 모든 단축키를 검색할 수 있는 키보드 바로 가기 대화상자도 있습니다(**⌘/**)(Docs 장 참고).

## Option+Command 단축키

Option+Command는 Word가 구조화된 점프를 위해 남겨 둔 계층이고, GenOffice도 같은 방식으로 채웁니다. 그중 대부분은 Docs가 차지하고, Sheets는 Excel과 같은 동작을 위해 자기 것 두 개를 차지합니다. 어디서나 통하는 조합도 하나 있습니다.

**Docs**

| 단축키 (macOS)  | 하는 일        | Windows / Linux    |
| --------------- | -------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 제목 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 표준           | Ctrl+Alt+0         |
| ⌥⌘M             | 단락           | Ctrl+Alt+M         |
| ⌥⌘A             | 새 메모        | Ctrl+Alt+A         |
| ⌥⌘F             | 각주 삽입      | Ctrl+Alt+F         |
| ⌥⌘E             | 미주 삽입      | Ctrl+Alt+D         |
| ⌥⌘G             | 이동           | Ctrl+G             |

그중 둘은 Windows에서 달라집니다. Word가 둘로 갈라 놓은 것과 같은 이유입니다. **⌥⌘D는 macOS의 것**으로, Dock을 보이게 했다가 감추는 단축키입니다. 그래서 미주는 Mac에서는 ⌥⌘E이고 그 밖의 곳에서는 Ctrl+Alt+D입니다. 그리고 **이동**은 Alt를 뗍니다. Mac 단축키가 Alt를 그대로 갖고 있는 것과 달리 Windows에서는 Ctrl+G면 됩니다.

**Sheets** — 그리드에 포커스가 있을 때

| 단축키 (macOS) | 하는 일       | Windows / Linux |
| -------------- | ------------- | --------------- |
| ⌥⌘0            | 바깥쪽 테두리 | Ctrl+Shift+7    |
| ⌥⌘−            | 테두리 없음   | Ctrl+Shift+−    |

Windows가 Mac 쪽 두 개를 그대로 옮긴 것은 아닙니다. Excel for Mac이 Sheets에 **둘 다**를 줍니다 — ⌘⇧7과 ⌥⌘0은 같은 바깥쪽 테두리를 두는 두 가지 키입니다 — 그래서 Windows에서는 이 명령이 원래 쓰던 Ctrl+Shift 자리를 그대로 유지하고, Option 계층은 아예 없습니다.

**⌥⌘0은 Docs에서는 표준, Sheets에서는 바깥쪽 테두리**라는 점을 기억해 두세요. 둘이 같은 편집기에 함께 나타나는 일은 없으므로 실제로 충돌하지는 않지만, ⌥⌘0은 이미 사용 중이어서 전역 단축키로 쓸 수 없습니다.

**모든 편집기**: **⌥⌘R / Ctrl+F1** — 위에서 설명한 대로 리본을 축소합니다.

그래서 macOS에서 ⌥⌘D는 GenOffice가 쓸 수 있도록 비워 두어집니다. 앞으로 어떤 명령이 필요로 하더라도요.
