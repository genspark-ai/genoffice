# บรรทัดคำสั่งและเอเจนต์

ทุกการติดตั้งมีคำสั่ง `genoffice` ที่ใช้เอนจินชุดเดียวกับหน้าต่าง ตัวแยกเอกสารชุดเดียวกัน ตัวเขียนไฟล์ชุดเดียวกัน ตัวเรนเดอร์ชุดเดียวกัน ไฟล์ที่แอปบันทึกกับไฟล์ที่คำสั่งเขียน คือไฟล์เดียวกัน และการตรวจที่ผ่านในแผง AI ก็คือการตรวจที่คำสั่งผ่านเช่นกัน

```sh
genoffice --help          # every command
genoffice guide slides    # the op reference, for writing your own
```

นั่นคือทั้งหมดในหน้าจอเดียว — ทุกคำสั่งมีบรรทัดบอกว่ามันทำอะไร ตามด้วยตัวเลือกทั่วไปและรหัสการจบการทำงาน:

![ผลลัพธ์จริงของ genoffice --help: แบนเนอร์เวอร์ชัน ทุกคำสั่งพร้อมคำอธิบายหนึ่งบรรทัด และตัวเลือกทั่วไปกับรหัสการจบการทำงาน](img/cli.png)

## หาคำสั่งมาใช้

macOS และ Windows แถมคำสั่งนี้ไว้ในแพ็กเกจของแอป ถ้าอยากเรียกด้วยชื่อ ให้รัน `genoffice install-cli` ครั้งเดียว คำสั่งจะสร้างลิงก์ไปยังไฟล์ไบนารีที่แถมมาไว้ใน `/usr/local/bin` หรือใน `PATH` ของผู้ใช้บน Windows

## คำสั่งที่ควรรู้จัก

| คำสั่ง            | ทำอะไร                                                                                                                                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open`            | เปิดเอกสารในแอป ถ้ายังไม่ได้รันก็จะสั่งให้แอปเริ่มทำงาน                                                                                                                                                 |
| `selection`       | สิ่งที่ผู้ใช้เลือกไว้ในไฟล์นั้น ณ ตอนนี้ ขณะที่แอปยังทำงานอยู่ นี่คือตัวชี้ของ "ตัวนี้" / "ตรงนี้" คำสั่งนี้คืนช่วงบล็อก ช่วงเซลล์ในชีต องค์ประกอบของสไลด์ หรือหนึ่งหน้า ตามตัวแก้ไขที่เปิดไฟล์นั้นอยู่ |
| `convert`         | แปลงรูปแบบโดยใช้เอนจินของตัวแอปเอง                                                                                                                                                                      |
| `create`          | สร้างเอกสารจากเนื้อหาที่มีโครงสร้าง                                                                                                                                                                     |
| `render`          | ได้ PNG หนึ่งไฟล์ต่อหนึ่งหน้า ตามที่ตัวเรนเดอร์วางหน้ากระดาษ                                                                                                                                            |
| `pdf`             | อ่านชั้นข้อความของ PDF ทีละหน้า โดยไม่ต้องเปิดโปรแกรม                                                                                                                                                   |
| `info`            | ข้อมูลเมตาดาต้าและสรุปโครงสร้างของเอกสาร                                                                                                                                                                |
| `search`          | ค้นบนเว็บหรือค้นรูป ผ่านผู้ให้บริการที่ตั้งค่าไว้ในแอป                                                                                                                                                  |
| `image` / `media` | สร้างรูป หรืออธิบายและถามคำถามเกี่ยวกับไฟล์รูป วิดีโอ หรือเสียง                                                                                                                                         |
| `merge`           | เติมค่าในตัวแทน `{{key}}` ของเทมเพลต `.docx`, `.pptx` หรือ `.xlsx`                                                                                                                                      |
| `capabilities`    | บอกว่าเครื่องนี้ตั้งค่าฟีเจอร์บนคลาวด์อะไรไว้บ้าง                                                                                                                                                       |
| `guide`           | คู่มือ op และแนวทางการออกแบบ สร้างจากนิยามชุดเดียวกับที่ตัว executor ใช้ตรวจ จึงเลื่อนจากสิ่งที่ `apply` รับได้ไม่ได้ `--json` จะคืนคู่มือพร้อมสคีมาของแต่ละ op                                         |
| `install-cli`     | เอา `genoffice` ไปไว้ใน `PATH`                                                                                                                                                                          |
| `skill`           | รายชื่อเอเจนต์เขียนโค้ดที่เจอบนเครื่องนี้ และติดตั้งหรืออัปเดต skill ของ GenOffice เข้าไปในเอเจนต์เหล่านั้น                                                                                             |
| `mcp`             | เปิดทุกคำสั่งเป็นเครื่องมือ Model Context Protocol ดู **การเชื่อมต่อเอเจนต์เขียนโค้ด**                                                                                                                  |

## การแก้ไข เอกสาร ชีต และสไลด์

`genoffice docs`, `genoffice sheet` และ `genoffice slides` อ่านและเขียนผ่านช่องทางเดียวกับที่แอปใช้ และใช้คำศัพท์ชุดเดียวกัน **op** คือการแก้ไขหนึ่งครั้ง ส่วน **spec** คือรายการของ op ที่จะถูกใช้ตามลำดับ

```sh
genoffice sheet read report.xlsx
genoffice slides apply deck.pptx --ops ops.json --dry-run
genoffice docs apply brief.docx --ops ops.json
```

`--dry-run` จะบอกว่าชุดงานนี้จะทำอะไร และไม่เขียนอะไรลงเลย นี่คือวิธีที่ถูกในการตรวจสอบ spec ก่อนใช้จริง แผง AI ในแอปทำงานบน op ชุดนี้พอดี คุณสั่งมันได้อะไร ก็เขียนสคริปต์ให้มันทำได้อะไร

## Model Context Protocol

`genoffice mcp` จะเปิดทุกคำสั่งเป็นเครื่องมือ MCP ส่วน `genoffice mcp install <agent|all>` จะลงทะเบียนไว้ในค่าตั้งของเอเจนต์เขียนโค้ดแต่ละตัว เรื่องฝั่งนั้นดู **การเชื่อมต่อเอเจนต์เขียนโค้ด**

## สิ่งที่คำสั่งนี้ทำไม่ได้

คำสั่งนี้อ่านและเขียนไฟล์ได้ แต่มันไม่ใช่แอป ไม่มีหน้าต่าง และกล่องอัปเดตในแอปก็ใช้ไม่ได้ สิ่งที่ต้องใช้หน้าต่าง เช่น แผง AI หรือการตรวจคุณภาพสไลด์ที่เรนเดอร์แล้ว ต้องรอคุณเปิดไฟล์ก่อน `genoffice render` ให้ค่าพิกเซลได้โดยไม่ต้องมีหน้าต่าง ส่วน `genoffice slides` ตรวจเลย์เอาต์ของงานนำเสนอเองได้
