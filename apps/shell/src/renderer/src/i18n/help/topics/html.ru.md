# Редактор HTML

Редактор HTML открывает .html / .htm в двух режимах: **предпросмотр** (отрендеренная страница) и **исходник**.

- **Предпросмотр**: настоящий рендеринг; относительные таблицы стилей и картинки загружаются рядом с файлом.
- **Инспектор предпросмотра**: щёлкните, чтобы выбрать элемент, дважды щёлкните, чтобы отредактировать его текст на месте, удалите через панель инструментов и спросите ИИ о выделенном.
- **Режим исходника**: правка HTML; ctrl+F для поиска, а «Заменить» сохраняет переписанную разметку.
- **Сохранение**: побайтово верное (BOM/CRLF/завершающий перевод строки сохраняются); сохранение без изменений ничего не переписывает.
- **Масштаб**: ctrl+колесо или щипок масштабирует предпросмотр; ctrl+Z внутри предпросмотра отменяет последнюю правку.

## Панель инструментов

Щёлкните любой элемент в предпросмотре, и над ним появится панель:

![Плавающая панель над выбранным элементом](img/html-toolbar.png)

- **Файл и история**: сохранить, сохранить как…, отменить, повторить, найти; переключатель **автосохранения** пишет изменения по расписанию.
- Переключатель **Предпросмотр / Исходник**; **Показ** открывает страницу во весь экран.
- **Форматирование**: полужирный, курсив, увеличить и уменьшить кегль; **панель стилей** для выбранного элемента (цвета и прочее).
- **Вставка**: заголовок, абзац, таблица, изображение (по ссылке), ещё.
- **Действия с изображением** (при выбранном изображении): обрезка, **удаление фона**, замена, сохранение пропорций.
- **Действия с элементом** (при выбранном в инспекторе предпросмотра): удалить, дублировать, вверх и вниз.
- **Кнопка ИИ**: открывает панель ИИ; можно спросить о выбранном элементе прямо оттуда.

## Вставка каркаса

Для пустой страницы команда **Вставка ▸ Вставить каркас** пишет минимальный документ в стандартном режиме:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title></title>
  </head>
  <body></body>
</html>
```

Каждая часть здесь по какой-то причине — потому это команда, а не то, что пришлось бы набирать руками:

- **doctype** — иначе предпросмотр работает в quirks mode, где размеры блоков и раскладка таблиц подчиняются другим правилам, чем вы ожидаете;
- **`lang`** — иначе у программы чтения с экрана не будет языка, на котором читать страницу, и браузер подберёт шрифт и проверку орфографии для неверного языка;
- **charset** — иначе страница с нелатинским текстом может превратиться в нечитаемый набор символов (mojibake).

Мета-тег viewport намеренно отсутствует: это рендерится в настольной панели, где мобильному viewport не на что повлиять.

`lang` следует за языком интерфейса приложения, поэтому вставляемый каркас — как раз тот, под который ваши инструменты уже настроены. Дальше правьте его как угодно.

Пункт появляется только в режиме правки и только пока документ пуст: как только появится содержимое, вставлять каркас *куда* уже некуда.
