# חיבור סוכן תכנון

‏GenOffice מדברת ב- Model Context Protocol, ולכן סוכן תכנון יכול לקרוא, לכתוב ולרנדר את המסמכים שלכם דרך אותם מנועים שהאפליקציה משתמשת בהם. הסוכן אינו מנחש פורמט קובץ: הוא מקבל את סכמות הפעולות המוטיפות מאותם הגדרות שמולן המבצע מאמת.

## רישום

המקרה הרגיל הוא פקודה אחת:

```sh
genoffice mcp install all
```

היא מוצאת את סוכני התכנון שבמחשב הזה — Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode, Windsurf — וכותבת את רשומת שרת ה-stdio בהגדרות של כל אחד מהם, ומשאירה את שאר הקובץ כפי שמצאה אותו.

```sh
genoffice mcp list             # where each agent stands
genoffice mcp install cursor    # just one
genoffice mcp uninstall cursor  # take it back out
```

סוכן שהתקנתם במקום לא שגרתי זקוק ל-`--dir <path>`; ו-`--force` כותב מחדש רשומה שכבר קיימת.

## הרצה עצמאית

עבור לקוח במחשב אחר, הגישו אותו ב-HTTP במקום זאת:

```sh
genoffice mcp --http 8765 --token <secret>
```

‏`--host <addr>` משנה את הכתובת שבה הוא מאזין. העבירו ללקוח את אותו אסימון.

גם קבצים עוברים ב-HTTP: `PUT /files/<name>` מעלה קובץ אחד, כל כלי מקבל כתובת `http(s)` במקום נתיב, והפלטים חוזרים ככתובות הורדה — וכשהם קטנים מספיק, כמשאבים מוטמעים. פעולות, מפרטים ו-Markdown עוברים בתוך הבקשה בכל מקרה.

## מה הסוכן מקבל

כל פקודה היא כלי. המעניינות שבהן:

- **`docs`, `sheet`, `slides`** — קוראות ועורכות קובץ דרך נתיב הכתיבה של האפליקציה עצמה, **פעולה** (op) אחת בכל פעם. מצגת חדשה הולכת `deck_start`, `deck_page`, `deck_build`.
- **`render`** — PNG אחד לכל עמוד, בפריסה של המרונדר של האפליקציה, כך שהסוכן יכול להסתכל על שקופית במקום לנחש.
- **`pdf`** — שכבת הטקסט של PDF, עמוד אחר עמוד, בלי תהליך של האפליקציה.
- **`info`** — מטא-נתונים ותקציר מבנה, שבדרך כלל הוא הקריאה הראשונה הזולה ביותר על קובץ לא מוכר.
- **`search`, `image`, `media`** — הספקים המוגדרים באפליקציה, ולכן הסוכן לא צריך מפתחות משלו.
- **`merge`** — מילוי תבנית `{{key}}`.

## סכמות, ותקציב קטן יותר

‏`apply` ו-`create` מכריזות על הפרמטרים `ops`, `cells` ו-`data` שלהן עם הסכמה המוטיפה של כל פעולה, שנוצרה מ-`genoffice guide <domain> --json`. זה מדויק אך לא קטן. לקוח עם חלון הקשר צר יכול לבקש מערכים פשוטים במקום זאת:

```sh
genoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 genoffice mcp
```

## המיומנות

סוכן שאינו מכיר את מילון הפעולות ינחש. ‏`genoffice skill` מתקין מיומנות של GenOffice בסוכנים שהוא מוצא, ומביא איתה את המפנייה ואת מדריכי העיצוב — אותו חומר ש-`genoffice guide` מדפיס.

## מה זה אינו

שרת ה-MCP קורא קבצים וכותב קבצים. הוא אינו החלון: אין חלונית AI, וחלונית העדכון שבאפליקציה אינה חלה. אם שלב מסוים זקוק לחלון, פתחו את הקובץ.
