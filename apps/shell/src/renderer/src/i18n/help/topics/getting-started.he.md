# התחלה מהירה: הממשק והבסיס

‏GenOffice היא חבילת משרד שרצה כולה על המחשב שלך: חלון אחד, שורת כרטיסיות אחת, ובתוכה שישה עורכים — Docs (עיבוד תמלילים), Sheets (גיליונות), Slides (מצגות), PDF, Markdown ו-HTML. הקבצים הם .docx / .xlsx / .pptx / .pdf אמיתיים, ניתנים להחלפה מלאה עם Word, Excel ו-PowerPoint. לא נדרשת רשת.

## סקירת הממשק

![מסך הבית](img/home-screen.png)

החלון מורכב משלושה חלקים:

- **רשת כרטיסיות (למעלה)**: כל קובץ פתוח הוא כרטיסייה. כרטיסיית הבית השמאלית תמיד קיימת ולא ניתן לסגור אותה; שאר הכרטיסיות הן המסמכים שלך. לחיצה כפולה על כרטיסיה משנה את שם הקובץ במקום.
- **אזור התוכן**: העורך (או הבית) ששייך לכרטיסייה הפעילה.
- **שורת התפריטים**: בשורת התפריטים של המערכת ב-macOS, למעלה החלון ב-Windows/Linux. תפריטי File/Edit/View מתחלפים בהתאם לעורך הפעיל.

## יצירת מסמך

אחת מאלה:

- לחצו על כרטיסיית יצירה מהירה בקטע [התחלה מהירה](help://getting-started) של **הבית** (AI Docs, AI Sheets, AI Slides, ...).
- תפריט **File ▸ חדש**: Docs (⌘N/ctrl+N), Sheets, Slides, Markdown, HTML או PDF.
- גררו קובץ לחלון, או לחצו עליו פעמיים במנהל הקבצים שלכם (אם GenOffice היא האפליקציית ברירת המחדל).

מסמך חדש נפתח ללא שם; הקובץ על הדיסק נוצר רק בשמירה הראשונה.

## פתיחת קבצים

- תפריט **File ▸ פתיחה** (⌘O/ctrl+O) פותח את בוחר המערכת: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html.
- לחצו על כל פריט ברשימת **האחרונים** של הבית.
- `genoffice <file>` מהטרמינל גם פותח קבצים.

## מודל השמירה

- **שמירה ידנית**: ⌘S/ctrl+S, או File ▸ שמירה / שמירה בשם. השמירה הראשונה תבקש מיקום ושם.
- **שמירה אוטומטית** נדלקת רק לאחר ששמרתם את הקובץ ידנית לפחות פעם אחת — PDF שרק קראתם ממנו לעולם לא ייכתב מחדש בשקט. השמירה האוטומטית מופעלת זמן קצר לאחר שהתוכן משתנה.
- סגירת כרטיסייה עם שינויים שלא נשמרו שואלת קודם Save / Discard / Cancel.
- כל כתיבה מתבצעת באופן אטומי (קובץ זמני + שינוי שם), כך שניתוק חשמל לא ישאיר קובץ חצי-כתוב.

## קיצורי מקלדת נפוצים

| פעולה           | macOS | Windows / Linux |
| ---------------- | ----- | --------------- |
| מסמך חדש        | ⌘N    | ctrl+N          |
| פתיחה           | ⌘O    | ctrl+O          |
| שמירה           | ⌘S    | ctrl+S          |
| סגירת כרטיסייה | ⌘W    | ctrl+W          |
| פתיחת מדריך זה | F1    | F1              |

קיצורי המקלדת בתוך כל עורך (משחל עיצוב, חיפוש והחלפה, פעולות טבלה, ...) מפורטים בפרקים שלהם; ל-Docs יש גם תיבת דיאלוג קיצורי מקלדת הניתנת לחיפוש (ראו את הפרק שלה).
