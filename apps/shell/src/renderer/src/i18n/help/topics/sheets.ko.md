# Sheets: 스프레드시트

Sheets는 Excel과 비슷한 스프레드시트 편집기입니다. 계산은 별도의 Rust 엔진 프로세스가 맡습니다(거기서 충돌이 나도 앱 전체가 죽지는 않습니다). .xlsx를 읽고 쓰며, .csv와 .tsv는 표로 엽니다.

## 화면

- **리본**: 탭이 8개 있습니다. 하나씩 아래에서 설명합니다.
- **수식 입력줄**: 활성 셀의 수식을 표시하고 편집합니다. 자주 쓰는 함수를 지원합니다.
- **시트 탭**(아래): 시트 추가, 이름 바꾸기, 삭제, 이동.
- **셀 편집**: 더블클릭하거나 그냥 입력합니다. Enter로 확정하고 아래로, Tab으로 오른쪽으로, Esc로 취소합니다(Excel 습관 그대로).
- **단축키**: Excel 계열에 맞춰져 있습니다(ctrl+C/V/X, ctrl+Z/Y, ctrl+F 등).

## 리본 탭

- **홈**: 글꼴, 채우기, 테두리, 표시 형식(통화/백분율/구분자, 소수 자릿수 늘이기·줄이기), 맞춤, 셀 병합, 행/열 삽입과 크기, 조건부 서식, 표 서식 적용, 셀 스타일, 클립보드와 서식 복사, 정렬 및 필터.
- **삽입**: 도형, 아이콘, 기호, 수식(방정식), 화면 캡처 등.
- **페이지 레이아웃**: 테마 색과 글꼴, 눈금선/머리글 인쇄 전환, 페이지 나누기 미리 보기.
- **수식**: 자동 합계와 함수 삽입, 이름 정의(선택 영역에서 만들기도 함), 참조되는 셀 추적/참조하는 셀 추적, 조사식 창, 시트/통합 문서 다시 계산.
- **데이터**: 정렬과 필터(고급 필터, 필터 지우기 포함), 텍스트 나누기, 통합 문서 병합, 모두 새로 고침.
- **검토**: 메모 보기(표시, 이전/다음 메모), 번역.
- **보기**: 눈금선과 머리글 표시 전환, 확대/축소, 기본 보기/페이지 나누기 미리 보기.
- **차트 디자인**: 차트를 선택했을 때만 나타납니다. 차트 종류, 스타일과 색, 데이터 범위를 편집합니다.

"데이터" 탭의 버튼을 하나씩(그림의 왼쪽부터):

![데이터 탭](img/sheets-data.png)

- **피벗 테이블**: 현재 범위에서 피벗 테이블을 만들고 필드를 끌어 집계합니다.
- **새로 고침**: 현재 피벗 테이블의 데이터를 다시 계산합니다.
- **텍스트/CSV에서**: .csv/.txt를 구분자로 나누어 새 시트로 가져옵니다.
- **통합 문서 병합**: 다른 .xlsx의 시트를 이 문서로 가져옵니다.
- **모두 새로 고침**: 모든 피벗 테이블과 외부 데이터 집합을 다시 계산합니다.
- **정렬**(드롭다운): 오름차순/내림차순/사용자 지정 정렬(여러 열 규칙).
- **필터**: 머리글 행에 ▼ 드롭다운을 붙입니다. 남길 값을 체크합니다.
- 그 옆에 세로로 쌓인 작은 버튼: **지우기**(모든 행을 되돌림), **다시 적용**(현재 필터를 다시 실행), **고급**(조건 범위로 필터링).
- **텍스트 나누기**(드롭다운): 한 열을 구분자나 고정 너비로 여러 열로 나눕니다.
- **빠른 채우기**: 예시를 하나 주면 열의 나머지가 그 예시에 맞춰 자동으로 채워집니다(ctrl+E).
- **중복된 항목 제거**: 선택한 열을 기준으로 중복된 행을 지웁니다.
- **데이터 유효성 검사**(드롭다운): 선택 영역의 입력 규칙(드롭다운 목록, 숫자 범위 등).
- **통합**: 여러 범위를 분류별로 한곳에 모읍니다.
- **가상 분석**(드롭다운): 목표값 찾기/데이터 테이블.
- **그룹/그룹 해제**(드롭다운): 행 또는 열 그룹과 접기/펼치기.
- **부분합**: 분류별 소계 행을 삽입합니다.

"수식" 탭의 버튼을 하나씩:

![수식 탭](img/sheets-formulas.png)

- **함수 삽입**(fx): 함수를 검색하며 인수 마법사가 함께 열립니다.
- **자동 합계**(드롭다운): 한 번 누르면 SUM, 추가로 평균/개수/최대/최소.
- **최근 사용한 함수 / 재무 / 논리 / 텍스트 / 날짜 및 시간 / 찾기 및 참조 / 수학 및 삼각 / 기타**: 분류별로 함수를 둘러 보고 삽입합니다.
- **이름 관리자**: 이름이 지정된 범위를 보고 만들고 삭제합니다.
- **이름 정의**(드롭다운): 선택 영역에 이름을 붙입니다. **수식에서 사용**은 기존 이름을 수식에 넣고, **선택 영역에서 만들기**는 머리글 행이나 열의 문자로 범위에 이름을 붙입니다.
- **참조되는 셀 추적 / 참조하는 셀 추적**: 수식의 데이터가 어디에서 오고 어디로 나가는지 파란 화살표로 보여 줍니다. **연결선 제거**로 지웁니다.
- **수식 표시**: 셀에 결과 대신 수식 자체를 보여 줍니다.
- **오류 검사**: 수식 오류의 위치를 찾아 설명합니다.
- **조사식 창**: 신경 쓰이는 셀을 고정해 현재 값을 지켜 봅니다.
- **계산 옵션**(드롭다운): 자동과 수동 중 무엇으로 다시 계산할지 정합니다. 수동일 때 옆의 **지금 계산**/**시트 계산**으로 직접 실행합니다.

## 숫자와 서식

- 표시 형식: 일반, 숫자, 통화, 백분율, 날짜/시간, 분수, 과학적 표기 등.
- 맞춤, 줄 바꿈, 셀 병합, 테두리와 채우기.
- 행 높이와 열 너비는 드래그로 조정하며, 경계를 더블클릭하면 자동으로 맞춥니다.

## 데이터

**정렬과 필터**(예: 한 열을 내림차순으로 정렬):

1. **그 열의 아무 셀**을 누릅니다(열 전체를 선택할 필요는 없습니다).
2. 홈 탭 ▸ **정렬 및 필터** ▸ **내림차순**. 행 전체가 함께 다시 정렬됩니다(범위 하나로는 처리).
3. 원하는 규칙(여러 열, 색으로 나누기)으로 정렬하려면 같은 경로에서 **사용자 지정 정렬**을 고릅니다.
4. 필터: 머리글 행을 선택하고 **정렬 및 필터 ▸ 필터**를 누르면 각 머리글에 ▼ 드롭다운이 생겨 남길 값을 체크할 수 있습니다. 필터를 지우면 모두 돌아옵니다.

- 정렬과 필터.
- 틀 고정.
- .csv / .tsv: 표로 바로 엽니다(탭 구분 tsv는 표 하나로 분석합니다). 저장하면 원래 형식으로 되돌려 씁니다.

## 오른쪽 클릭 메뉴

- **격자 안에서**: 편집기(Univer) 자체 메뉴 — 잘라내기/복사/붙여넣기, 행/열 삽입과 삭제, 숨기기, 셀 병합, 틀 고정 등 일상적인 항목.
- **아래 상태 표시줄에서**: 상태 표시줄에 어떤 통계를 보여 줄지 고릅니다(평균/개수/합계 등). 선택은 그대로 유지됩니다.
- **아래 시트 탭에서**: 시트 추가, 이름 바꾸기, 삭제, 색, 숨기기 등(Univer의 탭 메뉴).
- 위쪽 탭 바의 오른쪽 클릭 메뉴는 [탭과 창 관리](help://tabs-and-windows) 장에서 설명합니다.

## 스크립트 편집기(고급)

Sheets에는 일괄 처리를 위한 **스크립트 편집기**가 들어 있습니다. Google Apps Script와 비슷한 API를 씁니다.

- 열기: 도구 ▸ 스크립트 편집기(버전에 따라 개발자 메뉴).
- 화면: 왼쪽이 스크립트 라이브러리(새로 만들기/삭제), 오른쪽이 코드 편집기와 출력 창. **실행/중지** 버튼이 있습니다.
- API는 비동기입니다:

```js
const sheet = await SpreadsheetApp.getActiveSpreadsheet()
const active = await sheet.getActiveSheet()
const range = await active.getRange('A1:C10')
const values = await range.getValues() // 2차원 배열
await range.setValues(values.map((row) => row.map((v) => v * 2)))
Logger.log('done')
```

- `SpreadsheetApp`(진입점), `Sheet`(getName/getRange/getLastRow…), `Range`(getValue(s)/setValue(s)/clear…), `Logger.log`, `Utilities.sleep`.
- 스크립트는 **샌드박스 워커**에서 실행됩니다. 네트워크도 파일 시스템도 DOM도 없고, 닿을 수 있는 것은 위 API뿐이라 버그가 있는 스크립트나 악의적인 스크립트가 다른 데이터에 손댈 수 없습니다.
- 출력 창에는 줄 수 상한이 있어 엄청난 로그가 화면을 멈추게 하지 않습니다.
- **AI도 스크립트를 실행할 수 있습니다**: 어시스턴트의 `run_script` 도구가 같은 샌드박스 API를 실행합니다. 일괄적이고 규칙적인 변환에 적합합니다.

## AI

- 옆의 AI 패널: 범위를 선택해 자연어로 지시합니다(서식 변경, 데이터 생성, 수식 작성 등).
- AI가 한 변경은 패널에서 되돌릴 수 있습니다.

## 저장과 내보내기

- .xlsx로 저장합니다(수식과 서식이 보존됩니다). 다른 이름으로 저장과 PDF 내보내기는 인쇄의 쪽나누기를 따릅니다.
- 자동 저장은 전체 규칙을 따릅니다(처음 수동 저장 후 켜짐).

## 안정성

- 계산 엔진의 사이드카는 UI와 프로세스가 분리되어 있습니다. 극단적인 데이터로 엔진이 멈춰도 메시지가 나오고 세션 복구를 시도할 뿐, 앱 전체가 죽지는 않습니다.
