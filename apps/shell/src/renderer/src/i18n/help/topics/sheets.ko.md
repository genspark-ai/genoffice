# Sheets: 스프레드시트

GenOffice Sheets는 Microsoft Excel과 깊이 호환되는 스프레드시트 편집기입니다. 수식 계산과 대용량 데이터 집계는 UI와 분리된 별도의 Rust 엔진 프로세스(사이드카)가 담당하므로, 극단적인 데이터로 계산 엔진이 중단되더라도 메인 앱 창이 함께 종료되지 않습니다. 표준 `.xlsx` 통합 문서를 직접 읽고 쓰며, `.csv`와 `.tsv` 텍스트 파일도 곧바로 표 형태로 열어 편집하고 원래 형식으로 저장할 수 있습니다.

## 화면 구성과 기본 조작

- **리본**: 일상적인 표 작업 흐름에 맞춰 8개의 메인 탭(및 차트 선택 시 나타나는 컨텍스트 탭)으로 구성되어 있으며, 아래에서 탭별로 자세히 설명합니다.
- **수식 입력줄**: 시트 격자 바로 위에 자리하며 현재 활성 셀의 원본 수식이나 텍스트를 보여 주고 편집합니다. 함수 자동 완성과 인수 안내를 지원합니다.
- **시트 탭**(화면 아래): 통합 문서 안의 모든 워크시트를 나열하며, `+` 버튼으로 새 시트 추가, 더블클릭으로 이름 바꾸기, 드래그로 순서 이동, 마우스 오른쪽 클릭 메뉴로 삭제·복제·탭 색상 지정·숨기기를 수행할 수 있습니다.
- **셀 편집**: 셀을 더블클릭하거나 선택한 상태에서 바로 타이핑을 시작합니다. `Enter`로 확정하고 한 행 아래로, `Tab`으로 확정하고 한 열 오른쪽으로 이동하며, `Esc`를 누르면 입력을 취소하고 이전 값으로 되돌립니다(익숙한 Excel 조작 방식 그대로입니다).
- **단축키**: `Ctrl+C/V/X`, `Ctrl+Z/Y`, `Ctrl+F`, `F2`(셀 제자리 편집), `F4`(절대/상대 참조 전환) 등 데스크톱 Excel 계열의 표준 단축키(macOS에서는 `⌘` 조합)와 맞추어져 있습니다.

## 리본 탭

- **홈**: 글꼴, 채우기, 테두리, 표시 형식(통화/백분율/구분자, 소수 자릿수 늘이기·줄이기), 맞춤, 셀 병합, 행/열 삽입과 크기, 조건부 서식, 표 서식 적용, 셀 스타일, 클립보드와 서식 복사, 정렬 및 필터.
- **삽입**: 그림, 도형, 텍스트 상자, 링크, 메모, 체크박스, 머리글/바닥글, 기호, 수식; **아홉 가지 차트 형식**(세로 막대형, 가로 막대형, 꺾은선형, 영역형, 원형, 분산형, 방사형, 도넛형, 세로 막대형+꺾은선형 조합)과 **추천 차트**(선택 영역에 맞춰 형식을 정리하고 미리 보여 줍니다); 현재 셀을 기준으로 하는 **피벗 차트**; **스파크라인**(꺾은선형, 세로 막대형, 승/패); 피벗 테이블을 필터링하는 **슬라이서**와 **시간 표시 막대**.
  - 차트, 피벗 차트, 스파크라인은 저장된 통합 문서 안의 실제 개체입니다.
  - **슬라이서**와 **시간 표시 막대**는 세션 제어입니다. 이들이 적용한 필터는 저장되며 Excel도 같은 필터가 적용된 피벗 테이블을 보여 주지만, 슬라이서 버튼 자체는 파일에 들어 있지 않습니다.
- **페이지 레이아웃**: 테마 색과 글꼴, 눈금선/머리글 인쇄 전환, 페이지 나누기 미리 보기.
- **수식**: 자동 합계와 함수 삽입, 이름 정의(선택 영역에서 만들기도 함), 참조되는 셀 추적/참조하는 셀 추적, 조사식 창, 시트/통합 문서 다시 계산.
- **데이터**: 정렬과 필터(고급 필터, 필터 지우기 포함), 텍스트 나누기, 통합 문서 병합, 모두 새로 고침.
- **검토**: 메모 보기(표시, 이전/다음 메모), 번역, 그리고 **보호** 그룹(**시트 보호**, **통합 문서 보호**, **범위 편집 허용**).
  - 보호는 .xlsx 안에 기록되며 이 앱이 적용하는 보호에는 비밀번호가 없습니다. 그래서 같은 버튼이 **보호 해제…** 로 바뀌어 보호를 되돌립니다. _실제로_ 비밀번호를 가진 다른 프로그램의 보호는 여기서 해제할 수 없습니다.
  - 두 보호 버튼은 즉시 적용됩니다. 취소할 대화상자가 없고, 저장할 때 기록된다는 안내만 상태 줄에 표시됩니다.
  - **범위 편집 허용**은 시트 나머지 부분이 잠겨 있어도 편집할 수 있게 남겨 둘 셀을 표시합니다.
- **보기**: 눈금선, **수식 입력줄**, 머리글, 활성 행 및 열 강조 표시 전환; 확대/축소; **기본**과 **페이지 나누기 미리 보기**. 눈금선과 머리글은 시트와 함께 저장되고, 강조 표시는 사용자만의 설정입니다.
- **차트 디자인**: 차트를 선택했을 때만 나타납니다. 차트 종류, 스타일과 색, 데이터 범위를 편집합니다.

- **피벗 테이블**: 현재 범위에서 피벗 테이블을 만들고 필드를 끌어 집계합니다.
- **새로 고침**: 현재 피벗 테이블의 데이터를 다시 계산합니다.
- **텍스트/CSV에서**: .csv/.txt를 구분자로 나누어 새 시트로 가져옵니다.
- **통합 문서 병합**: 다른 .xlsx의 시트를 이 문서로 가져옵니다.
- **모두 새로 고침**: 모든 피벗 테이블과 외부 데이터 집합을 다시 계산합니다.
- **정렬**(드롭다운): 오름차순/내림차순/사용자 지정 정렬(여러 열 규칙).
- **필터**: 머리글 행에 ▼ 드롭다운을 붙입니다. 남길 값을 체크합니다.
- 그 옆에 세로로 쌓인 작은 버튼: **지우기**(모든 행을 되돌림), **다시 적용**(현재 필터를 다시 실행), **고급**(조건 범위로 필터링).
- **텍스트 나누기**(드롭다운): 한 열을 구분자나 고정 너비로 여러 열로 나눕니다.
- **빠른 채우기**: 예시를 하나 주면 열의 나머지가 그 예시에 맞춰 자동으로 채워집니다(ctrl+E).
- **중복된 항목 제거**: 선택한 열을 기준으로 중복된 행을 지웁니다.
- **데이터 유효성 검사**(드롭다운): 선택 영역의 입력 규칙(드롭다운 목록, 숫자 범위 등).
- **통합**: 여러 범위를 분류별로 한곳에 모읍니다.
- **가상 분석**(드롭다운): 목표값 찾기—수식 셀의 값이 목표값에 도달하도록 입력 셀 하나의 값을 찾습니다.
- **그룹/그룹 해제**(드롭다운): 행 또는 열 그룹과 접기/펼치기.
- **부분합**: 분류별 소계 행을 삽입합니다.

"수식" 탭의 버튼을 하나씩:

![수식 탭](img/sheets-formulas.png)

- **함수 삽입**(`fx` 버튼): 함수를 키워드로 검색하고 각 인수의 의미와 계산 미리보기를 안내하는 단계별 인수 마법사와 함께 호출합니다.
- **Excel 365 정규식 함수 및 PERCENTOF**: 수식 입력줄에서 최신 Excel 365의 정규식 함수군인 **`REGEXTEST`**(텍스트가 정규식 패턴과 일치하는지 판별), **`REGEXEXTRACT`**(첫 번째 일치 항목, 모든 일치 항목의 배열 또는 캡처 그룹 추출), **`REGEXREPLACE`**(`$0`, `${n}`, 명명된 캡처 그룹 `${name}` 확장 및 문맥 내 N번째 일치 항목만 치환 지원)와 전체 대비 부분집합의 비율을 구하는 **`PERCENTOF(data_subset, data_all)`** 함수를 그대로 사용할 수 있습니다. 네 함수 모두 데스크톱 Excel과 동일한 인수 서명을 따르며, 유니코드(`u` 플래그)를 기본 지원해 `\p{...}` 문자 클래스를 쓸 수 있고, 화면 멈춤을 유발하는 지수적 백트래킹 위험 정규식 패턴은 사전에 감지해 안전하게 거부합니다.
- **자동 합계**(드롭다운): 한 번 클릭해 인접 범위의 `SUM`(합계) 수식을 넣거나, 드롭다운을 열어 평균(`AVERAGE`), 숫자 개수(`COUNT`), 최댓값(`MAX`), 최솟값(`MIN`)을 즉시 삽입합니다.
- **최근 사용한 함수 / 재무 / 논리 / 텍스트 / 날짜 및 시간 / 찾기 및 참조 / 수학 및 삼각 / 기타**: 함수의 정확한 철자가 기억나지 않아도 분야별 카테고리 메뉴를 둘러보며 원하는 함수를 찾아 인수 마법사와 함께 삽입할 수 있습니다.
- **이름 관리자**: 통합 문서 안에 정의된 모든 이름 지정 범위를 한 창에서 확인하고 새로 만들거나 참조 범위를 수정·삭제합니다.
- **이름 정의**(드롭다운): 현재 선택한 셀 영역에 읽기 쉬운 이름을 붙입니다. **수식에서 사용**은 기존 이름을 작성 중인 수식에 바로 붙여넣고, **선택 영역에서 만들기**는 선택 영역의 첫 행이나 첫 열 머리글 텍스트를 이용해 여러 범위에 한꺼번에 이름을 지정합니다.
- **참조되는 셀 추적 / 참조하는 셀 추적**: 복잡한 수식이 어느 상위 셀에서 데이터를 가져오는지(참조되는 셀), 또는 현재 셀의 값이 어느 하위 수식으로 흘러가는지(참조하는 셀) 격자 위에 파란색 화살표로 시각화해 주며, 점검이 끝나면 **연결선 제거**로 깔끔하게 지울 수 있습니다.
- **수식 표시**: 시트 전체의 셀을 '계산된 결과값 표시'와 '`=...` 수식 원본 문자열 표시' 사이에서 한 번에 전환합니다(상태 표시줄에도 수식 보기 상태가 안내됩니다).
- **오류 검사**: 시트 안의 `#VALUE!`, `#NAME?`, `#REF!`, `#DIV/0!` 등 수식 오류가 발생한 셀을 차례로 찾아 위치를 짚어 주고 오류 원인을 설명합니다.
- **조사식 창**: 다른 시트나 수천 행 아래에 있는 핵심 요약 셀들을 플로팅 창에 고정해 두고, 멀리 떨어진 입력 표를 수정하면서 실시간 값 변화를 한눈에 지켜볼 수 있습니다.
- **계산 옵션**(드롭다운): 기본값인 '자동'(셀을 고칠 때마다 즉시 재계산)과 초대형 문서를 위한 '수동' 재계산 모드를 전환합니다. 수동 모드일 때는 옆의 **지금 계산**(`F9`, 통합 문서 전체)이나 **시트 계산**(`⇧F9` / `Shift+F9`, 현재 시트만) 버튼으로 원하는 시점에 직접 계산을 실행합니다.

## 숫자와 서식

- 표시 형식: 일반, 숫자, 통화, 백분율, 날짜/시간, 분수, 과학적 표기 등.
- 맞춤, 줄 바꿈, 셀 병합, 테두리와 채우기.
- 행 높이와 열 너비는 드래그로 조정하며, 경계를 더블클릭하면 자동으로 맞춥니다.

## 데이터

**정렬과 필터**(예: 한 열을 내림차순으로 정렬):

1. **그 열의 아무 셀**을 누릅니다(열 전체를 선택할 필요는 없습니다).
2. 홈 탭 ▸ **정렬 및 필터** ▸ **내림차순**. 행 전체가 함께 다시 정렬됩니다(범위 하나로는 처리).
3. 원하는 규칙(여러 열, 색으로 나누기)으로 정렬하려면 같은 경로에서 **사용자 지정 정렬**을 고릅니다.
4. 필터: 머리글 행을 선택하고 **정렬 및 필터 ▸ 필터**를 누르면 각 머리글에 ▼ 드롭다운이 생겨 남길 값을 체크할 수 있습니다. 필터를 지우면 모두 돌아옵니다.

- 정렬과 필터.
- 틀 고정.
- .csv / .tsv: 표로 바로 엽니다(탭 구분 tsv는 표 하나로 분석합니다). 저장하면 원래 형식으로 되돌려 씁니다.

## 오른쪽 클릭 메뉴

- **격자 안에서**: 편집기(Univer) 자체 메뉴 — 잘라내기/복사/붙여넣기, 행/열 삽입과 삭제, 숨기기, 셀 병합, 틀 고정 등 일상적인 항목.
- **아래 상태 표시줄에서**: 상태 표시줄에 어떤 통계를 보여 줄지 고릅니다(평균/개수/합계 등). 선택은 그대로 유지됩니다.
- **아래 시트 탭에서**: 시트 추가, 이름 바꾸기, 삭제, 색, 숨기기 등(Univer의 탭 메뉴).
- 위쪽 탭 바의 오른쪽 클릭 메뉴는 [탭과 창 관리](help://tabs-and-windows) 장에서 설명합니다.

## AI

- 옆의 AI 패널: 범위를 선택해 자연어로 지시합니다(서식 변경, 데이터 생성, 수식 작성 등).
- 📎 버튼으로 프롬프트에 파일을 첨부하거나 패널로 끌어 놓을 수 있습니다. 파일은 질문과 함께 전달되고 이미지는 썸네일로 돌아옵니다.
- 답변이 셀을 참조할 수 있습니다. 참조를 클릭하면 그리드가 그 셀로 이동합니다.
- AI가 한 변경은 패널에서 되돌릴 수 있습니다.

## 저장과 내보내기

- .xlsx로 저장합니다(수식과 서식이 보존됩니다). 다른 이름으로 저장과 PDF 내보내기는 인쇄의 쪽나누기를 따릅니다.
- 자동 저장은 전체 규칙을 따릅니다(처음 수동 저장 후 켜짐).
