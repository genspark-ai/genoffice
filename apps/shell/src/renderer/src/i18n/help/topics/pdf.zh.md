# PDF：阅读、注释与涂黑

GenOffice 的 PDF 编辑器并不是一个只能翻页查看的简易阅读器，而是一套兼具阅读、批注与深度改写能力的完整工具，顶部配有五个功能区标签：**开始 / 注释 / 编辑 / 页面 / 视图**。在这里你既可以顺畅地做高亮、插便签、手写批注，也可以直接修改正文文字、用 OCR 识别扫描件并原位改字、对机密段落执行彻底的物理涂黑（Redact）、加盖手写或数字证书签名，还能直接填写并保存交互式表单。

## 阅读与导航

- **左侧导航边栏**：点击左侧栏顶部的切换图标，可以在**页面缩略图**（直观展示每一页的版面预览、高亮框出当前屏幕可见的页码范围，单击任意缩略图即可瞬间跳页）与**文档大纲**（展示 PDF 内部自带的章节书签树）之间自由切换。
- **可编辑的书签大纲**：左侧的大纲面板不再只是只读目录，你可以点开大纲顶部的编辑按钮（`✎`），随时为当前正在阅读的页面**新建书签**，或者对已有书签直接进行**行内重命名**与**删除**；点 `✓` 退出编辑模式后修改会保留在当前待存大纲中，并在你保存文档时作为标准的 `/Outlines` 书签跳转结构完整写回 PDF 文件（如果你在「页面」页签里删除或重排了页面，书签指向的目标页码也会自动同步更新或随被删页面一并清理）。
- **页面缩放控制**：你既可以使用窗口右下角的缩放比例控件按档位调整页面大小，也可以按住 `Ctrl` 键（macOS 上为 `⌘` 键）同时滚动鼠标滚轮进行连续顺滑缩放。
- **单页与整篇旋转**：在「页面」功能区里，你可以选择只将当前页面顺时针或逆时针旋转 90°，也可以一键旋转整份文档的所有页面；调整后的旋转角度会在你下次保存文件时真实写入 PDF 页面属性中。
- **全文检索与高亮**：按下 `⌘F` / `Ctrl+F` 即可打开搜索栏进行全文检索，所有命中词都会在页面上实时高亮标出，支持区分大小写与全词匹配，并可用回车键在各个命中位置之间快速跳转。
- **加密 PDF 解锁阅读**：打开受口令保护的加密 PDF 时，系统会弹出一个独立的密码输入小窗；输入的密码仅在当前打开会话的内存中使用，用来解锁页面渲染，绝不会被明文记录到日志里。

## 文字选择与标注（注释 ▸ 高亮家族）

不妨随便打开一份带文字层的 PDF 亲自试一下这套标注流程：

1. 用鼠标在正文任意一句话上**按住左键拖选一段文字**，松开鼠标的瞬间，所选文字正上方会自动浮出一排轻巧的快捷标注工具条：

![选中文字后浮出的标注条](img/pdf-highlight.png)

2. 点击浮动工具条上的**高亮**（旁边的彩色小方块可以展开调色板更换马克笔颜色）、**下划线**或**删除线**即可一步完成标记；如果点最右侧的**问 AI**，则会把当前选中的这段原文连同你的提问一起发送给侧边的 AI 助手面板进行解读、翻译或总结。
3. 如果想取消刚刚画上去的某条标注，只需要对同一段文字重新拖选一次，再点一下浮动条上那个正处于高亮激活状态的对应按钮即可一键撤销（采用与 Word 一致的开关切换逻辑），或者直接单击选中该标注后按键盘上的 `Delete` 键将其移除。

日常做文字批注时还有几个实用细节值得留意：

- 只要在正文上拖选任意文字，上方浮出的工具条就会固定提供 **高亮 / 下划线 / 删除线 / 复制 / 问 AI** 五项最常用的操作，无需频繁抬头去点顶部功能区。
- 哪怕是之前保存进文件、或是别人用 Acrobat 等其他软件画好传给你的历史标注，在 GenOffice 里同样可以直接点击选中并通过 `⋯` 菜单或按 `Delete` 键删掉。
- **绘图模式与选字模式的自动切换**：当你在顶部激活了矩形、箭头等绘图工具时，为了防止落笔时误选底下的文字，正文文字层会暂时锁定不可选；但只要你在页面上画完并落定一个图形，绘图工具就会自动解除激活并回到默认的选择模式，让你能紧接着继续拖选文字。
- 所有高亮、下划线和删除线的颜色都可以在调色板里自由更换；**对已经带有同一种标注的文字范围再次点击同一个标注按钮，效果就是取消该标注**，操作习惯与 Word 完全一致。

## 绘图工具（注释 ▸ 绘图）

在「注释」功能区里一共提供了六种图形批注与遮挡工具：**墨迹（自由手绘）、矩形、椭圆、箭头、便签**，以及专门用于保密脱敏的**涂黑区域**。

- **即画即停的开关设计**：每个绘图按钮都是一个独立开关，点一下进入绘制状态，**在页面上画完一个图形后会自动退回普通选择模式**，省去了每次画完都要手动按 `Esc` 切回鼠标指针的麻烦（如果你需要连续画多个框，只需再点一下该工具按钮；在未落笔前再次点击已激活的工具按钮也会直接取消绘制）。
- **线条粗细与色彩调节**：自由手绘的墨迹支持调整笔触粗细，矩形、椭圆和箭头则通过鼠标拖拽拉出大小与方向，所有图形的线条颜色都可以在配套的绘图调色板里随时挑选。
- **后期调整与移动**：画在页面上的任何图形都不是死板的像素，你随时可以用鼠标单击选中它们，按 `Delete` 键删除、按住直接拖拽平移位置，或者拉动矩形与椭圆四周的控制手柄自由缩放尺寸。
- **涂黑（Redact）机密内容的完整脱敏流程**（以彻底抹掉合同里的一行敏感金额或身份证号为例）：

  1. 切换到顶部的**注释**页签，点击**涂黑区域**按钮使其进入激活状态。
  2. 用鼠标在需要抹除的文字或图片上方**拖出一个矩形框**——此时框选区域会先被一层醒目的斜纹预览标记盖住，代表「待涂黑」，同时顶部工具栏会浮现出**取消标记**和**应用涂黑**两个确认按钮：

  ![画出涂黑标记后的页面](img/pdf-redact.png)

  3. 核对无误后点击**应用涂黑**并在弹窗中确认，GenOffice 会让你另存为一份全新的脱敏工作副本并自动在当前窗口打开它——在这份副本中，刚才被框住区域的底层文字流与图像数据已经从 PDF 文件结构里被**彻底物理擦除**（绝不是简单在上面盖一层能被别人移走或复制出底字的黑框），任何人都无法恢复；与此同时，你磁盘上的原始未涂黑文件保持原样不动，防止误删无法挽回。

  如果在正式点击「应用涂黑」之前发现框画歪了或者框多了，只需点击工具栏上的**取消标记**，就能一键清空当前页面上所有尚未生效的斜纹框并重新框选。

## 便签与评论线程

- **放置图钉便签**：在「注释」页签选择**便签工具**后，在页面需要批注的位置单击一下即可钉上一枚醒目的小图钉，同时在页边展开一张评论输入卡片（评论者的署名可以在设置或卡片中自定义）；输入完毕点击确认后，这条便签就会以标准的 PDF Text 注释格式保存下来，在 Adobe Acrobat 或系统预览里都能正常识别。
- **扁平化评论回复线程**：单击页面上已有的图钉即可展开完整的讨论卡片，你可以直接在下面**回复**他人的批注（采用与 WPS 和 Acrobat 相同的扁平化对话流呈现）、随时重新**编辑**自己写下的评论内容，或者一键**删除**单条回复乃至整个讨论串。
- **安全的修改写回**：正在编辑但尚未保存的评论草稿在会话期间会稳妥保留；一旦触发手动保存或自动保存，更新后的文字就会精准写回 PDF 文件内部原有的那条注释对象中，完整保留上下文的回复关联关系。

## 编辑 PDF 内容（编辑页签）

- **直接编辑正文文字**：在「编辑」页签下点击**编辑文字**，即可直接用鼠标点进 PDF 页面上的现有文字块进行增删改字（底层由高性能的 pdfium 引擎驱动，并会自动分析原段落的字形属性，尽最大可能匹配并延续原有的复杂字体与字号外观）。
- **插入全新文字块**：点击**插入文字**后在页面任意空白处单击，就能放下一个全新的可搜索文本框，并自由指定它的字体家族、字号大小与文字颜色。
- **插入图片与图章**：支持从本地磁盘挑选图片（如公司 Logo、票据截图）插入到 PDF 页面任意位置并自由缩放，也可以直接加盖预设或自定义的审阅图章。
- **扫描件 OCR 文字识别与原位改字**：面对只有页面图片、选不中任何文字的扫描版 PDF，点击**识别文字（Recognize text）**即可对文档中的所有扫描页运行本地 OCR 识别（不设死板的页数上限），在页面上生成一层既能全文搜索、又能直接双击进入**原位修改（in-place edit）**的文字层；更贴心的是，在编辑识别出的文字时，原始扫描底图依然保留在下方供你比对，你可以随时点击工具条上的**眼睛图标开关**，决定修改后的文字是直接渲染显示在页面表面，还是仅保留在透明的底层搜索层里。
- **交互式表单填写**：对于包含标准 AcroForm 表单域的 PDF（如申请表、报销单、税务表格），无需切换任何特殊模式，直接点击输入框、复选框或下拉项就能就地填写，所有填好的表单数据都会在保存文件时直接持久化写入 PDF。

## 签名（手写、图片与数字证书）

- **手绘墨迹签名**：用鼠标或触控板直接手写绘制你的个人签名，既可以自由贴在页面任意位置，也可以直接绑定到 PDF 表单的专用签名域上。
- **图片印章签名**：上传一张已有的透明底手写签名照片或印章图片作为签名直接落版。
- **签名库复用**：创建好的手写签名或图片签名会自动保存在本机签名库中，以后给其他合同文件签字时点一下就能直接拖出来复用，不用每次重画。
- **数字证书加密签名（注释页签）**：需要具备防篡改法律效力的正式电子签章时，可以在「注释」页签点击**证书签名**，直接调用操作系统证书库里的个人证书，或者导入本地的 `.p12` / `.pfx` 证书文件进行签名；签名时既可以选择在页面指定位置盖上可见的签章外观，也可以选择对文档执行「认证签名（Certify）」以限制他人后续修改。
- **增量写入保护多方会签**：每一次加盖数字证书签名，GenOffice 都会采用 PDF 标准的**增量更新（Incremental Update）**方式写出一个新文件并在当前标签页打开它——这样在一份多人会签的合同上，你签下名字后绝不会破坏前面其他人已经盖好的数字签名有效性；注意在签名前请先保存好正文修改，因为数字签名锁定的是文件落盘那一刻的精确字节。
- **签名验证横幅**：打开任何带有数字签名的 PDF 时，文档顶部都会自动出现一条醒目的签名状态横幅；点击**查看签名**即可逐一检查每个签名的哈希完整性、签名覆盖范围以及完整的证书颁发链（当前全部在本地离线校验，不发起联网的 CRL / OCSP 吊销状态查询）。

## 页面操作（页面页签）

- **可视化旋转、删除与拖拽重排**：在左侧缩略图栏或「页面」页签里，直接用鼠标按住页面缩略图上下拖动就能重新编排页码顺序；删除页面前会弹出确认提示，防止误删重要页面。
- **跨文档导入页面与插入空白页**：点击**导入页面**可以把另一份 PDF 文件里的指定页面直接抽进来插到当前文档中；点击**插入空白页**则能在当前位置快速补入一张同尺寸的干净白纸供你写字或贴图。
- **替换页面与边距裁剪**：**替换页面**可以用另一份 PDF 的页面把当前文档中连续的一段页码整体换掉（非常适合替换排版更新后的某几页正文）；**裁剪页面**则允许你拉框裁掉多余的白边或页眉页脚，并支持勾选「应用到全部页面」一次性统一整本书的版心。
- **统一纸张尺寸与倒序排列**：当一份合并出来的 PDF 里既有 A4 又有巨幅扫描图时，使用**页面大小**可以把整份文档的所有页面一键等比缩放到同一种标准纸张规格；而双面扫描仪扫反了页序时，点一下**倒序排列**就能把整份文档从最后一页到第一页彻底翻转过来。
- **提取页面**：将当前选中的一页或多页单独抽取出来，直接另存为一份全新的独立 PDF 文件。
- **拆分 PDF**：提供两种实用的拆分方式——第一种是**按页码范围拆分**，把一份长 PDF 切成若干个独立的子文件；第二种是**网格切分单页**，把每一张大幅面页面（比如对开扫描的书页或海报）按行列网格裁成多张小页面。
- **合并 PDF**：同样提供两种合并形态——既可以把外部的一份或多份 PDF 文件按顺序**追加拼接**到当前文档里，也可以把多页内容**拼版缩印到同一张纸**上。为了保护系统稳定性，在开始读取文件合并之前，GenOffice 会先预先核算所有待合并文件的总大小，一旦**总体积超过 1 GiB 就会主动拦截**并给出清晰提示，避免超大文件一次性耗尽系统内存。
- **安全的落盘策略**：所有页面级的旋转、重排、裁剪与增删都会在你下一次按下保存时写回文件；如果你使用「另存为」保存工作副本，磁盘上的原始 PDF 文件将保持毫发无损。

## 导出与打印

- **本地导出为 Word / PPT / Excel**：无论是通过顶部菜单 **文件 ▸ 导出为 Word… / PPT… / Excel…**，还是直接点击功能区上的 **PDF 转换** 按钮，所有格式转换都在你本机离线完成，不会把任何一页文档上传到外部服务器。导出为 `.pptx` 时会按「每一页 PDF 生成一张幻灯片」转换，导出为 `.xlsx` 时则会按「每一页 PDF 生成一张独立工作表」提取表格与文字，并在导出前让你自由选择保存路径。
- **所见即所得打印**：按下 `⌘P` / `Ctrl+P` 或点击打印按钮即可调用系统打印服务，严格按照你当前调整好的页面顺序与旋转方向输出，并支持自由指定打印页码范围。

## 保存与涂黑安全边界

- **常规保存与自动保存**：日常做的文字高亮、便签、正文改字、OCR 文字层以及页面整理，在手动保存或触发自动保存时都会通过防断电的原子写入直接更新到当前文件中。
- **涂黑脱敏强制另存副本**：唯有**涂黑（Redact）在点击「应用涂黑」时**会强制引导你生成一份全新的文件副本，而绝不直接覆盖原文件——这样既确保外发给别人的副本里敏感信息已被彻底物理清除，又避免你自己手里的原始底稿因为一次不可逆的涂黑而永远失去原文。
