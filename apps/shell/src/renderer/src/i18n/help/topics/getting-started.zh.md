# 快速入门：界面与基本操作

GenOffice 是一个完全运行在本机的办公套件：一个窗口、一排标签页，装着文档（Docs）、表格（Sheets）、幻灯片（Slides）、PDF、Markdown 和网页（HTML）六个编辑器。文件读写的是真正的 .docx / .xlsx / .pptx / .pdf，与 Word、Excel、PowerPoint 完全互通，不需要联网。

## 界面总览

![主屏一览](img/home-screen.png)

窗口分为三块：

- **顶部标签条**：每个打开的文件是一个标签页。最左边的「主页」标签永远存在、不可关闭；其余标签对应你打开的文档，双击标签可以直接重命名文件。
- **内容区**：当前标签对应的编辑器（或主页）。
- **菜单栏**：macOS 在系统菜单栏，Windows/Linux 在窗口顶部。文件、编辑、视图等菜单会随当前标签切换成对应编辑器的版本。

## 新建文档

三种方式任选：

- 在**主页**的「快速开始」区点对应的卡片（AI 文档、AI 表格、AI 幻灯片等）。
- 菜单 **文件 ▸ 新建**：Docs（⌘N/ctrl+N）、表格、幻灯片、Markdown、网页、PDF 六种。
- 直接把文件拖进窗口，或双击系统里的文件（若 GenOffice 已设为默认应用）。

新建的文档先以「未命名」状态打开，第一次保存时才会在磁盘上创建文件。

## 打开文件

- 菜单 **文件 ▸ 打开**（⌘O/ctrl+O）弹出系统选择框，支持 .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 主页的「最近使用」列表直接点开。
- 命令行 `genoffice <文件>` 也可以打开（适配脚本）。

## 保存模型

- **手动保存**：⌘S/ctrl+S，或 文件 ▸ 保存 / 另存为。第一次保存会让你选位置和文件名。
- **自动保存**：只有在同一个文件上做过**至少一次手动保存**之后才会开启——只读不改的 PDF 永远不会被悄悄改写。自动保存触发于内容变更后的短暂停顿。
- 关闭有未保存改动的标签时，会先询问「保存 / 放弃 / 取消」。
- 所有写入都是原子落盘（先写临时文件再改名），中途断电不会留下半个文件。

## 常用快捷键

| 操作       | macOS | Windows / Linux |
| ---------- | ----- | --------------- |
| 新建文档   | ⌘N    | ctrl+N          |
| 打开       | ⌘O    | ctrl+O          |
| 保存       | ⌘S    | ctrl+S          |
| 关闭标签   | ⌘W    | ctrl+W          |
| 打开本手册 | F1    | F1              |

各编辑器内部（格式刷、查找替换、表格操作等）的快捷键见对应章节；Docs 还带一个可搜索的快捷键对话框（菜单 视图 或 帮助里的「键盘快捷键」）。
