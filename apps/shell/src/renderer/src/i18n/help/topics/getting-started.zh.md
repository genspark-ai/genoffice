# 快速入门：界面与基本操作

GenOffice 是一套完全运行在你自己电脑上的本地办公套件，它将文字处理（Docs）、电子表格（Sheets）、演示文稿（Slides）、PDF、Markdown 和网页（HTML）六款编辑器整合在同一个窗口和同一排顶部标签页里。所有编辑器读写的都是标准的 .docx、.xlsx、.pptx 与 .pdf 文件，与微软 Word、Excel、PowerPoint 保持原生互通，日常打开、编辑和保存文档完全不需要联网。

## 界面总览

![主屏一览](img/home-screen.png)

打开应用后，整个主窗口由三个核心部分加上全局界面缩放控制组成：

- **顶部标签条**：你打开的每一个文档都会在这里显示为一个独立的标签页，可以像使用浏览器一样随时点击切换、拖拽排序或拉出成新窗口。最左边的「主页」标签页永远常驻且不可关闭，方便你随时回到文件列表；其余文档标签只要双击标题（或右键选择「重命名」），就能在原地直接修改磁盘上的文件名。
- **中央内容区**：占据窗口绝大部分面积的主工作区，会根据你当前激活的标签页自动切换成对应的编辑器画布（或者在切回「主页」标签时显示最近文件、收藏夹与本地目录列表）。
- **系统与窗口菜单栏**：在 macOS 上位于屏幕顶部的系统菜单栏，在 Windows 和 Linux 上则嵌在窗口最上方。这里的「文件」「编辑」「视图」等下拉菜单并不是静态不变的，而是会随着你当前切换到的文档类型，动态替换成该编辑器专属的命令集合。
- **界面整体缩放**：如果你在高分屏、外接大显示器或紧凑型笔记本屏幕上觉得整个软件的按钮、文字和侧边栏偏小或偏大，可以通过顶部菜单 **视图 ▸ 放大 / 缩小 / 实际大小**（macOS 快捷键为 `⌘⌃=` / `⌘⌃-` / `⌘⌃0`，Windows 与 Linux 为 `Ctrl+Alt+=` / `Ctrl+Alt+-` / `Ctrl+Alt+0`）把整个应用窗口的 UI 比例在 80% 到 150% 之间按档位缩放，而且无论是 macOS 左上角的红黄绿窗口按钮还是 Windows 右上角的最小化与关闭按钮，在缩放时都会自动留出安全间距，绝不会与标签栏发生遮挡。

## 新建文档

想要创建一份空白文档时，可以根据你当前所处的位置任选以下三种最顺手的方式：

- 在**主页**顶部的[快速开始](help://getting-started)区域，直接点击对应的文档卡片（包括 AI 文档、AI 表格、AI 幻灯片、AI Markdown、AI 网页和 AI PDF），系统会立即新建对应格式的文件并切入编辑器。
- 在任何界面打开顶部菜单栏的 **文件 ▸ 新建**，从下拉菜单中选择 Docs 文字文档（也可以直接按快捷键 `⌘N` / `Ctrl+N`）、电子表格、演示文稿、Markdown、网页或空白 PDF。
- 直接从操作系统的访达（Finder）或文件资源管理器里把已有的本地文件拖进 GenOffice 窗口，或者在将 GenOffice 设为系统默认办公软件后直接双击桌面上和文件夹里的文档图标。

除了空白 PDF 需要立即落盘以外，新建的各类文档一开始都会以「未命名」的内存草稿状态在标签页里打开，只有当你第一次按下保存键时，才会在磁盘上真正创建出文件。

## 打开文件

- 点击顶部菜单 **文件 ▸ 打开**（或按下快捷键 `⌘O` / `Ctrl+O`）会唤起操作系统的原生文件选择窗口，原生支持打开 `.docx`、`.doc`、`.xlsx`、`.xls`、`.csv`、`.tsv`、`.pptx`、`.ppt`、`.pdf`、`.md`、`.html` 以及 `.txt`、`.json` 等常见办公与文本格式，并且支持按住 Shift 或 Command/Ctrl 一次框选多个文件同时打开到不同标签页。
- 切到主屏的「最近使用」或「收藏」列表，直接单击任意一行文件即可在当前窗口的新标签页里打开它；如果该文件已经在某个标签页里开着，则会直接帮你切到那个标签页而不会重复打开两份。
- 如果你习惯使用终端或编写自动化脚本，也可以直接在命令行里运行 `genoffice <文件路径>`，把指定文档直接推送到正在运行的 GenOffice 窗口中打开。

## 文件的保存与自动保存机制

- **手动保存与另存为**：在任何编辑器里按下 `⌘S` / `Ctrl+S`（或通过菜单 **文件 ▸ 保存 / 另存为**）即可把当前修改写入磁盘；如果是刚新建的「未命名」文档，第一次保存时会先弹出系统保存框让你挑好存放目录并输入文件名。
- **安全的自动保存策略**：为了防止你只是打开一份他人发来的文档或 PDF 随便翻看几眼、却被后台悄悄改写了文件时间戳甚至覆盖了原件，某个文件的自动保存只有在你对该文件执行过**至少一次手动保存**之后才会正式接管；接管后，每当你输入内容并短暂停顿，最新改动就会自动同步到磁盘。
- **关闭前的未保存保护**：只要当前标签页里存在还没写入磁盘的改动，无论是点击标签上的 `×` 还是按快捷键关闭窗口，系统都会先弹出提示框让你明确选择「保存」「放弃更改」或「取消」，绝不会悄无声息地丢掉你的心血。
- **防断电原子写入**：GenOffice 的每一次存盘都采用严格的「先写入同目录临时文件、校验完整后再原子重命名替换原文件」机制，哪怕在保存瞬间遇到电脑断电、死机或磁盘满载，磁盘上也绝不会留下损坏了一半的废文件。

## 常用全局快捷键

| 操作       | macOS | Windows / Linux |
| ---------- | ----- | --------------- |
| 新建文档   | ⌘N    | ctrl+N          |
| 打开       | ⌘O    | ctrl+O          |
| 保存       | ⌘S    | ctrl+S          |
| 关闭标签   | ⌘W    | ctrl+W          |
| 打开本手册 | F1    | F1              |
| 折叠功能区 | ⌥⌘R   | Ctrl+F1         |

**折叠与精简功能区**在所有带功能区（Ribbon）的编辑器里都可以使用：按下 `⌥⌘R`（Windows 与 Linux 为 `Ctrl+F1`）或者直接双击当前选中的功能区页签标题（如「开始」「插入」），下方的整排工具按钮就会收起，只保留最上面薄薄一行页签名称，从而给正文画布腾出更大的纵向视野；收起期间只需单击任意一个页签名称就能重新展开命令面板，而且每个编辑器都会各自记住你上次离开时是展开还是折叠状态。此外，Docs 文字编辑器还额外提供了一档介于完整展开与彻底折叠之间的**紧凑模式**：按下 **⌥⌘K**（Windows 与 Linux 为 `Ctrl+Alt+K`）即可把命令条上的文字标签隐去、只保留一排紧凑的图标按钮，这个偏好同样会在下次启动时自动保留。

至于各个编辑器内部专属的操作快捷键（比如格式刷、查找替换、插入行列、幻灯片放映等），可以在对应编辑器的章节或完整的「快捷键一览」章节中查阅；在 Docs 文字编辑器中，你还可以随时按下 **⌘/**（或 `Ctrl+/`，也可从「视图」与「帮助」菜单进入）呼出一个支持实时搜索的「键盘快捷键」速查窗口。

## Option+Command（Ctrl+Alt）结构化快捷键组

在桌面版微软 Word 中，`Option+Command`（Windows 上对应 `Ctrl+Alt`）这一层组合键专门留给了标题样式切换、插入批注与脚注等结构化编辑命令；GenOffice 完全沿用了这套肌肉记忆设计。其中绝大部分组合键归 Docs 文字编辑器使用，Sheets 电子表格也利用这一层补齐了两个与 Excel for Mac 对齐的边框快捷键，外加一个在所有编辑器里通用的功能区折叠键。

**Docs 文字编辑器**

| 快捷键（macOS） | 作用           | Windows / Linux    |
| --------------- | -------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 标题 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 正文           | Ctrl+Alt+0         |
| ⌥⌘M             | 段落           | Ctrl+Alt+M         |
| ⌥⌘A             | 新建批注       | Ctrl+Alt+A         |
| ⌥⌘F             | 插入脚注       | Ctrl+Alt+F         |
| ⌥⌘E             | 插入尾注       | Ctrl+Alt+D         |
| ⌥⌘G             | 定位           | Ctrl+G             |

仔细看上面这张表会发现，有两项在 macOS 与 Windows 上的按键字母并不完全呈镜像关系，这同样是为了与桌面版 Word 保持一致：因为 **macOS 系统自身占用了 `⌥⌘D`** 用来切换程序坞（Dock）的自动隐藏，所以「插入尾注」在 Mac 上改用 `⌥⌘E`，而在 Windows 与 Linux 上则保持大家熟悉的 `Ctrl+Alt+D`；另外「定位」对话框在 Mac 上使用带 Option 的 `⌥⌘G`（把 `⌘G` / `⇧⌘G` 留给查找与字数统计），而在 Windows 上直接使用更简短的 `Ctrl+G`。

**Sheets 电子表格**（当表格网格处于焦点状态时）

| 快捷键（macOS） | 作用     | Windows / Linux |
| --------------- | -------- | --------------- |
| ⌥⌘0             | 外侧框线 | Ctrl+Shift+7    |
| ⌥⌘−             | 无框线   | Ctrl+Shift+−    |

这里的平台差异同样源于 Excel 的历史设计：在 Excel for Mac 中，添加外侧框线同时支持 `⌘⇧7` 和 `⌥⌘0` 两套按键，而在 Windows 版 Excel 中一直使用的是 `Ctrl+Shift+7` 和 `Ctrl+Shift+-`。因此 GenOffice 在两个平台上分别保留了各自最地道的按键习惯，不必强行去记另一套陌生组合。

需要注意的是，**`⌥⌘0` 在 Docs 里代表「应用正文样式」，而在 Sheets 里代表「添加外侧框线」**。由于这两个编辑器分别运行在各自的标签页中、永远不会同时争抢焦点，日常使用时完全不会发生冲突；这也意味着 `⌥⌘0` 已经被具体编辑器认领，不再作为跨应用的全局快捷键。

**所有编辑器通用**：如前文所述，按下 **`⌥⌘R` / `Ctrl+F1`** 可以在任何编辑器里一键收起或展开顶部功能区。

这样分配下来，macOS 上除了被系统 Dock 占走的 `⌥⌘D` 以外，整套 `Option+Command` 快捷键层既保留了老用户的习惯，又做到了各司其职、互不打架。
