# 快速入门：界面与基本操作

GenOffice 是一个完全运行在本机的办公套件：一个窗口、一排标签页，装着文档（Docs）、表格（Sheets）、幻灯片（Slides）、PDF、Markdown 和网页（HTML）六个编辑器。文件读写的是真正的 .docx / .xlsx / .pptx / .pdf，与 Word、Excel、PowerPoint 完全互通，不需要联网。

## 界面总览

![主屏一览](img/home-screen.png)

窗口分为三块：

- **顶部标签条**：每个打开的文件是一个标签页。最左边的「主页」标签永远存在、不可关闭；其余标签对应你打开的文档，双击标签可以直接重命名文件。
- **内容区**：当前标签对应的编辑器（或主页）。
- **菜单栏**：macOS 在系统菜单栏，Windows/Linux 在窗口顶部。文件、编辑、视图等菜单会随当前标签切换成对应编辑器的版本。

## 新建文档

三种方式任选：

- 在**主页**的[快速开始](help://getting-started)区点对应的卡片（AI 文档、AI 表格、AI 幻灯片等）。
- 菜单 **文件 ▸ 新建**：Docs（⌘N/ctrl+N）、表格、幻灯片、Markdown、网页、PDF 六种。
- 直接把文件拖进窗口，或双击系统里的文件（若 GenOffice 已设为默认应用）。

新建的文档先以「未命名」状态打开，第一次保存时才会在磁盘上创建文件。

## 打开文件

- 菜单 **文件 ▸ 打开**（⌘O/ctrl+O）弹出系统选择框，支持 .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 主页的「最近使用」列表直接点开。
- 命令行 `genoffice <文件>` 也可以打开（适配脚本）。

## 保存模型

- **手动保存**：⌘S/ctrl+S，或 文件 ▸ 保存 / 另存为。第一次保存会让你选位置和文件名。
- **自动保存**：只有在同一个文件上做过**至少一次手动保存**之后才会开启——只读不改的 PDF 永远不会被悄悄改写。自动保存触发于内容变更后的短暂停顿。
- 关闭有未保存改动的标签时，会先询问「保存 / 放弃 / 取消」。
- 所有写入都是原子落盘（先写临时文件再改名），中途断电不会留下半个文件。

## 常用快捷键

| 操作       | macOS | Windows / Linux |
| ---------- | ----- | --------------- |
| 新建文档   | ⌘N    | ctrl+N          |
| 打开       | ⌘O    | ctrl+O          |
| 保存       | ⌘S    | ctrl+S          |
| 关闭标签   | ⌘W    | ctrl+W          |
| 打开本手册 | F1    | F1              |
| 折叠功能区 | ⌥⌘R   | Ctrl+F1         |

**折叠功能区**在每个编辑器里都可用：标签行照旧保留，下面的命令条收起；选中的标签同时充当折叠开关，所以功能区折叠期间不会有标签处于选中状态，按任意标签即可让命令条重新出现。双击标签效果相同。折叠与否按编辑器分别记住。

各编辑器内部（格式刷、查找替换、表格操作等）的快捷键见对应章节；Docs 还带一个可搜索的快捷键对话框（**⌘/**）（菜单 视图 或 帮助里的「键盘快捷键」）。

## Option+Command 这一组快捷键

Option+Command 是 Word 留给结构化跳转的层级，GenOffice 也按同样的方式填充。其中大部分归 Docs，Sheets 也有两个自己的快捷键，用来对齐 Excel；另外还有一个组合在所有编辑器里都能用。

**Docs**

| 快捷键（macOS） | 作用           | Windows / Linux    |
| --------------- | -------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 标题 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 正文           | Ctrl+Alt+0         |
| ⌥⌘M             | 段落           | Ctrl+Alt+M         |
| ⌥⌘A             | 新建批注       | Ctrl+Alt+A         |
| ⌥⌘F             | 插入脚注       | Ctrl+Alt+F         |
| ⌥⌘E             | 插入尾注       | Ctrl+Alt+D         |
| ⌥⌘G             | 定位           | Ctrl+G             |

其中两个在 Windows 上会变，原因和 Word 拆分它们的一样。**macOS 占用了 ⌥⌘D**——它用来显示和隐藏 Dock——所以尾注在 Mac 上是 ⌥⌘E，在其他地方是 Ctrl+Alt+D。而**定位**则省掉了 Alt：Mac 上的组合键带着 Alt，Windows 上只要 Ctrl+G。

**Sheets**（网格获得焦点时）

| 快捷键（macOS） | 作用     | Windows / Linux |
| --------------- | -------- | --------------- |
| ⌥⌘0             | 外侧框线 | Ctrl+Shift+7    |
| ⌥⌘−             | 无框线   | Ctrl+Shift+−    |

Windows 并不是把 Mac 上那两个组合改写一遍。Excel for Mac 给 Sheets **两套都有**——⌘⇧7 和 ⌥⌘0 是同一种外侧框线的两个按键——所以在 Windows 上这个命令保留它本来就有的 Ctrl+Shift 位置，而 Option 这一层干脆就不存在。

注意 **⌥⌘0 在 Docs 里是「正文」，在 Sheets 里是「外侧框线」**。两者不会出现在同一个编辑器里，所以实际使用不会冲突；但 ⌥⌘0 已经被占用，不能再作为全局快捷键。

**所有编辑器**：**⌥⌘R / Ctrl+F1** 按上文所说的折叠功能区。

这样一来，macOS 上的 ⌥⌘D 就空着留给 GenOffice，将来若有命令想用，随时可以拿。
