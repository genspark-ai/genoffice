# หน้าแรก: ไฟล์ของคุณอยู่ที่ไหน

หน้าแรกคือหน้าเริ่มต้นของ GenOffice: แถบนำทางอยู่ทางซ้าย ส่วนรายการไฟล์และการ์ดสร้างด่วนอยู่ทางขวา

![หน้าแรก](img/home-screen.png)

## การนำทางในแถบด้านข้าง

- **ล่าสุด**: ไฟล์ที่คุณเปิดล่าสุด จัดกลุ่มตามช่วงเวลา (สัปดาห์นี้ / เดือนนี้ / ก่อนหน้านี้)
- **รายการโปรด**: ไฟล์ที่คุณทำเครื่องหมายดาวไว้ วางเลื่อนเมาส์เหนือแถวไฟล์แล้วคลิกดาวเพื่อเพิ่มหรือนำออก
- **Genspark Projects**: หลังจากลงชื่อเข้าใช้บัญชี Genspark จะแสดงโปรเจกต์ที่คุณสร้างด้วย Genspark AI บนเว็บ คลิกที่โปรเจกต์เพื่อกลับไปแก้ไขต่อในเบราว์เซอร์ รองรับการค้นหา การเรียงตามเวลา การรีเฟรช และการโหลดเพิ่มเติม
- **โฟลเดอร์**: ปักหมุดโฟลเดอร์ที่ใช้บ่อยไว้ในแถบด้านข้าง (เพิ่มโฟลเดอร์…) แล้วกระโดดไปหาได้เหมือนที่คุณใช่บุ๊กมาร์ก รายการที่เข้าไม่ได้จะแสดงว่าไม่พร้อมใช้งานและนำออกจากรายการได้
- **ถังขยะ**: ชี้ไปยังถังขยะของระบบ ไฟล์ที่ลบจะไปอยู่ที่นั่นและกู้คืนจากระบบปฏิบัติการได้

## รายการไฟล์

แต่ละแถวจะแสดงไอคอน ชื่อไฟล์ เวลาที่แก้ไข และข้อมูลอื่น **⋯ เมนู** ของแถวมีตัวเลือก:

- **เปลี่ยนชื่อ**: เปลี่ยนชื่อแบบอินไลน์ โดยคงนามสกุลไฟล์ไว้ให้อัตโนมัติ
- **เพิ่มในรายการโปรด / นำออกจากรายการโปรด**
- **สร้างสำเนา**: สร้างสำเนาไว้ในโฟลเดอร์เดียวกัน
- **ลบ**: ย้ายไฟล์ไปยังถังขยะของระบบ ไม่ใช่การลบถาวร
- **แสดงในโฟลเดอร์**: ค้นหาตำแหน่งไฟล์ในโปรแกรมจัดการไฟล์ของคุณ

## การค้นหา

ช่องค้นหาด้านบนค้นหาสองอย่างพร้อมกัน:

- **ชื่อไฟล์**: กรองตามชื่อได้อย่างรวดเร็ว
- **เนื้อหาไฟล์**: GenOffice จัดทำดัชนีไฟล์ของคุณอยู่เบื้องหลัง (ข้อความในไฟล์ docx/xlsx/pptx/pdf/md/html โดยใช้ OCR เป็นทางสำรองสำหรับ PDF ที่เป็นภาพสแกน) การค้นหาจากข้อความในเนื้อหาจึงหาไฟล์เจอด้วย ขอบเขตและตัวเลือกเปิดปิดอยู่ในการตั้งค่าการค้นหา

## การ์ดเริ่มต้นอย่างรวดเร็ว

การ์ดเหนือรายการไฟล์สร้างเอกสารใหม่ได้ในขั้นตอนเดียว การคลิกการ์ดจะสร้างไฟล์ประเภทนั้นและเปิดตัวแก้ไขของมันขึ้นมา คุณเริ่มพิมพ์ได้ทันที หรือให้ AI ร่างให้ก็ได้ (ทุกตัวแก้ไขมี **ปุ่ม AI** ในแถบเครื่องมือ และมี **ถาม AI** ในเมนูคลิกขวาของข้อความที่เลือก)

ไฟล์ใหม่จะไปอยู่ในโฟลเดอร์ที่เลือกอยู่ในแถบด้านข้าง หากไม่ได้เลือกไว้ก็จะไปยังโฟลเดอร์เริ่มต้น

แต่ละการ์ดทำอะไร:

- **AI Docs** (.docx): เอกสารข้อความว่างในตัวแก้ไข Docs ไฟล์จะถูกเขียนลงดิสก์เมื่อ **บันทึกครั้งแรก** เท่านั้น และเอกสารใหม่จะเปิดมาพร้อมแผง AI ที่กางออก (ปิดได้ที่ การตั้งค่า → "เปิดแผง AI ในเอกสารใหม่")
- **AI Sheets** (.xlsx): สเปรดชีตว่างในตัวแก้ไข Sheets ก่อนที่คุณจะบันทึก ยังไม่มีไฟล์อยู่บนดิสก์ เพราะชื่อถูกกันไว้ให้การบันทึกครั้งแรก และหลังจากให้ AI สร้างเนื้อหาครั้งแรกแล้ว ไฟล์ยังถูกตั้งชื่ออัตโนมัติตามเนื้อหาได้ด้วย
- **AI Slides** (.pptx): งานนำเสนอว่างในตัวแก้ไข Slides
- **AI Markdown** (.md): เอกสาร Markdown ว่างในตัวแก้ไข Markdown
- **AI HTML** (.html): เว็บเพจว่างในตัวแก้ไข HTML
- **AI PDF** (.pdf): ต่างจากอีกการ์ด เพราะมัน **สร้างทันที** เป็น PDF ว่างหน้าเดียวของจริงในโฟลเดอร์เป้าหมาย แล้วเปิดเป็นไฟล์ปกติ (ตัวแก้ไข PDF ทำงานกับไฟล์จริง) เหมาะกับการใส่คำอธิบาย ปิดบังข้อมูล หรือเพิ่มข้อความ และไฟล์จะถูกตั้งชื่ออัตโนมัติตามเนื้อหาได้ตอนบันทึกครั้งแรก
- **เปิดไฟล์ในเครื่อง**: กล่องเลือกไฟล์ของระบบสำหรับ Word (.docx/.doc), Excel (.xlsx/.xlsm/.xls/.csv/.tsv), PowerPoint (.pptx/.ppt), PDF, Markdown (.md/.markdown) และเว็บเพจ (.html/.htm) เลือกได้หลายไฟล์ และแต่ละไฟล์จะได้แท็บของตัวเอง

> เคล็ดลับ: เมนู ไฟล์ ▸ สร้างใหม่ ในแถบเมนูสร้างเอกสารชนิดเดียวกันได้ (⌘N/Ctrl+N เริ่มต้นเป็นเอกสารข้อความ) และการลากไฟล์เข้ามาในหน้าต่างจะเปิดไฟล์นั้น

## โปรเจกต์บนคลาวด์ (Genspark Projects)

- การใช้งานครั้งแรกต้องลงชื่อเข้าใช้บัญชี Genspark (ขั้นตอนแบบรหัสอุปกรณ์: GenOffice จะแสดงรหัส คุณจบการเข้าสู่ระบบในเบราว์เซอร์)
- รายการโปรเจกต์จะซิงก์กับเว็บ คำสั่ง เปิดในเบราว์เซอร์ จะกระโดดไปที่นั่นเพื่อทำงานต่อ
- การไม่ลงชื่อเข้าใช้ไม่กระทบคุณสมบัติในเครื่องใด ๆ ทั้งสิ้น
