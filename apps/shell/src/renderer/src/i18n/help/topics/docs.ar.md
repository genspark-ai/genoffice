# Docs: معالجة النصوص

Docs هو محرّر نصوص شبيه بـ Word: يقرأ ويكتب ملفات .docx حقيقية مع ترقيم صفحات يطابق تمامًا ما يُعرض على الشاشة.

## الشريط

التبويبات: **الصفحة الرئيسية / إدراج / تخطيط / تصميم / مراجع / مراجعة / عرض**، إضافة إلى تبويبات سياقية تظهر حسب العنصر المحدّد (تصميم الجدول، الصور).

- **الصفحة الرئيسية**: الحافظة؛ الخط (بما في ذلك مقاسات خطوط CJK وعلامات التوكيد)؛ الفقرة (المحاذاة/المسافة البادئة/تباعد الأسطر/القوائم)؛ الأنماط (عنوان 1-6/عادي/اقتباس، قابلة للتعديل).
- **إدراج**: فواصل الصفحات والأقسام، الجداول (بما فيها الجداول السريعة)، الصور، الأشكال، الارتباطات التشعبية، الرأس والتذييل، أرقام الصفحات، التاريخ، مربعات النص.
- **تخطيط**: الهوامش، اتجاه الورقة وحجمها، الأعمدة، المسافات البادئة وتباعد الفقرات.
- **تصميم**: السمات، مجموعات الألوان، العلامة المائية، حدود الصفحة.
- **مراجع**: جدول المحتويات (قابل للتحديث)، الحواشي والتعليقات الختامية، التسميات التوضيحية، الإسنادات الترافقية.

  ![تبويب مراجع](img/docs-references.png)

- **مراجعة**: التدقيق الإملائي، التعليقات، تعقّب التغييرات (عروض «الكل» و«التبسيط»)، عدد الكلمات.
- **عرض**: المسطرة، خطوط الشبكة، جزء التنقل، التكبير، و«اختصارات لوحة المفاتيح» القابلة للبحث.

## قائمة النقر بزر الفأرة الأيمن

انقر بالزر الأيمن في أي موضع من المتن — تتكيّف القائمة مع ما نقرت عليه. المجموعات الرئيسية:

- **الحافظة**: قص / نسخ / لصق / **لصق كنص عادي**.
- **الخط والفقرة**: تغيير العائلة والحجم، الغامق والمائل والتسطير، المحاذاة والمسافات البادئة والتباعد دون الحاجة إلى فتح الشريط.
- **مرادفات**: تعرض مرادفات الكلمة المحدّدة؛ انقر أحدها للاستبدال.
- **ترجمة** (الذكاء الاصطناعي): يترجم المحدّد إلى اللغة الهدف (الإنجليزية، الصينية المبسّطة، اليابانية، الكورية، الفرنسية، الألمانية، الإسبانية، ...) عبر لوحة الذكاء الاصطناعي.
- **تعليق جديد**: يرفق تعليقًا بالمحدّد.
- **تدقيق إملائي** (عند كلمة خاطئة): البدائل المقترحة، تجاهل الكل، الإضافة إلى القاموس، ضبط لغة التدقيق.
- **ارتباط تشعبي**: فتح / تحرير / نسخ الرابط / إزالة الارتباط التشعبي.
- **صورة**: عرض الصورة، حفظ الصورة باسم…، **التفاف النص** (داخل السطر / مربع يمين ويسار / أعلى وأسفل / خلف النص / أمام النص)، ترتيب العناصر.
- **الحقول** (جدول المحتويات، أرقام الصفحات): تحديث الحقل / إظهار وإخفاء أكواد الحقول / تحرير الحقل.
- **ترقيم القائمة** (داخل قائمة): إعادة بدء الترقيم / متابعة الترقيم / تغيير مستوى القائمة / تعيين قيمة الترقيم.
- **جدول** (المؤشر داخل جدول): إدراج صفوف/أعمدة، دمج / تقسيم الخلايا، تقسيم الجدول، ملاءمة تلقائية، محاذاة الخلايا، توزيع الصفوف/الأعمدة، خصائص الجدول، قائمة الحذف، تحديد.

## التحرير

- البحث والاستبدال (ctrl+F / ctrl+H): التمييز بين الأحرف الكبيرة والصغيرة، الكلمة الكاملة، التعبيرات النمطية.
- نسخ التنسيق؛ تراجع/إعادة متعدّد المستويات؛ خيارات اللصق.
- الجداول: دمج/تقسيم الخلايا، عمليات الصفوف والأعمدة، الحدود والتظليل، الفرز، الصيغ.
- الصور: التفاف النص، القص، الضغط؛ لوحة الرسم.

## طباعة النصوص الصينية واليابانية والكورية

- انضغاط علامات الترقيم وقواعد كينسوكو في نهاية الأسطر مطابقة لما في Word؛ مع التحويل بين العرض الكامل والنصف.
- يغطي قوائم الخطوط المقترحة أسماء عائلات خطوط CJK الشائعة في Windows وmacOS.

## الذكاء الاصطناعي

- زر الذكاء الاصطناعي في الشريط واللوحة الجانبية: إعادة صياغة، توسيع، ترجمة، تلخيص، إدراج جدول، إضافة إلى ذلك تعليمات حرة.
- يأخذ كل دور للذكاء الاصطناعي لقطة أولًا؛ يمكنك الرجوع من قائمة الإصدارات، ويمكن التراجع عن عملية الرجوع نفسها.

## الحفظ والتصدير

- عند الحفظ بصيغة .docx تُعاد كتابة الفقرات المتغيّرة فقط — أما المحتوى الذي لم يُمس فيبقى كما هو بايتًا ببايت.
- تصدير إلى PDF (حسب الترقيم الحالي) وإلى صور لكل صفحة.

## الطباعة

ctrl+P عبر مربع حوار النظام، والصفحات تظهر كما ستُطبع تمامًا.
