# 主屏（Home）：文件都在哪

主屏是 GenOffice 的起点：左边是导航栏，右边是文件列表和快速创建卡片。

![主屏](img/home-screen.png)

## 侧栏导航

- **最近**：最近打开过的文件。每一行都标着时间——今天、昨天或具体日期。
- **收藏**：你标过星的文件。把鼠标悬停在文件行上点星标即可加入或移出。
- **使用手册**：打开本手册。
- **Genspark Projects**：登录 Genspark 账号后，显示你在网页端用 Genspark AI 创建的项目；点击即可在浏览器中继续编辑。支持搜索、按时间排序、刷新和加载更多。
- **文件夹**：用「添加文件夹…」加入侧栏，或从文件管理器拖进来的目录。每一个都会成为一个根目录，可以打开、在其中新建子文件夹、重命名和移除；离线的根目录显示为「不可用」，也可以从列表中移除。「新建文件夹」可以再建一个。

这里没有「回收站」入口。删除的文件都进了系统废纸篓，怎么还原是操作系统的事。

## 文件列表

每一行显示图标、文件名、修改时间等信息。行上的 **⋯ 菜单** 提供：

- **打开**，以及** 打开所在文件夹**，在系统文件管理器里定位该文件。
- **复制路径**。
- **移动到文件夹…**：打开文件夹选择器并真正移动文件；当目标位置已有同名文件时，可选择跳过、覆盖或重命名。
- **重命名**：就地改名（扩展名自动保留）。
- **收藏 / 取消收藏** — 星标在重启后依然保留，改名后也跟着文件走。
- **创建副本**：在同一目录中创建一份副本。
- **删除**：移入系统废纸篓，不是永久删除。
- **从列表中移除**，在顶层的「最近」视图中，只去掉这一条而不动文件本身。

### 一次处理多个文件

勾选某一行的复选框，或按住 ⌘/ctrl 点击，即可建立选择；表头的复选框全选当前列出的所有项，列表上方的工具条会显示已选数量（**已选 {n} 项**），并为整组提供** 移动到文件夹…**和** 删除文件**。多选之后也可以直接拖到侧栏的某个文件夹上。

## 搜索

顶部的搜索框同时搜两类东西：

- **文件名**：按名称快速过滤。
- **文件内容**：GenOffice 会在后台给文件建索引（docx/xlsx/pptx/pdf/md/html 的文字，扫描版 PDF 走 OCR 回退），所以搜正文也能找到文件。搜索设置里可以调整范围与开关。

## 快速开始卡片

主屏上方的卡片一步创建新文档。点卡片 = 新建一个对应类型的文件并进入它的编辑器——你可以直接自己动手写，也可以让 AI 起草（每个编辑器的功能区都有 **AI 按钮**，或选中内容后右键 ** 问 AI**）。

新建的文件会落在侧栏当前选中的文件夹里；没有选中则落在默认文件夹。

各卡片的作用：

- **AI Docs**（.docx）：空白文字文档，进入 Docs 编辑器。文件在你** 首次保存时**才真正写入磁盘；新文档默认展开 AI 面板，不需要时可在 设置 → 「新文档中打开 AI 面板」关掉。
- **AI Sheets**（.xlsx）：空白电子表格，进入 Sheets 编辑器。保存之前磁盘上并没有这个文件——文件名预留给首次保存；首次让 AI 生成内容后，文件还可按内容自动改名。
- **AI Slides**（.pptx）：空白演示文稿，进入 Slides 编辑器。
- **AI Markdown**（.md）：空白 Markdown 文档，进入 Markdown 编辑器。
- **AI HTML**（.html）：空白网页文档，进入 HTML 编辑器。
- **AI PDF**（.pdf）：和其他卡片不同——它会** 立即**在目标文件夹创建一个真正的空白单页 PDF，并作为普通文件打开（PDF 编辑器处理的是真实文件）。适合在上面做注释、涂黑、添加文字；首次保存时可按内容自动改名。
- **打开本地文件**：弹出系统文件选择框，支持 Word（.docx/.doc）、Excel（.xlsx/.xlsm/.xls/.csv/.tsv）、PowerPoint（.pptx/.ppt）、PDF、Markdown（.md/.markdown）和网页（.html/.htm）。可一次选多个文件，每个文件一个标签页。

> 提示：菜单栏 文件 ▸ 新建 也能新建同样类型的文档（⌘N/Ctrl+N 默认新建文字文档）；把文件直接拖进窗口等于打开它。

## 云端项目（Genspark Projects）

- 首次使用需要登录 Genspark 账号（设备码流程：GenOffice 给你一个码，你在浏览器完成登录）。
- 项目列表与网页端同步；「在浏览器中打开」跳转继续编辑。
- 不登录不影响本地任何功能。
