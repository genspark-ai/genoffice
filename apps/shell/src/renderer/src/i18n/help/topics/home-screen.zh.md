# 主屏（Home）：文件都在哪

主屏（Home）是你每次启动 GenOffice 看到的第一个工作台，也是整个套件的文件管理中心：左侧是常驻的分类导航栏，右侧上方是一排新建文档的快速开始卡片，下方则是清晰的文件列表与全文搜索栏。

![主屏](img/home-screen.png)

## 左侧导航栏

- **最近**：按你最后一次打开或编辑的时间倒序排列所有近期处理过的文档，每一行右侧都会直观标注具体时间（今天、昨天或具体年月日），让你早上打开电脑一眼就能找回昨天没写完的稿子。
- **收藏**：汇总所有被你点亮过星标（`★`）的重要常用文件。在任意文件列表里把鼠标悬停到某一行上，点一下星标即可将它加入或移出收藏夹；当收藏的文件越来越多时，你还可以点开文件行右侧的 `⋯` 菜单选择**移动到分组**，把文件归入自己起名的项目或专题分组中，并在收藏视图顶部按分组标签一键筛选。
- **AI 问答（知识库）**：内置的本地个人知识库问答面板——它会自动以你所有「收藏」的文件作为可信资料库，让你用自然语言跨多份文档提问，并在每一句回答后面附上可点击跳转的原文出处引用（详细用法见下文）。
- **Genspark Projects（云端项目）**：登录你的 Genspark 账号后，这里会自动同步列出你在 Genspark 网页端用 AI 创建过的所有云端项目；支持按关键词搜索、按时间排序、手动刷新与分页加载更多，点击任意项目即可直接拉起浏览器继续在云端编辑。
- **文件夹**：你可以点击「添加文件夹…」或者直接从系统的访达（Finder）/ 文件资源管理器里把电脑上的常用工作目录拖进左侧栏，把它固定为一个常驻根目录。固定后不用离开 GenOffice 就能直接在里面浏览子目录、点击「新建文件夹」创建新目录、重命名或将目录从侧栏移除；如果某个挂载在移动硬盘或网络共享盘上的目录当前未连接，侧栏会温和地将它标为「不可用」，你也可以随时把它从列表中清理掉。

顺带一提，左侧导航栏里刻意没有单独做一套应用私有的「回收站」：在 GenOffice 里删除的任何本地文件，都会统一移入你操作系统的原生**废纸篓（macOS）或回收站（Windows/Linux）**，万一删错了直接去系统废纸篓点「放回原处」即可，绝不会让你在两套回收站之间两边翻找。

## 文件列表与单行快捷菜单

右侧文件列表的每一行都会清晰展示文件格式图标、文件名、所在位置与最后修改时间；把鼠标悬停到任意一行上并点击右侧的 **`⋯` 更多菜单**（或在行上右键），即可对该文件执行全套管理操作：

- **打开 / 打开所在文件夹**：在当前窗口的新标签页里打开该文档进行编辑，或者直接唤起操作系统的访达 / 文件资源管理器并高亮定位到该文件所在的磁盘目录。
- **复制路径**：将该文件在磁盘上的完整绝对路径一键复制到系统剪贴板，方便粘贴到终端命令、聊天窗口或脚本里。
- **移动到文件夹…**：弹出目录选择器，把该文件连同磁盘上的真实文件一起搬家到另一个文件夹中；如果目标文件夹下恰好已经存在同名文件，系统会弹出提示让你自主选择跳过、覆盖原文件还是自动加上序号重命名后再移入。
- **重命名**：使当前行的文件名就地变成输入框进行改名，文件原本的扩展名（如 `.docx`、`.xlsx`）会自动为你保留，并对非法字符与同名冲突做即时拦截。
- **收藏 / 取消收藏**：为该文件点亮或取消星标；星标状态不仅在重启软件后持久保留，哪怕你随后在应用内给文件改了名或移了目录，星标和分组关系也会稳稳跟着文件走。
- **创建副本**：在当前文件所在的同一磁盘目录下立即复制出一份「`<原文件名> 副本`」，并自动出现在你的最近列表中供你随时点开。
- **删除**：将磁盘上的文件安全移入操作系统的废纸篓或回收站，而不是不可挽回的彻底粉碎。
- **从列表中移除**（仅在顶层「最近」视图中出现）：如果你只是觉得「最近」列表里某条历史记录看着眼花、想把列表清清爽爽理一理，点它只会把这条浏览记录从最近列表里抹掉，而磁盘上的真实文件分毫无损。

### 批量勾选与一次处理多个文件

当你需要一次性整理几十份散乱的文档时，可以勾选文件行最左侧的复选框（或者按住 `⌘` / `Ctrl` 键逐行点选，也可以直接勾选表头最左上角的总复选框一键全选当前列出的所有文件）。一旦选中了多个文件，列表正上方就会浮现出一条批量操作工具栏，实时显示当前已选中的文件数量（**已选 {n} 项**），并提供一键**移动到文件夹…**和批量**删除文件**；除此之外，你还可以直接用鼠标按住选中的这批文件，把它们一起拖进左侧导航栏的任意一个目标文件夹里完成批量归档。

## 文件名与正文全文搜索

主屏右上方的搜索框同时打通了「按文件名找」和「按正文内容找」两条检索通道：

- **按文件名快速过滤**：敲入关键词的瞬间，就会按文件名实时筛出匹配的文档。
- **跨格式正文全文检索**：GenOffice 会在后台为你打开或挂载过的本地文档（涵盖 `.docx`、`.xlsx`、`.pptx`、`.pdf`、`.md`、`.html` 内部的所有正文文字与表格内容）自动建立本地全文索引——哪怕你完全忘了某份合同或报告叫什么文件名，只要在搜索框里敲入你印象中正文里出现过的一个词或一句话，照样能把那份文件精准揪出来；你还可以在设置面板的「生图、媒体与搜索」里灵活调整索引范围与重排开关。

## 顶部「快速开始」新建卡片

主屏正上方一字排开的彩色卡片是新建文档最快的入口。单击任意一张卡片，就会立刻在当前窗口新建一个对应格式的空白文档并切进它的专属编辑器——进去之后，你既可以像用传统办公软件一样直接在画布上自己动笔写，也可以直接利用展开的 AI 面板（或者随时点击编辑器功能区上的 **AI 按钮**、选中内容右键点**问 AI**）让 AI 助手帮你搭框架、写初稿。

新建的文件在首次保存时，默认会落在你刚才在左侧导航栏里选中的那个文件夹下；如果刚才看的是「最近」或「收藏」，则会默认落到你在设置里指定的默认保存位置。

每张快速开始卡片的具体分工与落盘规则如下：

- **AI Docs（`.docx`）**：新建一份空白的 Word 文字处理文档并进入 Docs 编辑器。在你第一次按下保存键之前，它只作为内存草稿存在、不会往磁盘里乱塞垃圾文件；新建时如果展开了 AI 面板可直接让 AI 起草公文或报告（如果你不喜欢每次新建都自动弹出 AI 面板，可以在 **设置 ▸ 通用 ▸ 新文档中打开 AI 面板** 里将它设为默认关闭）。
- **AI Sheets（`.xlsx`）**：新建一本空白的 Excel 电子表格并进入 Sheets 编辑器。同样在首次手动保存前不会占用磁盘文件；更聪明的是，如果你打开空白表格后先让 AI 助手帮你生成了一张数据表，首次保存时系统还会根据表格里的主题内容自动为你拟定一个合适的文件名。
- **AI Slides（`.pptx`）**：新建一套空白的 PowerPoint 演示文稿并进入 Slides 编辑器，你只需在 AI 面板里输入一句话主题或几条大纲，就能让 AI 直接生成整套排版好的幻灯片。
- **AI Markdown（`.md`）**：新建一份空白的 Markdown 笔记文档并进入双栏实时预览的 Markdown 编辑器。
- **AI HTML（`.html`）**：新建一份空白的网页文档并进入支持可视化检查器与源码双模式的 HTML 编辑器。
- **AI PDF（`.pdf`）**：这张卡片的落盘时机与前面五种不同——因为 PDF 编辑引擎底层操作的是真实的物理文件结构，点击它后会**立即在目标文件夹下创建出一份真正的空白单页 PDF 文件**并作为普通文件打开。它非常适合用来当一块干净的 PDF 画板，往上面贴图、加文字块、手写签字或合并其他页面；而且在你第一次往里面填好内容并保存时，系统同样支持根据页面上的文字内容自动帮文件起一个得体的新名字。
- **打开本地文件**：点击后会直接弹出操作系统的原生文件选择窗口，支持一次性单选或多选打开 Word（`.docx` / `.doc`）、Excel（`.xlsx` / `.xlsm` / `.xls` / `.csv` / `.tsv`）、PowerPoint（`.pptx` / `.ppt`）、PDF（`.pdf`）、Markdown（`.md` / `.markdown`）和网页（`.html` / `.htm`）文件，选中的每个文件都会在顶部开启一个独立标签页；此外，普通的纯文本文件（`.txt`）和配置文件（`.json`）也可以直接从这里打开，它们会直接进入 Markdown 编辑器的纯净源码视图供你查看和修改。

> 小贴士：无论你当前在主屏还是在任何一个编辑器里，随时都可以通过顶部菜单栏的 **文件 ▸ 新建** 创建上面这六种文档（快捷键 `⌘N` / `Ctrl+N` 默认新建最常用的 Docs 文字文档），或者直接把桌面上的文件拖进窗口打开。

## 向你的个人知识库提问（AI 问答）

- **点亮星标即入库**：使用知识库问答前，只需要先在文件列表里把你想纳入参考范围的文档点亮星标加入「收藏」（凡是 GenOffice 能读的 `.docx`、`.xlsx`、`.pptx`、`.pdf`、`.md`、`.html` 格式全都支持）；切到左侧栏的**AI 问答**后，面板顶部会直接显示当前知识库收录了多少份标星文件（还可以点开查看具体包含哪些文件），如果还没有收藏任何文件，界面也会贴心引导你先去给文件点星。
- **回答句句有据可查**：当你向知识库提问（比如「上个季度的三份采购合同里，违约金比例分别是多少？」）时，AI 给出的回答会明确标出每一条结论分别引自哪一份文件；用鼠标单击回答里的引用标签，就会立刻在对应的编辑器标签页里打开那份原始文档供你核对原文。
- **登录要求与内存级会话隐私**：使用知识库问答需要先登录你的 Genspark 账号；你的提问与回答对话历史仅保存在当前运行期间的内存里，一旦关闭应用窗口就会彻底清空，不会在磁盘上留下聊天记录。
- **基于本机索引与自动失效清理**：知识库底层检索复用的是你电脑本地的文件全文索引（与主屏顶部搜索框同源）；如果某份之前标过星的文件后来在磁盘上被你移走或删掉了，它会自动从知识库语料范围中静默剔除，不会报错卡住。
- **收藏分组不影响全局检索视野**：你在「收藏」视图里创建的命名分组只用来帮你自己在列表里分类整理文件——当你向知识库提问时，AI 永远会横跨你**全部已收藏的文件**寻找答案（当然你也可以在提问框里输入 `@` 直接点名指定某几份收藏文件来回答），不用担心因为文件放在不同分组里而被漏查。

## 云端项目（Genspark Projects）

- **首次设备码登录**：第一次点开左侧栏的「Genspark Projects」时，界面会引导你登录 Genspark 账号（同样采用省心的设备码流程：客户端展示验证码并打开浏览器，你在浏览器点一下确认即完成绑定）。
- **网页端项目无缝接力**：登录后会自动拉取你在 Genspark 网页端用 AI 生成或编辑过的全部云端项目列表，点击任意项目上的「在浏览器中打开」即可直接跳转到网页端继续深度编辑。
- **完全可选，不绑架本地功能**：如果你只把 GenOffice 当作纯粹的本地办公软件使用，完全可以不去登录云端项目，本地的所有编辑器与自带密钥（BYOK）模型能力丝毫不受影响。
