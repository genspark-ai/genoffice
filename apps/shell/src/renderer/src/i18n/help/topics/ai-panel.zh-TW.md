# AI 助理面板

在 GenOffice 的所有六個編輯器裡，你都可以隨時喚出內建的 AI 助理面板：只需在畫布上框選一段文字、一片表格或一個網頁元素，用平常說話的方式交代任務，就能看著 AI 即時串流輸出分析並直接幫你把修改落到文件裡。

## 如何喚起與日常對話流

![Docs 中的 AI 面板](img/ai-panel.png)

- **三種順手的喚起入口**：你既可以隨時點擊任意編輯器頂部功能區右側醒目的 **AI 按鈕**展開側邊欄，也可以在內文或表格中選取一段內容後點擊滑鼠右鍵選擇**問 AI**，或者在 PDF 與 HTML 選取內容後浮出的快捷列上直接點 **Ask AI（問 AI）**。
- **用自然語言直接交代任務**：在面板底部的輸入框裡用白話寫下你想做的事（比如「把這段會議紀錄改寫成正式的立項通知」「給右邊加一欄算出每個人的銷售額佔比」「把這一頁 PPT 重新排成左右對比卡片」），按下 `Enter` 鍵即可傳送。
- **串流輸出與自動呼叫文件工具**：AI 的思考與回覆會以**即時串流（Streaming）**方式逐字呈現；當任務需要讀取文件上下文、搜尋知識庫或直接動手修改段落、儲存格和投影片時，助理會自動在背景依序呼叫對應的文件操作工具並繼續往下推進，直到把整套任務妥善做完。
- **隨時一鍵喊停**：如果看到一半發現方向不對或者已經拿到了想要的資訊，隨時點擊輸入框旁邊的**停止**按鈕（或按 `Esc` 鍵）即可立即中斷目前這一輪生成。
- **邊跑邊發的指令排隊佇列**：當 AI 正在串流輸出或忙著執行上一輪長任務時，你完全不需要乾等著它跑完——直接在輸入框裡繼續敲入你的下一條補充指令並按 `Enter`，新指令不會被丟棄也不會打斷目前輪，而是會自動進入**待發佇列**。此時輸入框正上方會浮現一條佇列狀態列，顯示目前有幾條訊息在排隊；點開狀態列，你隨時可以修改排隊中的訊息文字、刪掉某條、拖曳調整傳送先後順序、暫停自動傳送或一鍵清空佇列。只要上一輪回答一結束，佇列裡的下一條指令就會自動接力發出；而按下 `Esc` 鍵則依然是終止目前正在執行的這一輪。

## AI 助理在各個編輯器裡都能做什麼

- **Docs 文字處理**：潤飾改寫文風、擴寫章節篇幅、多語種精準翻譯、提煉長文摘要、根據文字描述自動生成並插入結構化表格或配圖，以及批次調整各級標題與內文排版格式；而且每一輪動手修改文件前都會自動留存一份版本快照。
- **Sheets 試算表**：根據自然語言編寫複雜的巢狀函數與正規表示式公式、依規律自動填入或清洗髒資料、批次改寫儲存格文字，以及自動設定條件式格式、框線與數值顯示樣式。
- **Slides 簡報**：根據一句話主題或大綱從零生成整套多頁簡報、對現有投影片重新調整圖文版面配置、精簡或擴寫頁面上的演講文案。
- **PDF 文件**：針對你用滑鼠選取的某一段專業術語、外文段落或整頁財報合約進行深度問答、多語種翻譯與核心要點總結。
- **Markdown 與 HTML 編輯器**：對技術文件或網頁文案進行潤飾改寫、順著上下文續寫新章節、多語種翻譯，或針對預覽檢查器選取的網頁 DOM 元件直接修改樣式與結構。
- **跨文件個人知識庫問答（首頁 ▸ AI 問答）**：自動從你標了星號（收藏）的所有本機文件裡檢索事實依據並給出帶有出處引用的回答——該功能在「首頁（Home）」一章中有專門介紹，而且你在 **Docs 文字編輯器**裡開啟右側 AI 面板時，同樣可以直接呼叫這項跨檔案知識庫技能來邊查資料邊寫報告。

## 版本回滾與編輯安全邊界

- **Docs 持久化版本快照清單**：在 Docs 文字編輯器的 AI 面板頂部設有一個**版本清單**——AI 每動手修改一次文件，系統都會先自動拍下一張完整快照；你隨時可以從清單裡挑中之前的任意一輪一鍵回滾過去，而且「回滾」這個動作本身也支援按 `⌘Z`／`Ctrl+Z` 復原。更貼心的是，這些快照會持久化儲存，哪怕你關掉文件明天再重新開啟，之前的 AI 修改快照依然在清單裡隨時可退。
- **與手動編輯完全一致的安全管線**：AI 對文件、試算表或投影片做出的任何修改，走的全都是和你自己敲鍵盤一模一樣的標準編輯管線——每一步都支援一般復原（`⌘Z`／`Ctrl+Z`），並且都受文件儲存機制管轄，絕不會繞過你的確認在背景悄悄篡改磁碟上的原檔案。

## 把敏感選取範圍對 AI 隱藏（隱私佔位符）

- **給機密內容戴上「隱形面具」**：在 **Slides、HTML 和 Markdown** 編輯器裡，如果文件中某幾處包含不想傳給雲端大模型的客戶真名、未公開財務數字或內部金鑰，你可以先選取那段內容，點擊滑鼠右鍵選擇**把選取的內容對 AI 隱藏**，然後為它起一個好認的佔位符名稱（如 `客戶甲` 或 `核心營收`）——設定完畢後，AI 助理在讀取文件時讀到的就只是 `{{客戶甲}}` 這樣的無害佔位符，而看不到背後的真實文字。（在 Markdown 編輯器中，需先點亮頂部工具列上的「閉眼」隱私開關來啟用該右鍵選單項目；在 HTML 編輯器中，該右鍵入口位於原始碼編輯面板內。）
- **完全不影響真實檔案、列印與匯出**：隱藏標記只作用於傳往 AI 模型的上下文檢視，而你文件底層依然完整保留著真實的原始文字——因此無論是平時在螢幕上閱讀、按下儲存寫入磁碟、匯出為 PDF／Word，還是連接印表機印出來，看到的都是百分之百完整的真實內容；儲存關閉後再重新開啟文件，之前設好的隱藏保護標記也依然穩穩保留。想解除隱藏時，只需再次按右鍵點擊同一個選單項目即可（Markdown 編輯器裡會清晰顯示為**把選取的內容重新對 AI 顯示**）。
- **HTML 支援全方位語法級隱藏**：在 HTML 原始碼模式下，你不僅可以把頁面元素的內文文字對 AI 隱藏，還能把 HTML 標籤的屬性值（如私密 `href` 連結、介面位址）乃至 `<script>` 腳本裡的字串字面值一併隱藏起來，而右側渲染出來的網頁預覽畫面不會發生絲毫改變。
- **Slides 支援整圖隱藏與防截圖洩露**：在 Slides 簡報中，除了隱藏文字方塊裡的文字外，還可以把**整張圖片、影片或音訊元素**對 AI 隱藏；更嚴謹的是，一旦某一頁投影片上包含任何被設為對 AI 隱藏的內容，系統在背景執行自動版面視覺檢查時就會**嚴禁將該頁渲染成截圖傳給多模態模型**，而是會自動跳過該頁的截圖檢查並在介面上向你明確說明，堵住「文字藏住了、卻被整頁截圖拍出去」的漏洞。
- **清楚了解隱藏的作用邊界**：需要提醒的是，這套「對 AI 隱藏」機制專門用於攔截**GenOffice 應用程式內建 AI 面板**傳往大模型的上下文；而當你在終端機裡直接執行 `genoffice` 命令列工具、透過 MCP 協定讓外部本機程式設計代理直接讀取磁碟檔案、或是執行無頭批次匯出時，由於這些工具直接操作磁碟上的真實檔案，它們依然能夠讀到檔案中的完整原文。

## 資料隱私與金鑰儲存

- **只傳往你自己選定的模型服務**：你在 AI 面板裡輸入的指令以及目前任務涉及的那部分文件上下文，只會傳送給**你在設定裡親自設定或登入的模型服務商**（Genspark 官方託管服務，或你自己填寫的 BYOK 自訂端點，詳見下一章「AI 模型與設定」）；如果你既沒有登入也沒有設定任何端點，GenOffice 就不會對外發出任何 AI 請求。
- **本機文件與金鑰絕不亂傳**：你的本機檔案絕不會被背景偷偷打包上傳到任何與目前請求無關的伺服器；你自己填寫的 BYOK API 金鑰也只儲存在你本機的應用程式設定檔中，僅在向你指定的端點發請求時作為 HTTP 請求標頭欄位傳出。
