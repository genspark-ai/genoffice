# AI 모델과 설정

## 제공업체와 모델 구성

모든 AI 모델 제공업체, 사용자 지정 엔드포인트, API 키는 홈 화면 왼쪽 아래의 계정 줄을 눌러 여는 **설정** 창에서 통합 관리합니다.

![설정 창](img/settings-general.png)

- **Genspark 공식 호스팅 모델**: 브라우저 기기 코드(Device Code) 방식으로 Genspark 계정에 로그인하기만 하면 별도의 API 키 발급이나 URL 설정 없이 공식 호스팅 대화 모델과 멀티모달 기능을 즉시 사용할 수 있습니다.
- **사용자 지정 엔드포인트(BYOK)**: 직접 발급받은 API 키나 사내 게이트웨이를 연결하려면 **설정 ▸ AI 모델**(및 **이미지·미디어·검색**)에서 프로토콜별로 기본 URL(Base URL)과 API 키를 입력합니다. OpenAI 호환 프로토콜, Anthropic(Claude), Google Gemini, DeepSeek, DashScope(Qwen), MiniMax, Atlas Cloud 등 주요 프로토콜이 기본 내장되어 있습니다. 입력한 키는 이 컴퓨터의 현재 사용자만 읽을 수 있는 앱 설정 파일에 안전하게 보관되며, 실제 요청을 보낼 때도 지정한 엔드포인트로 향하는 HTTP 요청 헤더에만 실려 전송됩니다.
- **역할별로 서로 다른 모델 조합 가능**: 문서 대화 및 초안 생성, **AI 이미지 생성**, **이미지 및 동영상 시각 분석**마다 각각 가장 뛰어난 제공업체와 전용 모델을 개별적으로 골라 조합할 수 있습니다.
- **MiniMax H3-Image 및 MiniMax H3-Image Highspeed 이미지 생성**: 이미지 생성 제공업체에서 MiniMax를 선택하면 기존 `image-01` 외에도 고해상도 기본 모델인 **MiniMax H3-Image**와 빠른 생성 속도에 초점을 맞춘 **MiniMax H3-Image Highspeed**를 모두 사용할 수 있습니다(글로벌 엔드포인트와 중국 `api.minimax.cn` 모두 지원). 두 H3 이미지 모델은 기본적으로 선명한 **2K 해상도** 출력을 요청하며, 기존 이미지를 바탕으로 편집할 때 한 번에 **최대 16장의 참조 이미지**를 함께 전달할 수 있습니다.
- **저장 전 원클릭 연결 테스트**: 새로운 엔드포인트와 키를 저장하기 전에 **연결 테스트** 버튼을 누르면 기본 URL에 정상적으로 연결되는지, API 키가 유효한지, 선택한 모델이 응답하는지를 그 자리에서 바로 검증할 수 있습니다.
- **경로와 쿼리 문자열을 포함한 게이트웨이 URL 지원**: 기본 URL에 하위 경로나 쿼리 문자열(예: 사내 프록시나 API 게이트웨이 주소)이 포함되어 있어도 GenOffice가 기존 경로와 쿼리 매개변수를 보존한 채 엔드포인트 경로를 정확하게 이어 붙입니다.

## 로컬 CLI 연동(Codex 계열)

- **로컬 CLI 실행 파일 경로 지정**: 클라우드 HTTP API뿐만 아니라 컴퓨터에 설치된 로컬 Codex 계열 CLI 프로그램 경로를 설정에서 직접 지정할 수도 있습니다(한글 등 비 ASCII 문자가 포함된 홈 디렉터리와 `~` 접두사도 완벽히 작동하며, `~`는 전체 경로로 자동 확장됩니다). **모델 감지** 버튼을 누르면 해당 CLI를 호출해 사용 가능한 모델 목록을 자동으로 탐색해 불러옵니다.
- **파일 존재 여부만 확인하는 유연한 경로 검증**: 경로 유효성 검사는 해당 실행 파일이 디스크에 실제로 존재하는지만 확인하며, 폴더 이름에 불필요한 영문 전용 문자 집합 제한을 두지 않습니다.

## 변경 사항이 적용되는 시점

- **진행 중인 답변을 끊지 않고 다음 차례부터 즉시 적용**: 설정 창에서 모델이나 엔드포인트, API 키를 바꾸고 저장하면 열려 있는 모든 편집기에 즉시 반영됩니다. 저장하는 순간 AI 패널에서 이미 답변이 스트리밍 출력 중이었다면 해당 차례는 이전 설정으로 끝까지 안전하게 마무리되고, 바로 다음 프롬프트부터 새 모델이 적용됩니다.
