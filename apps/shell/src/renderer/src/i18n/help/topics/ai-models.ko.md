# AI 모델과 설정

## 제공업체와 모델

모델과 키는 설정에서 구성합니다(홈의 왼쪽 아래 계정 줄).

![설정 창](img/settings-general.png)

- **Genspark 제공형**: 로그인만 하면(기기 코드 방식) 바로 쓸 수 있습니다. 설정이 필요 없습니다.
- **사용자 지정 엔드포인트(BYOK)**: 설정 ▸ AI에서 프로토콜별로 기본 URL과 API 키를 입력합니다. OpenAI 호환, Anthropic, Gemini, DeepSeek, DashScope(qwen) 등. 키는 이 컴퓨터의 앱 설정 파일에 저장되며 요청 헤더에만 실려갑니다.
- 기능마다 다른 모델을 고를 수 있습니다. 대화/생성, 이미지 생성, 이미지 분석.
- **연결 테스트**: 저장하기 전에 엔드포인트 연결과 모델 노출 여부를 확인할 수 있습니다.
- 기본 URL에는 경로와 쿼리 문자열을 넣을 수 있어(게이트웨이 형식) 엔드포인트 경로가 올바르게 이어 붙습니다.

## CLI 연동(Codex 계열)

- 설정에서 로컬 CLI 프로그램 경로를 지정할 수 있습니다(ASCII가 아닌 홈 디렉터리와 ~ 접두사도 동작하며 ~는 자동으로 확장됩니다). 모델 감지는 그 CLI에서 쓸 수 있는 모델을 살펴봅니다.
- 검증은 존재 여부만 확인합니다. 문자 집합 제한은 없습니다.

## 변경이 적용되는 시점

- 모델과 엔드포인트 변경은 즉시 적용됩니다. 진행 중인 대화는 다음 회차 전까지 이전 설정을 사용합니다.
