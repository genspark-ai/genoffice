# HTML 編輯器

HTML 編輯器開啟 .html / .htm，有兩種模式：**預覽**（算繪後的頁面）與**原始碼**。

- **預覽**：真實算繪；相對路徑的樣式表與圖片會依檔案位置載入。
- **預覽檢查器**：按一下選取元素、按兩下就地編輯其文字、由工具列刪除，以及針對選取內容問 AI。
- **原始碼模式**：編輯 HTML；ctrl+F 尋找，全部取代後儲存重寫後的標記。
- **儲存**：位元組忠實（保留 BOM／CRLF／結尾換行）；沒有修改時不會重寫。
- **縮放**：ctrl+滾輪／雙指縮放可縮放預覽；在預覽內按 ctrl+Z 可復原上一步編輯。

## 工具列

在預覽中按一下任一元素，其上方就會浮現一條工具列：

![選取元素後浮現的工具列](img/html-toolbar.png)

- **檔案與歷史**：儲存、另存新檔、復原、重做、尋找；**自動儲存**開關會定時寫入。
- **預覽／原始碼**切換；**全螢幕**以全螢幕顯示頁面。
- **格式**：粗體、斜體、字型大小增減；選取元素的**樣式面板**（色彩等）。
- **插入**：標題、段落、表格、圖片（以連結指定）、更多。
- **圖片操作**（選取圖片時）：裁剪、**移除背景**、替換、鎖定長寬比。
- **元素操作**（在預覽檢查器中選取元素時）：刪除、複製、上移／下移。
- **AI 按鈕**：開啟 AI 面板，可直接就選取的元素提問。

## 匯出

都在「檔案」選單中，全部是本機作業，而且都會詢問結果要存到哪裡：

- **匯出為 Word…** 與 **匯出為 PDF…** 會寫出真正的 .docx 或 .pdf 檔案。
- **匯出為單檔 HTML…** 會寫出一個內嵌了圖片的 .html 檔案。它不會覆寫你目前開啟的檔案，而且會告訴你有幾張圖片未能內嵌。

## 插入骨架

面對一張空白頁面，**插入 ▸ 插入骨架** 會寫入一份最小的標準模式文件：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

每一部分都有存在的理由——所以它是一個命令，而不是要你手打的東西：

- **doctype**：少了它，預覽會以怪異模式執行，方塊模型與表格版面會依你預期不同的規則走；
- **`lang`**：少了它，螢幕閱讀器不知道該用哪種語言朗讀頁面，瀏覽器也會挑錯字型與拼字檢查工具；
- **charset**：少了它，整頁非拉丁文字都可能被解碼成亂碼。

這裡刻意不放 viewport meta：它算繪在桌面端面板裡，沒有行動裝置視窗可影響。

`lang` 會依應用程式的介面語言而定，因此你插入的骨架正是你的工具鏈已經設定好的那一個。之後可以自由修改。

這個選單項目只會在編輯模式中出現，而且只在文件為空時出現——一旦有了內容，就沒有可以往裡插入骨架的東西了。
