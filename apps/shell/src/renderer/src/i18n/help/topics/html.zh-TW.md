# HTML 編輯器

GenOffice 的 HTML 編輯器專門用來檢視和修改 `.html`／`.htm` 網頁檔案，提供**視覺化預覽模式**（直接渲染真實網頁並支援點選改字）與**原始碼模式**（直接編輯底層 HTML 標籤與樣式腳本）雙模式無縫切換，非常適合用來製作和微調數據報告網頁、郵件範本、單頁著陸頁或互動式簡報。

- **真實網頁預覽模式**：直接渲染完整的 HTML 頁面，網頁裡透過相對路徑引用的本機 CSS 樣式表、腳本與同目錄圖片資源都會自動依檔案所在位置正常載入並呈現。
- **視覺化預覽檢查器（Inspector）**：在預覽模式下無需去翻幾千行原始碼——直接用滑鼠單擊頁面上的任意一個標題、段落、卡片或圖片就能選取該 DOM 元素，**雙擊文字即可直接在網頁畫布上就地改字**，也可以用浮出的工具列一鍵刪除、複製、上下移動該元素，或者點 **Ask AI（問 AI）** 直接讓 AI 助理針對你選取的這一個網頁局部做修改。
- **純淨原始碼編輯模式**：切換到原始碼模式後即可直接編寫或修改底層 HTML、行內 CSS 與 JavaScript 程式碼；按下 `⌘F`／`Ctrl+F` 支援在原始碼中全文尋找並一鍵「全部取代」後寫入磁碟儲存。
- **位元組級無損儲存**：與 Markdown 編輯器一樣，儲存 `.html` 檔案時嚴格保持位元組級忠實——檔案原本的 BOM 標頭、`CRLF`／`LF` 換行符號制式以及結尾換行皆原樣保留，未發生修改時按下儲存不會無故重寫磁碟檔案。
- **自由縮放與視覺化復原**：在預覽畫布上按住 `Ctrl`（或 macOS 上的 `⌘`）滾動滑鼠滾輪，或者在觸控板上雙指捏合即可平滑縮放網頁預覽比例；在預覽模式下做出的任何雙擊改字或元素刪改，都可以隨時按 `⌘Z`／`Ctrl+Z` 逐步復原。
- **對 AI 隱藏網頁敏感欄位**：在原始碼模式下框選任意一段不想暴露給大模型的原始碼片段——無論是頁面元素的內文文字、標籤屬性值（如真實連結、信箱）還是 `<script>` 裡的字串字面值——按右鍵選擇**把選取的內容對 AI 隱藏**並命名佔位符後，AI 助理讀到的原始碼裡就只會看到佔位符，而左側渲染出來的真實網頁畫面與儲存後的檔案則分毫不受影響（詳見「AI 助理面板」一章）。

## 頂部工具列與元素浮動工具列

在視覺化預覽畫布上用滑鼠單擊選取任意一個網頁元素時，該元素正上方會自動浮出一排上下文快捷工具列，與視窗頂部的固定工具列搭配使用：

![選取元素後的浮動工具列](img/html-toolbar.png)

- **檔案與操作歷史**：頂部工具列最左側提供儲存（`⌘S`／`Ctrl+S`）、另存新檔、多層級復原、取消復原與尋找按鈕，右側配有**自動儲存**開關，開啟後會在編輯停頓後自動將最新網頁寫入磁碟。
- **預覽／原始碼切換與全螢幕展示**：隨時在**預覽**、**分割畫面**與**原始碼**檢視之間切換（快捷鍵 `⌘\`／`Ctrl+\`）；點擊旁邊的**展示**按鈕則可以收起所有工具列，進入全螢幕純淨展示模式來演示你的互動式網頁。
- **文字格式與元素樣式面板**：支援對選取文字一鍵設定**粗體**、**斜體**、增大或減小字級；當你在預覽中點中某個元素時，還可以展開**樣式面板**直觀修改它的文字顏色、背景色與外觀屬性。
- **快速插入網頁構件**：無需手寫標籤，直接點擊工具列上的**插入**群組即可往網頁裡放各級標題、內文段落、結構化表格、圖片（或超連結）以及更多常見 HTML 元素。
- **網頁圖片專屬操作**（當在預覽中點擊選取一張 `<img>` 圖片時浮現）：可以直接在網頁上拉框**裁剪**圖片、呼叫內建演算法一鍵**移除圖片背景（去背）**、從本機挑選新圖**取代**原圖，或者開關**鎖定長寬比**防止縮放變形。
- **DOM 元素結構操作**（當預覽檢查器選取任意一個網頁區塊時）：支援一鍵**刪除**該元素、在原地**複製（克隆）**一份相同的元素區塊，或者點擊**上移／下移**直接調整它在父容器裡的前後排列順序（也可直接使用快捷鍵 `⌥↑`／`⌥↓` 或 `Alt+↑`／`Alt+↓`）。
- **AI 按鈕與局部改頁**：點擊頂部 **AI 按鈕**（或在選取元素後按 `⌘K`／`Ctrl+K`）即可展開右側 AI 面板，直接讓 AI 幫你重寫選取的這塊網頁元件、調整 CSS 版面或生成新的圖表卡片。

## 匯出為 Word、PDF 與單一檔案 HTML

所有匯出命令皆整合在頂部選單列的**檔案**選單中，全部在本機離線執行，並在匯出時彈窗詢問儲存位置：

- **匯出為 Word… 與 匯出為 PDF…**：將目前渲染出來的網頁內容連同排版樣式直接轉換為真正可編輯的 `.docx` Word 文件，或者依頁面版式輸出為標準的 `.pdf` 檔案。
- **匯出為單一檔案 HTML…**：當你做的網頁引用了多張本機相對路徑圖片、想把它打包傳給別人且避免出現「破圖」時，選擇此項就會自動把網頁裡引用的所有本機圖片編碼內嵌（Inline Data URL）並寫出為一個獨立自包含的 `.html` 檔案；它總是另存為新檔案而絕不會覆蓋你目前正在編輯的工程原稿，並且在匯出完成時還會明確回報是否有外部圖片未能成功內嵌。

## 一鍵插入標準 HTML5 文件骨架

當你新增或開啟一份完全空白的 `.html` 檔案並切到原始碼編輯模式時，點擊頂部選單 **插入 ▸ 插入骨架**，編輯器就會立即為你寫入一份最精簡、最規範的現代 HTML5 標準文件骨架：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

這段看似簡短的骨架裡，每一行都承擔著避免網頁排版踩坑的關鍵職責——這也正是為什麼要把它做成一個一鍵命令，而不是讓你每次憑記憶手敲：

- **`<!DOCTYPE html>` 宣告**：一旦漏寫這一行，瀏覽器的渲染引擎就會退化進古老的「怪異模式（Quirks Mode）」，導致 CSS 盒模型寬度計算、表格尺寸與彈性版面全都依非標準規則跑偏；
- **`lang` 語言屬性**：如果沒有宣告頁面語種，無障礙螢幕助讀程式就不知道該用哪國發音規則朗讀頁面，渲染引擎也容易在中日韓多文種混排時挑錯預設回退字型或拼字檢查字典；
- **`<meta charset="UTF-8" />` 字元集宣告**：沒有明確指定 UTF-8 編碼時，網頁裡的中文、日文或特殊符號在其他人的瀏覽器裡開啟極易被依舊編碼解碼成滿屏亂碼。

細心的讀者可能會注意到，這份預設骨架裡刻意沒有塞入行動端常見的 `<meta name="viewport">` 標籤：因為 GenOffice 的 HTML 編輯器渲染在桌面端寬幅面板裡，本身不存在需要縮放適配的手機視口。

此外，`<html>` 標籤上的 `lang` 屬性值在插入時會自動跟隨你目前 GenOffice 設定的介面語言（例如繁體中文介面下會自動生成對應的語言標記），生成之後你隨時可以在原始碼裡依需求修改。

為了防止不小心沖掉已有程式碼，**插入骨架**這個選單項目只有在你處於原始碼編輯模式、並且目前文件**完全為空**時才會顯示出來；一旦文件裡已經有了哪怕一個字元的內容，該選單項目就會自動隱去。
