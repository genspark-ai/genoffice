# แบบอักษร: แบบอักษรของระบบและตระกูลที่ดาวน์โหลดได้

## รายการแบบอักษร

ตัวควบคุมแบบอักษรอยู่บนแท็บหน้าแรกของตัวแก้ไขแต่ละตัว (ด้านล่างคือกลุ่มแบบอักษรใน Slides):

![กลุ่มแบบอักษรในแถบเครื่องมือของ Slides](img/fonts.png)

ตัวเลือกแบบอักษรของแต่ละตัวแก้ไขรวมไว้ด้วยกัน: แบบอักษรที่ติดตั้งในเครื่อง + แบบอักษรที่มักมีในแต่ละแพลตฟอร์ม (ตระกูลที่พบบ่อยของ Windows และ macOS ทั้งภาษาตะวันตกและจีน ญี่ปุ่น เกาหลี รวมถึงชื่อที่เป็นภาษาท้องถิ่นของแบบอักษรจีน ญี่ปุ่น เกาหลี ในระบบของตัวเอง) เมื่อระบบสามารถแจกชื่อแบบอักษรที่มีในเครื่องได้ รายการจะจัดกลุ่มตามสิ่งที่มีจริง แต่ถ้าแจกชื่อไม่ได้ รายการจะแสดงรายชื่อผู้สมัครทั้งหมด

## แบบอักษรที่ดาวน์โหลดได้ (Slides)

- ตัวเลือกแบบอักษรของ Slides เปิด **แคตตาล็อกแบบอักษร** ขึ้นมาได้: เป็นชุดแบบอักษรโอเพนซอร์ส (OFL) ที่คัดสรรแล้ว ครอบคลุมหลายภาษา และแต่ละตระกูลมีทั้งน้ำหนักปกติและตัวหนา
- เมื่อเลือก ระบบจะดาวน์โหลดและติดตั้งจาก CDN (ยืนยันด้วย checksum) เข้าไปในคลังแบบอักษรของแอป — เอกสารทุกฉบับที่หลังจากนั้นใช้ได้ทันที ไม่ต้องติดตั้งระดับระบบ
- สิ่งที่ติดตั้งอยู่ในไดเรกทอรีส่วนตัวของแอป และหายไปเมื่อถอนการติดตั้งแอป

## การจัดหน้าเอกสารภาษาจีน ญี่ปุ่น เกาหลี

- แบบอักษรจีน ญี่ปุ่น เกาหลี ใน Docs รองรับการบีบอัดเครื่องหมายวรรคตอนและกฎห้ามขึ้นบรรทัดและห้ามลงท้ายบรรทัดที่สอดคล้องกับ Word (ดูบทของ Docs)
- ตระกูล CJK ในแคตตาล็อกครอบคลุมจีนตัวย่อและตัวเต็ม ญี่ปุ่น เกาหลี ทั้งแบบเซริฟและแบบไร้เซริฟ

## การจัดการแบบอักษรในเครื่อง

- รายการ ติดตั้งไฟล์แบบอักษรในเครื่อง จะโหลดไฟล์ .ttf/.otf จากดิสก์เข้าไปในคลังแบบอักษรของแอป
- คลังจัดเก็บแยกตามตระกูล และตระกูลเดียวกันสามารถมีหลายน้ำหนักพร้อมกันได้
