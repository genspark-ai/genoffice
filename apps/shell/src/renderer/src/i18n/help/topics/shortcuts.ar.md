# اختصارات لوحة المفاتيح

لكل محرر روابط مفاتيح خاصة به، وقليل منها فقط يعمل في كل مكان. هذه الصفحة هي القائمة الكاملة، مجمَّعة حسب التطبيق، مع وضع اختصار macOS بجوار اختصار Windows / Linux.

## اقرأ هذا أولًا

**لا شيء تقريبًا هنا عام.** مفاتيح الوصول الثلاثة أدناه عامة؛ أما كل ما بعدها فيخص التطبيق الذي أمامك، ويتغيّر عند تبديل علامات التبويب.

| الإجراء                                          | macOS | Windows / Linux |
| ------------------------------------------------ | ----- | --------------- |
| فتح دليل المستخدم — يعمل في أي مكان داخل التطبيق | F1    | F1              |
| طيّ الشريط أو توسيعه — كل المحرِّرات             | ⌥⌘R   | Ctrl+F1         |
| فتح ورقة اختصارات لوحة المفاتيح — في Wأوd فقط    | ⌘/    | Ctrl+/          |

- **يفتح F1 هذا الدليل**، لا ورقة الاختصارات. تنتمي هذه المفتاح إلى قائمة التطبيق، لذا تعمل من Wأوd أو Sheets أو Slides أو PDF أو علامة التبويب Home على حد سواء.
- **مفتاح تبديل الشريط هو `Ctrl+F1`، أو `⌥⌘R` على macOS.** أما الضغط على `F1` وحدها فلا يفعل شيئًا — فـ F1 هي الدليل، ومفتاح الشريط لا يتشاركها عن قصد. ويُقبل `Ctrl+F1` على macOS أيضًا، لكن `⌥⌘R` هي المفتاح الذي يستخدمه Office fأو Mac.
- **ورقة اختصارات لوحة المفاتيح تخص Wأوd وحده** (`⌘/`). وتسرد جدول Wأوd أدناه بالضبط. لا توجد ورقة مماثلة في أي محرر آخر.
- **`⌘O` و`⌘S` و`⌘P` منفَّذة بشكل منفصل في كل محرر**، وسلوكها ليس متطابقًا تمامًا. أما `⌘P` في Wأوd فتُظهر أولًا معاينة طباعة بحيث تساوي الورقة المطبوعة الواحدة صفحة واحدة على الشاشة؛ وفي PDF تفتح مربع طباعة PDF؛ وفي Sheets وSlides لكل منهما مفتاحاه الخاصة.
- **الباقي خاص بكل تطبيق.** عندما تكون علامة تبويب Wأوd نشطة، يكون `⌘B` هو التخطيص الغامق في Wأوd. وعندما يكون Slides نشطًا، يكون `⌘B` هو التخطيص الغامق في Slides، والقائمة التي ينتمي إليها ليست القائمة التي اعتدت عليها. وحيث لا يعمل الربط إلا مع وجود تحديد أو في لوحة معينة، يوضّح عمود الإجراء ذلك.

## اصطلاحات الكتابة

- يستخدم عمود macOS الرموز المألوفة: `⌘` للأمر Command، و`⌥` للخيار Option، و`⇧` للإزاحة Shift، و`⌃` للتحكم Control.
- ويكتب عمود Windows / Linux هذه الرموز بالحروف: `Ctrl` و`Alt` و`Shift`.
- وحيث يحتاج GenOffice فعلًا إلى مفاتيح مختلفة على المنصتين، تُظهر الجداول ذلك. والحالات الشائعة هي `⌃H` لـ «البحث والاستبدال» (إذ يخص `⌘H` على macOS أمر «الإخفاء»)، و`⌥⌘G` لـ «الانتقال إلى»، ومفتاح الإغلاق في Slides.
- يُكتب الاختصار الذي لا يعمل إلا مع تحديد في عمود الإجراء بدلًا من إعطائه عمودًا خاصًا به، حتى يبقى عرض الجدول ثلاثة أعمدة.

## Wأوd

يحتوي Wأوd على شريط قوائم كاملًا، لذا تعمل اختصارات الملف والتنسيق أدناه كلما كانت علامة تبويب Wأوd نشطة، أيًّا كان المستند المفتوح. أما اختصارات التحرير فتحتاج مستندًا محمَّلًا قابلًا للتعديل مع وجود مؤشر الإدراج داخل النص؛ وهي لا تعمل أثناء الكتابة في مربع البحث أو في طلب الذكاء الاصطناعي أو في أي حقل آخر.

## Sheets

GenOffice Sheets شبكة متوافقة مع Excel. معظم الاختصارات أدناه هي اختصارات Excel التي تعرفها بالفعل.

> **التحرير هو الأولوية.** تُتجاهَل كل اختصار تقريبًا في Sheets أثناء تحرير خلية أو الكتابة في **شريط الصيغة**، حتى تحتفظ الكتابة وتحريك المؤشر ومفتاح المسافة العكسية بدلالاتها المعتادة في تحرير النص. وإذا بدا أن مفتاحًا لا يفعل شيئًا، فتحقق مما إذا كنت في منتصف التحرير: اضغط Esc أو Enter أولًا ثم أعد المحاولة. والأوامر التي تعمل على التحديد لا تفعل شيئًا أيضًا ما دام مربع حوار مفتوحًا. وحيث يكون الاختصار استثناءً لهذه القاعدة، توضّح الجداول ذلك.

يخصّ Sheets وحده اصطلاحان. `⌘` و`⌃` تشغلان خانة المعدِّل نفسها — فكلاهما مقبول في كل منصة، لذا `⌘1` و`Ctrl+1` هما الاختصار نفسه. **الخانة الفارغة في عمود Windows / Linux تعني أن الاختصار متاح على macOS وحده.**

## Slides

GenOffice Slides محرر عروض تقديمية بأسلوب PowerPoint. معظم المفاتيح تفعل الشيء نفسه أينما كنت، لكن بعضها يغيّر المعنى حسب موضع التركيز — داخل مربع نص، أو عندما يكون **لوحة المصغرات** أو **لوحة المخطط** أو **فراز الشرائح** هو العنصر الذي يحمل التركيز. هذه الحالات معلَّمة في عمود الإجراء.

### داخل إطار المعاينة، مع تحديد عنصر

| الإجراء                            | macOS      | Windows / Linux    |
| ---------------------------------- | ---------- | ------------------ |
| سؤال الذكاء الاصطناعي عن العنصر    | ⌘K         | Ctrl+K             |
| حذف العنصر                         | ⌫ / Delete | Backspace / Delete |
| الشقيق السابق                      | ↑          | ArrowUp            |
| الشقيق التالي                      | ↓          | ArrowDown          |
| تحديد العنصر الأصل                 | ←          | ArrowLeft          |
| تحديد أول عنصر فرعي                | →          | ArrowRight         |
| تحريك العنصر إلى الأعلى في المستند | ⌥↑         | Alt+ArrowUp        |
| تحريك العنصر إلى الأسفل في المستند | ⌥↓         | Alt+ArrowDown      |
