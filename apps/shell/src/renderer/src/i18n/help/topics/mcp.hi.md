# कोडिंग एजेंट जोड़ना

GenOffice Model Context Protocol बोलता है, इसलिए कोई कोडिंग एजेंट उन्हीं इंजनों से आपके दस्तावेज़ पढ़, लिख और रेंडर कर सकता है जिन्हें ऐप इस्तेमाल करता है। एजेंट किसी फ़ाइल प्रारूप का अंदाज़ा नहीं लगा रहा: उसे टाइप किए गए ऑप स्कीमा उसी परिभाषाओं से मिलते हैं जिनके विरुद्ध एक्सीक्यूटर सत्यापन करता है।

## पंजीकृत करना

आम तौर पर यह एक कमांड है:

```sh
genoffice mcp install all
```

यह इस मशीन पर मिले कोडिंग एजेंट — Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode, Windsurf — ढूँढता है और हर एक के अपने कॉन्फ़िग में stdio सर्वर प्रविष्टि लिख देता है, उस फ़ाइल का बाक़ी हिस्सा जैसा मिला वैसा ही छोड़ देता है।

```sh
genoffice mcp list             # where each agent stands
genoffice mcp install cursor    # just one
genoffice mcp uninstall cursor  # take it back out
```

किसी असामान्य जगह इंस्टॉल किया गया एजेंट `--dir <path>` लेता है; और `--force` पहले से मौजूद प्रविष्टि दोबारा लिख देता है।

## इसे खुद चलाना

किसी दूसरी मशीन के क्लाइंट के लिए, उसकी जगह इसे HTTP पर परोसें:

```sh
genoffice mcp --http 8765 --token <secret>
```

`--host <addr>` बदलता है कि यह कहाँ सुनता है। वही टोकन क्लाइंट को भी दें।

HTTP पर फ़ाइलें भी आती-जाती हैं: `PUT /files/<name>` एक अपलोड करता है, हर टूल पथ के स्थान पर `http(s)` URL लेता है, और आउटपुट डाउनलोड URL के रूप में लौटते हैं — और जब छोटे हों तो एम्बेड किए गए संसाधनों के रूप में भी। ऑप, स्पेक और Markdown दोनों ही स्थितियों में इनलाइन भेजे जाते हैं।

## एजेंट को क्या मिलता है

हर कमांड एक टूल है। दिलचस्प वाले:

- **`docs`, `sheet`, `slides`** — ऐप के अपने राइट पथ से एक बार में एक **ऑप** करके फ़ाइल पढ़ते और संपादित करते हैं। नया डेक `deck_start`, `deck_page`, `deck_build` से बनता है।
- **`render`** — हर पेज के लिए एक PNG, ऐप के रेंडरर द्वारा लेआउट किया हुआ, ताकि एजेंट स्लाइड को देख सके बजाय उसका अंदाज़ा लगाए।
- **`pdf`** — किसी PDF की टेक्स्ट लेयर, पेज-दर-पेज, बिना ऐप प्रक्रिया के।
- **`info`** — मेटाडेटा और संरचना सारांश, जो अजनबी फ़ाइल पर आम तौर पर सबसे सस्ती पहली कॉल होता है।
- **`search`, `image`, `media`** — ऐप में कॉन्फ़िगरूड प्रोवाइडर, इसलिए एजेंट को अपनी कुंजियाँ नहीं चाहिए।
- **`merge`** — `{{key}}` टेम्पलेट भरता है।

## स्कीमाएँ, और छोटा बजट

`apply` और `create` अपने `ops`, `cells` और `data` पैरामीटर टाइप की गई प्रति-ऑप स्कीमा के साथ बताते हैं, जो `genoffice guide <domain> --json` से बनती है। यह सटीक है पर छोटी नहीं। कम संदर्भ-विंडो वाला क्लाइंट उसके बजाय सादे एरे माँग सकता है:

```sh
genoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 genoffice mcp
```

## स्किल

जिस एजेंट को ऑप शब्दावली नहीं आती, वह अंदाज़ा लगाएगा। `genoffice skill` जिन एजेंटों को पाता है उनमें GenOffice स्किल इंस्टॉल करता है, साथ में संदर्भ और डिज़ाइन गाइड — वही सामग्री जो `genoffice guide` छापता है।

## यह क्या नहीं है

MCP सर्वर फ़ाइलें पढ़ता और लिखता है। यह विंडो नहीं है: कोई AI पैनल नहीं होता, और ऐप के भीतर की अपडेट संवाद लागू नहीं होती। अगर किसी चरण को विंडो चाहिए, तो फ़ाइल खोलिए।
