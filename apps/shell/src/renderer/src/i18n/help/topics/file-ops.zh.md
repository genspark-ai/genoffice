# 文件操作：重命名、删除、导出

这一章汇总介绍跨所有编辑器通用的底层文件管理操作（包括重命名、删除进废纸篓、复制副本、原子保存以及跨格式导出）；至于各个编辑器内部专属的高级导出选项，也可以在对应编辑器的专门章节中查阅。

在主屏（Home）的文件列表中，把鼠标指针悬停到任意一行文件上，右侧就会浮现出集中了绝大多数文件管理命令的 **`⋯` 更多菜单**（直接在文件行上点击鼠标右键效果相同）：

## 重命名文件

GenOffice 提供了两处最顺手的重命名入口，无论你当时是在主屏挑文件还是已经在编辑器里写文章，都能随手改名，而且两边走的是完全相同的一套安全校验管线：

- 在主屏（Home）的「最近」「收藏」或「文件夹」列表里，点击目标文件行右侧的 **`⋯` ▸ 重命名**。
- 在任何已经打开并保存过的文件上，直接**双击顶部的文件标签页标题**（或者右键点击该标签页并选择**重命名**），让标签标题就地变成输入框改名（详见[标签页与窗口管理](help://tabs-and-windows)一章）。

重命名时的贴心保护规则：如果你输入新名字时省去了后缀，系统会自动帮你保留原本的扩展名（如 `.docx`、`.xlsx`）；如果输入的名字里包含操作系统禁止的非法路径字符（如 `/`、`\`、`:`、`*`、`?`）、以点号 `.` 结尾，或是撞上了 Windows 的系统设备保留名（如 `CON`、`NUL`、`PRN`），系统都会当场拦截并弹出清晰的本地化错误提示；如果同一个文件夹下已经存在同名文件（同时妥善处理大小写不敏感磁盘上的仅大小写改名），也会被安全拦下而绝不会静默覆盖别人的文件。确认提交后，修改的是磁盘上的真实文件名，所有已打开标签页的标题、主屏「最近」列表以及「收藏」列表都会在同一瞬间自动同步更新。

## 删除文件（移入系统废纸篓）

- 在主屏文件行点击 **`⋯` ▸ 删除**（或多选文件后点顶部工具条的批量删除）时，系统会先弹出一个确认框明确列出即将删除的文件，经你确认后才会将它们移入操作系统的**原生废纸篓（macOS）或回收站（Windows / Linux）**。如果删完发现误删了，直接打开桌面上的系统废纸篓点「放回原处 / 还原」即可找回——GenOffice 刻意不在应用内部另搞一套只有几秒钟寿命的底部撤销提示条，因为文件恢复本来就应该交由操作系统级废纸篓稳妥托管。

## 创建文件副本

在主屏文件行点击 **`⋯` ▸ 创建副本**，系统会立即在原文件所在的同一个磁盘目录下复制生成一份名为「`<原文件名> 副本`」的新文件（如果目录下已经有副本了，会自动递增追加序号如 `副本 2`）。新生成的副本会自动出现在你的**最近**文件列表最上方，但不会强行打断你当前的工作替你直接弹开新标签页——它就安静地躺在列表第一位，需要时点一下即可打开。

## 保存、另存为与防断电保护

- **手动保存（`⌘S` / `Ctrl+S`）**：将当前编辑器里的最新内容写回磁盘文件；如果是一份刚新建、还没落过盘的「未命名」文档，第一次按保存时会先弹出系统保存对话框让你选定存放目录并起好文件名。
- **另存为（`⇧⌘S` / `Ctrl+Shift+S`）**：将当前文档的完整状态写入你指定的新路径或新文件名下，而磁盘上原有的旧文件保持改动前的样子不变；执行完「另存为」后，当前打开的标签页会自动无缝切换到这份新文件上继续编辑。
- **防损坏的原子写入机制**：GenOffice 中的每一次保存都严格采用「先在目标目录旁写出完整临时文件、刷盘成功后再通过原子级重命名替换原文件」的策略，哪怕在存盘中途遭遇电脑断电、进程被强制杀死或磁盘空间耗尽，也绝不会把你原本好端端的旧文件覆盖成损坏了一半的空壳。
- **克制安全的自动保存**：某个文档的自动保存只有在你对它执行过**至少一次手动保存**之后才会开启（详见[快速入门](help://getting-started)一章），确保只读查看的外部文件绝不会被后台静默改写。

## 导出为 PDF

- **Docs 文字处理**：通过顶部菜单 **文件 ▸ 导出为 PDF**（或功能区对应按钮），直接按当前屏幕上所见即所得的分页与页眉页脚版式输出为标准矢量 PDF。
- **Slides 演示文稿**：选择导出为 PDF 时，系统会按每一张幻灯片对应一页 PDF 的比例逐页高清栅格化输出，遇到上百页的大型演示文稿时会显示实时进度提示并带有超时保护。
- **Sheets 电子表格**：按照你在「页面布局」页签中设定好的纸张方向、打印网格线开关与分页预览边界，将工作表干净地导出为分页 PDF。
- 所有编辑器的 PDF 导出都在本机后台的隐藏渲染窗口中独立完成，既不需要联网上传，也不会抢占或闪烁你当前正在操作的编辑画面，渲染完毕后直接落到你指定的磁盘位置。

## 导出为 Word 文档与分页图片

- **PDF ▸ 导出为 Word / PPT / Excel**：在 PDF 编辑器中通过「文件」菜单或功能区的「PDF 转换」按钮，可以在本机离线将 PDF 文档转换成可编辑的 `.docx` Word 文档（尽最大可能还原复杂的双栏、表格与段落排版）、每页一张幻灯片的 `.pptx` 或每页一张工作表的 `.xlsx`。
- **Docs / Slides / Markdown ▸ 导出为图片**：支持将整篇文档或整套演示文稿按页批量渲染输出为一组高清 `.png` 图片文件，保存在你选择的文件夹下。

## 打印文档

在任何一个编辑器里按下快捷键 `⌘P` / `Ctrl+P`（或通过菜单 **文件 ▸ 打印**），都会唤起分页打印预览或操作系统的原生打印对话框；在 Docs 中打印预览会自动定位到你光标当前所在的那一页，而在 PDF 中则会严格按照你当前调整好的页面排列顺序与旋转方向送印。

## 新建的「未命名」文件在保存前放在哪？

当你新建一份空白的 Docs、Sheets、Slides、Markdown 或 HTML 文档时，在你第一次按下保存键并亲自为它挑选磁盘目录之前，这份草稿**纯粹只存在于当前应用进程的内存里**，不会在你的桌面或文档目录里偷偷留下一堆名叫「未命名 1、未命名 2」的垃圾文件；一旦你完成了第一次手动保存、给它在磁盘上安了家，自动保存就会立刻接过接力棒，在后续编辑中替你持续守护每一次修改。
