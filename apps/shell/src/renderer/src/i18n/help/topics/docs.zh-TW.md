# Docs：文字處理

GenOffice 的 Docs 是一款與微軟 Word 深度相容的文字處理器，直接讀寫標準的 `.docx` 文件格式，並採用真實的所見即所得分頁排版引擎，你在螢幕上看到的每一行折行、每一張跨頁表格和每一處頁首頁尾，列印或匯出為 PDF 時都會分毫不差地呈現出來。

## 功能區（Ribbon）全覽

頂部功能區共設有八個常駐主分頁：**常用／插入／繪圖／版面配置／設計／參考資料／校閱／檢視**；當你用滑鼠點中文件裡的特定物件時，右側還會自動浮現對應的專屬上下文分頁（比如點進表格時出現「表格設計」與「表格版面配置」，選取圖片或圖案時出現格式分頁，雙擊進入頁首或頁尾區域時出現「頁首及頁尾」分頁）。此外，Docs 的功能區還獨享一檔介於完整展開與徹底摺疊之間的**緊湊密度模式**：按下快捷鍵 `⌥⌘K`（Windows 與 Linux 為 `Ctrl+Alt+K`）即可隱去按鈕旁邊的文字說明、只留下一排清爽的圖示，騰出更多縱向視野，而且你的選擇會在下次開啟時自動記住。

- **常用**：包含剪貼簿與複製格式；完整的字型設定（涵蓋初號、小初、一號等全套中文傳統字級、著重號、上下標與字元網底），旁邊配有**清除所有格式設定**按鈕與**顯示／隱藏編輯標記**（段落換行符號、空格點等）開關；段落排版區除了四種對齊、左右縮排、行距與一般項目符號外，還提供**定義新的項目符號／定義新的編號格式／多層次清單**，允許你自訂符合公文或論文規範的清單樣式並直接存進目前文件；右側則是快速樣式庫（標題 1–6、內文、引文等，皆支援按右鍵修改）以及列出全文所有樣式的**樣式窗格**。在修改任意樣式時，你都可以為它**分別指定中文字型（東亞字型）與西文字型**（比如讓中文顯示為新細明體或微軟正黑體，而同一段裡的英文與數字自動使用 Times New Roman），這套中西文字型搭配會完整寫入 `.docx` 檔案，在桌面版 Word 與 GenOffice 之間來回編輯儲存都不會遺失。
- **插入**：支援在游標處插入分頁符號與分節符號；拉出任意列 × 欄的表格網格（或開啟**插入表格…**對話框輸入精確欄列數與自動調整模式）；插入本機圖片、幾何圖案與自由文字方塊；從預設範本庫中一鍵套用精美的**封面頁**或補入**空白頁**；插入內建的**圖表**、報刊風格的**首字放大**與**文字藝術師**；插入會自動更新的動態功能變數（目前日期、時間、目前頁碼、總頁數、檔案名稱）；加上超連結、在內文裡埋設**書籤**並建立指向它的交叉參照；新增頁邊註解、編輯不同節的頁首頁尾與頁碼樣式，以及插入特殊符號與專業數學公式。
  - **圖表**插入到文件裡的是帶有獨立底層資料表的真正原生圖表物件（支援直條圖、折線圖、圓形圖等），而絕不是一張死板的靜態截圖；無論在 GenOffice 裡還是把檔案傳給同事用微軟 Word 開啟點擊「編輯資料」，都能隨時調出它背後的數字表修改數值並即時重繪圖表。
- **繪圖**：讓你能直接用滑鼠、觸控板或手寫筆在文件頁面上方自由批註圈畫，所有工具都集中在**繪圖工具**群組下——點**選取**按鈕可隨時退回普通的內文打字狀態，點**筆**或**螢光筆**即可開始手寫或半透明塗抹標記，點**橡皮擦**後只需在任意一筆線條上單擊或輕輕掃過就能把整根筆跡乾淨擦除。緊挨在旁邊的**筆樣式／螢光筆樣式**是一個二合一面板，裡面同時裝著調色盤和一排筆尖粗細供你隨手切換（按鈕名稱會自動跟隨你目前拿的是鋼筆還是螢光筆）。所有手寫墨跡都以浮動在內文文字上方的標準註解層形式儲存在 `.docx` 檔案裡，儲存重開後依然原樣保留，如果想一次性清空整篇文件的塗鴉，點一下旁邊群組裡的**全部清除**即可。
- **版面配置**：集中管理整篇文件或目前節的紙張規格（A4、Letter、16 開等）、直向與橫向紙張方向、上下左右頁邊距、單欄與多欄排版，以及精確到點（pt）或行的段落縮排與段前段後間距。
- **設計**：提供多套精心調校的文件整體佈景主題、配套色彩方案與標題內文字型組合，同時支援在頁面底層加上斜向文字或圖片**浮水印**，以及設定整頁四周的**頁面框線**。
- **參考資料**：專為長篇報告、學術論文和標書設計，支援一鍵自動擷取各級標題生成可點擊跳轉、可隨時重新整理頁碼的**自動目錄**，在目前頁底或文末插入自動編號的**註腳與章節附註**，為圖表加上規範的**標號**，以及插入指向標題、書籤、註腳或圖表編號的動態**交叉參照**。

- **校閱**：點開**編輯器（Editor）**即可通讀全文，一次性排查拼字錯誤、文法病句與標點不當；內建多語種**翻譯**與即時拼字檢查；提供完整的頁邊**註解**協作流（點擊 **AI 處理註解** 可以讓 AI 助理自動讀取尚未解決的註解意見並逐條幫你改好對應內文）；支援標準的**追蹤修訂（Track Changes）**，可在「所有標記」與清爽的「簡單標記」檢視之間切換，逐條或全部接受／拒絕他人修改，還能點 **AI 摘要修訂** 讓 AI 用幾句話幫你概括這份文件被改了哪些地方；此外還提供即時字數統計、拿目前文件與另一份版本逐字對比差異的**比較**功能，以及防止他人亂改的**保護文件**。
- **檢視**：提供五種不同側重點的文件閱讀與排版視角——最常用的所見即所得**整頁模式**、鋪滿視窗寬度的 **Web 版面配置**、專注章節層級結構的**大綱模式**、適合長文沉浸閱讀的**閱讀模式**以及檢查分頁位置的**分頁預覽**；右側配有畫面縮小、放大、100%、頁寬與整頁顯示控制，以及開關右側 **AI 面板**、切換頁面**深色模式**、勾選顯示尺規、格線與左側導覽窗格的核取方塊；視窗群組支援為同一份文件開**新增分頁**、上下**分割**對比以及快速**切換分頁**；最後還能隨時呼出支援搜尋全部按鍵的**鍵盤快捷鍵**速查對話框。
- **無樣式文件的智慧推斷大綱**：很多法務合約、行政公文或從外部匯入的老文件在排版時並沒有規範套用「標題 1／標題 2」樣式，而是單純用一行簡短的粗體文字、全大寫字母或帶羅馬數字／阿拉伯數字編號的獨立短行（如 `I. BACKGROUND` 或 `一、專案背景`）來充當章節小標題；當整篇文件沒有任何正式標題樣式時，Docs 會自動根據這些段落特徵在不改動原文件任何位元組的前提下為你**智慧推斷出章節大綱**，並以半透明的推斷標記呈現在左側導覽窗格的大綱樹與大綱模式中，讓你照樣能點擊跳轉章節，而一旦你給某行推斷標題套上了正式的標題樣式，它就會立刻轉正為真實的文件標題。
  - **深色模式**採用與新版微軟 Word 相同的貼心設計：開啟後只會把中間的紙張頁面和四周畫布底色變成護眼的深色（內文墨水顏色也會在螢幕顯示時智慧反轉為淺色，但底層真實的字型顏色屬性絕不被篡改，列印和匯出 PDF 時依然是白紙黑字），而頂部的彩色功能區則保持原樣不變；這個開關會被獨立記住，並且優先級高於應用程式全域的深淺色主題。
  - **分割檢視**會在目前編輯區正下方再拉開第二個獨立的捲動窗格，上下兩個窗格顯示的是同一份即時同步的文件，讓你能一邊在上面看著第一章的背景數據、一邊在下面寫第五章的結論，省去上下翻滾幾十頁的奔波；用完後點擊分隔條邊緣的 `×` 即可合攏。

## 左側導覽窗格與大綱重構

在頂部選單或功能區勾選 **檢視 ▸ 導覽窗格**，即可在視窗左側展開一個多功能導覽側邊欄，裡面整合了三樣閱讀長文最離不開的工具：**文件標題大綱樹**、涵蓋全文並即時列出所有符合上下文的**搜尋框**，以及一頁一張的**頁面縮圖**。導覽窗格的開合狀態會在關閉應用程式後自動儲存，習慣靠左側目錄樹寫長文件的人下次開啟軟體時它依然在原位候命。

其中的**大綱**分頁絕不僅僅是一張只能點著跳頁的靜態目錄表——在大綱樹裡的任意一條標題上點擊滑鼠右鍵，你就可以直接對整篇文件的章節骨架做摺疊或結構重組：

- **摺疊／展開目前章節**：在某條標題上選擇摺疊後，該標題連同它下屬的所有子章節都會在大綱樹裡收攏起來，讓你能把寫完的章節先收好、專心盯著正在寫的這一章，而內文內容本身依然完好留在文件裡。
- **全部摺疊／全部展開**：只需點一下就能把整棵大綱樹一次性收攏到頂層或全部攤開；在面對動輒幾十頁、上百個小節的長篇調查報告或技術手冊時，這能讓你瞬間從密密麻麻的子標題裡抽身出來看清全篇主脈絡。
- **依層級過濾顯示標題（顯示標題層級）**：你可以指定大綱樹只展示到第幾級標題——比如選擇_顯示標題 1_ 或 _顯示標題 2_，就能立刻篩掉細枝末節的三四級小標題，留下一張真正適合快速掃讀的骨幹目錄。
- **升級／降級章節（連帶子樹一起升降）**：按右鍵選擇升級或降級時，不僅目前標題本身的層級會改變（如從「標題 2」變成「標題 1」），掛在它下面的所有子標題也會自動跟著同步升降一級，把一整節升格為一整章只需點一下滑鼠。
- **在前面新增標題／在後面新增標題**：無需先把視線移回內文去找游標位置，直接在大綱樹裡按右鍵就能在指定章節的前方或後方原地插入一個同級的新標題並開始輸入。
- **刪除標題及其全部下屬內容**：這是大綱右鍵選單裡威力最大、最需要留意的一項——它刪除的不是內文中孤零零的一行標題文字，而是**把該標題連同它統領的整節內文與所有子章節（整棵子樹）一次性徹底刪掉**，非常適合在改稿時整段砍掉某個廢棄章節（如果誤刪，隨時可以按 `⌘Z`／`Ctrl+Z` 完整復原）。
- **選取標題與內容**：點擊後會直接幫你在內文畫布中從該標題開頭一直框選到它整個子章節的末尾，方便你緊接著執行整章複製、剪下搬家或統一交給 AI 改寫。

## 隨點擊物件智慧變化的右鍵選單

在內文畫布的任何位置點擊滑鼠右鍵，彈出的選單都會根據你滑鼠落點處的具體物件自動組合出最趁手的命令，主要分為以下幾大類：

- **剪貼簿操作**：提供最常用的剪下、複製、帶格式貼上，以及在從網頁或 PDF 複製內容過來時極其好用的**只貼上純文字**（自動洗掉亂七八糟的背景色與外網字級）。
- **就地修改字型與段落**：在選取的文字上按右鍵就能直接改字型家族、字級大小、粗體、斜體、底線，或者調整段落對齊、縮排與行距，手指完全不用跑到視窗最頂部的「常用」功能區去點。
- **同義詞取代**：對著某個英文或中文詞彙按右鍵展開**同義詞**子選單，系統會列出若干語境相近的候選詞，單擊任意一個即可原地取代掉原詞，幫你避免在一頁文章裡反覆出現同一個詞。
- **AI 多語種選字翻譯**：選取一段文字後按右鍵選擇**翻譯**，即可在子選單裡直接指定目標語言（支援繁體中文、簡體中文、英語、日語、韓語、法語、德語、西班牙語等主流語種），自動喚起右側 AI 面板給出地道譯文。
- **新增註解**：直接針對目前選取的詞句在頁邊掛上一條審閱註解氣泡。
- **拼字糾錯選單**（當右鍵點在帶有紅色波浪線的疑似拼字錯誤單字上時浮現）：會在選單最上方直接列出拼字修正建議供你一鍵取代，也可以選擇**全部略過**、將該專有名詞**加入本機字典**，或為目前選取範圍重新指定**校對語言**。
- **超連結管理**（當點在連結上時）：支援直接在瀏覽器中**開啟超連結**、**編輯超連結**網址與顯示文字、一鍵**複製連結網址**，或者**移除超連結**恢復為普通內文。
- **圖片排版與文繞圖**（當右鍵點中圖片時）：支援全螢幕**檢視圖片**、將文件內嵌的圖片**另存為**本機檔案、切換五種經典的 Word **文繞圖方式**（與文字排列、矩形左右環繞、上下型環繞、文字在後、文字在前），以及調整多張浮動物件重疊時的上下**排列層級**（移到最前／移到最後、上移／下移一層）。
- **動態功能變數控制**（當游標位於自動目錄、頁碼或日期等功能變數物件內部時）：支援立即**更新功能變數**以重新整理最新頁碼或標題、在計算結果與底層代碼之間**切換功能變數代碼顯示**，以及開啟對話框**編輯功能變數**屬性。
- **清單編號控制**（當游標位於有序編號清單中時）：可以隨時讓目前行**重新開始編號**（重設為 1）、與上方斷開的清單**繼續編號**、**變更清單階層**，或者開啟**設定編號值**強制從任意指定數字開始往下排。
- **表格全方位操作**（當游標位於表格內部時）：無需去頂部找表格分頁，按右鍵就能直接在上下左右**插入列或欄**、**合併或分割儲存格**、從目前列把一張大表**分割為兩張表格**、設定**自動調整**（依內容、依視窗或固定欄寬）、調整儲存格內部九宮格**對齊方式**、**平均分配各列高與各欄寬**、開啟**表格內容**對話框、呼出**刪除儲存格／列／欄／整表**子選單以及快速選取欄列。

## 核心編輯與排版能力

- **強大的尋找與取代（`⌘F`／`Ctrl+F` 與 `⌃H`／`Ctrl+H`）**：除了普通關鍵字搜尋外，完整支援**區分大小寫**、**全字拼寫須相符**以及高階的**正規表示式（Regex）**尋找與批次取代，讓你能輕鬆批次清洗複雜的公文格式或編號。
- **複製格式、深度復原與智慧貼上**：支援單擊刷一次或雙擊連續刷多處的複製格式刷、不限步數的多層級復原與取消復原，以及貼上外部富文本時自由選擇保留來源格式、合併格式或僅保留純文字。
- **與 Word 排版一致的專業表格**：完整支援儲存格合併與分割、欄列增刪、內外框線線型與網底填色、依欄排序以及表格內嵌公式計算。遇到內容很長的跨頁表格時，長列會在紙張底部自然切分並跨頁續排；如果你希望在某個表格儲存格內部指定位置強制換到下一頁，只需在儲存格裡按下 `Ctrl+Enter`（macOS 為 `⌘⏎`）即可從該處精準翻頁，列印與匯出 PDF 時同樣嚴格生效。
- **圖片修飾與繪圖畫布**：支援自由裁剪圖片邊緣、依解析度壓縮文件內圖片體積以減小檔案大小、設定文繞圖，以及插入獨立的繪圖畫布來統一組織複雜的流程圖圖案。

## 中日韓（CJK）專業排版細節

- **標點擠壓與避頭尾規則（Kinsoku）**：嚴格對齊桌面版 Word 的中文排版規範，句號、逗號、右括號等行尾禁則標點絕不會孤零零掉到下一行開頭，左引號、左括號等行首禁則標點也絕不會留在上一行末尾，連續標點之間會自動執行恰當的字距壓縮；同時內建一鍵全形／半形轉換與簡繁中文互轉工具。
- **跨平台中文字型智慧比對**：內建的字型候選與度量表完整涵蓋了 Windows 與 macOS 上常見的中、日、韓字型家族名稱（包括新細明體、微軟正黑體、宋體、微軟雅黑、蘋方／PingFang TC、思源黑體／宋體等的中英文別名），跨系統開啟同事傳來的文件時版面行距與折行位置依然穩固。

## AI 寫作與審校助理

- **預設動作與自由指令結合**：點擊功能區上的 **AI 按鈕**或展開右側 AI 面板後，你既可以直接點選**潤飾改寫、擴寫篇幅、多語種翻譯、提煉摘要、從文字生成表格**等高頻預設卡片，也可以在輸入框裡用自然語言提出任何排版或寫作要求。
- **自動留存快照，隨時無損回滾**：AI 助理對你的文件動手做每一輪修改之前，都會先在背景為目前文件自動拍下一份完整的版本快照；你隨時可以在 AI 面板的**版本歷史清單**裡一鍵回滾到任意一輪修改前的狀態，而且即便點了回滾，回滾這個動作本身也同樣支援按 `⌘Z`／`Ctrl+Z` 再次復原，讓你能毫無顧慮地讓 AI 嘗試各種大刀闊斧的改稿方案。

## 儲存與匯出

- **位元組級保守的 `.docx` 增量儲存**：當你儲存一份修改過的 `.docx` 文件時，Docs 的寫入引擎**只會重寫你真正改動過的那幾個段落**，而文件裡沒有被你碰過的其他段落、複雜功能變數、內嵌物件與原始 XML 屬性都會保持**位元組級原封不動（byte-identical）**，徹底杜絕了「開啟別人的複雜合約只改了一個錯別字、儲存後卻把整篇排版搞亂」的行業痛點。
- **高保真匯出為 PDF 與逐頁圖片**：無需借助外部虛擬印表機，直接依目前所見即所得的分頁結果匯出為標準 PDF 檔案，或者把每一頁分別匯出為高畫質 PNG 圖片。
- **列印預覽自動定位到目前游標所在頁**：當你正在編輯一份幾十頁長文件的中間某頁、按下 `⌘P`／`Ctrl+P`（或從檔案選單開啟列印預覽）想要檢查目前這一頁的排版效果時，列印預覽視窗會**直接跳轉到你內文游標目前所在的那一頁**，省去了每次開啟列印預覽都只能從第 1 頁重新往後翻找的麻煩。

## 列印

按下 `⌘P`／`Ctrl+P` 即可進入內建的所見即所得分頁列印預覽，確認紙張、頁碼範圍與份數後直接呼叫作業系統列印服務輸出。
