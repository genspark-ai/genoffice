# Docs：文字處理

Docs 是類 Word 的文字處理器：讀寫真正的 .docx，分頁排版所見即所得。

## 功能區

分頁：**常用／插入／版面配置／設計／參考資料／校閱／檢視**，外加隨選取物件出現的內容關聯分頁（表格設計、圖片等）。

- **常用**：剪貼簿；字型（含中日韓字級與強調點號）；段落（對齊／縮排／行距／清單）；樣式（標題 1-6／內文／引文，可修改）。
- **插入**：分頁符號／分節符號、表格（含快速表格）、圖片、圖形、超連結、頁首及頁尾、頁碼、日期、文字方塊。
- **版面配置**：邊界、紙張方向與大小、分欄、段落縮排與間距。
- **設計**：佈景主題、色彩組合、浮水印、頁面框線。
- **參考資料**：目錄（可更新）、註腳／尾注、圖說、交叉參照。

  ![參考資料分頁](img/docs-references.png)

- **校閱**：拼字檢查、註解、修訂追蹤（全部標記／簡單標記檢視）、字數統計。
- **檢視**：尺規、格線、導覽窗格、縮放，以及可搜尋的**鍵盤快速鍵對話框**。

## 右鍵選單

在內文任意位置按右鍵，選單會依你點到的物件變化。主要分組：

- **剪貼簿**：剪下／複製／貼上／**只貼上文字**。
- **字型、段落**：不必進入功能區就能更改字型與字級、加上粗體／斜體／底線，以及調整對齊／縮排／行距。
- **同義字**：列出所選字詞的同義字；點一下即可取代。
- **翻譯**（AI）：透過 AI 面板，把選取內容翻譯成目標語言（英文、簡體中文、日文、韓文、法文、德文、西班牙文⋯）。
- **新增註解**：在選取範圍上加上註解。
- **拼字**（拼錯的字詞上）：建議取代、全部忽略、加入字典、設定校對語言。
- **超連結**：開啟／編輯／複製連結／移除超連結。
- **圖片**：檢視圖片、圖片另存為、**文字環繞**（嵌入／左右型／上下型／置於文字下方／浮於文字上方）、排列層級。
- **功能變數**（目錄、頁數等）：更新功能變數／切換功能變數代碼／編輯功能變數。
- **清單編號**（在清單內）：重新開始編號／繼續編號／變更清單層級／設定編號值。
- **表格**（游標在表格內）：插入列／欄、合併／分割儲存格、分割表格、自動調整、儲存格對齊、平均散佈列／欄、表格屬性、刪除選單、選取。

## 編輯

- 尋找與取代（ctrl+F / ctrl+H）：支援區分大小寫、全字相符、正規表示式。
- 格式刷；多層復原／重做；貼上選項。
- 表格：合併／分割儲存格、插入與刪除列欄、框線與網底、排序、公式。
- 圖片：文字環繞、裁剪、壓縮；繪圖畫布。

## 中文排版

- 標點壓縮與避頭尾斷行與 Word 對齊；全形／半形轉換。
- 字型候選涵蓋 Windows 與 macOS 常見的中日韓字型名稱。

## AI

- 功能區的 AI 按鈕與側邊面板：改寫、擴寫、翻譯、摘要、插入表格等預設功能，加上自由指令。
- 每次 AI 處理前都會先建立快照；可從版本清單回復，而且回復本身也可以復原。

## 儲存與匯出

- 儲存 .docx 時只會重寫有變更的段落——未動到的內容保持位元組完全相同。
- 可匯出 PDF（依目前分頁）與逐頁圖片。

## 列印

以 ctrl+P 開啟系統對話方塊，分頁所見即所得。
