# Docs：文字處理

Docs 是類 Word 的文字處理器：讀寫真正的 .docx，分頁排版所見即所得。

## 功能區

分頁：**常用／插入／繪圖／版面配置／設計／參考資料／校閱／檢視**，外加隨選取物件出現的內容關聯分頁（表格設計與版面配置、圖片、頁首與頁尾）。

- **常用**：剪貼簿；字型（含中日韓字級與強調點號）搭配 **清除所有格式設定** 與 **顯示/隱藏編輯標記** 開關；段落（對齊／縮排／行距／清單）另有 **定義新的項目符號／定義新的編號格式／多層次清單**，可將您自訂的清單樣式存進文件；樣式（標題 1-6／內文／引文，可修改），另有 **樣式窗格** 列出完整清單。
- **插入**：分頁符號／分節符號、表格（列 × 欄格點，或以 **插入表格…** 指定精確大小）、圖片、圖形、文字方塊、預設集庫中的 **封面頁** 與 **空白頁**、**圖表**、**首字放大**、**文字藝術師**、功能變數（日期、時間、頁碼、總頁數、檔案名稱）、超連結、**書籤** 與交互參照、註解、頁首及頁尾與頁碼、符號與方程式。
  - **圖表** 插入的是帶有本身資料的真正圖表物件——橫條、折線或圓餅——而不是一張圖片。Word 的「編輯資料」會開啟它背後的數字。
- **繪圖**：在頁面上以墨跡書寫的工具集中在 **繪圖工具** 群組——**選取** 可回到文字編輯，接著是 **畫筆**、**螢光筆** 與 **橡皮擦**（點一下或一抹即去掉整筆）。旁邊的 **畫筆樣式**／**螢光筆樣式** 是同一個控制項，裡面同時放著色彩樣板與一排粗細；其名稱會跟著目前啟用的工具走。墨跡以浮在文字上方的註解形式存進文件，因此存檔後重新開啟依然存在，而下一個群組的 **全部清除** 會一次清空。
- **版面配置**：邊界、紙張方向與大小、分欄、段落縮排與間距。
- **設計**：佈景主題、色彩組合、浮水印、頁面框線。
- **參考資料**：目錄（可更新）、註腳／尾注、圖說、交叉參照。

  ![參考資料分頁](img/docs-references.png)

- **校閱**：**編輯器** 通讀全文檢查拼字、文法與標點；**翻譯**；拼字檢查；註解（**AI 處理註解** 會處理尚未解決的註解）；修訂追蹤（所有標記／簡易標記檢視）、接受／拒絕，以及 **AI 總結修訂**；字數統計；與另一個檔案 **比較**；**保護文件**。
- **檢視**：檢視檔案有五種方式——**整頁模式**、**Web 版面配置**、**大綱模式**、**閱讀模式** 與 **分頁預覽**；縮小／放大／百分比／頁寬／單頁；**AI 面板**；**深色模式**；尺規、格線與功能窗格；**新增索引標籤**、**分割** 與 **切換索引標籤**；以及可搜尋的 **鍵盤快速鍵** 對話方塊。
  - **深色模式** 只會讓頁面與周圍的畫布變暗，絕不會影響功能區——這正是 Word 在深色編輯介面與深色視窗之間的取捨。這個選擇會被記住，而且不論應用程式佈景為何都以它為準。
  - **分割** 會在下方開啟第二個窗格，可獨立捲動並與第一個窗格同步；用窗格邊緣的 × 將它關閉。

## 功能窗格

**檢視 ▸ 功能窗格**會開啟一個側邊窗格，裡面放三樣東西：文件的標題大綱、涵蓋整份文件的尋找方塊，以及每頁一張的縮圖。窗格是否開啟會在兩次啟動之間記住，所以習慣靠大綱翻文件的人，下次開啟還是能這麼翻。

**大綱**就是標題樹。在大綱裡右鍵點某個標題，既能摺疊它，也能改結構，而不只是用來瀏覽：

- 標題上的**展開 / 摺疊**會把該標題的整個子樹收起來——章節不見了，內文還留在文件裡。
- **全部展開 / 全部摺疊**一鍵收放整棵樹。遇上長報告，這就是「掃得過的大綱」和「一堵字牆」的差別。
- **顯示標題層級**依你在意的深度篩選這棵樹，於是*顯示標題 1* 留下來的就是一張真的掃得動的目錄。
- **升級 / 降級**改變標題的層級，下面所有標題跟著繼承這個層級——一章就這樣變成一節。
- **在前面新增標題 / 在後面新增標題**在游標處插入標題，不用離開窗格。
- **刪除**會把標題*連同它下面的全部內容*一起刪掉，這是最需要小心的一項：它刪的是子樹，不是某一行。
- **選取標題和內容**從標題一直選到子樹結尾，正好可以整節編輯。

## 右鍵選單

在內文任意位置按右鍵，選單會依你點到的物件變化。主要分組：

- **剪貼簿**：剪下／複製／貼上／**只貼上文字**。
- **字型、段落**：不必進入功能區就能更改字型與字級、加上粗體／斜體／底線，以及調整對齊／縮排／行距。
- **同義字**：列出所選字詞的同義字；點一下即可取代。
- **翻譯**（AI）：透過 AI 面板，把選取內容翻譯成目標語言（英文、簡體中文、日文、韓文、法文、德文、西班牙文⋯）。
- **新增註解**：在選取範圍上加上註解。
- **拼字**（拼錯的字詞上）：建議取代、全部忽略、加入字典、設定校對語言。
- **超連結**：開啟／編輯／複製連結／移除超連結。
- **圖片**：檢視圖片、圖片另存為、**文字環繞**（嵌入／左右型／上下型／置於文字下方／浮於文字上方）、排列層級。
- **功能變數**（目錄、頁數等）：更新功能變數／切換功能變數代碼／編輯功能變數。
- **清單編號**（在清單內）：重新開始編號／繼續編號／變更清單層級／設定編號值。
- **表格**（游標在表格內）：插入列／欄、合併／分割儲存格、分割表格、自動調整、儲存格對齊、平均散佈列／欄、表格屬性、刪除選單、選取。

## 編輯

- 尋找與取代（ctrl+F / ctrl+H）：支援區分大小寫、全字相符、正規表示式。
- 格式刷；多層復原／重做；貼上選項。
- 表格：合併／分割儲存格、插入與刪除列欄、框線與網底、排序、公式。
- 圖片：文字環繞、裁剪、壓縮；繪圖畫布。

## 中文排版

- 標點壓縮與避頭尾斷行與 Word 對齊；全形／半形轉換。
- 字型候選涵蓋 Windows 與 macOS 常見的中日韓字型名稱。

## AI

- 功能區的 AI 按鈕與側邊面板：改寫、擴寫、翻譯、摘要、插入表格等預設功能，加上自由指令。
- 每次 AI 處理前都會先建立快照；可從版本清單回復，而且回復本身也可以復原。

## 儲存與匯出

- 儲存 .docx 時只會重寫有變更的段落——未動到的內容保持位元組完全相同。
- 可匯出 PDF（依目前分頁）與逐頁圖片。

## 列印

以 ctrl+P 開啟系統對話方塊，分頁所見即所得。
