# Sheets：电子表格

Sheets 是类 Excel 的表格编辑器，计算由一个独立的 Rust 引擎进程承担（崩溃不影响主程序）。打开与保存都是真 .xlsx；.csv 和 .tsv 会作为表格打开。

## 界面

- **功能区**：八个页签，逐页说明见下。
- **公式栏**：显示与编辑当前单元格的公式；支持常用函数。
- **工作表标签**（底部）：新建 / 重命名 / 删除 / 移动工作表。
- **单元格编辑**：双击或直接输入；Enter 确认下移、Tab 右移、Esc 取消（Excel 习惯）。
- **快捷键**：与 Excel 家族对齐（ctrl+C/V/X、ctrl+Z/Y、ctrl+F 查找等），详见应用内提示。

## 功能区页签

- **开始**：字体、填充、边框、数字格式（货币/百分比/千分位/增减小数位）、对齐、合并单元格、行列增删与行高列宽、条件格式、套用表格格式、单元格样式、剪贴板与格式刷、排序筛选。
- **插入**：形状、图标、符号、公式（方程）、屏幕截图等。
- **页面布局**：主题颜色与字体、打印网格线/标题开关、分页预览。
- **公式**：自动求和与函数插入、定义名称（可由所选单元格生成）、追踪前例/从属、监视窗口、重新计算/重算工作表。
- **数据**：排序与筛选（含高级筛选、清除筛选）、文本分列（自 CSV/文本）、合并工作簿、全部刷新。
- **审阅**：批注浏览（显示批注、上一条/下一条）、翻译。
- **视图**：网格线与标题开关、缩放、普通视图/分页预览。
- **图表设计**：选中图表时出现——换图表类型、样式与配色、编辑数据范围。

「数据」页签逐个按钮（对照下图，从左到右）：

- **数据透视表**：把当前区域生成透视表，拖字段做行列聚合分析。
- **刷新**：重算当前透视表的数据。
- **从文本/CSV**：把 .csv/.txt 按分隔符导入为新工作表。
- **合并工作簿**：把其他 .xlsx 的表合并进当前文件。
- **全部刷新**：重算所有透视表与外部数据。
- **排序**（下拉）：升序 / 降序 / 自定义排序（多列与规则）。
- **筛选**：给表头加 ▼ 下拉，勾选保留值。
- 筛选旁的竖排小按钮：**清除**（恢复全部行）、**重新应用**（再跑一遍当前筛选）、**高级**（用条件区域做高级筛选）。
- **分列**（下拉）：把一列按分隔符或固定宽度拆成多列。
- **快速填充**：给一个示例，其余行按示例自动填充（⌃E/ctrl+E）。
- **删除重复值**：按所选列去掉重复行。
- **数据验证**（下拉）：给选区设输入规则（下拉列表、数值范围等）。
- **合并计算**：把多个区域按类别汇总到一处。
- **模拟分析**（下拉）：单变量求解 / 模拟运算表。
- **组合 / 取消组合**（下拉）：行或列分组、折叠展开。
- **分类汇总**：按分类字段插入小计行。

「公式」页签逐个按钮：

![公式页签](img/sheets-formulas.png)

- **插入函数**（fx）：搜索函数并带参数向导。
- **自动求和**（下拉）：一键 SUM，还有平均值/计数/最大最小等。
- **最近使用的函数 / 财务 / 逻辑 / 文本 / 日期和时间 / 查找与引用 / 数学和三角函数 / 其他函数**：按分类浏览并插入函数。
- **名称管理器**：查看、新建、删除命名区域。
- **定义名称**（下拉）：给选区起名；**用于公式**把已有名称插进公式；**根据所选内容创建**用首行/首列文字批量命名。
- **追踪引用单元格 / 追踪从属单元格**：画蓝色箭头标出公式的数据来源与去向；**删除箭头**清除。
- **显示公式**：单元格里显示公式本身而非结果。
- **错误检查**：定位并解释公式错误。
- **监视窗口**：把关心的单元格加进来，随时看它的当前值。
- **计算选项**（下拉）：自动/手动重算；手动模式下用旁边的**立即计算 / 计算工作表**手动触发。

## 数字与格式

- 数字格式：常规、数值、货币、百分比、日期时间、分数、科学计数等。
- 对齐、换行、合并单元格、边框与填充色。
- 行高列宽拖拽调整，双击边界自适应。

## 数据

**排序与筛选**（以按某列降序为例）：

1. 点表格里**该列的任意一个单元格**（不用选中整列）。
2. 开始页签 ▸ **排序和筛选** ▸ 选 **降序**；相邻列的整行会跟着一起重排（按整个区域排序）。
3. 想按自己的规则（多列、按颜色）：同一路径选 **自定义排序**。
4. 筛选：选中表头行后点 **排序和筛选 ▸ 筛选**，每个表头出现 ▼ 下拉，勾选想留下的值；**清除筛选** 恢复全部。

- **冻结窗格**：视图页签 ▸ 点要冻结范围右下方的单元格 ▸ 冻结窗格——滚动时上方与左侧始终保持可见。
- .csv / .tsv：直接打开为表格（制表符分隔的 tsv 按表解析），保存回原格式。

## 右键菜单

- **表格里右键**：编辑器（Univer）自带菜单——剪切/复制/粘贴、插删行列、隐藏、合并单元格、冻结窗格等常用项。
- **底部状态区右键**：选择状态栏要显示哪些统计（平均值 / 计数 / 求和等），选择即生效并记住。
- **底部工作表标签右键**：工作表的新增 / 重命名 / 删除 / 颜色 / 隐藏等（Univer 标签菜单）。
- 顶部标签条的右键菜单见「标签页与窗口管理」。

## 脚本编辑器（进阶）

Sheets 内置一个**脚本编辑器**：用类 Google Apps Script 的 API 批量处理数据。

- 打开：菜单 工具 ▸ 脚本编辑器（或开发者菜单，随版本）。
- 界面：左侧脚本库（可新建/删除），右侧代码编辑器 + 输出窗格；**运行 / 停止** 按钮。
- API 形态（异步）：

```js
const sheet = await SpreadsheetApp.getActiveSpreadsheet()
const active = await sheet.getActiveSheet()
const range = await active.getRange('A1:C10')
const values = await range.getValues() // 二维数组
await range.setValues(values.map((row) => row.map((v) => v * 2)))
Logger.log('done')
```

- `SpreadsheetApp`（入口）、`Sheet`（getName/getRange/getLastRow…）、`Range`（getValue(s)/setValue(s)/clear…）、`Logger.log`、`Utilities.sleep`。
- 脚本运行在**沙箱 Worker**里：没有网络、没有文件系统、没有 DOM，只能通过上述 API 触达表格——恶意或写错的脚本动不了你的其他数据。
- 输出窗格有行数上限，防止巨量日志拖垮界面。
- **AI 也能调用脚本**：AI 助手的 `run_script` 工具执行同样的沙箱 API，适合批量/规则化改写。

## AI 能力

- 右侧 AI 面板：选中区域后用自然语言下指令（改格式、生成数据、写公式等）。
- AI 的修改可以通过面板回滚。

## 保存与导出

- 保存为 .xlsx（公式与格式保留）；另存为、导出 PDF 按打印分页。
- 自动保存遵循全局规则（首次手动保存后开启）。

## 稳定性

- 计算引擎（Rust 边车）与界面进程隔离：极端数据导致引擎退出时，界面会提示并尝试恢复会话，不会连坐整个应用。
