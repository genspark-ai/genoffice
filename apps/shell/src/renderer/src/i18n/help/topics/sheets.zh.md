# Sheets：电子表格

GenOffice 的 Sheets 是一款与微软 Excel 高度兼容的电子表格编辑器，底层公式运算由一个与界面分离的独立 Rust 计算引擎进程承担（即便遇到超大规模或极端复杂的公式数据导致引擎进程重启，也不会拖垮主窗口界面）。它直接打开和保存标准的 `.xlsx` 工作簿，同时也能把 `.csv` 和 `.tsv` 文本文件直接当作结构化表格打开编辑。

## 界面布局与基础交互

- **顶部功能区（Ribbon）**：按日常制表流程划分为八个主功能页签（外加选中图表时浮现的上下文页签），每个页签的具体功能会在下文逐一展开介绍。
- **公式编辑栏**：位于表格画布正上方，用来实时显示和编辑当前活动单元格里的原始公式或文本内容，支持函数自动补全与参数提示。
- **底部工作表标签栏**：横向排列当前工作簿中的所有工作表（Sheet），你可以随时在这里点击 `+` 新建工作表、双击标签重命名、拖拽调整前后顺序，或通过右键菜单删除与隐藏工作表。
- **单元格输入与键盘流**：双击单元格或选中后直接敲键盘即可开始输入；按下 `Enter` 键确认输入并跳到下一行，按下 `Tab` 键确认并跳到右侧一列，按下 `Esc` 键则放弃刚才敲入的内容并恢复原值，完全遵循老 Excel 用户的肌肉记忆。
- **熟悉的快捷键体系**：无论是 `Ctrl+C / V / X` 剪切板操作、`Ctrl+Z / Y` 撤销重做、`Ctrl+F` 查找，还是 `F2` 就地编辑与 `F4` 切换绝对/相对引用（macOS 上对应 `⌘` 组合键），都与桌面版 Excel 家族保持对齐。

## 功能区八大页签详解

- **开始**：集中了日常排表最常用的高频工具，包括字体与字号设置、单元格背景填充色、四周边框样式、数字显示格式（货币、百分比、千分位分隔符以及一键增减小数位数）、水平与垂直对齐、合并及居中单元格、插入或删除行列与调整行高列宽、条件格式高亮、套用预设表格样式、单元格快速样式库、剪贴板与格式刷，以及快速排序和筛选入口。
- **插入**：支持往表格里放图片、几何形状、自由文本框、超链接、单元格批注、交互式复选框、打印页眉和页脚、特殊符号与数学公式；在数据可视化方面，内置了**九种常用图表类型**（柱形图、条形图、折线图、面积图、饼图、散点图、雷达图、圆环图，以及柱形+折线组合图），并提供**推荐的图表**功能——它会根据你当前框选的数据特征自动评估最匹配的图表类型并生成实时预览；此外还能从当前光标所在的区域一键创建**数据透视图**、在单元格内部绘制反映趋势的**迷你图**（支持折线、柱形、盈亏胜负三种形态），以及专门用来交互式过滤数据透视表的**切片器**与**日程表**。
  - 图表、数据透视图和单元格迷你图都会作为标准的 OpenXML 对象真实保存在 `.xlsx` 工作簿里，在桌面版 Excel 中打开依然可以继续编辑。
  - **切片器**和**日程表**则属于当前编辑会话的快捷筛选面板：你通过它们勾选出的筛选结果会真实写回数据透视表并保存到文件中（用 Excel 打开看到的是完全一致的筛选后透视表），而悬浮在画布上的切片器按钮面板本身不会写入文件。
- **页面布局**：用来设置整本工作簿的主题配色方案与主题字体，控制打印或导出 PDF 时是否显示网格线与行列标头（A、B、C 与 1、2、3），以及开启分页预览来检查纸张切分位置。
- **公式**：提供一键自动求和与带向导的函数插入器、命名区域管理（支持根据所选单元格首行或首列自动批量创建名称）、画蓝色箭头追踪公式的前导引用与从属单元格、常驻盯盘的监视窗口，以及手动触发重算整本工作簿或当前工作表。
- **数据**：涵盖单列与多列自定义排序、自动筛选与高级条件区域筛选、把粘成一列的 CSV 或长文本按分隔符拆开的「文本分列」、跨文件「合并工作簿」，以及一键刷新所有数据透视表。
- **审阅**：用于集中浏览和管理单元格批注（切换显示/隐藏、跳转到上一条或下一条批注）、调用 AI 翻译选中单元格内容，以及管理工作表安全的**保护**功能组——包含**保护工作表**、**保护工作簿**和**允许编辑区域**三项。
  - 在 GenOffice 中开启的保护会真实写入 `.xlsx` 文件结构，且默认不捆绑加密口令，防止你自己忘掉密码打不开；开启保护后，功能区上的同一个按钮会立刻变成**取消保护…**，随时再点一下就能解开。但如果某份表格是在其他软件里加了*带密码*的保护，则无法在这里直接绕过密码移除。
  - 点击「保护工作表」或「保护工作簿」后会立即在当前表格生效，不会弹出繁琐的二次确认框打断你，只会在底部状态栏温和提示一句该保护状态将在保存文件时一并写入磁盘。
  - **允许编辑区域**非常适合制作下发给别人填写的模板表：你可以先把需要别人填数据的那几列标记为允许编辑区域，然后再锁住整张工作表，这样填表人就不会误改旁边的汇总公式。
- **视图**：用来随时开关表格网格线、顶部**公式栏**、行列标头，以及非常实用的「十字高亮突出显示当前活动行与列」（避免在宽表里看串行）；此外还提供画面缩放比例调节，以及在**普通视图**与**分页预览视图**之间切换。其中网格线和行列标头的显示状态会随工作表一起存进文件，而活动行列的十字高亮则作为你本人的阅读偏好保存在本机。
- **图表设计**（上下文页签）：只有当你在画布上单击选中某张图表时才会在功能区最右侧浮现，方便你随时更换图表类型、一键切换配色与视觉样式，或者重新框选图表背后绑定的数据源区域。

![数据页签](img/sheets-data.png)

- **数据透视表**：根据当前选中的数据源区域一键创建数据透视表，在侧边字段列表里把字段拖进「行」「列」「值」或「筛选」区，即可完成按维度分组求和、计数或求平均等多维交叉汇总。
- **刷新**：当原表里的底层数字发生改动后，点击此按钮即可立即重新计算并更新当前选中的那张数据透视表。
- **从文本/CSV**：把外部的 `.csv` 或 `.txt` 纯文本数据文件按指定的分隔符（逗号、制表符、分号等）解析并导入为当前工作簿里的一张新工作表。
- **合并工作簿**：把磁盘上其他 `.xlsx` 文件里的工作表批量抽取并合并到你当前正在编辑的这本工作簿中，省去来回打开多个文件手动复制粘贴的麻烦。
- **全部刷新**：一次性重新计算并刷新当前工作簿里的所有数据透视表与关联数据集。
- **排序**（带下拉菜单）：支持对当前列一键执行**升序**或**降序**排列（相邻列的数据会自动跟着整行一起移动，绝不会排乱对应关系），也可以打开**自定义排序**添加多级排序条件（比如先按部门排、同部门再按销售额降序排）。
- **筛选**：给数据表第一行的表头单元格挂上 `▼` 下拉箭头按钮，点开箭头即可通过勾选具体数值或设置文本/数值条件，只把符合条件的行留在屏幕上。
- **筛选右侧的三个小按钮**：**清除**用于一键撤掉所有列的筛选条件、让隐藏的行全部重新显示出来；**重新应用**用于在被筛选列的数据修改后按当前规则再跑一遍过滤；**高级**则允许你在表格旁边单独写一块条件区域，执行复杂的多条件「与/或」高级筛选。
- **分列**（带下拉菜单）：当你把一段从网页或日志里复制出来的文字粘进一列时，用它可以按特定分隔符（如逗号、空格、竖线）或固定字符宽度，把这一列干净利落地拆成多列。
- **快速填充**：无需编写复杂的文本截取公式，只要在旁边新列的第一行手动敲入一个你期望的提取或拼接示例，然后点击此按钮（或按下快捷键 `⌃E` / `Ctrl+E`），系统就会自动识别你的规律并把整列剩下的行瞬间填满。
- **删除重复值**：指定按哪一列或哪几列的组合来判断重复，一键剔除表格里多余的重复数据行并汇报清理数量。
- **数据验证**（带下拉菜单）：为选中的单元格区域设定合法的输入准入规则——既可以做成只允许从预设名单里点选的「下拉列表」，也可以限制只能输入特定范围内的整数、小数、日期或特定长度的文本，并在有人输错时弹出提示。
- **合并计算**：把分散在多张工作表或多个不同区域的同结构数据，按照行/列分类标签自动对齐并做求和、求平均等汇总合并。
- **模拟分析**（带下拉菜单）：内置经典的**单变量求解（Goal Seek）**工具——当你已经写好了利润或贷款计算公式、明确知道自己想要公式最终得出什么目标结果，却想反推某个上游输入单元格应该填多少时，用它可以自动迭代倒推出精确的输入值。
- **组合 / 取消组合**（带下拉菜单）：把选中的连续多行或多列打包成可折叠的层级分组，表头外侧会出现 `+` / `-` 折叠按钮，方便在大型财务报表里随时收起明细、只看大类。
- **分类汇总**：针对已经按某列排好序的数据表，自动在每个分类交界处插入一行小计（Subtotal），并在表格末尾附上总计行。

![公式页签](img/sheets-formulas.png)

- **插入函数**（`fx` 按钮）：打开带搜索框的函数挑选器，选中函数后会进入分步参数填写向导，边填边能看到每个参数的含义说明与计算预览。
- **Excel 365 正则表达式函数与 PERCENTOF**：公式栏原生支持最新 Excel 365 引入的正则家族函数 **`REGEXTEST`**（测试文本是否匹配给定正则，返回 `TRUE/FALSE`）、**`REGEXEXTRACT`**（按正则从文本中提取首个匹配、全部匹配数组或捕获组内容）和 **`REGEXREPLACE`**（按正则匹配并替换文本，支持 `$0`、`${n}` 与命名捕获组 `${name}` 展开，以及只替换第 N 次匹配），外加专门用于计算子集占总集比例的 **`PERCENTOF(data_subset, data_all)`** 函数；这四个函数的参数签名与桌面版 Excel 完全一致，默认启用 Unicode（`u` 标志）以支持 `\p{...}` 等属性匹配，并且内置了与 Univer 引擎相同级别的指数级回溯安全检查，一旦检测到可能导致界面卡死的危险正则表达式会直接拒绝并返回错误值，绝不会把表格挂死。
- **自动求和**（带下拉菜单）：点击主按钮即可在选中区域下方或右侧一键插入 `SUM` 求和公式；点开旁边的下拉箭头，还能同样一键插入**平均值（AVERAGE）**、**计数（COUNT）**、**最大值（MAX）**或**最小值（MIN）**。
- **按分类浏览函数库**（最近使用的函数 / 财务 / 逻辑 / 文本 / 日期和时间 / 查找与引用 / 数学和三角函数 / 其他函数）：如果你记不清某个函数的具体英文拼写，可以直接点开对应的领域分类下拉菜单，在列表里浏览并直接把函数插入当前单元格。
- **名称管理器**：在一个集中面板里查看当前工作簿里定义过的所有「命名区域」，支持新建语义化的区域名称、修改现有名称指向的单元格坐标范围，或删除不再使用的旧名称。
- **定义名称**（带下拉菜单）：直接为你当前框选的单元格区域起一个好记的名字（比如把 `B2:B100` 命名为 `销售额`），之后写公式时点旁边的**用于公式**就能直接把名字代进去；如果选了**根据所选内容创建**，更能直接拿选区首行或最左列的表头文字，一次性批量给整张表的所有数据列自动起好名字。
- **追踪引用单元格 / 追踪从属单元格**：遇到复杂嵌套公式算出的数字不对劲时，点一下这两个按钮就会在网格上方画出直观的蓝色指引箭头，清楚标出当前公式的数据究竟是从哪些上游单元格拿来的（引用单元格），或者当前单元格的数字又喂给了哪些下游公式（从属单元格）；排查完毕后点一下**删除箭头**即可恢复干净画面。
- **显示公式**：一键把整张工作表从「显示计算结果」切换为「在单元格里直接显示 `=...` 公式源码」（状态栏也会同步提示当前正处于显示公式模式），非常适合全局审阅整张表的公式逻辑是否统一。
- **错误检查**：自动扫描当前工作表里出现 `#VALUE!`、`#NAME?`、`#REF!`、`#DIV/0!` 等错误值的单元格，帮你逐个定位并给出错误成因说明。
- **监视窗口**：当你在一张几千行的大表前端修改参数、却想知道远在另一张工作表末尾的几个核心汇总单元格是怎么跟着变的时候，可以把那几个核心单元格添加进「监视窗口」悬浮面板里，无需来回翻表就能实时盯着它们的最新数值。
- **计算选项**（带下拉菜单）：默认处于**自动重算**模式，任何单元格一改，全表依赖它的公式都会立即更新；如果你正在编辑一张包含几十万个公式的超大型工作簿，可以临时切到**手动重算**模式以获得丝滑的输入响应，等数据改完后再点旁边的**立即计算**（重算整本工作簿，快捷键 `F9`）或**计算工作表**（仅重算当前表，快捷键 `⇧F9` / `Shift+F9`）。

## 数字格式与单元格排版

- **丰富的数字显示格式**：在不改变单元格底层真实数值的前提下，支持将数字设置为常规、保留指定位数的小数、带货币符号的金额、会计专用对齐、百分比、长短日期与时间、分数、科学记数法，或是直接按纯文本存储（非常适合防止长身份证号或前面带零的工号被自动抹零）。
- **对齐、换行与外观**：支持设置文字水平与垂直对齐方向、开启「自动换行」让长句子在单元格内折行显示、将多个相邻单元格合并为一个大标题格，以及自由搭配内外边框线型与背景底纹颜色。
- **拖拽与自适应行高列宽**：用鼠标按住行号或列标之间的分隔线拖动即可手动调节行高与列宽；如果某个单元格里的文字或数字太长显示不下，直接**双击该列标右侧的分隔线**，列宽就会自动伸缩到刚好完整容纳整列最长内容的宽度。

## 日常数据整理技巧

**如何按某一列快速排序或筛选**（以按「销售额」列从高到低降序排列为例）：

1. 用鼠标单击表格里**该数据列中的任意一个单元格**即可（完全不需要费力去框选整列或整张表，系统会自动识别周围相连的数据区域）。
2. 在顶部「开始」页签（或「数据」页签）点击 **排序和筛选 ▸ 降序**，整张数据表的所有行就会按照这一列的大小从高到低重新排列，而且每一行左右相邻列的数据都会严丝合缝地跟着一起移动，绝不会发生张冠李戴的错行现象。
3. 如果你想按多个字段先后排序（比如先按「地区」排，同一地区内再按「日期」排）或者按单元格颜色排序，可以在同一个菜单下点击**自定义排序**，在弹窗里逐层添加排序规则。
4. 如果想只筛选出某几类数据查看：选中表头所在行后点击 **排序和筛选 ▸ 筛选**，每个表头单元格右侧都会出现一个 `▼` 小箭头，点开后只勾选你想保留的类别即可将其余行暂时隐藏；看完后点击**清除筛选**，所有隐藏行就会原封不动地恢复显示。

除了排序与筛选之外，日常看大表还有两项高频能力：

- **高级筛选与分列整理**：上方「数据」页签介绍过的文本分列、删除重复值、快速填充与高级筛选，都可以与常规筛选配合使用。
- **冻结首行或冻结窗格**：浏览几百行、几十列的大表时，切到「视图」页签，先用鼠标点一下**你想要固定不动区域右下方紧挨着的那个单元格**，再点击**冻结窗格**（或者直接选「冻结首行」「冻结首列」），之后无论你怎么向下或向右滚动表格，上方的表头和左侧的名称列都会稳稳停在屏幕边缘供你对照。
- **原生读写 `.csv` 与 `.tsv` 文件**：双击或从「文件 ▸ 打开」选择 `.csv`（逗号分隔）或 `.tsv`（制表符分隔）文件时，Sheets 会直接将它们解析成整齐的网格表格供你用公式和排序工具加工，按下保存时则会原样写回原本的纯文本分隔格式，不会强行把你的脚本数据文件改写成二进制格式。

## 四处各司其职的右键菜单

- **在表格单元格网格上右键**：弹出表格编辑器（Univer 引擎）的完整单元格上下文菜单，包含剪切、复制、粘贴（含仅粘贴数值/格式）、在上方或下方插入与删除整行整列、隐藏与取消隐藏行列、合并与拆分单元格、设置冻结窗格等全部日常制表命令。
- **在窗口最底部的状态栏上右键**：当你框选了一片包含数字的单元格时，底部状态栏会实时汇总显示这片选区的统计值；在状态栏上点击右键，你可以自由勾选要在底部常驻显示哪些指标（如**平均值、计数、数值计数、最大值、最小值、求和**等），勾选结果会立即生效并跨会话永久记住。
- **在底部的工作表（Sheet）标签上右键**：弹出针对单张工作表的管理菜单，支持新建工作表、重命名当前表、删除、复制工作表、给工作表标签涂上醒目的分类标记颜色，以及隐藏或取消隐藏工作表。
- 至于窗口最顶部文档标签条上的右键菜单（重命名磁盘文件、在新窗口打开、在旁边分屏等），请参阅[标签页与窗口管理](help://tabs-and-windows)一章。

## AI 制表与数据分析助手

- **框选区域直接用自然语言下指令**：打开右侧的 AI 助手面板后，你可以先在表格里框选一片数据区域，然后直接用大白话交代任务（例如「把这一列乱七八糟的日期统一改写成 YYYY-MM-DD 格式」「在右边加一列计算同比增长率公式」「根据这三列数据生成一张汇总表并标出前五名」），AI 会直接调用表格操作工具替你完成填写和排版。
- **拖拽或点击附加参考文件**：你可以点击输入框旁边的 `📎` 附件按钮，或者直接把电脑上的其他表格、文档或截图文件拖进 AI 面板里；附件会随你的问题一起发给模型做跨文件比对或数据提取，如果返回结果里包含图片也会以清晰缩略图展示。
- **点击单元格坐标直接跳转定位**：当 AI 在回答中分析你的表格数据并引用到某个具体单元格或区域坐标（例如 `D14` 或 `Sheet2!B3:C10`）时，引用会渲染成可点击的高亮标签，用鼠标点一下就能让左侧表格画布直接滚动并定位到那个单元格上。
- **不满意随时一键回滚**：AI 对表格做出的每一轮批量修改都经过统一的编辑历史管线，如果觉得生成的公式或改写的格式不合意，随时可以通过 AI 面板回滚或按撤销键退回修改前的状态。

## 保存与导出

- **完整保留公式与样式的 `.xlsx` 保存**：按下 `⌘S` / `Ctrl+S` 保存时，工作簿中的所有公式、函数、数字格式、条件格式、图表、数据透视表与命名区域都会按标准 `.xlsx` 规范完整落盘；同时支持「另存为」新文件，以及按照当前页面布局设置的分页规则直接**导出为 PDF**。
- **全局一致的自动保存**：只要该表格文件已经手动保存过至少一次，后续编辑就会按照全局规则自动定时落盘，无需担心忘按保存键。

## 独立引擎带来的稳定性保障

- **Rust 计算边车进程隔离**：Sheets 把最吃内存与 CPU 的大规模公式重算、数据透视聚合与文件解析放在一个独立的 Rust 原生边车进程（Sidecar）里运行，与你的界面渲染进程彻底物理隔离；万一遇到损坏的外部文件或极端庞大的数组公式导致计算进程异常退出，主窗口绝不会跟着崩溃闪退，而是会在界面上给出明确提示并自动尝试拉起引擎恢复你刚才的编辑会话。
