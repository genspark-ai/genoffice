# 快捷键一览

每个编辑器都有自己的按键绑定，其中只有少数在任何地方都通用。本页是完整清单，按应用分组，macOS 与 Windows / Linux 的组合键并排列出。

## 先读这一节

**这里几乎没有什么是全局的。** 只有下面三个入口键是全局的；再往后的都属于当前摆在面前的那个应用，切换标签页就会随之改变。

| 操作                               | macOS | Windows / Linux |
| ---------------------------------- | ----- | --------------- |
| 打开用户手册——在应用任何位置都可用 | F1    | F1              |
| 收起／展开功能区——所有编辑器通用   | ⌥⌘R   | Ctrl+F1         |
| 打开「键盘快捷键」表——仅 Word      | ⌘/    | Ctrl+/          |

- **F1 打开的是本手册**，不是快捷键表。它属于应用程序菜单，所以在 Word、Sheets、Slides、PDF 或 Home 标签页中都能用。
- **切换功能区用 `Ctrl+F1`，macOS 上用 `⌥⌘R`。** 单按 `F1` 不会有任何反应——F1 是手册，功能区组合键刻意不与它共用。macOS 上也接受 `Ctrl+F1`，不过 Office for Mac 实际使用的是 `⌥⌘R`。
- **「键盘快捷键」表只有 Word 有**（`⌘/`）。它列出的正是下面那张 Word 表。其他编辑器都没有。

![Word 自带的「键盘快捷键」面板：左侧是操作，右侧是组合键，按文件、编辑、文本、段落、插入、审阅、视图分组](img/word-shortcuts.png)

- **`⌘O`、`⌘S` 和 `⌘P` 在每个编辑器背后都是各自单独实现的**，行为也不完全一致。Word 的 `⌘P` 会先排版打印预览，让一张打印纸正好对应一个屏幕页面；PDF 的 `⌘P` 打开 PDF 打印对话框；Sheets 和 Slides 又各有各的一套。
- **其余的按键都按应用区分。** Word 标签页处于激活状态时，`⌘B` 是 Word 的加粗；Slides 激活时，`⌘B` 是 Slides 的加粗，而它所属的菜单并不是你熟悉的那一个。只在有选中内容或某个特定窗格中才生效的绑定，「操作」列里会写明。

## 约定

- macOS 一列使用熟悉的符号：`⌘` Command、`⌥` Option、`⇧` Shift、`⌃` Control。
- Windows / Linux 一列则拼写出来：`Ctrl`、`Alt`、`Shift`。
- 在 GenOffice 确实需要两个平台使用不同按键的地方，表格会如实标出。常见的有：`⌃H` 对应「查找和替换」（macOS 把 `⌘H` 留给了「隐藏」）、`⌥⌘G` 对应「定位」，以及 Slides 的关闭键。
- 只在有选区时才生效的组合键，写在「操作」列里而不另开一列，这样每张表始终保持三列宽。

## Word

Word 有完整的菜单栏，因此下面的文件与格式组合键只要 Word 标签页获得焦点就可用，无论当前打开的是哪个文档。编辑类组合键需要文档已加载且可编辑，并且光标位于正文中；当你正在「查找」框、AI 提示框或任何其他输入框里打字时，它们不会触发。

| 操作           | macOS | Windows / Linux |
| -------------- | ----- | --------------- |
| 新建           | ⌘N    | Ctrl+N          |
| 新建窗口       | ⇧⌘N   | Ctrl+Shift+N    |

⌘P 不是浏览器的打印。Word 会先排版打印预览，让一张打印纸正好等于一个屏幕页面，然后才打开它自己的打印对话框。

## Sheets

GenOffice Sheets 是一个兼容 Excel 的表格。下面大多数快捷键就是你已经熟悉的 Excel 快捷键。

> **编辑优先。** 当你正在编辑单元格或在**公式栏**中输入时，Sheets 中几乎所有快捷键都不起作用，这样打字、移动光标和退格键才保留文本编辑的本来含义。如果某个按键看起来毫无反应，先看看是不是正处于编辑状态：按 Esc 或 Enter，再重试一次。对选区生效的命令在对话框打开时同样不起作用。组合键是这条规则的例外时，表格里会写明。

有两条约定是 Sheets 特有的。`⌘` 和 `⌃` 共用同一个修饰键位——两个在所有平台上都被接受，所以 `⌘1` 和 `Ctrl+1` 是同一个组合键。**Windows / Linux 一列留空，表示该组合键仅存在于 macOS。**

## Slides

GenOffice Slides 是一个 PowerPoint 风格的演示文稿编辑器。大多数按键无论你在哪里都做同样的事，但少数几个会随焦点改变含义——在文本框内部，或者**缩略图窗格**、**大纲窗格**或**幻灯片浏览窗格**获得键盘焦点时。这些情况在「操作」列里标出。

| 查找（在形状中编辑文字时不可用） | ⌘F     | Ctrl+F          |
| 用 AI 注释选区（需先选中形状）   | ⌘K     | Ctrl+K          |
| 放大                             | ⌘=     | Ctrl+=          |
| 缩小                             | ⌘-     | Ctrl+-          |
| 实际大小（100%）                 | ⌘0     | Ctrl+0          |
| 全选                             | ⌘A     | Ctrl+A          |
| 向前／向后切换形状选择           | ⇥ / ⇧⇥ | Tab / Shift+Tab |

新建幻灯片是另一处平台分法。每个平台都有自己的键，另一个什么都不做：macOS 上是 ⇧⌘N，Windows 和 Linux 上是 Ctrl+M。⌘M 在 macOS 上办不成这件事，因为那是系统的最小化键。

全选随焦点而定：焦点在缩略图窗格、大纲窗格或幻灯片浏览窗格时，它选中所有幻灯片；在别处则选中当前幻灯片上的所有元素。Tab 在幻灯片上的各个形状之间循环，而且只有幻灯片画布本身获得焦点时才如此。

## PDF
